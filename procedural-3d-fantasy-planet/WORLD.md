# Aetheris · 星球设定集 v2

> **已定（v2）**
> 1. 地表 **5 块大陆**（+1 块沉没陆）。
> 2. **穹顶执政团 = 冷漠的技术寡头，且正在滑向掠夺**（"二偏三"）。

## 0. 一句话

Aetheris 不是一颗自然形成的星球，而是一台**以地壳为共鸣腔、以星光为燃料的行星级引擎**。它的主人在天上，靠**开关太阳**统治下面的人；下面的人则用**走音**回敬他们。

## 1. 天体与尺度（为什么这里的物理是这样）

| 项目 | 数值 | 设定解释 |
| --- | --- | --- |
| 半径 | `4.2`（游戏单位，约 6,400 km） | 比地球略小、密度更高 |
| 一昼夜 | 200 s（约 12 分钟） | 自转极快，赤道被离心力拉出浅海盆；生物因此进化出**储光**本能 |
| 海平面 | `0.012` | 被引擎**刻意锁死**：潮汐钟靠这个常数，海水总量是人为设定过的 |
| 卫星 | 1 颗 | 表面是陨击坑与废金属——它是轨道"**冠**"的一块断片 |
| 光 | 单一恒星 | 恒星很稳定，不稳定的是行星用来**收集**它的设施 |

### 2.2 逐块展开

**Ⅰ Vaelmar 苍苔行省**
- **地形**：温带丘陵、河谷、苔原台地（`LUMINOUS GROVE` / `MEADOW TERRACE` / `HIGHLAND FOREST`），针叶、橡树与垂柳。
- **文明**：**苔庭联邦**（Tilin）——树居城邦联盟，不写字，把历史**编进菌丝**：发光脉络越密，记录越重大。
- **建筑**：活树塔、根系桥、树冠间的苔织回廊。
- **生物**：三眼鹿、苔背兽、萤蛾。
- **政治**：九圣所的**母圣所 VAEL** 在此，所有灵脉读数以它的钟为准。

**Ⅱ Sennar 森纳荒原**
- **地形**：琥珀沙丘（`AMBER DUNES`）、盐碱台地、玄武岩省（`BASALT PROVINCE`）、活火山与热泉。
- **文明**：**灰烬商团**（Ash Concord）——商队城邦同盟，垄断**镜子**：日镜坯料只有这里的玻璃窑烧得出来。
- **建筑**：风塔、镜井、玄武岩采石城。
- **生物**：甲壳沙蜥、玻璃蜂（蜂巢是天然棱镜）、熔脉蠕虫。
- **政治**：**SENNAR GATE** 是最大的陆路关隘；**THALOR SPIRE** 是灵脉最不稳定的节点，也是走私的起点。

**Ⅲ Caelth 凯尔高地**
- **地形**：雪线以上的山脊与冰原（`ALPINE RIDGE` / `FROST PLAIN`）、冰斗、蓝冰裂隙。
- **文明**：**守夜修会**（Vigil）——不是政权，是"值班的人"，观测天穹与灵脉，行动来临前敲钟。
- **建筑**：冰穹观星台、悬冰回廊、冰川下的**共鸣腔**。
- **生物**：白脊兽、极光鳐。
- **政治**：**CAEL HOLD** 是修会总部；**AUNE RELIQUARY** 是一座被封存的旧实验室——修会知道得比它承认的多。

**Ⅳ Mirella 米瑞拉环礁**
- **地形**：环礁、浅潟湖、红树林沼泽（`LUMINOUS JUNGLE` / `WILLOW MARSH`）、珊瑚脊。
- **文明**：**潮汐歌者**（Tide Chanters）——用低频咏唱引发驻波，养殖、航行、搬运重物都靠"唱"。
- **建筑**：环礁浮台、潮汐钟楼、珊瑚船坞。
- **生物**：蝠鲼群（唯一跨大陆迁徙物种）、珊瑚鲸、发光水母。
- **政治**：**MIRELLA ARCH** 是跨洋航路起点；**ORU WATCH** 只在水位低于某值时才露出。

**Ⅴ Vessper 维斯珀孤陆**
- **地形**：陨击盆地、晶化地、"晶柱回廊"（看似自然，其实是被冲击熔化后重新凝固的发射设施）。
- **文明**：**晶誓团**（Crystal Oath）——半石化的少数族群，靠水晶共振延命，记得"上一次能飞的时候"。
- **建筑**：晶柱回廊、已毁的地下发射井、冷却湖。
- **生物**：晶簇蛛、回声鸟。
- **政治**：**VESSPER RING** 是唯一的环形圣所，也是最古老的建筑。

### 2.4 植被（随大陆气候，已实现）

植被不是全星球一套，而是**按行省配的**。每块大陆有一张自己的物种清单与配额（`PROVINCE_FLORA`），清单里没有的物种不会长在那里；同一块大陆内部再由**海拔与湿度**分工（针叶占高坡、橡树占林窗、垂柳占低湿洼地），所以一个省能同时有几种植物，但不会出现「沙漠里冒出一片温带林」。

| 大陆 | 气候读法 | 植被 | 数量（低配 / 满配） |
| --- | --- | --- | --- |
| Vaelmar 苍苔行省 | 温带丘陵、河谷、台地 | 针叶林（高坡、干）、阔叶橡（林窗）、垂柳（低湿） | 430 / 195 / 95 |
| Sennar 森纳荒原 | 赤道西侧荒漠与玄武岩 | 仙人掌（低地）、**荆棘灌丛**（新模型） | 235 / 305 |
| Caelth 凯尔高地 | 南半球高纬冰原 | **霜垫**苔藓团（新模型）、少量风弯针叶 | 530 / 72 |
| Mirella 米瑞拉环礁 | 赤道东侧热带 | **巨蕨**（新模型）、棕榈、热带阔叶 | 220 / 240 / 92 |
| Vessper 维斯珀孤陆 | 极区晶化盆地 | **无植被**——只有晶体、玄武岩与地衣级碎屑 | 0 |

水晶同样按地质走，不是全星球的装饰：**Vessper 晶化盆地 `340` 根（低配 `150`）、Sennar 火山玻璃 `48` 根（低配 `22`）**，其余三块大陆一根也没有——那里只有岩石与岩壁（岩石 `540`、高山岩壁 `120`，全球分布）。

三个新模型（原先的气候空缺）：

- **霜垫 `cushionGeometry`**：苔丘簇（3–5 个压扁半球，灰绿/霜绿）+ 一圈苍白薹草，整株不到 `0.05` 单位高——冻原上没有能立起来的植物。
- **荆棘灌丛 `scrubGeometry`**：12 条细枝从同一点散开、末端再分叉，枝上挂着小型橄榄色叶簇与浅色尖刺，`0.15` 单位高——掠过脚踝的干灌木。
- **巨蕨 `fernTreeGeometry`**：短干顶起 9 条先扬后垂的羽轴，每条羽轴两侧各有 9 对叶片，`0.29` 单位高——雨林下的树蕨。

贴地一层也跟着行省走：`PROVINCE_GROUND` 给每个省配「草/蕨/花」的密度与色相偏移——Vessper 三样全为 0，Caelth 只剩一层灰绿绒毛，Sennar 是枯草与零星尘色小花，Mirella 是全套。

### 2.3 建筑与生物（已实现）

| 大陆 | 建筑语法 | 生物（氛围层） |
| --- | --- | --- |
| Vaelmar | 活树塔（苔光树冠）、角树桥、木构聚落 | 萤蛾：暖色、慢、沿苔面成片 |
| Sennar | 风塔、倾斜镜井、玄武岩矮墙 | 玻璃蜂：冷白、快、棱镜闪光 |
| Caelth | 天文台穹顶、观测尖塔 | 霜羽：苍白、近乎下落 |
| Mirella | 高脚屋、歌环、潮汐环 | 潮虫：青绿、上飘 |
| Vessper | 晶柱、环形发射基座、倒下的塔架 | 晶屑：淡紫、忽明忽暗 |

- 建筑是静态合批：56 个 `InstancedMesh`、约 5000 个实例、约 32 万三角形，取点规则为「省份 + 海拔 0.03–0.26 + 彼此间隔 ≥ 0.20」，每块大陆 15–22 处聚落（全星球 98 处）；九座圣所脚下各两处（`0.46–0.70` 单位，避开圣所自己的岛基），降落点旁固定一处。
- 房子是**构件拼的**：`wall`（勒脚 / 压顶 / 收分墙身 / 檐口 / 三窗带窗台窗楣 / 门洞）、`roof`（带出檐坡顶 + 檐口封板 + 正脊）、`hip`、`spire`（飞檐攒尖 + 宝顶）、`drum`、`dome`、`tower`（八面收分 + 束带 + 箭窗 + 塔顶压顶）、`platform`、`ledge`、`beam`、`mast`；明暗烘进顶点色（材质 `vertexColors: true`，颜色取中间调 `#9c8a6a / #8c8275 / #d2ccb8`），白天读得出体量转折，夜里只有窗火与水晶微光（自发光 `0.40 / 0.26`）。
- 布局语法：**地面 → 地标 → 住屋群 → 街道小件**。每处聚落现场抽平面（`lane` / `row` / `hollow` / `cross` / `shore`）、地标（各省三到四个）与房屋形制（`cottage` / `longhouse` / `tower` / `round` / `flat` / `barn` / `stilt` / `shed` / `treehouse` / `ruin`，按省给权重）；地面尺寸跟着平面走，围环用圆台、长排用方台。整个布局以「房屋单位」书写，最后乘 `TOWN_SCALE = 1.8`——眼高 `0.10` 时一栋民宅连屋顶 `0.13–0.17`，门是要走进去的。
- **地形与水岸真的会改变聚落的样子**（`town-traits-28`）：判「坡地」用的是**镇子尺度的坡度**（外推 `.48` 一拍量出来 `> .62`）：坡上 `row`（沿等高线的单排）权重乘 `2.4`、`cross` 乘 `1.3`、`hollow`（围环）降到 `0.25`；平地反过来给环屋和十字巷。**水边不决定形态，只加分**（`settlement-plans-39`）：这块地在水线附近是细密群岛，`60%` 的落点边上一伸手就是水，早先「哪边见水就算岸线镇」的判法把 `74%` 的聚落都压成了同一种面水单排（`shore 52/100`）。现在「最近见水距离」只决定 `shore` 抽签的份量（`.06` 内乘 `4`、`.13` 内乘 `2.4`），只有生成器特意留了海港的那批落点才强制成岸线镇——单排面水、伸一座码头台出去、两侧立柱、尽头一盏灯；其余水边聚落会照自己的地形长成巷子、环屋或十字巷。实测六张世界 `600` 处聚落：`shore 36%`、`row/lane/hollow` 各 `13%`、`cross 8%`、`basin 7%`、`fallen/colonnade/lattice` 各 `3–4%`。
- **坡地上的房子是落地的**（`town-terrain-30`）：每栋房在自己地块的中心和四个角各测一次地形，楼板放在最高的那个角上，石砌勒脚一路填到最低的角——所以你看到的是下坡侧的石头台基，不是悬空的门槛；`stilt` 和 `treehouse` 的腿、树干也一路伸到地面。城镇的基座在坡上是一道**挡土台**（顶面仍是城镇地坪，底面伸到脚下最低的地面），陡坡连地坪都不做了，只留半径 `0.108k` 的核心台给地标，民宅围着核心一级级踩下去。这里还藏着一个几何上的坑：城镇画在切平面上，离镇心 `t` 的任何部件即使地面全平也会比球面高出 `t²/2r`（`.25` 半径就是 `.03`，够塞进一只脚），这一项必须从地面读数里扣掉，否则整座镇子像浮在草皮上。
- **镇子和地表是有接触的**（`town-life-31`）：一条土路从镇心顺落坡方向走出去，石板块块压进坡面（用法线摆正，不是平摆在空中），路基上补挡土墙和台阶；路出镇的地方立一座门，各省一套做法；市镇路边堆着货箱。
- **镇子是活的**：63 只烟囱每只冒三团烟（189 个点，顶点着色器算完，1 个 draw call、零 CPU 开销），140 盏灯在入夜后往地面上打暖色光斑（合并成一个加法混合网格，`uNight` 随日光衰减）。
- **悬崖聚落**：地表找得到落差 > `.030` 的地方，每省挑最陡的一处，架三层出挑甲板——每层两根斜撑、一栋房，层间用台阶连着，顶层两根横梁锚进岩壁，最下层一根桅杆挂灯。全星球只有一到五处，属于奇观，不是常态。
- **祭坛脚下的神龛**（`shrine-weather-33`，`-34` 重做）：九座悬空祭坛脚下的地面各有一处**路标**——至少一根 `.34` 高的瘦石柱（深色玄武岩，和镇子浅色的墙分得很开），柱顶一盏灯（比民宅高出一倍，走过镇子也看得见）；空地够的地方立两根夹成一道门，门楣横在上头，门下铺一小块沉进地面的石围裙；两根柱子永远站在同一个高度上——坡地的落差由一块门槛石吃掉，柱脚落在石面上，围裙边压着三块祭品石。运气好的那几座会有真正的**院子**：铺石圆台、一圈缘石、两级台阶、一条石板道，以及一道爬向祭坛却断在半空的台阶——只剩一半的朝圣路。多数神龛没有院子，因为祭坛底下本来就是镇子：生成器在每座祭坛脚下放了两处聚落，周围的空地早就被房子占了，所以这里的神龛更像街角的一处**门**，而不是广场。
- **天气落在建成的世界上**（`shrine-weather-33`）：雨会按材质各自的吸水量把土路、石道、木构和石砌打暗、压粗造度（土路 `0.96 → 0.39`，木构次之，玻璃水晶几乎不动），雨停精确回干；湿地面上的灯光斑更亮；炊烟不再自己往上飘，而是被**风**按年龄的平方压向下风处，雨里更薄。
- **大镇与小镇**：到最近的圣所越近，聚落越大。`tier 2`（`sizeScore > .86`）的市镇住户多一到两栋，并且额外多一眼井或一座神龛；远离圣所的只剩三栋房和一个地标。坡地上的房子会在四角长出支柱，把地板顶到同一个高度，所以陡坡上的镇子读起来是"架"在那里的；瓦砾、柱础、桅杆这类直接落地的构件，按脚底下真实的地面摆，不按镇子那块水平基准（`-37`）；台基切进坡里的那一圈，坡落下去的一侧会砌上一条挡土缘墙（`-38`；全星球 `100` 处带台基的镇子有 `77` 处砌了出来，最深的一圈拦着 `0.61` 单位高的坡）。
- **每省一种只有它会建的边缘形制**——不是"多抽几次签"，而是各省语法里一条别的省没有的分支：
  - **Vaelmar `treehouse`**：树干 → 平台 → 小屋，长在潮地上，脚下不落地。
  - **Sennar `windcatcher`**：高竖井 + 顶端风斗，把沙漠风压进下面那间屋；一同带出的是一整条街的竖向剪影。
  - **Caelth `needle`**：矮圆室 + 屋顶长出的冰刃，雪的省里唯一"往上长"的东西。
  - **Mirella `chanter`**：六根柱子吊起一座圆鼓屋，顶上悬一圈玻璃鸣环——房子本身就是乐器。
  - **Vessper `fallen`**：塔基环 + 断柱 + 倒下的塔帽 + 瓦砾，底下仍有晶体在亮；它是地标而不是民宅。
  - 外加各省共享、低权重的 `ruin`（断墙 + 斜梁 + 瓦砾）：老了的那部分。测试断言这五种形制**互不外泄**，并且每个省至少真的建出来一处。
- 每处聚落有一根签名高构（树塔 / 风塔 / 观测尖塔 / 歌环塔 / 发射晶柱），连宝顶最高约 `0.54`——在海拔 0.10 的视点上，它们先于细节越过视野边缘。
- 虫群是一个 190 点（窄屏 110）的粒子场，**在世界空间中各自漂移**（`0.005–0.014`/秒），越出相机周围 `0.36` 单位或竖向 `+0.14/−0.10` 就从对面折回；按 `provinceAt()` 重设颜色、大小与漂移方向——它是"气氛里的活物"，不是可交互动物。
- 真正的大动物仍然只有蝠鲼；可交互动物、水下遗迹、巡管虫尚未做（见 [`worklog.md`](worklog.md)）。

## 3. 水域：三块，各有各的"物理"

| 水域 | 深度 | 特征 | 谁住在那 |
| --- | --- | --- | --- |
| **镜海 The Mirror Sea** | 浅（0–40 m） | 内海、无风、近镜面；珊瑚与海草床 | 歌者的养殖场、浅滩遗迹、发光浮游生物 |
| **环洋 The Circling Ocean** | 中深 | 环绕全球的风暴带，把五块大陆隔开；夜间有荧光藻爆发 | 蝠鲼迁徙走廊、远洋商船、浮岛 |
| **无光沟 The Vane Trench** | 极深 | 光照与灵脉都到不了，靠热液维持 | 沉默者、异形生物圈 |

- 镜海负责**美**，环洋负责**隔阂**（正因横渡成本极高，五块大陆才保有各自的文明形态），无光沟负责**深度**。
- **水是透的**：水面不再是一层涂色的壳，浅处能直接看见海床（镜海因此才是"镜"——你能看见底，才敢下去），越深越吞光：`5 m` 清、`20 m` 发青、`65 m` 之后只剩水色。同一片浅滩，站在岸上看比从正上方看更"稠"——因为视线是**斜着**穿过水体的，这就是折射在观感上唯一真正改变画面的那一项。
- **玩家可以真的潜下去**（`C` 下潜 / `Space` 上浮，浮力会把双手放开的人送回水面）。深度上限 `0.30` 半径 ≈ 读数条 230 m，且永远停在海床之上；水下雾、光衰减与低通滤波让深度读作"变暗"。三档水深与读数条一致：`< 50 m` 镜海、`50–170 m` 环洋、`> 170 m` 无光沟。

### 3.1 水底：沉默者（The Silent Architects）

- **是谁**：Aetheris 第一代建造者，涅里瓦沉陆的原住民。灵脉网、九圣所地基、天上的"冠"，都是他们造的。
- **为什么沉默**：他们主动把意识**下沉**进地壳共鸣网络，身体留在沟底，成为灰色、有纹路、像珊瑚又像碑的"柱群"。整条无光沟是一个**活的处理器**。
- **异形生物圈**（引擎的免疫系统）：**巡管虫**（节点清淤）、**回声群**（共振代替语言）、**织光水母**（把泄漏的灵脉光捕进体内再吐出）、**溺者之影**（只在穹顶关闭太阳时升起）。
- **关键**：水下文明**不是遗迹，是待机的系统**。地表的九圣所只是它伸出去的"手指"。

**三个真实杠杆**

1. **镜税**：阳光按配额发放。不服从的城市，那片天空会阴三天。
2. **灵脉配额**：光柱强度由穹顶分配，配额决定谁能点亮夜里的城市。
3. **解释权**：每次行动之后，由共鸣议会发布"这次是什么、为什么会这样"。**解释权就是合法性**——这也是为什么地表至今仍称之为"异象"。

**走音者（The Detuned）**

- 不是组织，是一种**习惯**：苔庭的记录者、歌者的低音部、从修会叛逃的观测员、晶誓团的旧工程师，各自行动，互不隶属。
- 武器不是刀，是**不协和**：在灵脉同步时插入一个错音，让整张网跑偏；伪造配额让某个城市多亮一夜；把日镜的一片换成不透光的赝品。
- 他们的签名是一声**很轻的跑调**——你在灵脉涌动时听到的那一下"不对"，就是他们留下的。
- 讽刺之处：他们以为自己在对抗穹顶，但他们的"错音"恰好是**沉默者**需要的唤醒信号。

## 6. 不存在"异象"：五个行动

地表的人管这些叫异象，因为**他们没有别的词**——天暗了、星落了、森林亮了，这些事不由他们决定，也不由他们解释。

实际上它们是穹顶执政团的五项常态作业。每一项都有官方口径、真实目的，以及走音者留下的破绽。

| 代号 | 官方口径（地表听到的） | 真实目的（穹顶在做的事） | 走音者留下的破绽 |
| --- | --- | --- | --- |
| **LEY SURGE** 灵脉涌动（16 s） | "众圣所在彼此应答" | **全网硬同步**：给浮晶格充电，同时读取每个节点的负载——谁在偷电、谁在囤光，一清二楚 | 同步期间插一个错音，读取就会算错；代价是某个街区的灯永远亮不回来 |
| **STARFALL** 星陨雨（14 s，仅夜间） | "天空在缓慢坠落" | **清轨作业**：把"冠"的碎片剪进大气，清出一条走廊，顺便把不申报的载荷丢下来 | 每一次流星雨里，都有一颗**不会烧完**的东西——他们会去捡 |
| **SOLAR VEIL** 暗日之蚀（24 s） | "一枚暗月遮住了太阳" | **遮光示威**：让整个半球同时抬头看天。24 秒足够让所有人记起，光是谁的 | 计时器。真正的日食不会正好 24 秒；走音者用它向下面喊话："他们数的和你一样" |
| **BLOOM TIDE** 荧光潮（18 s） | "每片叶子都记得光" | **强制生长期**：把生长频率灌进灵脉，逼生物圈超额产出（药材、纤维、孢子），溢出的光就是"荧光" | 这是唯一的窗口——到处都在发光时，人和货可以不被看见地移动 |
| **ZENITH MIGRATION** 天穹迁徙（16 s） | "兽群顺热气流上升" | **驱赶作业**：用浮晶格脉冲把蝠鲼赶出镜阵航线，同时取走它们体内的磁记忆 | 蝠鲼是唯一能飞越环洋的邮差；走音者会在它们身上绑东西 |

### 6.5 走音者的签名（已实现）

地表的人说"异象来了又走了"，走音者说"我们又塞了一个音进去"。

- 每一次作业进行到第 `2.2 s` 之后，灵脉里会不定期出现一次**错音**：间隔 `3.2–6.6 s`，一次作业里通常 3–7 下。
- 你能感知到两层：
  - **看**：九圣所的灯光、符文与灯笼会在那一瞬间**暗一下、抖一下**（约 0.85 s 内恢复），像电压不稳。
  - **听**：如果打开了声音（`M`），会听到一声很轻的**双音失谐**——两个正弦波差 8–20 音分，短促、带一点金属感。
- 声音只在作业进行时出现，**平时不会有**。所以老练的人只要听见那一声跑调，就知道有人在动灵脉。
- 控制台：`aetheris.detune()` 手动触发一次；`aetheris.diagnostics().detune` 是本次会话累计的次数。

> 设定上的残忍之处：这个"错音"确实在破坏穹顶的读数，但它同时是沉默者的唤醒信号。**走音者每成功一次，沟底就醒一点。**

### 6.6 代价：借来的都要还（已实现）

穹顶不是"从星球上取能"，而是**从五条循环里借**：地脉、空气、天光、生长、动物。借了要还，还的时候带利息——利息就是玩家看见的东西。

| 作业 | 借走什么 | 立刻可见的代价 | 恢复 |
| --- | --- | --- | --- |
| LEY SURGE | 地脉余量 | 夜里圣所与符文暗约 25%，光柱变细 | 3 分钟回到 100%，最后 30 s 略微过亮（回弹） |
| STARFALL | 大气清洁度 | 尘埃：雾密度 +8%、日落更橙、星星略暗 | 4 分钟自然沉降 |
| SOLAR VEIL | 天空的"温度" | 之后 2 分钟日光偏冷、影子更硬——**镜阵留下的痕迹** | 2 分钟 |
| BLOOM TIDE | 生物圈的储光 | 孢子 / 草地 / 树冠发光降到约 55%，林子"哑掉" | 2 分钟，然后反弹到 115% 一小段（应激） |
| MIGRATION | 蝠鲼的磁记忆 | 蝠鲼群数量 −40%、远离圣所，天空变安静 | 3 分钟，回来时反而多 20%（补偿性聚集） |

**累积项：透支值 Extraction**

- 每次作业 `+0.06`，每分钟 `−0.01`，取值 `0..1`。
- 影响：夜间荧光整体最多再暗 12%、雾更冷、星星更"干净"（暖色更少）。
- 不做 UI 数字（保持沉浸），但 `diagnostics().extraction` 可查；每次刷新重置，不写 `localStorage`。

**已定的四个选择（v3）**

1. **瞬时为主，累积只做氛围**：每次作业都能看见因果；Extraction 只让世界慢慢变冷，不影响玩法。
2. **不显示 HUD 数字**：只在天空、雾和荧光上体现，`diagnostics().extraction` 可查。
3. **不持久化**：刷新即重置。
4. **玩家可以修复**：作业期间每触发一次"错音"，这一轮的账单 **×0.5**（最低到 `1/8`）。走音者从氛围变成一种选择。

**实现参数（页面里的真值）**

| 项目 | 数值 |
| --- | --- |
| 账单 | 一次作业 `+1.0` 到对应领域；每次错音 `×0.5`；地板 `0.125` |
| 回复时间 | light `180 s`、air `240 s`、sky `120 s`、growth `120 s`、fauna `180 s` |
| 透支值 | 每次（折后）作业 `+0.06×账单`，`−1/6000` 每秒（约 1.7 小时清空）；雾向冷色 `(0.055,0.095,0.120)` 混 `10%`，星空 `×(1 − 0.10)`，荧光再 `−(≤12%)` |
| 光的代价 | 圣所/符文/灯笼 `×(1 − 0.28×debt + 回弹)`，回弹在最后 12% 内最多 `+10%` |
| 空气的代价 | 雾密度 `×(1 + 0.08×debt)`，雾色向暖尘 `(0.16,0.115,0.075)` 混合 `22%`，星空 `×(1 − 0.15×debt)` |
| 天空的代价 | 日光向冷 `(0.80,0.88,1.0)` 混合 `35%`，半球光 `×(1 − 0.20×debt)`，曝光 `×(1 − 0.04×debt)` |
| 生长的代价 | 全局荧光 `×(1 − 0.45×growth − 0.12×extraction + 回弹)`，钳在 `0.25–1.15` |
| 动物的代价 | 蝠鲼绘制数量 `× (1 − 0.40×fauna)`（下限 4 只） |

**为什么地表会误以为是天象**

1. 五项行动都**只改变光**（亮度、颜色、雾、曝光），不改变地形——看上去就像天气。
2. 每一项都在 `14–24 秒`内结束，且有过门（fade in / fade out），像自然现象。
3. **解释权在议会手里**，而议会在穹顶手里。

**这套设计带来的后果**

- 行动的**频率在上升**：`SOLAR VEIL` 从"每年一次"变成"每几个月一次"，官方说法是"潮汐异常"。
- 你（外来者）第一次看到它们时，会觉得这是魔法；看第三次就会开始计时——**24.0 秒**。
- 沉默者正在被这些"错音"唤醒。它们苏醒那天，地表会先以为是又一场异象。

### 7.3 现在：退化中的 I 型

| 指标 | 状态 |
| --- | --- |
| 卡尔达肖夫指数 | **K ≈ 0.72**（能支配行星能量，但利用率低、高度依赖旧设施） |

### 7.4 你，怎么来的

你是**迫降的外来者**。你的船在进入大气时被穹顶当成一枚碎片处理掉了——**它被算进了 `STARFALL` 的统计里**，所以没有人来找你，也没有人知道你在这里。这是整个故事的起点，也是 `STARFALL` 这个行动最好的用法：**它既是穹顶的作业，也是你的入场方式。**

> 主线后续再构造。可用的钩子：走音者会先找到你（他们监听着每一次"不该出现的坠落"）；穹顶会先否认你存在；修会会先给你一件旧仪器，然后什么都不说。
