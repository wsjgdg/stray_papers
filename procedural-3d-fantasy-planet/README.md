# Aetheris · 程序化奇幻星球

> 一颗可以「从轨道降落、再用双脚走进去」的实时程序化行星：地形、海洋、云、植被、遗迹、天气与声音全部在浏览器里当场生成，无美术资源、无构建步骤。

`index.html` 就是完整应用（约 4.3k 行，260 KB）：HTML/CSS 外壳 + 一个内联 ES module，运行时按需从 CDN 载入 three.js `r174`。全部几何与贴图都由固定随机种子 `819213` 推导，因此每次刷新看到的都是同一颗 Aetheris。

---

## 1. 快速开始

```bash
cd procedural-3d-fantasy-planet
python3 -m http.server 8080
# 打开 http://localhost:8080/
```

不需要 `npm install`、不需要打包。也可以直接双击 `index.html`（CDN 允许跨域），但用本地静态服务器更稳妥。

依赖（全部走 CDN，首次访问需要联网）：

| 资源 | 用途 |
| --- | --- |
| `three@0.174.0`（jsDelivr + importmap） | 渲染、后处理（`EffectComposer` / `UnrealBloomPass`） |
| Google Fonts（Cormorant Garamond / DM Sans） | 标题与 HUD 字体 |

浏览器要求 **WebGL2**。启动时会先做能力探测：若 WebGL2 不可用，页面会给出明确的失败提示（含 GPU 名称、构建号与失败阶段），而不是黑屏。

## 2. 操作

### 轨道模式（ORBIT / FLYING）

| 操作 | 作用 |
| --- | --- |
| 拖拽 / 方向键 / `WASD` | 环绕星球；`Shift` 加速 |
| 滚轮 / 双指捏合 / 右下 `+` `-` | 缩放（6.4 – 32 半径） |
| 点击「DESCEND TO THE SURFACE」或 `F` | 降落到最近的陆地上 |

### 地表模式（SURFACE / WALKING）

| 操作 | 作用 |
| --- | --- |
| `WASD` / 方向键 / 左下摇杆 | 行走；`Shift` 冲刺；摇杆推一半就是半速；涉水时自动改为游泳 |
| 点击画面（鼠标） | 进入指针锁定后自由视角；`Esc` 释放；触屏直接拖拽 |
| `I` `K` / `J` `L` | 抬头 / 低头、左转 / 右转（键盘看视角，速度 1.25 / 2.0 rad/s，与鼠标同轴） |
| `Space` / `JUMP` | 跳跃：按住跳满高度，轻点只有一个小跳；落地前 0.14 s 内按下会自动接上 |
| `C` 按住 | 陆地上**下蹲**、水里**下潜**（同一个键，看脚下是什么）；触屏按钮会跟着显示 `CROUCH` / `DIVE` |
| `Space` 按住（水里） | 上浮（触屏是 `RISE`）；松手会慢慢浮回水面 |
| `O` / 点右下 `ARCHIVE` | 打开「野档」侧栏（不暂停世界，`Esc` 或再按 `O` 关闭） |
| 点击三座圣所路标 | 视角自动转向该遗迹（带一段平滑转身；按任意视角键会打断） |
| `F` | 返回轨道，镜头沿地表弧线飞出 |

#### 地表读数：这是哪一块大陆

站在地表时，左下角（窄屏在左上角）那行小字现在是三段：**大陆 · 本地形态 · 坐标**。

- 十进制坐标是**真值**：`23.6°N 42.1°E` 就是玩家当前的方向向量换算出来的。
- 大陆名来自 `provinceAt()`，只用两样已有的东西推断：**纬度**与**气候模型给出的 biome**。因此它永远和旁边的形态标签自洽——
  - 沙漠、玄武岩 → **SENNAR** 森纳荒原
  - 热带 → **MIRELLA** 米瑞拉环礁
  - 苔原、南半球高山 → **CAELTH** 凯尔高地
  - |纬度| ≥ 62° → **VESSPER** 维斯珀孤陆
  - 其余温带（含北半球高地） → **VAELMAR** 苍苔行省
- 下水后名字换成水域，第二段变成**水深**：`MIRROR SEA`（< 50 m，浅、无风）、`CIRCLING OCEAN`（50–170 m，风暴带）、`VANE TRENCH`（> 170 m，光照与灵脉都到不了的深沟）。
- 读数一旦跨区，会有一瞬间的**字距展开**动画（1.6 s），像盖了一次章；只是 HUD，不打扰视角。
- 控制台：`aetheris.where()` → `{ province, water, depth, lat, lon }`。

左下角的圆形方向盘与 `JUMP` 按钮**只在触屏设备上出现**（`(pointer: coarse)` 或无悬停的触摸屏），桌面端一律隐藏——电脑用 `WASD` + `Space` + 鼠标，窄窗口也不会再冒出手机控件。

#### 水里：可以真的潜下去（v3 新增）

以前的水只是一层贴图——脚底被钉在海平面上，所以你只能"滑"过去。现在整条水柱都可以下潜：

| 项目 | 数值 / 行为 |
| --- | --- |
| 下潜 / 上浮 | `C` 下潜 `0.055`、`Space` 上浮 `0.085`（半径/秒）；放手靠浮力 `0.016` 慢慢浮回水面 |
| 深度上限 | `0.30` 半径（读数条约 230 m），另外永远停在海床之上 8 mm |
| 何时算"在水下" | 眼睛低于水面 `0.038` 以上时，模式标签变成 `SURFACE / DIVING`，整屏开始变蓝 |
| 视觉 | 雾会迅速收拢到 `0.92` 密度并转成深青 `(0.016, 0.082, 0.098)`；日光衰减 78%、半球光 55%、曝光 20%——深度读起来是"变暗"，不是"变远" |
| 声音 | 总输出的低通滤波器从 18 kHz 压到约 1.4 kHz，风声降 40%，像耳朵里灌了水 |
| 水下生物 | 水母（`0.012–0.26` 深）与海雪（`0.006–0.30` 深），只在相机真正没入水面后才出现，出水即隐藏 |
| 水面 | 泳姿速度 `0.20`，涉水会自动切换；`Space` 在水里**不会**跳，所以不会误触 |
| 出入水 | **连续过渡**：脚踩海床时眼高 = 海床 + 站高，漂浮时 = 水面 + `0.033`，两条曲线在"水深 = 站高 − 0.033"处刚好相交。岸线来回走不会跳视角（实测最大单步 `2 mm`）；从高处跳进海里是**真的下落**，触水一次后就稳定在水面 |

三个水域都能到：镜海（`< 50 m`）浅得能看见珊瑚，环洋（`50–170 m`）往下就开始失去颜色，无光沟（`> 170 m`）里只剩水母和你自己。控制台：`aetheris.diagnostics()` 里有 `depth` 与 `submerged`。

#### 水面：现在是一块玻璃，不是一层盖子（v4 新增）

之前的水面是**不透明**的：`gl_FragColor` 的 alpha 恒为 `1.0`，海床从来就没被画出来过；所谓"折射"只是在噪声空间里挪了个采样点去取焦散（`refractPos = vWorld + (n − radial) * (.045 + depth * .22)`），属于**假的**——下面没有任何东西真的透上来。所以看上去永远是一层涂了色的壳。

现在水面改成**透射面**，三层叠起来才成立：

| 层 | 做法 |
| --- | --- |
| 透射 | 水面 `transparent: true` + `depthWrite: false`，`renderOrder = 8`（排在所有半透明植被/光点之后），于是**真实海床几何**直接透上来看得见，而不是被水色重画一遍 |
| 吸收 | 不是按垂直深度，而是按**折射后的光程**：`cosI = dot(view, n)` → Snell `cosT = sqrt(1 − .5625 (1 − cosI²))`（`.5625 = 1/1.333²`，水相对空气）、`pathLength = depth / cosT`，再 `alpha = 1 − e^(−46 · pathLength)`。所以同一片浅滩，站在岸边看比从正上方看更"稠"——这才是折射会改变画面的那一项 |
| 反射 | Schlick 菲涅尔继续接管掠射角（`alpha ≥ fresnel × .94`），远处海面照旧是天空的镜子；泡沫、焦散、雾各自有下限/上限把 alpha 夹住 |

实测 alpha 曲线（正上方看）：5 m `0.05` → 8 m `0.21` → 12 m `0.37` → 19 m `0.60` → 34 m `0.84` → 65 m `0.98` → 156 m 以上 `1.0`。也就是说：**齐膝的水是透明的窗口，齐腰开始变青，20 m 之后基本只剩水色**，掠射角再额外压向镜面。

为什么没做屏幕空间折射（采样上一帧/另一个 RT 做像素位移）：那需要每帧**再渲一遍场景**（或额外的深度 RT + 手写深度测试），在这颗星球上等于 GPU 成本翻倍，而视觉上只是浅水海床位移几个像素。现在这套"透射 + 光程吸收 + 折射焦散"在观感上已经给出同一件事，代价是零额外 draw call。

#### 视点高度与下蹲（v3 新增）

原来眼高 `0.055`，比草叶（`0.035`）高不了多少，蕨类与花卡片会直接糊在脸上。现在：

| 项目 | 数值 |
| --- | --- |
| 站立眼高 | `0.10`（约 2.9 倍草叶高度，能越过大多数蕨类与灌木） |
| 下蹲眼高 | `0.05`，按住 `C` 平滑过渡（`16 /s` 指数趋近，约 0.15 s 到位） |
| 下蹲代价 | 移动速度 `×0.5`，跳跃初速 `×0.6`，冲刺失效；水里按 `C` 仍然是下潜，不会蹲 |
| 触屏 | 右侧第二个按钮：陆地 `CROUCH`、水里 `DIVE`，按住生效 |
| 贴身植物 | 相机周围有一圈**压缩气泡**（`0.06–0.20` 单位，GPU 端把实例缩到 `6%`），蕨类与花在你走到跟前时会自己让开；另外整体叶片尺寸下调约 20% |

决定方式：**先压缩植物，再微调视点**。单纯抬高视角会让人变成"漂浮的巨人"，把世界比例搞坏；气泡只影响你脚下那一小圈，远处景色不变。

顺带说明：把视点抬高后，**圣所与省域建筑的比例才看得对**——之前它们在你的视线以下，所以"看不见"。

#### 省域建筑与生物（v3 新增）

每块大陆原来只有一句设定，现在有可见的东西：

| 大陆 | 你会在天边看见 | 你会撞见的活物 |
| --- | --- | --- |
| VAELMAR | 活树塔（苔光树冠）+ 角树桥；圣所脚下有木构聚落 | 萤蛾：暖色、缓慢、成片浮在苔面上 |
| SENNAR | 风塔、倾斜的镜井、玄武岩矮墙 | 玻璃蜂：冷白、快、带一点棱镜的闪 |
| CAELTH | 天文台穹顶 + 观测尖塔 | 霜羽：苍白、几乎是往下掉的 |
| MIRELLA | 高脚屋、歌环、潮汐环 | 潮虫：青绿、往上飘，像倒着下的雨 |
| VESSPER | 晶柱与环形发射基座，一半是歪的 | 晶屑：淡紫、会闪 |

- 建筑是**静态合批**的（52 个 `InstancedMesh`、约 `3,450` 个实例、约 `27 万` 三角形）：每块大陆 15–22 处聚落（全星球 98 处），外加**九座圣所脚下各两处**（`0.46–0.70` 世界单位，刚好在岛基之外），以及**你降落点旁边一处**——下地第一眼就能看到房子。聚落之间至少隔 `0.20` 单位，两块平台不会叠在一起。
- **同一块大陆的聚落不长一个样**：每处聚落按**自己脚下那块地**决定平面布局（`lane` 一条巷子两侧交替 / `row` 沿等高线的单排 / `hollow` 围成环 / `cross` 两条短巷成十字 / `shore` 面水单排 + 码头）、一个**地标**（各省三到四个）和每栋房子自己的**形制**。陡坡上 `row` 的权重 ×`2.4`、`hollow` ×`0.25`，平地上反过来；**只要有水就是岸线镇**（`14/14` 处水边聚落都朝水排屋、伸出码头），不是抽签抽到的。四省各有一套形制权重池（`HOUSES`）：木构的 `cottage / longhouse / tower / barn / shed`、森纳的 `flat / cottage / tower / shed / round`、凯尔的 `round / cottage / tower / longhouse / shed`、米瑞拉的 `stilt / round / cottage / shed`——所以 Vaelmar 的一处可能是「门楼 + 单排长屋」，下一处是「会堂 + 围环农舍」。实测每省 4–5 种平面 × 3–4 种地标，组合数 9–12 种，没有两处聚落按同一张图施工。另外还有三种**边缘形制**：Vaelmar 的 `treehouse`（树干 + 平台 + 小屋）、各省低权重的 `ruin`（断墙 + 斜梁 + 瓦砾）、Vessper 的 `fallen`（断塔基 + 倒下的塔帽）。离家最近的圣所越近，聚落越大：`tier 2` 的市镇会多一眼井或一座神龛。
- 房子不是「几根棍子」，而是**由构件拼出来的体量**：每个构件（`wall` / `roof` / `hip` / `spire` / `drum` / `dome` / `tower` / `platform` / `ledge` / `beam` / `mast`）都是 1×1×1、底面在原点的单位件，实例就是「多宽、多高、多深」。`wall` 一件里就有**勒脚 + 勒脚压顶 + 收分墙身 + 檐口 + 三个窗洞（带窗台与窗楣）+ 门洞**；屋顶是**带出檐的坡顶**（檐口封板 + 正脊）或攒尖、穹顶、带束带与门洞的鼓座；门窗前再点**暖色窗火**。
- 明暗不是靠调材质，而是**烘进顶点色**：每个构件的勒脚、墙身、檐口、窗洞各有自己的色调（`bakeColor` + 噪声微扰），材质一律 `vertexColors: true`、颜色取中间调（木构 `#9c8a6a`、玄武岩 `#8c8275`、白石 `#d2ccb8`），所以白天能读出体量的转折，夜里有灯但不高荧光（玻璃/水晶自发光 `0.40 / 0.26`）。
- 聚落按「**地面 → 地标 → 住屋群 → 街道小件**」的语法生成：地面有三种（带缘石的圆台 / 方台 / 铺石圆盘）；地标是各省的三选一——Vaelmar `archive`（档塔 + 攒尖）/ `hall`（大会堂 + 陡坡顶 + 两盏门灯）/ `gate`（双塔 + 门桥）；Sennar `wind`（风塔 + 塔帽 + 倾斜镜盘）/ `well`（井圈 + 镜面 + 桅杆）/ `caravan`（院落矮墙 + 布篷）；Caelth `observatory`（鼓座 + 穹顶 + 观测尖塔）/ `bell`（钟塔 + 攒尖 + 门前石柱）/ `vault`（环形地宫 + 低穹顶）；Mirella `song`（歌环塔）/ `dock`（吊脚船坞 + 滑道）/ `bell`（吊脚钟楼 + 双环）；Vessper `basin`（环形基座 + 晶柱）/ `lattice`（歪斜桅杆阵）/ `colonnade`（晶石柱廊）/ `fallen`（塌下来的塔基）。
- 房子的形制不是一个盒子换屋顶：`cottage` 一坡顶 + 窗 + 踏步；`longhouse` 长脊沿巷、三窗、常带烟囱；`tower` 两层收进（楼层腰线 + 小一号的上层 + 各自的窗）；`round` 鼓座 + 穹顶/攒尖；`flat` 平顶 + 女儿墙；`barn` 高坡大谷仓；`stilt` 四柱吊脚 + 平台板 + 檐廊；`shed` 低矮披屋。
- **尺度对人**：布局用「房屋单位」写，最后一乘 `TOWN_SCALE = 1.8`。眼高 `0.10`，一栋民宅连屋顶约 `0.13–0.17`——门是要走进去的，不是摆件。视野半径约 `0.92` 单位，签名构先于细节越过视野边缘。
- 虫群是**氛围层**：190 个发光点（窄屏 110），**在世界空间里各自漂移**（速度 `0.005–0.014`/秒 + 正弦扑动），离开相机 `0.36` 单位或上下超出 `+0.14 / −0.10` 就从对面折回——所以走动时它们有真实视差，而不是黏在镜头上抖。按省重设颜色/大小/漂移方向。真正的大动物仍然只有蝠鲼。
- 还没有做的：可交互动物（三眼鹿、珊瑚鲸这类）、水下遗迹、巡管虫——见 [`worklog.md`](worklog.md)。

#### 巡检图：左上角的圆盘（v4 新增）

第一人称下，左上角会出现一张**随朝向旋转**的圆形小图（`146 px`，手机 `104 px`；轨道视角与降落过场里自动隐藏）。它是**脚下这一圈**——半径 `0.72` 单位（约 3 公里，直径 6 公里），只画你真的走得到的地方：

| 图层 | 表现 |
| --- | --- |
| 水陆分界 | 深青是水，海岸线用亮青实线描出来（`1.6 px`），浅滩与潟湖一眼分得清 |
| 大陆分界 | 五个行省各自的底色（苔绿 / 沙黄 / 冰蓝 / 环礁青 / 晶紫），省界用**虚线**（`3-3`）标出 |
| 特殊建筑 | 聚落是 `2.2 px` 的浅色点，圣所是琥珀色菱形 |
| 特殊地脉 | 圣所之间会拉出淡青的**灵脉连线**（只在两者同时入图时出现） |
| 动物群落 | 蝠鲼群的每只个体各打一个 `1.8 px` 的冷白点，成群时自然连成一片 |

实现上只有一个关键词：**开局把整颗星球画完**。加载期间烘一张 `2048 × 1024` 的等距圆柱图（窄屏 `1024 × 512`）：陆地/海洋直接取**地形网格顶点**的半径（网格本身就是等距圆柱排布，不用 `heightAt`），省界按 `provinceAt` 逐像素上色，海岸线与省界一起画进位图。之后运行时**一个采样都不做**。

| 情况 | 行为 |
| --- | --- |
| 站着不动 | 画面**逐像素一致**（实测 120 次重绘 0 差异） |
| 转头 | 只是把同一张图转一下，没有任何采样 |
| 走路 | 同上——图不动，是你在图上移动 |
| 每帧开销 | 一次带旋转 + 纬度拉伸的 `drawImage`，`0.04 ms`；**间隔采样**：每 3 帧（20 Hz）重绘一次，`0.013 ms/帧` |
| 加载 | 一次性 `~250 ms`（Node 实测，浏览器同量级），藏在加载画面后面；烘完才会亮出第一帧地图 |
| 精度 | 海岸线形状由地形网格决定（约 `0.05` 单位 = 圆盘上 `16 px`），岸边做了 `±0.004` 的软过渡，放大 3 倍也不出锯齿台阶 |

等距圆柱图到脚下切平面的换算是**仿射**的：`ctx.rotate` 跟着朝向转，`ctx.scale` 里的 `1/cos(lat)` 负责高纬度的经度拉伸（极点附近夹在 `×5`），所以整张图只需要一次 `drawImage`。省界用 `(x+y)%5` 打出虚线，海岸线是 1 px 亮青色。

圆盘本身不再挂 `backdrop-filter: blur()`——那会让浏览器每一帧都把背后的 3D 画面重新模糊一遍。

#### 全球测绘图：按 `G` 打开（v4 新增）

左上圆盘（或顶栏的 `G` 图标）点一下，或者直接按 `G`，整块屏幕铺开的就是**整颗星球**：加载期烘好的那张 `2048×1024` 等距圆柱图原样铺满，北朝上，经纬网、五块行省的名称、聚落、祭坛与灵脉、兽群、以及「你现在在哪、朝哪、脚下圆盘管多大」全在上面。

它和圆盘是**同一张位图**，所以打开只是**一次 `drawImage`**（`2048×1024` 软件画布 `6 ms`，浏览器更快），不会重新投影、不会重新采样、更不会重新烘。打开方式：

| 入口 | 说明 |
| --- | --- |
| 左上圆盘 | 悬停会亮起，点一下展开（右下角有个 `G` 角标） |
| 顶栏地图图标 | 和野档图标并排 |
| 键盘 `G` | 任意视角都能开，`G` / `ESC` / 点空白处关 |

**五个行省现在是真正的板块，不是同一块地上的调色盘。** 以前 `provinceAt` 按地貌就地判定（沙漠归 SENNAR、苔原归 CAELTH……），于是同一块大陆被切成芝麻粒大小的色块；现在改成球面上的**加权最近种子划分**（power diagram）：五个种子固定，每个省是一整块连着的大区，省界是一条从海岸走到海岸的长曲线，再用两层噪声把这条线揉弯。五个权重按陆地面积配平——实测每省占陆地 `17.6% / 21.6% / 18.4% / 19.2% / 23.2%`，相邻陆地点 `99.7%` 同省（只在地理边界上不同）。

**锚点与传送。** 图上那些「圆圈 + 十字」是**传送锚点**，一共 18 个，全部取自岛上已有的聚落（`heightAt` 在 `0.03–0.26`，绝不在水里），彼此至少相隔 `1.25` 单位（约 2.6 公里）——不密到看着像点阵，也不疏到走不到。悬停会亮起并显示编号（如 `VAELMAR · 03`），点一下就飞过去：走的是轨道→地面同一段镜头弧线，配一记淡青闪白。左上圆盘上它们是淡青小空心环，走路时也能认路；你自己的出生点永远是 `01` 号锚点。

底部的图例说明了三种标记：**浅白方块 = 聚落**，**琥珀菱形 = 祭坛（灵脉节点）**，**淡青细线 = 灵脉**。地图上那些琥珀菱形全部都落在祭坛的石头基座上——如果你在世界上只看到一块石头，那是祭坛的底座（其中两座是悬空的），不是没有意义的岩石。

#### 地表移动手感

走路不是「按下即满速」，而是一套带惯性的地面控制器：

| 机制 | 具体数值 / 行为 |
| --- | --- |
| 加速度 | 起步 `7.5`、刹车 `11`（‑1/s 指数趋近），走到常速约 0.3 s，松开摇杆几乎立即停住 |
| 速度 | 行走 `0.34`、冲刺 `0.66`、游泳 `0.20`（半径/秒）；摇杆按位移比例给速度 |
| 坡度 | 采样前方 0.06 单位处的真实地形，换算成 rise/run 坡度：22° 的缓坡只慢 7%，58° 陡坡慢 29%，陡壁最多降到 55%；同坡度下坡最多 +18% |
| 空中 | 起跳保留水平动量，空中只做 2.6 倍率的缓转向，不会在半空自动刹车 |
| 跳跃 | 起跳速度 `0.78`、重力 `3.15`：满跳约 0.093 世界单位高（≈ 1.7 个眼高）、滞空 0.48 s；轻点收力只有 0.058；离地 0.1 s 内仍可跳（coyote time），落地前 0.14 s 按下会被缓存 |
| 视角 | 鼠标 / `IJKL`（`J` `L` 转头 2.0 rad/s、`I` `K` 俯仰 1.25 rad/s，按帧速无关的 dt 积分）；俯仰夹在 ±1.48 rad；冲刺时 FOV 70° → 73.2°，晃动幅度随速度增长；落地有轻微下沉，涉水有缓慢起伏 |
| 转向 | 只改朝向时不会掉速（用向量长度补偿），转身不会像刹车 |

所有反馈都是叠加在相机上的：碰撞半径、贴地高度、地面补丁的刷新位置仍按纯几何计算，所以晃动不会穿地或抬高视点。

## 3. 世界是怎么生成的

| 系统 | 做法 |
| --- | --- |
| **地形** | 双层域扭曲 + 大陆/群岛/山脊噪声；叠加 ridged multifractal 山脉、冰斗、河谷、台地、峡谷、沉积台阶与微观起伏。同一个 `heightAt()` 同时驱动可见网格、植被落点与行走碰撞，因此看不到「贴图山」与「碰撞山」不一致 |
| **配色** | 由纬度温度、湿度噪声与海拔决定 biome（temperate / tropical / desert / tundra / alpine / volcanic），再逐顶点混色，雪线随 biome 变化 |
| **海洋** | Gerstner 涌浪顶点位移 + 深度图、泡沫图、可平铺水法线/焦散图全部程序生成；含云影、月光高光与风暴浑浊度；水面为**透射面**——Snell 光程 Beer–Lambert 吸收、浅处透出真实海床、掠射角转镜面 |
| **云** | 两层程序云贴图（低层浓云 + 高层薄云），随昼夜与天气改变透明度/色温 |
| **植被（11 类，按大陆分配）** | 针叶/阔叶/垂柳/棕榈/仙人掌 + 新增**霜垫苔藓/荆棘灌丛/巨蕨**；每块大陆只有自己的物种清单（Vessper 一种也没有），省内再按海拔与湿度分工；分块实例化 + 距离 LOD（高模 / 低模 / 叶卡），近地表另有草、蕨、花、碎石一次成型 |
| **地质（岩石 / 岩壁 / 水晶）** | 岩石与高山岩壁全球分布（`540 + 120` 块），沿山脊与崖肩加密；**水晶只长在两块说得通的大陆**——Vessper 的晶化盆地 `340` 根、Sennar 的火山玻璃 `48` 根（低配 `150 / 22`），Vaelmar / Caelth / Mirella 一根不落 |
| **圣所遗迹** | 9 座（移动端 6 座）程序遗迹，符文环、光柱、漂浮碎片与悬浮岛，夜间自发光提升 |
| **生物与天象** | 蝠鲼群环绕遗迹飞行、流星、星空、太阳光晕、月亮 |
| **天气** | 雾密度/色、云量、风力、降雨粒子、闪电与屏幕闪光联动；天气会按当前 biome 自动切换 |
| **声音** | 运行时用 `AudioContext` 合成，随昼夜、天气与所处环境（轨道/地表）混音 |

### 光照与色调（写实取向）

整体美术按「自然光 + 物理材质」而不是「荧光奇幻」来校准：

| 项目 | 做法 |
| --- | --- |
| 光比 | 主光更强更硬（`2.62 → 2.96`），半球光 `0.56 → 0.40`、夜面补光 `0.52 → 0.34`；阴影更深，但地表仍留有月光与反照，不会看不见路 |
| 曝光 | 正午略收（`1.18 / 1.16 → 1.11 / 1.10`），把高光留给天空而不是糊在雪和浪花上 |
| 空气透视 | 雾色改为中性蓝灰（夜间 `0.024/0.038/0.054`，白天 `0.118/0.158/0.176`），密度略降：远处山脊靠色温后退，而不是被青色糊住 |
| 自发光 | 树冠经络、菌丝、水晶、孢子、珊瑚荧光藻、符文与灯笼的夜间强度整体下调约一半；夜林只剩微弱脉络与非连续的光点，昼夜都靠材质与明暗读形 |
| 泛光 | `UnrealBloom` 强度 `0.34 → 0.22`、阈值 `0.96 → 1.02`：只有太阳高光、符文与浪尖会溢出 |
| 调色 | 色调映射之后加一道很轻的 S 曲线 + 冷暗部 / 暖高光分离 + 极轻饱和度提升；暗角用 CSS 径向渐变实现，移动端（无 composer）同样生效 |

## 4. 特殊事件（穹顶作业）

天气是"常态"，这些事件是"例外"：每隔 1–2 分钟，世界会自行触发一次持续 14–24 秒的事件，顶部会出现一条专属横幅（`CONCORDAT OPERATION` + 代号 + 官方口径 + 真相 + 进度条）。所有效果都通过统一的 `eventFx` 权重（0→1→0）淡入淡出，不会硬切。

> **世界观提醒**：按 [`WORLD.md`](WORLD.md) §6，地表口中的"异象"其实是穹顶执政团的五项常态作业。所以横幅是**双层读法**——大标题下那行是地表相信的说法（"众圣所在彼此应答"），再小一号的那行才是真相（"灵脉网正在被读取"）。机制与数值未变，改的只是它被怎么解释。

| 事件 | 时长 | 世界会发生什么 |
| --- | --- | --- |
| **LEY SURGE** · 灵脉涌动 | 16 s | 符文 / 灯笼自发光暴涨，圣所光环变亮，一道加性光环从最近的圣所向外扩散，孢子与草地发光增强，雾色转向青绿。*官方口径：众圣所在应答；真相：全网硬同步，顺带读取每个节点的负载* |
| **STARFALL** · 星陨雨 | 14 s | 原本偶发的流星变成连续流星雨（更短、更快、间隔 0.1–0.4 s）。*官方口径：天空在缓慢坠落；真相：清轨作业，每次都会有一颗不烧完的东西* |
| **SOLAR VEIL** · 暗日之蚀 | 24 s | 一枚暗盘在太阳前成形、日光骤降到 7%、曝光与雾密度变化、星空浮现，天穹里的太阳高光同步熄灭。*官方口径：暗月遮日；真相：遮光示威，计时器正好 24 秒* |
| **BLOOM TIDE** · 荧光潮 | 18 s | 草叶、蕨类、花与森林光点的夜间自发光拉到 3 倍以上，整片林地"呼吸"。*官方口径：叶子记得光；真相：强制生长期，也是唯一能不被看见地移动的窗口* |
| **ZENITH MIGRATION** · 天穹迁徙 | 16 s | 蝠鲼群提速近 3 倍、收窄盘旋半径并抬高，绕着圣所尖塔成群爬升。*官方口径：兽群顺热气流上升；真相：用浮晶格脉冲把蝠鲼赶出镜阵航线* |

规则与实现细节：

- **调度**：40–72 秒后第一次触发，之后每次结束再等 58–112 秒；同一事件不会连续出现两次。
- **夜间专属**：`STARFALL` 只在天空足够暗（`daylight ≤ 0.12`）时进入候选池，其余事件昼夜都可能发生。
- 事件权重不同（`BLOOM TIDE` 与 `LEY SURGE` 更常见，`SOLAR VEIL` 最稀有）。
- 手动触发：按 `E`，或控制台 `aetheris.triggerEvent()`（随机、自动避开上一次）/ `aetheris.triggerEvent('veil')`（指定）。
- 尊重 `prefers-reduced-motion`：时长缩短为 70%，仍然有淡入淡出。
- 事件使用独立的 PRNG（`seeded(20260214)`），不会扰动地形、植被、圣所的既有随机序列——同一颗星球的世界布局与之前完全一致。

#### 走音者的错音（v3 新增）

每一次作业进行到 `2.2 s` 之后，灵脉会不定期"走音"一次（间隔 `3.2–6.6 s`，单次作业通常 3–7 下）：

- **看**：九圣所的灯光、符文、灯笼与祭坛光环会在那一瞬**暗下去并轻微抖动**，约 0.85 s 内恢复；
- **听**：打开声音（`M`）时，会听到一声很轻的**双音失谐**——两个正弦波相差 8–20 音分，经带通后短促收尾；
- **只在作业期间出现**，平时灵脉是干净的。控制台可用 `aetheris.detune()` 手动来一下，`diagnostics().detune` 是本次会话的次数。

设定上这是走音者在往穹顶的读数里塞假数据；副作用是它同时也在唤醒沟底的沉默者（见 [`WORLD.md`](WORLD.md) §6.5、[`worklog.md`](worklog.md) §三）。

#### 作业的代价（v3 新增）

穹顶不是"取能"，是**从五条循环里借**：地脉、空气、天光、生长、动物。作业结束后，账单以天气和光的形式出现，几分钟后自愈：

| 作业 | 借走 | 你看到什么 | 恢复 |
| --- | --- | --- | --- |
| LEY SURGE | 地脉余量 | 夜里圣所、符文、灯笼、祭坛光环暗约 28%，之后末尾轻微过亮 | 180 s |
| STARFALL | 大气清洁度 | 雾密度 +8%、雾色偏暖尘、星星略暗 | 240 s |
| SOLAR VEIL | 天空的"温度" | 日光偏冷、半球光与曝光略降（镜阵留下的痕迹） | 120 s |
| BLOOM TIDE | 生物圈储光 | 孢子/草/树冠/卡片荧光整体降到约 55%，之后回弹到最多 +15% | 120 s |
| ZENITH MIGRATION | 蝠鲼磁记忆 | 天空里蝠鲼减少约 40%，然后恢复 | 180 s |

- **错音是解药**：作业期间每触发一次走音，这一轮的账单 `×0.5`（最低 `1/8`）——反抗因此是一个**可操作的选择**，不是一个氛围词。
- **透支值 Extraction**：每次（折后）作业 `+0.06`、每秒 `−1/6000`（约 1.7 小时清空），只把夜里的荧光再压最多 12%、雾色像结霜一样发冷、星星略少；**没有 HUD 数字**，刷新即重置。
- 控制台：`aetheris.costs()` 查看 `extraction / 各项 debt / bio 倍率 / 剩余蝠鲼数`。

## 5. 性能设计

目标是在「轻薄本 / 中端手机」上也能 60 fps 巡航。核心手段：

- **像素预算**：`pixelRatio = min(devicePixelRatio, 上限, sqrt(预算 / 视口面积))`，桌面 3.5–4.2 MP、移动 1.9 MP，避免高分屏直接渲 4K。
- **三档自适应画质**（`AUTO` 时按帧时间自动切换）：像素比、云层、叶卡、天气粒子数量、阴影刷新频率一起降级；降级使用 `InstancedMesh.count` / `setDrawRange`，不重传缓冲。
- **阴影**按帧节流（`shadowMap.autoUpdate = false`）：地表模式每 3 / 5 / 8 帧刷新，轨道模式降到每 10 / 14 / 20 帧（太阳几乎不动、玩家不在阴影体积里移动）；光源包围盒在地表模式收缩到 1.4 单位。
- **分段生成 + 让出主线程**：地形（~9 万顶点）、4 套 PBR 贴图、海面/云贴图、植被散布都在循环里 `await requestAnimationFrame()`，加载标签因此能持续更新而不会「假死」。
- **地表细节补丁双缓冲 + 分帧重建**：脚下那块高密度地形补丁不再在一帧内重算 9400 个顶点，而是逐帧填充备用缓冲（默认每帧 ~2–3 ms 预算），填充完成后一次交换几何体，再分 4 帧补齐草/蕨/花/石头。走路时不会再每隔一秒卡一下。
- **单批次渲染**：同类植被靠顶点色 + 实例色合并成一次 draw call；森林光点、孢子、瀑布、天气粒子各是一个 `Points` 着色器。

```js
window.aetheris.setWeather('storm') // 'clear' | 'mist' | 'rain' | 'storm' | 'snow' | 'ash'

window.aetheris.triggerEvent('veil')// 'ley' | 'starfall' | 'veil' | 'bloom' | 'migration'
window.aetheris.events              // 全部事件 id
window.aetheris.jump()              // 等同按 Space（仅地表模式生效）
window.aetheris.detune()            // 手动触发一次"走音"（灯光抖动 + 双音失谐）
window.aetheris.costs()             // { extraction, paid, debt:{light,air,sky,growth,fauna}, bio, mantas }
window.aetheris.where()             // { province, water, depth, lat, lon }
window.aetherisStartup              // 启动阶段、自检结果、错误详情
```

启动序列会执行一组断言（贴图预设、纹理可平铺、材质 shader 注入位置、shader chunk 是否存在等），失败会直接显示带堆栈的错误面板，方便定位是哪一步挂掉。

## 8. 已知取舍

- 星球半径 4.2 单位，属于「可玩的小行星尺度」：为了让走路手感成立，地表细节用局部高密度补丁 + 远处基础网格混合（0.145–0.19 rad 过渡带）实现，而不是全局位移贴图。
- 行星尺度的陆地植被是**预生成 + 分块 LOD**，不会随昼夜或天气重新生长；贴地草花会随玩家在局部重新散布。
- 音效是合成声景，非采样素材；移动端默认不自动播放（需用户手势，符合浏览器策略）。
- 还没做但已经想清楚的事（追捕、沉默者苏醒、作业代价）记在 [`worklog.md`](worklog.md)。
- 世界观的正式描述在 [`WORLD.md`](WORLD.md)：页面里的 7 个 biome、9 座圣所、5 项穹顶作业都是那份设定的「正史」部分；「异象」只是地表人的误称，真相见 WORLD.md §6。其余（大陆命名、水下遗迹、浮空城、走音者）仍是草案。
