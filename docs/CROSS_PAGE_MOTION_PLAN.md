## 各页共同门槛

1. 操作必须改变文本/结果，材质与关键文字动效只表现这个变化；不用无意义的悬停、滚动、条形进度控制台或持续全屏震动来冒充互动。
2. 重要文本始终可读、可复制；无 JS/弱 GPU/减少动效时直接显示结论或保留可读后备。触屏与键盘有替代输入。
3. 先在 375px 和 1280px 看 **初始、操作中、结果** 三态，再测 320–1440px、输入/回弹/分支、无溢出；跑 `scripts/smoke.js` 与 `scripts/test.js`，验证完整站打卡/离线行为。
4. 不改变正式站既有事实来源、六关顺序、进度 ID、证书条件和原型的“不调用 AI”说明。任何新增规则应可读、可重试。
