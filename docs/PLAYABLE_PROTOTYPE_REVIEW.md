# 可玩交互原型 · 本轮评审说明

> 2026-11-05 · 用户说“先试试吧”后制作。**这是独立试验，不是正式站点改版/最终离线交付包。**

## 打开方法

- 预览服务：Arena 的 **Interactive prototype** 预览（端口 8001，访问根路径自动进入原型）。
- 本地：浏览器直接打开 `ai-exploration-base/prototype/index.html`；三页均支持 `file://`，无联网字体、API、框架或 CDN。
- 从首页可选①与⑤两个可玩关；②③④⑥仍链接到**当前正式版**，没有假装完成交互改版。所有原型页面均有“完整关卡”入口。

## 可以实际试什么

1. **入口拨盘**：拖动环到不同方位，或聚焦环按左右键；任务名称、预览语、按钮目的地随之更换。手机可直接点下面六个关卡名，不需操作拨盘。
2. **①提示词铸造台**：在五种任务中切换，修改“做什么/给谁/具体限制”；右侧形态、完整度和可复制提示词即时更新。点“试试只说一句话”比较前后；复制后可去真实 AI 工具使用。预置示意与用户输入不会被冒充为离线 AI 生成的作品。
3. **⑤七幕反诈决策室**：复用正式版 `SCAM_SCRIPT` 七幕数据。第 2 幕圈话术、看解析；第 4 幕停下或继续；若继续第 6 幕还有一次核验机会；第 7 幕按实际选择生成复盘。可回到已看过的幕、改选、重试。所有涉及汇款的动作仅为情景文字，不涉及真钱或隐私。

## 保留边界 / 等用户评审

- 原型**不调用 `AIProgress.mark`、不修改六关打卡或证书**，也不改变正式站点页面。它专门用于判断新视觉和新交互方向是否值得推广。
- 首页其余四关是正式站点链接而非原型玩法；②预测、③挑战、④路线、⑥练习及《探索记录》仍只是下一阶段方案，**尚未实现**。
- 当前 `ai-exploration-base-v1.zip` 是前一轮正式网站包，未重打为这个试验原型。需要正式交付时再决策如何集成/打包。
- 两处简化：①实时拼接的是**提示词文本模板**，不能本地生成图文；⑤依照既有教学剧本提供有限的分支，而非真实案件或 AI 聊天。两页无 JS 时提供静态关键内容和正式版链接；动效关闭时互动结果仍可读。

## 本轮验证

- `file://` Chromium：原型首页、①、⑤在 320/375/768/1280/1440px 均无页面横向溢出；检查过桌面及手机截图。沙箱截图额外注入临时中文字体，目标设备字体仍需用户确认。
- 实测：首页拨盘键盘与指针选择改变任务；①两组输入输出确实不同、切换任务和复制可用；⑤找线索、停止分支、继续并选择危险结果两条路径均到达不同复盘；重新开始有效。
- HTTP：端口 8001 根路径重定向进入原型，手机宽度下进入①与⑤，资源无 4xx、页面无 JS 异常。
- `file://` 无脚本：①有静态提示词示例；⑤有七幕静态提要和来源关卡链接。`prefers-reduced-motion: reduce` 下均可操作。
- `scripts/smoke.js` 包括原型 HTML 本地引用及 JS 语法检查；旧站 `scripts/test.js` 回归通过；`git diff --check` 通过。
