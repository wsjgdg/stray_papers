# 第二版单幕试验：账面之下

> 2026-11-05｜入口：`ai-exploration-base/prototype/material-study.html`。这是第 4→5 幕的**独立材质试验**，并未替换正式六关、七幕决策原型或旧版离线 ZIP。对照第一版见 `docs/MOTION_LAB_REVIEW.md`。

## 为什么重做

第一版 `motion-lab` 虽有 WebGL 和弹簧，实质还是二维分屏遮罩：没有被操作的实体，也没有随手势变化的表面法线、背面和空间位置。用户指出它不符合“具体质感的视觉主体、手势持续改变材质/空间/运动状态”，此判断正确。这一版弃用原裂口架构，改为一张模拟账面纸张。

## 现在实际做了什么

- **纸张是细分的几何网格，不是 CSS 遮罩**。WebGL 1 中生成 80×48 网格，顶点按揭开程度、抓取高度、手速变化的折线卷曲；顶点着色器计算纸面位移和近似法线，片元着色器按正反面、折角和照明给出不同颜色。文书图案是离线 Canvas 2D 绘制的纸纤维、复线边框、防伪曲线、模拟账面与数字，再贴在可变形网格上。纸张下方是独立的“提现先交 20% 保证金”警示层。
- **同一次手势同时改变形体与结果**。在右侧抓手按住、向左拉，纸的折线进入画面；抓取高度改变整张纸的斜卷走势，速度影响卷曲半径、局部颤动与松手初速度。松手后物理阻尼承接拖动，未到阈值合回，越过阈值完成揭示。同一进度同步抓手位置、下层警示可见度、滑杆与复盘文字。近似透视与 3D 法线让背面可见，纸后投影跟随移动。
- **先读故事，再看代码**。+6,000 和 20% 是第五关第 4→5 幕教学模拟数字；显示盈利不等于真实入账，先交钱才能提现是诈骗信号。无需输入账户、不请求联网、不记录学习进度；下方链接回正式第五关来源与核验工具。
- **退化仍可读**。原生范围滑杆支持键盘；单击抓手、揭示和复位按钮可替代拖动；`prefers-reduced-motion` 直接跳到可读状态；WebGL 不可用或上下文丢失时改用可平移的 HTML 纸张；关闭 JS 时直接写出 20% 保证金的风险结论。中文画布字形使用本地精简 Noto Sans SC（45 KB，SIL OFL，许可证在原型目录）。仅场景可见/运动中运行绘制，移动端 DPR 最高 1.15、桌面 1.5。

## 2026-11-05：页面编排再设计

用户认可动效方向，但指出“页面布局太像教条、没有欣赏性和高级感”。原版确实是独立标题区 → 浅色演示框 → 结论区的教案模板。本轮**没有改成另一套方卡片**，而是把纸张放进全幅暗色档案桌面：标题与文书左右错位共同构成首屏，抓手/滑杆/按钮成为画面底部的低干扰仪表；后半段用留白、错列编号和一条大的判断语句做编辑式收束。警示仍由实际揭开纸张触发，而非滚动淡入。WebGL 网格原点随桌面/手机构图变化，底层警示、HTML 后备与抓手对齐；手机用纵向镜头保留可抓区域和阅读空间。新版没有引入远程资源或改正式站点。

## 失败的中间尝试与本轮回撤

用户反复指出下方排版失控，且整页除揭纸外没有可信的第二幕。我先后尝试了巨型引语、三条话术印章列表及纵向扫描轨道。虽然它们在功能测试中可用，但**越叠越像教学控制台，视觉确实比早期纸张场景退步**；这不是浏览器“代码回退”，是我的设计判断失误。现已从页面与脚本中撤掉扫描器、印章和进度计数，不再把它们说成当前成品。

当前下半段收束为一件连续操作的视觉主体：三面模拟客服话术滚筒。“保证金／解冻费／最后一笔”的印刷字面随上下拖动连续翻转、松手承接速度并吸附到对应面；下方“先转账”保持不变，所选话术的风险解释随选择改变。按钮、方向键、Home/End 与减少动效提供等价路径。没有 JS 时保留静态风险结论。中文子集字体、CSS 和 JS 带版本参数，页面只保留一个新的单幕预览入口；正式六关未替换。

## 已做的检查

- 沙箱 Chromium 在 `file://` 与本地 HTTP 下检查 280、320、375、430、768、900、1024、1280、1440px：WebGL 编译成功且无横向溢出；再次目视检查全页排版，删除了下半段巨型引语导致的生硬断行。截取 0%、55%、100% 场景；中文画布字形和底部文案重叠已修正。
- 桌面指针抓取、拖放完成揭示与复位；Chrome 移动触摸事件从抓手向左拖动后抵达 100%；减少动效下抓手回车、滑杆方向键、按钮立即可达；话术滚筒在 320/375/768/1280px 通过按钮/键盘切换，在 375px 桌面与触屏向上拖动切换到“最后一笔”；减少动效即时吸附，禁用 JS 时静态结论可见；模拟 WebGL 失效及 context lost 后仍能用滑杆/按钮揭示。
- `node scripts/smoke.js` 与 `node scripts/test.js` 均通过。尚未在真实 iOS/安卓设备测 GPU 帧时间、温升、手势延迟和不同浏览器色彩表现。

## 诚实的距离

这一版**比上一版更符合**“具体物体、持续手势、空间卷曲”标准，但它仍是轻量原生 WebGL 材质习作，而非与 Lando Norris、Why Zero 或 Noho 同等的完整制作：网格仅是薄纸片，背面和影子采用程序近似，非实际厚度、碰撞、自遮挡及预制高精资产；舞台也只有一个镜头、一种场景，缺少完整叙事系统和真机品质调优。视觉是否已经达到用户期待，需要用户亲自试玩与目标设备检验，不能用功能测试代替美术验收。

## 试玩观察点

1. 抓住右侧铜色纸边，先从上部慢拉到一半，放开；然后从下部快拉，观察两次卷曲与松手余势差异。
2. 用滑杆停在 55%，检查**纸张背面是否可辨、下层条件是否被几何露出**，而非仅有淡入。
3. 比较手机与桌面，按“看清提现条件”跳到完整结论；不喜欢动画时开启系统减少动效。

如仍嫌质感不足，下一步应首先对这张纸的折痕、边缘厚度、背面印刷和动态阴影做专业美术与真机调校，不要直接把试验铺到其他五关。
