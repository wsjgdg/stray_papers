# AI 探索基地 · 第三轮「信号觉醒」视觉与动效提案

> 2026-11-05 · **视觉与动效方向草案，交互部分已由 [《可玩交互提案 v2》](PLAYABLE_INTERACTION_PROPOSAL.md) 补强并取代。** 其中首页入口、①与⑤现有[独立可玩原型](../ai-exploration-base/prototype/index.html)供评审；正式站点与离线包仍保持原样，尚未铺开。

## 0. 为什么重来

第二轮虽然有六张概念图，但首屏仍是「大矩形图 + 文案 + 按钮」，六关使用相近的构图；页面间只是换图和换色。它是更整齐的页面，不是可探索的空间。下一轮不再靠增加图片、圆角或循环粒子来解释“高级”，而以**一个可被用户推动、会因操作改变形态的视觉母题**组织全站；读内容时再主动收敛，避免全程嘈杂。

### 一句话概念

**「信号觉醒 / SIGNAL FIELD」：每关是一次把混沌信号变成可理解能力的变形。** 贯穿全站的是一条有厚度的“信号带”：在首页是可进入的六个波域，进入关卡后分别成为成果剖面、时间刻度、实验轨道、路线岔流、警戒裂缝、提示词回路。它不是悬浮的装饰——**滚动、指向、聚焦、选择或拖动会使它重新组织内容**。六关共享一套动作语法，画面和交互不共享同一张 hero 模板。

## 2. 视觉定稿方向（供确认）

- **形态：**不用六个长方形大卡做主视觉。首页有偏心椭圆波域、开口曲线与伸出屏幕的轨道；章节首屏由大型不规则 SVG 蒙版与斜切字体构成。正文区只在事实、来源、表单需要稳定容器时用规整排版。圆形/曲线是通往内容的入口，不把每段字硬塞进不规则区域。
- **画面：**近黑蓝底 `#080A14`、冷白 `#F3F5F7`；主信号用电光蓝 `#6978FF` 与荧光青 `#A9F8E5`，⑤的风险转为朱红 `#FF644F`，⑥完成回路转为暖黄 `#FFE17A`。颜色遵从语义而不是每关随意换一套。大面积深色只在开场/舞台，长文转为暖浅色阅读层。
- **排版：**中文大标题占据画面、允许跨越图层但**不遮重要信息**；不靠幼稚的科技字体，使用本机可用的中文无衬线做主字体，等宽数字和小号章节标注形成对比。真实 UI 文本永远由 HTML 排出，不烘焙进生成图片。
- **素材：**第二轮图片可拆为局部纹理/景深底，不再直接作为一张矩形 hero；优先重绘轻量 SVG 的轨迹、剪影、刻度与局部遮罩。若新图不匹配母题，宁可不用；不把参考站图片搬进离线包。
- **镜头感：**近层文字、中层实体、远层光晕的不同速度营造深度；只有入口、章节切换和一个关卡关键操作是“重拍”，论据与来源段安静呈现。按钮与进度仍清楚，不做全站自定义光标或藏导航。

## 3. 首页：一条可玩的连续开场

**0 秒**：屏幕中央是一道细小的不稳定信号，超大标题“从好奇，到会用 AI”在其后；“开始探索”按钮、直接跳转六关的文字导航在首帧就可见，绝不等动画播完。

**0.2–1.2 秒（仅首次且用户未请求减少动效）**：信号带从一笔弧线展开成六个不等大的波域，文字从曲线空隙中显露。右下角「跳过开场」立刻结束时间线；重访不重播。没有启动遮罩/进度百分比伪加载。

**滚动 0–70%**：波域分散并沿一条连续弧线占据页面，进度细线在轨道上移动；用户的指针/键盘焦点进入某一波域时，其他域轻微后退，当前域显出“①认识 AI 能做什么 / 即刻体验”的标题与一帧真实玩法预览。点击/回车沿形态收束进入该关。触屏直接点域（**第一击即进入**，不要求先 hover）；每个域都是有明确名称的真实 `<a>`。

**滚动 70–100%**：六域收束为现有的 0/6～6/6 学习进度；已打卡点亮，未打卡仍可访问，末端可达结业页。返回首页保留进度，且可随时从普通导航直达任一关。关卡之间不采用横向强制滚动或滚轮劫持。

| 关卡 | 首屏场景（不是图片卡） | 用户的动作 → 可见的结果 | 必须保留的内容和退化形式 |
|---|---|---|---|
| ① AI 能做什么 | 五块不规则“成果切片”悬在一条展开的光带周围；中心是可读的实际示例，不是生成图里的假文字。 | 拖动/滑动分隔线或操作原生范围控件：切片从“需求”合并成“成果”，背面露出对应提示词；点某块则滚到它的完整示例。 | 五类成果与提示词完整保留；键盘方向键可控制对比；静态版直接上下展示需求、成果与提示词。 |
| ② 趋势 | 时间刻度由地平线弧形升起，数字在真实时间节点旁，而不是浮在装饰背景上。 | 滚动跨过节点时轨迹显露、图表高亮相应区间；点击年份/键盘聚焦也能读相同数值与来源。 | 时间线、数据、行业和来源都用 HTML/表格可读；不虚构增长动画的中间数值，不因动效改图表口径。 |
| ③ 实验室 | 一条轨道把碎片引向页面中央**已有的可操作本地实验**；工具上方有「打开实验」明确入口。 | 轨道随滚动汇合，进入实验区后运动**停止并交出控制权**；用户实际操作实验，三项目由不同轨道分支展开。 | 本地实验和三个项目链接照旧工作；任何装饰图层不得盖住控件、iframe 或键盘焦点。 |
| ④ 副业 | 三条流体路径从同一问题分岔，各自标有投入、交付与风险；不是三张并排卡。 | 点/聚焦一路，路径沿真实内容段落亮起，并定位到对应方案；切换路径时旧路线退场、新路线接续。 | 三层路线及风险提示完整；收益不做保底/上涨的视觉暗示；移动端为三条可点击纵向路线。 |
| ⑤ 反诈 | 一条看似诱人的亮线逐幕变得不稳定，七幕对话散布在其两侧；“核验出口”始终可见。 | 用户按既有双分支作选择：继续路径裂为红色警戒线、停下路径汇入核验工具；选项可返回重选；话术词典点按高亮对应危险句。 | 七幕、双分支、心理机制、话术词典与核实工具保留；**不把“继续受骗”做成奖励演出**；减少动效时分支以文本结果与标签呈现。 |
| ⑥ 学院 | 角色/背景/要求是三段未闭合的发光环；完整答案区在环外清晰可见。 | 点选或键盘操作三段提示词，环闭合后出现三个现有预置回答的对比，用户可立即切换档位；不是假装调用在线 AI。 | 提示词三要素、三档预置回答、Agent 流程、L1–L5 均保留；无需拖拽也能完成；练习与打卡可单独访问。 |

**结业：**六段波域在已完成进度上合成一个稳定的环，证书和原有文字功能保持清晰，可打印/保存；没有 6/6 时不显示虚假完成态。六关均保留章节编号、上/下一关、来源、打卡入口。

## 5. 动效分层与技术边界

1. **基础层，无 JS 也完整：**所有标题、说明、数值、来源、对话、按钮与导航是语义 HTML；SVG/图片只承载装饰和可替代的舞台视觉。链接使用真正的 `href`，外部资源不是运行前提。原有打卡、毕业逻辑不因动效改变。
2. **交互层：**本地已有 GSAP + ScrollTrigger 管理少量可逆时间线；CSS `clip-path` 和 SVG mask 做不规则揭幕，`transform/opacity` 做大部分运动；只有活跃场景被驱动。现有图片分层须使用单独的轻量素材，避免大图六张同时解码。
3. **高级层：**先用 DOM/SVG 在真实设备上验证“震撼度”。只有确实增加表达、且离线性能可接受时才考虑首页一个可关闭的 Canvas 光场；**不以 WebGL 或新框架作为前提**。不引入 CDN、在线字体、在线生成 API；任何可选特效失败都不影响阅读和进度。
4. **多页转场：**保持现有静态页面结构。点击内部链接最多用约 300ms 的局部收束后导航，目标页从对应形态入场；`file://`、新标签打开、JS 失效或减少动效时直接正常跳转。不依赖同源 View Transitions API、sessionStorage 来保证核心导航。
5. **避免常见假高级：**不做背景无尽粒子、所有元素统一 `fade-up`、鼠标磁吸影响点击、无法跳过的 loading、滚轮劫持或每滚一屏都全屏闪白。动态模糊、噪点和光晕不覆盖文字。

### 响应式/无障碍

- **桌面 ≥ 900px：**允许首页一段连续滚动时间线与章节少量局部固定镜头；焦点进入和点击能触发与 hover 同等的信息状态。
- **平板/手机 < 900px：**改成纵向可触控场景，不做大面积 pointer tracking、长时间 pin 或横向拖动导航；省掉同时绘制的远景层。320–430px 不横向溢出，44×44px 点击区。
- **`prefers-reduced-motion: reduce`：**不自动播放开场、不做缩放/视差/钉屏/拖尾；保留静态切片、清晰分支和即时状态变化。JS 关闭时也不能有因初始 `opacity:0` 而失踪的内容。
- 键盘可完成所有选择与打卡，焦点可见；一切资料链接可达。对比度、移动端 200% 文字缩放与中文实际字体在目标设备上复核；不把颜色作为骗局路径或关卡状态唯一信号。

## 6. 先试验，后铺开：确认点与验收

**审批点 A（本文件）：**确认“信号觉醒”的母题、深色沉浸舞台与浅色阅读层、六关动作分镜。此时**不改网站**。

**审批点 B（如获准实施）：**先制作首页入口 + ⑤反诈两个小范围**可操作原型**：一个验证形态与导航，一个验证长内容、分支、警示语气。提供桌面/手机动态录屏或可点预览；先评审“是否真的不方正、是否有参与感、是否愿意继续读”，不通过就调整，不盲铺六关。

**审批点 C：**原型通过后才扩展至其余五关与结业；逐关跑 320/375/768/1280/1440px、键盘、减少动效、无 JS 阅读、`file://` 断网、0/6→6/6→证书、刷新后进度、来源链接与 ZIP 完整性。性能目标是原型阶段在中端手机上无持续卡顿，实际以浏览器录制的滚动帧时间/内存峰值/资源体积为准，再定最终预算；不先许诺未经实测的 FPS。

**预期结果：**用户一眼看到六关是同一个世界，却通过六种不同的“动手改变信息”的方式记住它们。若不操作，知识和来源仍然完整。此提案需要用户确认后才能进入实施。
