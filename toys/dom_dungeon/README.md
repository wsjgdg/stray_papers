# 标签地牢（Tag Dungeon）

> 浏览器标签就是地牢层——一款发生在浏览器「里世界」里的轻量 Roguelike 网页小游戏。

一局 8 层，每层一屏、一个决策；攻击全自动，玩家只做少数关键操作。
一局 1~3 分钟、点开就玩、死了重开，移动端竖屏单手优先。

## 核心循环

1. 进层先看**准备卡片**（敌人构成一览），点「开始战斗」才计时——所有计时从这一刻起算
2. 台前自动攻击 + 手动主动技 / 闪避 / 切目标，清完本层
3. 三选一挑**词条**（四系：脚本 / 样式 / 网络 / 缓存，同系叠加触发羁绊）
4. 三选一挑**路线**（高风险高回报），进入下一层
5. 第 4 层小 Boss（全屏广告）、第 8 层大 Boss（崩溃页面）；通关结算评级

## 「UI 即玩法」机制族

这个游戏的主题是：界面不是展示层，是武器，也是敌人。

- **糊屏弹窗**：弹窗真的糊住技能按钮——甩出屏幕换碎片、砸向敌人造成重击、或点 × 三下关掉；
  约四成是「恶意弹窗」：× 会瞬移，假「立即领取」按钮会骗走你的倒计时
- **拟物化 Boss**：广告 Boss 的四个假关闭钮都要点破；本体暴露后瞄右上角小「×」弱点
  （每点中换位置）；它还会在分身标签窗里读条放大招，切过去连点打断
- **HUD 构筑**：战斗中可拖拽主动技钮 / 闪避钮 / 词条栏浮卡到屏幕六锚点，
  相邻关系实时换收益（供电短路 / 缓存复用 / 隐蔽 / 镜像联动 / 有线驱动）
- **内核多标签页**：花内存开后台战场、切换、冻结、关闭（半额结算）；
  弹窗敌人会自己跳进后台页，双面回廊路线的背面 Boss 跨页读条
- **真实存储彩蛋**：每局结束浏览器本地会真的落「垃圾文件」，
  首页「磁盘 · 垃圾文件」面板真的清理它们，前两次各换 +1 永久内存上限

## 敌人图鉴（节选）

弹窗（糊屏 + 跳转）、带盾广告、404、验证码（图案题）、内存泄漏（偷内存变强、击杀吐回）、
加载条、崩溃页面（三阶段：无限弹窗 / 无限重定向 / 蓝屏）；以及只在传说里出现的「管理员」。

## 操作

- 主动技：右下大圆钮 / 空格（部分角色长按蓄力）
- 闪避：左下圆钮 / 左右滑动战斗区
- 切目标：点敌人卡 / 「‹ ›」
- 暂停：Esc（暂停菜单内含玩法说明）
- 全键盘可玩；低配模式与减弱动态自动降级

## 玩法说明入口

- 首页顶栏「玩法」按钮
- 局内暂停菜单「玩法说明」按钮
- 说明浮层内 Esc 只关浮层，不会误触暂停 / 返回

## 技术

- 前端：React + TypeScript + Vite + Tailwind + shadcn/ui，音效 Web Audio 现场合成（零音频文件）
- 后端（可选 / 已降级）：原架构用 PocketBase（pb_hooks）做每日榜 / 云存档；现已脱离 VibeX / RunningHub，云功能在本地降级为无操作，游戏本体纯前端离线可玩
- 确定性：全部计时 / 掉落走种子哈希，同一种子完全可复现（每日挑战公平性基础）
- 存档：localStorage 本机存档（主力）；云同步已降级为本地无操作，不依赖任何服务端

## 独立运行（已脱离 VibeX / RunningHub）

本仓库是 VibeX 导出的可编辑源码，已改造为不依赖原平台即可构建运行：

- 构建：`npm install` → `npm run build`（产物在 `dist/`）
- 开发：`npm run dev`（http://localhost:8000）
- 预览：`npm run preview`
- 一键启动（Windows）：双击 `start-app.cmd`（默认 dev；`start-app.cmd preview` 走生产构建）
- 已移除的运行期平台依赖：RunningHub 登录 / SSO / 计费、PocketBase 云后端、AI 网关、可视化编辑运行时（rhSourcePlugin）、域名白名单。
- 排行榜 / 幽灵对照 / 云存档等原服务端功能在离线状态下降级为本地无操作，不崩溃、不弹窗。
- 已删除的平台残留：`public/sso-popup-callback.html`、原 `src/lib/{rhLogin,auth,aigc,llm,costConfirm}.ts`、`src/hooks/useCostConfirm.ts`、`src/components/rh/CostConfirmDialog.tsx`、`src/_rh_inspect.ts`、`.vibex/`（及 `.vibex-app-type`）、`.cursor` 的 VibeX 回传规则、`pocketbase/` 后端目录。
