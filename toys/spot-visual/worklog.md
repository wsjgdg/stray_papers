- hoveredId/setHoveredId 走 props（hover 触发的重渲染频率可接受）。

### 七轮补充 8：修复「投档线数据加载失败」（严重）

**根因**：`fetch-gaokao-data.mjs` 写出 `provs[prov] = { cats: {...} }`（多包一层），而数据层 `buildIndexes` 按 `provs[prov] = { 科类: {...} }` 直接迭代 → `cd.adm` undefined → TypeError → 被 catch 吞成 fail 态。**从第一版真实数据起，页面在浏览器里从未真正加载成功过**（此前所有验证只测了 SSR 壳/HTTP 状态码，单测夹具恰好用了与类型一致但与生成器不一致的结构）。

**修复**：生成器去掉 cats 包装（与 `RealDataset` 类型对齐）；重新生成主数据文件；新增回归测试——`public/data/gaokao-2025.json` 必须能被 `loadFullDataset` 成功加载（26 用例全绿）。

**教训**：数据管线必须有一条「真实产物 → 读取器」的端到端测试；浏览器端的 hydration 后行为不能用 curl 冒烟代替。

### 七轮补充 11：地图无点位根因（入场动画卡死）+ 灰点加粗

**根因**：ECharts 散点入场动画（scale 0→1）在部分 webview 中 rAF 不推进，全部符号永久停在 scale=0 —— 表现为「有地图、无任何点位」（含灰点/彩色点全消失）。经 zrender displayList 检查定位（symbol scaleX/Y=0），`animation:false` + flush 后全部恢复。
**修复**：china-map 组件统一注入 `animation:false`（大数据量入场动画本无意义）；geo 视野保持改为「仅用户真实漫游过才回灌」，且过滤 null/NaN center（此前 center:null 注入同样会杀死 scatter 投影）；灰点颜色加深为 #94A3B8、9px。
**验证**：河南物理 600 → 冲24/稳32/保79/区间外337，画布像素级确认琥珀/绿/蓝/灰四色齐全；宁夏历史 600 灰点 153 颗全渲染；批次切换（专科 154 超区间/切回）正常。

另：用户侧「页面无法切换」系本地验证服务器已关导致的死标签页，重启即恢复。
