# 食物成分表 PDF → VLM 转录作业单

## 一、读哪些页

**只读第二册（动物性）**，第一册（植物性）暂不做——我们的 19 条主料里动物性占多数，植物性几条仓库已有。

| 正文页 | **PDF 页** | 内容 | 状态 |
|---|---|---|---|
| p57–p63 | **80–86** | 畜肉类：猪肉部位、猪内脏、火腿、牛肉、牛内脏 | ✅ 已验证（80/82/83/84/85/86 实读） |
| p76–p77 | **99–100** | 禽肉类：鸭、鸡、鹅、火鸡（092211–094102） | ✅ 左页已验证，右页推定 |
| p78–p82 | **101–105** | 蛋类（10 类） | 推定 |
| p83–p90 | **106–113** | 乳类（101001 起） | ✅ 首屏已验证，后续推定 |
| p91+ | **114–140** | 水产类（12 类） | 推定 |

**保守做法：直接把 PDF 第 78–140 页整段转录**（63 页），多余的页跳过即可。

> 第二册 = 453 页；**附录「食物样品描述」被插在正文前部**（PDF 24–79 一带），所以按页序推算页码会错，务必用页脚数字确认。

## 二、怎么切图

- 用 mupdf 渲染：`node scripts/render-pdf.mjs v2 85 2.2`（已在项目里）
- 页图是**横排内容竖版页**，需**顺时针旋转 90°**（`sharp().rotate(90)`）
- 旋转后**从中间切成左右两张**，每张单独送 VLM：
  - 左半：食物编码 / 名称 / 可食部 / 水分 / 能量 kcal+kJ / 蛋白 / 脂肪 / 碳水 / 纤维 / 胆固醇 / 灰分 / 维生素类
  - 右半：维生素E / 维生素C / 钙 / 磷 / 钾 / **钠** / 镁 / 铁 / 锌 / 硒 / 铜 / 锰 / 备注
- 单张宽 ≥ 1400px（太窄数字会认错）

## 三、输出格式

**JSONL，一行一条记录**，不要包在 ``` 代码块里。

```json
{"src":"v2","pdfPage":85,"bookPage":62,"side":"L","code":"082112","name":"牛肉（里脊肉）［牛柳］","edible":100,"energyKcal":134,"proteinG":22.3,"fatG":5.0,"choG":0.9,"cholesterolMg":44}
{"src":"v2","pdfPage":86,"bookPage":63,"side":"R","code":"082112","name":"牛肉（里脊肉）［牛柳］","naMg":75.1,"kMg":140,"caMg":3,"pMg":241,"mgMg":29,"feMg":0.4,"znMg":4.73,"seUg":3.57}
```

字段约定：

| 字段 | 含义 | 规则 |
|---|---|---|
| `code` | 食物编码 | 原样，保留字母尾（如 `082101x`） |
| `name` | 食物名称 | 原样，含方括号别名 |
| `edible` | 可食部 % | 数字 |
| `energyKcal` / `proteinG` / `fatG` / `choG` / `cholesterolMg` | 左页指标 | 数字，不带单位 |
| `naMg` / `kMg` / `caMg` / `pMg` / `mgMg` / `feMg` / `znMg` / `seUg` | 右页矿物质 | 数字 |
| `bookPage` / `side` | 页脚页码 / L or R | 必填，用于排序校验 |

取值规则：

- `—`（破折号）→ **null**
- `Tr`（痕量）→ 原样字符串 `"Tr"`
- 看不清 → `"?"`
- **不要换算、不要补零、不要四舍五入**

## 四、VLM 提示词

### 左半页

```
你是中文出版物扫描件的数据转录员。这是一页《中国食物成分表》的表格扫描件（已旋转为正向）。

任务：逐行转录表格左侧部分，输出 JSONL（每行一个 JSON 对象），不要任何解释文字，不要 markdown 代码块。

每一行对应一个食物，字段：
code（食物编码，6位数字，可能带字母后缀如 082101x）
name（食物名称，原样保留，含［］内的别名）
edible（可食部，%）
energyKcal（能量 kcal 列的数值）
energyKJ（能量 kJ 列的数值）
proteinG（蛋白质 g）
fatG（脂肪 g）
choG（碳水化合物 g）
fiberG（膳食纤维 g）
cholesterolMg（胆固醇 mg）
ashG（灰分 g）

规则：
1. 严格按行转录，禁止跨行合并、禁止继承上一行内容
2. 「—」输出 null；「Tr」原样输出字符串 "Tr"；看不清输出 "?"
3. 数值原样，不要换算单位、不要补小数位
4. 表头、页脚、分类标题（如「畜肉类及制品」）不输出
5. 每行额外带上 "bookPage": 页脚页码（数字）, "side": "L"
6. 只输出 JSONL，第一行就是第一条 JSON
```

### 右半页

```
你是中文出版物扫描件的数据转录员。这是一页《中国食物成分表》表格的右半部分（已旋转为正向）。

任务：逐行转录，输出 JSONL（每行一个 JSON），不要解释，不要代码块。

字段：
code（食物编码）
name（食物名称）
vitETotalMg（维生素E总量 mg）
vitCMg（维生素C mg）
caMg（钙 mg）
pMg（磷 mg）
kMg（钾 mg）
naMg（钠 mg）
mgMg（镁 mg）
feMg（铁 mg）
znMg（锌 mg）
seUg（硒 μg）
cuMg（铜 mg）
mnMg（锰 mg）

规则：
1. 「钠 Na mg」这一列是关键，务必对正列，不要错位到相邻列（左右邻列是钾和镁）
2. 「—」输出 null；「Tr」输出 "Tr"；看不清输出 "?"
3. 数值原样，不要换算
4. 严格按行，禁止跨行合并或继承
5. 每行带上 "bookPage": 页脚页码, "side": "R"
6. 只输出 JSONL
```

## 五、跑完怎么给我

把 JSONL 文件放进项目任意位置，执行：

```bash
node scripts/ingest-vlm-jsonl.mjs <你的文件.jsonl>
```

脚本会：

1. 按 `code` 合并左右页记录（左页给能量，右页给钠）
2. 与仓库现成 1677 条数据交叉校验，列出钠值偏差 >5% 的条目
3. 输出 `.cache/vlm-merged.json`

加 `--write` 会生成 `src/lib/cfcd-extra.generated.ts`，我接着接进页面。

## 六、验收标准

先跑 **PDF 85 + 86 两页**（牛肉，p62/p63）做试水：

- 应产出约 20 条记录
- 与仓库比对：`082112` 钠应为 **75.1**、`082103` 应为 **45.4**、`082120`（牦牛肉）应为 **25.8**
- 偏差 >5% 的条目应为 **0 条**；若有偏差，说明那侧列错位或图太糊，加大渲染倍率重跑
