|---|---|

建议：只在想要「完整存档」时跑；为了应用数据，不值得。

## 提示词（跑则复制下面整段）

```
【任务】
你会收到一本扫描版工具书：《中国食物成分表 标准版 第6版 第一册（植物性食物）》。
请把它转成结构化数据，输出 JSON。

【材料特征】
1. 全书 387 页，扫描件，内容整体被旋转了 90°：文字是横躺的。请先把每页顺时针旋转 90° 再阅读。
2. 表格是**跨页排版**：
   - 左半页列到「核黄素」：食物编码、名称、可食部、水分、能量kcal、能量kJ、蛋白质、脂肪、碳水化合物、不溶性膳食纤维、胆固醇、灰分、总维生素A、胡萝卜素、视黄醇、硫胺素、核黄素
   - 右半页才是：烟酸、维生素C、维生素E、钙、磷、钾、**钠**、镁、铁、锌、硒、铜、锰、备注
   - 即**「钠」只在右半页**。同一批食物左右页编码相同。
3. 每页页脚有 bookPage 页码，用它标注来源页。
4. 本册大类包括：谷类及制品、薯类淀粉及制品、干豆类及制品、蔬菜类及制品、菌藻类、水果类及制品、坚果种子类、植物油、调味品等。

【跳过规则】以下页直接跳过，不要输出内容：
- 封面、版权、序、前言、目录、使用说明（讲编码规则与可食部公式的页）
- 附录「食物样品描述」（只有编码/名称/描述/产地等文字列，无任何营养数值）
- 单独占行的分类标题（如「蔬菜类及制品」「水生蔬菜类」跨行标题）

【逐页流程】
① 判断本页类型：数据表左半 / 数据表右半 / 非数据页
② 非数据页 → 输出 {"skip":true,"bookPage":页码,"reason":"原因"}
③ 数据表 → 逐行转录，一行一个食物，禁止合并、禁止继承上一行
④ 转完自检行数是否与图上一致

【输出格式】每页一个 JSON 对象，不要 markdown 代码块，不要解释文字：
{"src":"v1","bookPage":76,"side":"L","category":"蔬菜类及制品","rows":[{"code":"045419","name":"穿心莲","edible":100,"water":95.1,"energyKcal":17,"energyKJ":71,"proteinG":1.7,"fatG":0.2,"choG":4.0,"fiberG":2.5,"cholesterolMg":0,"ashG":0.7,"vitAUg":0,"caroteneUg":0,"retinolUg":0,"thiaminMg":0,"riboflavinMg":0}]}
{"src":"v1","bookPage":77,"side":"R","category":"蔬菜类及制品","rows":[{"code":"045419","name":"穿心莲","niacinMg":0.6,"vitCMg":12,"caMg":98,"pMg":32,"kMg":340,"naMg":7.6}]}

【字段定义】全部纯数字、不带单位、不换算、不补小数位。
通用：code（6 位 + 可选字母后缀，原样）、name（原样，含［］别名）、side（L/R）、category
左半：edible、water、energyKcal、energyKJ、proteinG、fatG、choG、fiberG、cholesterolMg、ashG、vitAUg、caroteneUg、retinolUg、thiaminMg、riboflavinMg
右半：niacinMg、vitCMg、vitETotalMg、caMg、pMg、kMg、naMg、mgMg、feMg、znMg、seUg、cuMg、mnMg、remark

【硬性规则】
1. 「—」→ null；「Tr」→ 原样字符串 "Tr"（不要变 0）；看不清 → "?"
2. 数值去掉逗号与空格，`1 234` 写 1234
3. **naMg 最易错位**：左邻是钾 K、右邻是镁 Mg。核对：蔬菜水果的 naMg 通常是个位数到几十，极少四位数
4. 同页出现重复 code = 串行，重录本页
5. **不要纠正原书疑似错误**：《野生蔬菜类》（048004–048084）原书能量 kcal 与 kJ 疑似标反，请按图上数字原样转录，不要自行调换
6. 不补全、不按常识修正、不合并同名不同编码
7. 编码可能带字母后缀（如 011201x 表示该类代表值），必须保留

【分批】按大类分段，每段 ≤20 页，段间可停：
第1段 谷类+薯类+干豆（约 PDF 30–80 页）
第2段 蔬菜类（约 80–150 页）
第3段 菌藻+水果（约 150–230 页）
第4段 坚果种子+植物油+调味品（约 230–300 页）
第5段 其余有营养素数值的表格页

【禁止】markdown 表格、解释总结、跳过任何数值、编造 bookPage（看不清写 null）。

现在开始，先输出第 1 段。
```

## 拿到结果后

```bash
node scripts/ingest-vlm-jsonl.mjs 第一册第1段.jsonl
```

脚本按 `code` 合并左右页，与仓库 1677 条比对，列出钠值偏差 >5% 的条目（这轮已修好 CSV 引号解析的 bug，之前误报的 71 条是假的）。
