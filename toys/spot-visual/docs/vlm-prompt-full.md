# 整本 PDF 送模型的完整提示词

复制下面整段作为 system/user prompt，连同 PDF 一起发出。

---

```
【任务】
你会收到一本扫描版工具书：《中国食物成分表 标准版 第6版 第二册（动物性食物）》。
请把它转成结构化数据，输出 JSON。

【材料特征，务必先理解】
1. 全书 453 页，扫描件，内容整体被旋转了 90°：文字是横躺的。请先在心里把每页顺时针旋转 90° 再阅读。
2. 一本书的表格是**跨页排版**的：
   - 左页（或左半页）列到「核黄素」为止：食物编码、名称、可食部、水分、能量kcal、能量kJ、蛋白质、脂肪、碳水化合物、膳食纤维、胆固醇、灰分、维生素A、胡萝卜素、视黄醇、硫胺素、核黄素
   - 右页（或右半页）才是：维生素E、维生素C、钙、磷、钾、钠、镁、铁、锌、硒、铜、锰、备注
   - 也就是说，**「钠」只在右半页**，左半页没有。同一批食物在两页里出现，编码相同。
3. 每页页脚有 bookPage 页码（正常方向的小数字），请用它标注来源页。
4. 并非所有页都是数据表。以下页面**直接跳过，不要输出任何内容**：
   - 封面、版权页、序、前言、目录、使用说明（讲编码规则、EPA/可食部公式的那些页）
   - 附录「食物样品描述」：特征是表格只有 食物编码/食物名称/食物描述/产地/采样地点/采样时间 等**文字列**，没有任何能量或营养素数值，且常在页面顶部标有「食物样品描述」字样
   - 跨行的分类标题行（如「畜肉类及制品」「猪肉及其制品」单独占一行、没有编码和数值的），不要当作数据行

【处理流程，逐页执行】
第 1 步：判断本页类型 → 是「数据表左半页」/「数据表右半页」/「非数据页」。
第 2 步：若非数据页，输出 {"skip": true, "bookPage": 页码, "reason": "简述原因"}。
第 3 步：若是数据表，逐行转录，每行一个食物，禁止合并、禁止继承上一行。
第 4 步：转录完后自检行数是否与图上数据行数一致，不一致就重数一遍。

【输出格式】
每页输出一个 JSON 对象，行之间不要留空，**不要 markdown 代码块**，不要任何解释文字：

{"src":"v2","bookPage":62,"side":"L","category":"畜肉类及制品","rows":[{"code":"082112","name":"牛肉（里脊肉）［牛柳］","edible":100,"energyKcal":134,"proteinG":22.3,"fatG":5.0,"choG":0.9,"cholesterolMg":44}]}

{"src":"v2","bookPage":63,"side":"R","category":"畜肉类及制品","rows":[{"code":"082112","name":"牛肉（里脊肉）［牛柳］","naMg":75.1,"kMg":140,"caMg":3,"pMg":241,"mgMg":29,"feMg":0.4,"znMg":4.73,"seUg":3.57}]}

【字段定义】
所有数值字段都是**纯数字，不带单位，不做换算，不补小数位**。

通用字段：
- code：食物编码，6 位数字，可能带字母后缀（如 082101x），原样保留
- name：食物名称，原样保留，含［］内的别名，不要删改标点
- side：本页是左半「L」还是右半「R」
- category：本页所属大类名（如 畜肉类及制品）

左半页字段（没有的填 null）：
edible（可食部 %）、water、energyKcal（能量 kcal）、energyKJ（能量 kJ）、proteinG、fatG、choG、fiberG、cholesterolMg、ashG、vitAMg、caroteneUg、retinolUg、thiaminMg、riboflavinMg

右半页字段（没有的填 null）：
vitETotalMg、vitCMg、caMg、pMg、kMg、naMg、mgMg、feMg、znMg、seUg、cuMg、mnMg、remark

【硬性规则】
1. 「—」「－」「-」表示未测 → 输出 null
2. 「Tr」表示痕量 → 原样输出字符串 "Tr"，不要变成 0
3. 某格确实看不清 → 输出 "?"，不要猜、不要用相邻行数值填补
4. 数值里的逗号、空格全部去掉；`1 234` 要写 1234
5. **钠 naMg 这一列最容易错位**：它左边是「钾 K」，右边是「镁 Mg」。转录后请核对：同一行 naMg 应明显小于 kMg 的多数情况，且不可能出现四位数（除非腌腊制品）。
6. 编码必须唯一：同一页内如果出现重复 code，说明串行了，请重录本页
7. 只转录看得见的行，不要补全、不要按常识修正数值

【分批要求】
不要一次输出全书。请按大类分段，每段不超过 20 页，段与段之间停下来等我确认或直接继续下一段：
第 1 段：畜肉类（PDF 约 78–86 页）
第 2 段：禽肉类 + 蛋类（约 87–105 页）
第 3 段：乳类（约 106–113 页）
第 4 段：水产类（约 114–140 页）
第 5 段：其余凡是有营养素数值的表格页

【禁止事项】
- 不要输出 markdown 表格
- 不要输出解释、总结、统计、致谢
- 不要合并同名不同编码的条目
- 不要跳过任何数值，哪怕它看起来不合理
- 不要自己编造 bookPage，页脚看不清就写 null

现在开始，先输出第 1 段。
```
