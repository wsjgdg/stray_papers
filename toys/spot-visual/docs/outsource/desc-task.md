## 写作规则（违反即返工）

1. **长度 60–110 个字符**（含标点）。短于 60 说明没内容，长于 110 说明在灌水。
2. **只写有把握的事实。** 不确定的年代、数字、人物一律不写。
3. **禁止出现下列内容**（这些由结构化字段提供，写在描述里会与数据冲突）：
   门票 / 票价 / 价格数字 / 开放时间 / 预约规则 / 电话 / 「最佳季节」。
4. **强断言必须能给出依据**，且 `basis` 里要写清来源：
   世界文化遗产 / 世界自然遗产 / 世界地质公园 / 全国重点文物保护单位 /
   国家级风景名胜区 / 国家森林公园 / 最大 / 唯一 / 第一 / 最早 / 最高。
   给不出依据就**换一种说法**，不要赌。
5. **能写事实就不写形容词。** 写「以花岗岩峰林地貌著称」而不是「美不胜收」；
   写「巨蟒出山、东方女神是标志性石柱」而不是「景色令人震撼」。
6. **`name` 必须逐字符照抄输入**（已做过名称清洗，含括号/间隔号都是最终版），
   改一个字描述就不生效。
7. 不要 ASCII 引号、不要换行、不要 markdown。
8. **写不出就跳过**（宁缺勿滥）：不输出该条即可，但在回复里说明跳过的名字与原因。
   拿模板句凑数会被直接退回。
