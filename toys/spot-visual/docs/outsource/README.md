## 四、命名口径（已在前 300 条上实践过，务必沿用）

1. **去行政前缀**：`浙江省温州市乐清市雁荡山景区` → `雁荡山景区`
2. **去管理机构 / 去公司名**：这类条目不是景区，直接 `drop`，`duplicateOf` 写库内对应的景区条目
3. **长短名并存（同一景区被列两次）**：判断依据是「**同市 + 同等级**」，此时 `drop` 长名、保留短名（或反过来保留信息更全的那条）
4. **泛名保留限定词**：`南山` / `灵山` / `台山` / `江湾` 这类全国重名的，加城市或县级限定（`九江南山景区`、`婺源江湾景区`、`湖口台山景区`），**不要直接压成两三个字**
5. **保留有辨识度的符号**：`小五台·金河景区` 的间隔号、`天津古文化街旅游区（津门故里）` 的括注是有效信息，不要为了「变短」删掉
6. **拿不准就 `keep`**。宁可少改，不可改错；改错会直接污染线上数据
