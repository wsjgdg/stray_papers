## 三、终检判定口径（47 条在册剔除 + 22 条已解禁）

一律「宁可没有图，也不上图不对」，以下六类进黑名单并记录理由：

1. 水印：`新华网` `人民图片` `每日甘肃` `知乎 @xxx` `MISTINE` 品牌角标
2. 地图/导览图/示意图（不是实景）
3. 多格拼贴图、宣传海报、叠加大字的合成图
4. 商品特写：玉器手镯、陶瓷器皿、陶塑、酒坛、文物单件
5. 主体不符：警局建筑、沙漠骆驼配「蒙古王府」、石墙配「熊猫苑」、城市天际线配山谷景区
6. 人物为主体（摆拍、合影、模特）或翻拍的照片/绘画插图

完整的 69 条（名称 + 逐条理由）在 `public/spots/_rejected.json`，可直接复核。

### 4. 别名重抓：把剔除表里的条目救回来

裸名查询（`七仙岭温泉国家森林公园`）与带城市前缀的查询（`吐鲁番市 火焰山景区`）在 Bing 上返回的结果集不同。

做法：对最后 66 条用「城市 + 原名」当别名抓取 `--per=3`，抓完后**把 `_report.json` 里的别名改回原名**（否则烘焙出的键对不上库内条目），再用 `make-spot-contact-sheet.mjs --names=<名单文件>` 按名单出拼图（新增参数：别名条目在报表里的位置是旧的，靠 offset 取不到）。

结果：**22 条拿到干净可用的新图**，从剔除表解禁；12 条新图仍带水印或主体不对，维持剔除。
