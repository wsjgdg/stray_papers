## 二、六十四轮任务

### 任务 1（主任务，建议优先）：把档案批次清单升级为常驻生成器

**现状**：`docs/outsource/profile-batch1..48.json` 是我一次性生成的**静态文件**。

**问题**：库条目会继续变（清洗改名、删重复条目、后续补录）。静态清单会和库**漂移**——
等外部 AI 交回批 20 时，里面某些 id 可能已经不在库里了，合并器会直接判「幽灵 id」整批拒收，
那批就白写了。描述清单那边你已经做成了常驻生成器（`tests/gen-desc-batches.test.ts`），档案这边还是静态的。

**要做**：
- 照 `gen-desc-batches.test.ts` 的写法做一个 `tests/gen-profile-batches.test.ts`（同一套 `GEN_*_BATCHES=1` 门控），
  按同样的排序规则（5A 优先，4A 按 address）重新切 48 批 × 100 条，字段与现状对齐（含 `id` / `name` / `city` / `level` / `address` / `category` / `mergeRule`）。
- 加一条**守护测试**：48 批的 id 并集 == 当前「需要档案」的条目全集，且跨批无重复。
  这条断言能在库变动后第一时间把漂移暴露出来。

**验收**：我跑 `npx vitest run` 后核一遍并集条数与重复数。

`docs/outsource/qc-desc-batchN.json` / `qc-profile-batchN.json`，内容：

```json
{
  "batch": 1,
  "mergedAt": "ISO 时间",
```
