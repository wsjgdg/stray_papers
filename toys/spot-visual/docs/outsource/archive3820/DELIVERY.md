## 五、使用与复核建议

1. 前端接入：将 spot-profiles.generated.ts 置于 src/lib/，按条目 id 读 SPOT_PROFILES[id]，low 字段为 true 时 UI 建议标注「待核实」。
2. 数据复核：qc-profile-batchN.json 的 sample 为固定种子抽样，可直接对照对应 out-profile-batchN.json 核查；重点核对 high 条目的 ticketPeak/openHours 与官方渠道真值。
3. 门禁建议：合入应用仓库后跑 tsc / vitest / next build 三连 + verify-outsource-pipelines.mjs 复核（一期收口时工作区曾重置、应用源码缺失，未跑过构建门禁）。
4. 后续批次若有修订：改 out-profile-batchN.json 后重跑官方合并器即可幂等更新合并档与读取表。
