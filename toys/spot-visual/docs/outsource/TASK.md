## 目标

把 `remaining-dirty.json` 里的 **353 条**脏景区名，整理成规范名（`rename`）、判定为重复条目（`drop`）或确认无需改动（`keep`）。

分 3 批：`[0:120]`、`[120:240]`、`[240:353]`。**每批交付后停顿等确认。**

| 文件 | 说明 |

## 输出

写入 `docs/outsource/out-name-fixes.batch3.json`（批 4、5 依次改文件名）：

```json
{
  "renames": [{ "from": "原名（逐字符照抄）", "to": "规范名", "reason": "一句话说明改了什么" }],

  "keep":    ["确认无需改动的原名"]
}
```

**三者并集必须恰好等于本批输入全集**，每条只出现一次。

---

## 判定规则（按顺序套用）

### 1. 先判断「是不是景区」
名称里带 `有限公司` / `股份有限公司` / `开发有限公司` / `管委会` / `管理委员会` / `旅游管委会` → **不是景区本体**，走 `drop`，`duplicateOf` 写库内对应的那个景区条目。

> 例：`杭州浙西大峡谷旅游股份有限公司` → `drop`，duplicateOf `浙江省杭州市临安区浙西大峡谷景区`

### 2. 再判断「是不是同一景区被列了两次」
判据是 **同市 + 同等级**（`city` 相同、`level` 相同），且去掉行政前缀后名称高度重合。此时 `drop` 掉冗余的那条，保留信息更全/更规范的一条。

> 例：`浙江省嘉兴市桐乡市乌镇景区` 与库内既有 `乌镇景区` 同市同级 → `drop` 前者，duplicateOf 写 `乌镇景区`

### 3. 剩下的是「同一景区，只是名字脏」→ `rename`
- 去掉省/市/县行政前缀：`河北省秦皇岛市抚宁区冰塘峪长城风情大峡谷景区` → `冰塘峪长城风情大峡谷景区`
- 修错别字：`施游`→`旅游`、`公团`→`公园`、`受旗`→`曼旗`、`孤游`→`旅游`
- 去掉与结尾重复的后缀：`塞罕坝森林公园景区` → `塞罕坝森林公园`

### 4. 泛名必须加限定
`南山` / `灵山` / `台山` / `江湾` / `黄龙` / `千佛山` / `天台山` / `清水湾` / `花园村` 这类在全国有多个同名的，**保留城市或县级限定**，不要压成两三个字：

> 例：`江西省九江市南山景区` → `九江南山景区`（不是 `南山景区`）
> 例：`江西省上饶市江湾景区` → `婺源江湾景区`

### 5. 拿不准就 `keep`
宁可少改，不可改错。**绝不编造**：不确定是不是同一景区，就分别保留。

## 最容易犯的错（前 300 条真实踩过）

| 错误 | 案例 | 后果 |
|---|---|---|
| **异地同名当同一景区合并** | `浙江省绍兴市东湖景区` 被并进 `东湖景区` —— 但库内 `东湖景区` 在**浙江嘉兴平湖市**，两者是不同景区 | 直接丢失一个 4A 条目 |
| **把撞名的 rename 当 rename** | 改名后与库内既有条目重名且同市同级，本应 `drop` | 干跑后出现重复行 |
| **压成泛名** | `南山景区`、`灵山景区` | 与外地同名景区混在一起，搜索无意义 |
| **动了已定稿的 301 条** | 重复处理 `already-touched.json` 里的条目 | 覆盖既有结论 |

## 交付前自检（必须逐条跑完再交）

1. `renames[].from` + `drops[].name` + `keep[]` 并集 = 本批输入全集，无重复、无遗漏
2. 每个 `from` 都能在 `remaining-dirty.json` 找到同名条目
3. 每个 `duplicateOf` 都存在于 `reserved-names.txt`（或本批 `keeps`/`renames.from` 中）
4. **每个 `to` 都不在 `reserved-names.txt` 中**（逐行比对），且本批内互不重复

   ⚠️ **自匹配陷阱**：`reserved-names.txt` 是「改名之前」的库，因此**它里面包含本批的源条目自身**。
   做撞名检查时必须先排除「本批所有 `from` / `drops.name`」，否则会把自己的源名当成「库内已有条目」。
   批 3 曾因此误判 `辽宁省大连市大连博物馆` 是「完全重复行」（实际库里只有 1 条）。
   正确做法：`候选池 = reserved-names.txt − 本批已处理名`。

5. 干跑：把本批 renames/drops 应用到 `reserved-names.txt` 的 4577 行，**不得产生新的重名**
6. 没有 `to` 是两三个字的泛名（除非确实唯一）
7. 输出是纯 JSON、UTF-8、无 BOM、无 markdown 代码块
