# 营养数据来源与覆盖边界

口味雷达里的「钠 / 糖」两个维度接了 USDA FoodData Central（FDC）。
完整拉过两次：一次 `query=Restaurant Chinese` 的 8 页共 **1408 条**（含钠字段），
其中命名字面含中式关键词的 **252 条**，但绝大多数是酱料、调味粉、速冻零售品，
真正是「成品菜」的只有 FNDDS / SR Legacy 里的几十条（左宗棠鸡、捞面、蛋卷、酸辣汤、炒饭、饺子、馄饨……）。

## 为什么覆盖只有 7 道菜

本项目收录的是**中国省域与地市名菜**（佛跳墙、臭鳜鱼、剁椒鱼头、灯影牛肉……），
FDC 收录的是**美式中餐**（General Tso’s chicken、Chow mein、Egg roll）。
两边只在少数通用品类上重叠：烤鸭、糖醋猪肉、炒饭、饺子。逐菜检索 432 个菜名后，
能对号入座的只有 7 个，且每个都写了对应关系说明；其余一律标「无外部条目」，不硬凑。

## 可以复核

任一 fdcId 都能直接查：`https://api.nal.usda.gov/fdc/v1/food/<fdcId>?api_key=...`。

## 没接的部分

- **消费调研**（外卖/点评菜品热度、销量）没有公开数据集，面板里明确写了未纳入。
- **辣 / 酸 / 香 / 鲜** 在营养库里没有对应量纲，只有 Scoville（辣）与蔗糖相对甜度（甜）这类公开量表做端点参照。
