# 深空指挥墙 · Deep Space Command Wall

一个纯前端的深空探测任务值班模拟网页应用。你将扮演地面测控中心的值班员，从点火起飞到地外着陆，全程盯遥测、处置突发警报、遥控巡视车科考，并把每一次任务存档进自己的生涯履历。

无任何后端与外部服务依赖——所有物理、遥测、剧情、音效均在浏览器本地实时演算，存档写入 `localStorage`。

## 任务线

| 任务 | 天体 | 特色玩法 |
| --- | --- | --- |
| LUNA-9 | 月球 | 微陨石雨近失命中、月夜生存 |
| ARES-1 | 火星 | 区域/全球级沙尘暴、风暴生存模式、电力亏损 |
| VNS-1 | 金星 | 240s 生存窗口倒计时、热负载博弈、应急散热、酸雾锋面、紧急上升撤离 |
| EUROPA-1 | 木卫二 | 冰裂隙测深、熔钻探海、新鲜冰晶 S 级采样窗口、冰下海洋取水 |
| TTN-1 | 泰坦 | 甲烷浓雾三段过渡、雾中遥感失效、越野拉力赛夜航 |

## 核心特性

- **全流程任务链**：上电自检 → 倒计时 → 点火 → 转移 → 制动 → 气动黑障 → 动力下降（可手动接管着陆）→ 触地 → 表面作业 → 结算单
- **1Hz 遥测主循环**：多路指标实时推演（含沙尘暴/浓雾对光照、下行速率、信号、母线的降额模型），60 点滚动曲线
- **随机事件体系**：航行突发危机二选一（含危机链与后续剧情回响）、限时警报处置、值班指令（可升级三环连环）、流星雨/紧急演练/中继握手/诊断灯序/呼号抽问/天线对准/极光观测等互动玩法
- **巡视车遥控**：WASD/方向键驾驶、漂移旋转、机械臂采样与化验分级（S–C）、拍照相册（四档滤镜/档案编号防伪校验/清单导出）、摩斯灯语、喇叭/双闪彩蛋、陷车救援拖曳、太阳能积尘清扫
- **发射回放**：着陆后解锁，~2Hz 关键帧环形缓冲，支持倍速/逐帧步进/四机位切换
- **每日挑战与生涯统计**：当日天体+修饰条件确定性生成、连击记账、生涯快照与分享卡
- **成就与珍藏**：59 项成就（含稀有彩蛋）、样品博物馆陈列厅、S 级珍宝鉴赏卡（canvas 手绘分享图）
- **字幕通讯剧本**：北京-巡视车双向播报随阶段/事件推进，黑障区信号中断演出
- **WebAudio 程序化音效**：警报蜂鸣、倒计时音阶、放晴风铃、发射轰鸣等全部实时合成，支持静音与背景音乐
- **无障碍与移动端**：读屏警报区、焦点环、触屏长按驾驶、响应式布局
- **存档健壮性**：节流写盘 + 覆盖前自动备份 + 损坏回退 + 版本迁移通道

## 技术栈

React 19 · TypeScript · Vite · Tailwind CSS 3 · lucide-react · Web Audio API · Canvas 2D

## 快速开始

要求 Node.js ≥ 20。本项目使用 npm 管理依赖（已移除 pnpm）。

> 提醒：本机 `registry.npmjs.org` 常不可达，安装请带镜像：
> `npm install --registry=https://registry.npmmirror.com`

```bash
npm install --registry=https://registry.npmmirror.com   # 安装依赖
npm run dev         # 开发模式, 默认 http://localhost:8000
npm run build       # 类型检查 + 生产构建, 产物在 dist/
npm run preview     # 本地预览生产构建
```

## 操作速查

- **驾驶**：`W A S D` / 方向键（输入框聚焦时自动豁免）；`空格` 喇叭、`F` 双闪、`Q` 漂移（键位徽章可点击重绑）
- **回放**：进入回放后 `←` `→` 逐帧步进
- **弹层**：`Esc` 逐层关闭（指南 → 简报 → 回放 → 成就墙 → 样品厅 → 报告 → 指标浮层）
- **采样**：静止且电量 >15% 时点击「机械臂采样」；样品入清单后点「化验」出分级报告

## 存档说明

- 存档键 `dsc-save-v1`，覆盖前自动备份至 `dsc-save-v1:bak`；主档损坏时自动回退备份
- 存档内容：成就、样品博物馆、生涯计数、拉力最佳、每日挑战连击、音频偏好等
- 顶栏「清除存档」将同时清空主档与备份并复位全部进度
