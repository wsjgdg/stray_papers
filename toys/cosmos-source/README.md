# 宇宙模拟器 · Cosmos Orrery

一个交互式 3D 宇宙模拟器：从太阳系行星轨道、近邻恒星、银河系旋臂，一路放大到本星系群、超星系团网络与可观测宇宙的微波背景。

基于 **Next.js 16 + Three.js + TypeScript + Tailwind CSS + shadcn/ui** 构建。

## ✨ 功能特性

### 太阳系（真实化）
- 8 大行星 + 4 矮行星（冥王星/阋神星/鸟神星/妊神星），J2000 真实轨道根数 + 开普勒方程迭代
- 11 颗卫星（月球/木卫一二三四/土卫六/土卫二/海卫一/火卫一二/冥卫一）
- 土星环（卡西尼缝细化）+ 天王星/海王星暗淡环
- **行星日夜分界线 shader**：昼夜半球 + 晨昏带 + 地球夜面城市灯光
- **大气瑞利散射菲涅尔描边**：行星边缘彩色光晕
- **土星环阴影投射**到行星表面（跟随太阳方向）
- 小行星带 + 柯伊伯带（1440 颗动态天体）
- 4 颗彗星（哈雷/海尔-波普等）双尾、流星雨、黄道光、地影

### 天文馆模式
- 地平坐标系、恒星时、太阳高度/赤纬
- 可调观测站经纬度
- 真实星空：7200 颗背景星 + 30 颗命名亮星 + 15 个星座 + 18 个深空天体 + 银河带

### 7 级宇宙缩放
1. **太阳系** → 2. **近邻恒星**（39 颗 + 10 颗系外行星）→ 3. **银河系**（4 旋臂 + 银心）→ 4. **本星系群**（24 星系）→ 5. **近邻宇宙**（31 星系 + 室女团）→ 6. **超星系团网络**（12 超星系团 + 宇宙网）→ 7. **可观测宇宙**（CMB 各向异性 + 8 类星体）

### 交互
- **宇宙漫游飞行**（WASD/Shift/Space/拖拽转向 + 速度档位）
- **自动巡航**（10 个预设航点跨缩放级别 + 跳过/拖拽取消）
- **时间轴拖拽**（1850–2200 任意时刻 + 5 个预设：J2000/1986 哈雷/今天/2061 哈雷/2114）
- 点击天体平滑聚焦动画（easeInOutCubic）
- 缩放级别切换 warp 闪现过渡
- 系外行星/星系 pick ball（不可见碰撞球提升点击精度）

## 📁 文件结构

```
src/
├── app/
│   ├── layout.tsx              # 元数据
│   └── page.tsx                # 入口（动态加载 CosmosViewer）
├── components/
│   └── cosmos-viewer.tsx       # React HUD（控制面板/档案/巡航/漫游/时间轴）
└── lib/
    └── cosmos/
        ├── engine.ts           # Three.js 引擎核心
        ├── cosmos-views.ts     # 6 个宇宙缩放级别构建器
        ├── textures.ts         # 程序化纹理 + shader
        ├── data.ts             # 太阳系数据
        ├── universe-data.ts    # 宇宙数据
        └── math-utils.ts       # 轨道力学/坐标变换
```

## 🚀 运行

```bash
bun install          # 安装依赖
bun run dev          # 启动开发服务器（http://localhost:3000）
bun run lint         # 代码检查
```

### 依赖
- `three@0.186.0` + `@types/three`
- Next.js 16 + React 19
- Tailwind CSS 4 + shadcn/ui
- lucide-react（图标）

## 📊 数据来源

- 星系：NASA/IPAC NED
- 超星系团：Tully et al. (2014) Laniakea 论文
