### 踩到的坑

1. **pnpm isolated linker 在 Windows 沙箱建不出符号链接** — `node_modules/@types/` 全空，`tsc` 报 TS2688。`.npmrc` 写 `node-linker` 无效（pnpm 11 已忽略该文件），必须写进 `pnpm-workspace.yaml`。最终 `nodeLinker: hoisted` + `onlyBuiltDependencies` 放行 rolldown 原生绑定。
2. **Windows 路径 bug（3 个脚本）** — `new URL("..", import.meta.url).pathname` 返回 `/C:/Users/...`，交给 `path.join` 变成 `C:\C:\Users\...` → ENOENT。原 VibeX 容器是 Linux 跑不出。改 `fileURLToPath()`。命中 `export-renpy.mjs` `text-pipeline.mjs` `gen-renpy.mjs`；`verify-*.mjs` 用 `readFileSync(new URL(...))` 直传 URL，不受影响。
3. **`no-irregular-whitespace` 误报中文排版** — JSX 文本节点里的全角空格 U+3000 是刻意留白，`skipStrings` 管不到，需 `skipJSXText: true`。
4. **存量 lint 债 52 error** — `eslint-plugin-react-hooks` v7 引入 React Compiler 系规则（set-state-in-effect / purity / refs / immutability 等），280 个源文件写在这些规则之前。逐个改是覆盖 2000+ 行的行为重构，与脱平台无关 → 统一降 `warn` 并在 `eslint.config.js` 写明理由。`react-refresh/only-export-components` 同理（Logic/View 分层约定冲突）。
5. **文案 bug** — `CampusTopBar.tsx:81` 与 `CampusMapCanvas.tsx:395` 把「奶蛙大学」写成「青蛙大学」，已修。

### 启动脚本踩的坑（都实测过，非推断）

1. **`.ps1` 必须 UTF-8 with BOM**。PS 5.1 靠 BOM 认编码；无 BOM 时中文被误解码，
   进而撑破引号，报 `字符串缺少终止符: '。` / `Try 语句缺少 Catch`。编辑工具写出的文件是无 BOM 的，
   改完必须重新落盘。校验用 `[Parser]::ParseFile($path,[ref]$tokens,[ref]$errors)`。
2. **`.cmd` 必须纯 ASCII**。cmd 用控制台代码页（GBK）读批处理，中文注释和 `echo` 全乱码。
   所有中文输出交给带 BOM 的 ps1。
3. **编码设置必须在任何输出之前**，且要 `chcp.com 65001` + `[Console]::OutputEncoding` 两步都做。
   我一开始放在 banner 之后 + 误写成 `chcp.com 65001.com`（多了 `.com`），双重失效。
4. **类型检查不能串行**。280 文件的 `tsc -b --force` 要十几秒，串行把启动拖到 22 秒还没 listen，
   curl 拿到 502。改成 `Start-Job` 后台并行，结果在服务器退出时打印（`Receive-Job -Wait` + `Remove-Job`）。
5. 单窗口验证方式：进程树应呈 `powershell -File start.ps1` → `node vite.js` 的父子关系，
   不是并列的独立进程。用 `Get-CimInstance Win32_Process` 看 ParentProcessId。
