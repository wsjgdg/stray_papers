# 奶蛙大学（Naiwa University）

> 陪八只奶蛙重过一学期：选项定沉默与好感，十条线 30 种结局；第二学期蛙还记得你，第三学期连记得也免了。

校园题材文字冒险（galgame 式对话推进）。一只平平无奇的奶白蛙，在一个把一切都格式化了的校园里过完一个学期——然后是下一个学期。四个数值来自同一次选择，方向却可以互相矛盾：

- **沉默值**：记录你被驯化了多少（结局按它分三档）
- **好感度**：记录你还剩多少真实连接（点头之交 → 饭搭子 → 树洞 → 真心蛙友）
- **印象分**：记录你表演得有多成功（公示栏五档评语）
- **被注意值**：记录你被盯上了多少（决定深夜约谈会不会找上门）

全剧台词、选项、结局与演出数据都在本地，无外接 AI、无任何联网推理。

## 玩法上手指南

**一个学期怎么过。** 新档开放两条线：教学线（开学第一课，共通性质）和医务室线（病假条——不舒服不需要认定，随时允许发生）。报到之后共通日程按天推进（第 1 天宿舍钥匙 → 第 2 天横幅换了 → 第 4 天期中 → 第 5 天期末周意向表 → 第 7 天清书仪式 → 第 8 天湖边的请柬）；白天在校园地图里选地点走线，夜里可能有深夜事件上门。一旦有了进度（比如走完教学线），其余常规线一起开放，进入自由推进：完成 4 条常规线（教学线计入其中）走到第 5 天，意向表认定——其余线锁定，认定的主场线连同客串线一起解锁（灰灰、格格还连带宿舍楼），专属剧情从这条线开始。湖边是隐藏线：不计入常规四条、也从来不必经，九条常规线全部走完它才亮。

**选项怎么读。** 每处选项当场结算：动的是全学期累计的沉默值（+1 / 0 / −1），或某只蛙的好感。带收束语的选项是真分岔——走完那条支路给一句收束语，图鉴的岔路册会记下你走过哪条；带「回响」标记的选项在第二学期会换一副面目回来。

**沉默值与结局。** 每条线三档结局按沉默值区间判定（如湖边：真话档 0–10 / 转述档 11–24 / 沉默档 25+），区间从 0 起无缝相接。沉默值越低离真话越近，但印象分和被注意值各有各的算法——四个数值不会一起变好，这正是这份剧情题眼所在。

**好感怎么读。** 四档：点头之交（0）/ 饭搭子（25）/ 树洞（55）/ 真心蛙友（85）。到树洞档，那只蛙开始讲树洞番外；到真心蛙友档、且听过对应那篇树洞之后，专属番外解锁——十二篇番外都是这么一篇篇接出来的。

**深夜与约谈。** 平日夜按晚放出深夜事件，不强制、错过不回头；期末约谈有被注意值门槛——被盯上的次数攒够了，约谈才找上门。

**多周目。** 第二学期蛙还记得你：146 处回响选项换一副面目回来，档案多出补记；第三学期连记得也免了——免检批注与补记并列不替换。毕业证按学期累计，成绩单引用当学期的沉默值、印象分与图鉴、岔路册完成度。

## 技术栈

- **前端**：React 19 + TypeScript + Vite 8 + Tailwind CSS 3 + shadcn/ui 风格组件 + React Router 7
- **后端**：无。纯静态单页应用——剧本、演出、存档、音频全部在浏览器本地，不请求任何外部服务
- **导出**：`html-to-image`（存图）、`jszip`
- **音频**：全部曲目在浏览器本地现场合成（`src/lib/bgm.ts`，17 首曲目、多基调弹法、隐藏安可曲），无音频文件
- **存档**：localStorage（`src/lib/gameSave.ts`）+ JSON 文件导入导出（`src/lib/backup.ts`）

## 快速开始

要求 Node.js 20.19+ 或 22.12+。

```bash
npm install       # 或 pnpm install
npm run dev       # 开发服务器（默认 http://127.0.0.1:5173）
npm run build     # tsc -b && vite build（类型检查含在内），产物在 dist/
npm run preview   # 本地预览 dist/ 产物
npm run lint      # ESLint
npm run typecheck # 仅类型检查
```

部署：把 `dist/` 整个目录丢到任意静态托管（nginx / GitHub Pages / 对象存储）即可，无需 Node 运行时、无需数据库、无需环境变量。

子路径部署：`npm run build -- --base=/your-subpath/`，路由 basename 与 Service Worker 注册路径会同步跟随。

## 剧本改动的固定管线

改了 `src/data/**` 的剧本内容后，按顺序重跑：

```bash
npm run export:renpy    # 刷新中间格式
npm run pipeline:text   # 刷新本地化与配音表
npm run verify:renpy    # 结构机检（死行 / 环 / 结局区间）
npm run gen:renpy       # 重新生成 Ren'Py 工程
npm run verify:demo     # 演示档口径（结构链 + 时长）
```

## 存档与设置

存档全部走本地（`src/lib/gameSave.ts`，localStorage），跨设备转移用设置里的「档案转移」导出 / 导入 JSON 文件（`backup.ts`）。设置含主题、文本缩放、行距、减少动效、BGM 开关与音量、连播等；结局收藏、页边批注、纪念册、念回留痕等跨周目进度都在设置里持久化。
