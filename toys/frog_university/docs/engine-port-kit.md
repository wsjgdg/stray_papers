# 可迁移工程包 —— 把这套故事搬去别的引擎

写给打算把《奶蛙大学》搬到另一个引擎（Ren'Py、自研对话解释器、纯文本工具、或任何「读数据讲故事」的宿主）的写作者与开发者。

本包只描述**数据与规则**：台词行、选项、结局、数值口径、收集清单、写作纪律。画面、音频、存档这些「壳」见 §7——它们不在搬迁范围内。正文全部使用引擎无关的说法；个别地方用「本项目当前实现」的口吻补一句出处，方便对照，不构成依赖。

数字说明：本文所有统计数字（幕数、节点数、区间、满值）均从剧本数据实测得出，逐条可与源数据核对（核对方法见 §6）。

## 时间线备注

以下为统计时点说明，仅此一节，正文不重复。这部剧本先后经过四轮结构迭代：日常文本按纪实标准整体改写 → 三档结局按「狠法」重写 → 关键选项升级为真分岔（带收束语）→ 加入二周目回响与记忆锚点；其后是多轮表情差分标注与各线场景尾部扩写，以及九轮「表现层垂直切片」（宿舍线、图书馆线、食堂线、社团线、操场线、自习楼线、行政楼线、教学楼线、湖边线）：切片只加演出字段（背景/音效/配乐/姿势/片头片尾/成就），台词行、选项、分岔、结局、数值口径零改动。本文描述的是**最终落盘状态**（2026-09 统计）。

## §0 一句话定位与适用范围

**这是一部校园题材 galgame 的剧情数据包**：九条线、18 幕、123 场、822 条台词行、132 个选项、27 个结局，外加一套与文本完全解耦的数值口径（沉默值 / 真话点数 / 表演分）和六类收集清单。所有内容以「带 id 的纯数据」存在，不含任何渲染代码。

**值得搬的场景**

- 把同一套故事移植到另一个对话引擎（Ren'Py 工程、自制脚本解释器、剧本朗读器、纯文本小说化改编）；
- 保留故事、只换外壳（换立绘、换数值显示、换平台）；
- 做二次创作（同世界观续写、改编、评述），需要一份「事实口径」而不是靠玩一遍来回忆。

**不值得搬的场景**

- 只想要一套「校园 galgame 模板」——本包的批判落点、梗的用法、数值语义都长在「这个学期」这个故事上，抽掉故事只剩空壳；
- 只想要视觉资源——那部分在 §7，且明确不建议搬。

**规模一览**（实测）：九条剧情线 / 18 幕 / 123 场景 / 822 条台词行 / 132 个选项（其中 54 个构成 18 处真分岔）/ 71 条二周目回响 / 16 段记忆锚点 / 27 个结局（另有 1 个全收集限定的「未编目」页）/ 54 张定格画（含 9 张线级结局定格，不进收集册；收集册分母 45）/ 33 首配乐 / 11 个深夜事件 / 12 段白日小事件 / 5 场共通日程 / 28 条校园公告 / 7 只蛙 / 63 句真话罐文案。演出层另有九条切片线的专属资产：宿舍线（《熄灯之后》切片一）5 张舞台背景（含断电差分）、10 个合成音效、3 种立绘姿势差分、1 套查寝装备差分；图书馆线（《卷王养成计划》切片二）4 张舞台背景（含「更深」时段差分）、3 个合成音效（另复用 1 个既有音效）、5 处姿势差分；食堂线（《已老实食堂》切片三）3 张舞台背景（昼/夜/打烊同机位三态差分——本片验证的是管线画白天场景的能力）、3 个合成音效、5 处姿势差分；社团线（《抽象社团招新》切片四）5 张舞台背景（含全剧唯一一张户外场景）、4 个合成音效（3 个新增 + 1 个复用快门）、5 处姿势差分；操场线（《躺在草坪上思考蛙生》切片五）3 张舞台背景（两个机位 + 一张同机位夜差分——本片给立绘加了第四种姿势「躺」，躺平线的招牌）、3 个合成音效、6 处姿势差分（含全剧第一次躺）；自习楼线（《上岸第一剑》切片六）4 张舞台背景（含储物柜区半开一格的近景机位——「一天之内的完整夜」，与图书馆构成凌晨双联）、3 个合成音效（另复用 2 个既有音效）、5 处姿势差分；行政楼线（《最终解释权》切片七）3 张舞台背景（窗口/加班夜/深夜收工同机位差分——「她伸手关了一半的灯」正是差分动作）、3 个合成音效、5 处姿势差分；教学楼线（《开学第一课》切片八）3 张舞台背景（楼前/大教室/散场走廊——全剧最短的一条线，但它是开头：第一张规划表、第一个「我等」）、3 个合成音效、5 处姿势差分；湖边线（《蛙生的意义》切片终章）3 张舞台背景（同机位三态：开场/夜深/天将亮——月亮往湖心挪、玉米桶见底、天光里只剩一扇灯）、3 个合成音效、5 处姿势差分（全用既有四档，这一晚没人躺——梗密度全场最低的线，表现层也最克制）；九线各 1 段片头与 1 段片尾定格、合计 19 个可解锁档案成就（带发布平台映射预留）。片头/片尾文案按线查表，新线接入时补键。

**数据在哪里**（本项目当前实现，一句带过）：剧本正文按线拆成九个数据文件（`src/data/scripts/`，文件名前缀即线缩写：fc / rk / cn / cb / fl / lk / zz / xg / ss），元信息与类型定义在 `src/data/storylines.ts` 并聚合导出为注册表；定格画、深夜事件、共通日程、二周目记忆开场、天气旁白各有独立注册表。搬迁时按 §1 的字段语义逐层导出即可，不依赖任何渲染代码。

## §1 剧本数据模型

### 1.0 层级总览

```
剧情线 Storyline
 └─ 幕 Act（每线 1–3 幕）
     └─ 场景 Scene
         ├─ 台词行 DialogueLine（0..n 条）
         └─ 选项 Choice（0..1 组，每幕合计 2–3 个）
 └─ 结局 Ending（每线固定 3 档）
 └─ 记忆锚点段 Resonance（0..2 处，二周目才插入）
```

### 1.1 线元信息（StorylineMeta）

| 字段 | 含义 | 引擎无关落点建议 |
|---|---|---|
| `id` | 全局唯一。九条线：`first-class` / `roll-king` / `canteen` / `club` / `lawn` / `lake` / `self-study` / `administration` / `lights-out` | 目标引擎里作顶层 label 名或目录名 |
| `title` / `shortTitle` | 完整线名（如《开学第一课》）与地图气泡短名 | 配置表两列 |
| `building` | 关联建筑（教学楼/图书馆/食堂/操场/社团活动中心/湖边/自习楼/行政楼/宿舍楼） | 地图跳转目标 |
| `intro` | 一句话简介，地图悬浮与剧情卡共用 | 悬浮层文案 |
| `memeLevel` | 梗浓度星级 1–5。决定该线的行文密度（湖边最低 = 2，梗几乎不出场） | 仅供续写参考，不进引擎逻辑 |
| `actCount` | 幕数，与实际幕列表长度一致 | 断言用 |
| `castIds` | 出场蛙 id 列表。这是数值系统的事实来源：「全体受益」类选项的受益范围 = 本列表里的 NPC | 存进角色注册表 |
| `hidden` | 湖边线为隐藏线：其余八条常规线全部完成后才开放，且不计入进度分母 | `if 常规线全通` gate |

### 1.2 台词行（DialogueLine）

| 字段 | 含义 | 落点建议（Ren'Py 通用说法） |
|---|---|---|
| `id` | 全局唯一，格式「线缩写-l序号」（如 `fc-l1`）。选项学期档案、已读记录、定格画绑定、锚点定位都以它为键 | 保留原值作 label / 行注释，**不要重排** |
| `speakerId` | 说话蛙；旁白与系统口吻用 `narration` | `Character` 定义 + narrator |
| `text` | 台词正文 | `Character` 对白 |
| `innerVoice` | 主角内心吐槽（可选），显示在台词下方小字。**text 为空串且 innerVoice 非空 = 一行纯内心独白** | narrator 行 / 缩进斜体样式 |
| `heart` | 真心话节点标记。剧本文件内**不手写**——真心话由引擎在运行时按好感阈值插入（见 1.6），插入的节点由引擎打上此标记供回想徽标使用。当前剧本正文中该字段出现 0 次，属正常 | 自定义属性 + 回想徽标 |
| `merge` | 播放流跳转：本行播完跳到该节点 id。用于分支段落末尾回到主线；缺省 = 顺序推进 | `jump` 到目标 label |
| `remember` | 二周目插入节点标记（回响 / 锚点段 / 档案补记由引擎在插入节点上打标，剧本不手写），播放界面显示「上学期」徽标 | 自定义属性 + 徽标 |
| `cg` | 定格画 id：本行展示时全屏定格淡入。纯演出、零数值语义，注册表见 1.8 | `show` CG 层 + 过渡 |
| `expression` | 表情差分：本行说话蛙的表情，8 档枚举（见 1.7）。旁白行忽略；不标 = 引擎按数值自动选 | `show sprite` 换表情 |
| `bg` | 舞台背景差分：本行的背景场景 id（如 `bg-dorm-corridor-out` = 走廊·断电后）。**背景是 sticky 的**——行没标 bg 时沿用本线最近一次的 bg（视觉小说标准行为，分支段与锚点段不闪跳）；本线从头到尾没标过 bg 才回落到该线所属建筑的场景背景。当前宿舍线 12 处、图书馆线 5 处、食堂线 3 处、社团线 6 处、操场线 4 处、自习楼线 4 处、行政楼线 3 处、教学楼线 3 处、湖边线 3 处逐行标注 | `show bg` 换景 |
| `se` | 音效：本行展示时播一次的合成音效 id（宿舍线 10 个：敲门/翻页/电闸咔哒/脚步/水滴/帘子/撕纸/应急灯嗡/秒针/杯子；图书馆线 5 处：合笔咔哒/保温杯拧开/闭馆铃/快门/翻页；食堂线 3 处：勺背刮锅沿/餐盘落台/铁门锁扣；社团线 4 处：气球爆/激光笔/快门/开关灯灭；操场线 3 处：草被压/汽水开瓶/手机静音震；自习楼线 5 处：翻页（复用）/储物柜铁门/笔尖沙沙/接水声/秒针（复用）；行政楼线 3 处：盖章钝响/打印机/钥匙串；教学楼线 3 处：撕海报/掌声/椅子拖过地；湖边线 3 处：湖水拍岸/手机摞石头/拨火）。同一行重复推进不重播 | `play sound` |
| `bgm` | 行级配乐覆盖：本行起切换的曲目 id，优先级高于「舞台背景推导」与「线自带基调」（见 4.6 场景映射）。当前宿舍线 2 处（夜谈 / 天亮）、图书馆线 2 处（凌晨之后 / 公示栏前）、食堂线 2 处（深夜窗口 / 打烊之后）、社团线 2 处（保持微笑 / 没人回去开）、操场线 2 处（辩完了 / 夜风把草坪吹凉了）、自习楼线 2 处（天从橘色褪成灰蓝 / 前后三秒）、行政楼线 2 处（那一格灯 / 改到手指自己会动）、教学楼线 2 处（青春风采 / 我等）、湖边线 2 处（都放下了 / 散场没有仪式） | `play music` |
| `pose` | 立绘姿势差分：`stand`（零差分）/ `lean`（前倾）/ `hold`（双臂环抱）/ `lie`（平躺，操场线专用），只作用于本行说话蛙；不标 = stand | sprite 属性 |
| `voice` | 语音脚本标记（P3 占位）：本行对应的语音条目名（缺省 = 行 id 本身）。当前不渲染——发布时按全剧本的 voice 清单生成录制顺序，分轨按蛙组织；播放器取音失败静默跳过，不阻塞文本推进。全语音与否由 Demo 验证后决定 | 发布清单生成 |
| `idle`（选项字段） | 沉默等待（批次 V）：选项浮层 30 秒无操作 → 自动走这个隐藏分支。无倒计时、无提示；被注意值 +1（不说话也被记一笔「沉默不语」）。只在个别关键节点配置（当前 2 处：教学线第一张表、湖边意义之问），玩家设置里可关。搬迁时保留「无提示」原则——提示一出，机制就死了 | 自定义 idle 分支 |
| `gear` | 服装差分：布尔。为真时本行说话蛙整只换成查寝装备版立绘（手电 + 签到板 + 查寝工牌；当前仅格格有此预设，其他蛙缺省不换） | sprite 属性 |

### 1.3 选项（Choice）

| 字段 | 含义 | 落点建议 |
|---|---|---|
| `id` | 全局唯一，格式「线缩写-c幕序+支序」（如 `fc-c2b`）。存档用它组成四段 key「线:幕:场:选项」（见 1.9） | label 命名规范 |
| `text` | 选项文案。写作纪律：先好笑，后扎心（§5） | `menu:` 条目 |
| `silenceDelta` | 沉默值增量。+1~+3：越「识时务」加分越高；`0` = 真话出口；−1/−2 = 少数「直接说破」的选项（全剧本共 6 个负值） | `default silence += N` |
| `affinityTarget` | 好感受益蛙；`"all"` = 本线 `castIds` 里的全体 NPC | `default aff[x] += N` |
| `affinityDelta` | 好感变化量 +2~+5；每线恰有 1 个 `−2` 的「代价选项」（两种：沉默 0 的真话出口，或表演型收场——都拿关系换出口，见 §3.2） | 同上 |
| `branch` | 真分岔：选中后播放流跳到该节点 id（分支段落首节点）。**同一场景若出现分岔，则该场景全部选项都必须带 `branch`**——其中直接汇流的选项 `branch` 指向汇流场景首节点 | `jump` |
| `echo` | 二周目回响台词 `{ text, speakerId, innerVoice? }`。`speakerId` 必须是该选项场景里在场的蛙或旁白；纯叙事、不改任何数值 | `if 周目≥2 且此前学期选过本项: call echo` |
| `coda` | 岔路收束语：本学期走过这条支路时，结局卡追加的一行（纯叙事，对三档结局都成立）。只允许出现在分岔选项上 | 结局卡追加行 |

### 1.4 幕与场景（Act / Scene）

| 字段 | 含义 | 落点建议 |
|---|---|---|
| `Scene.id` | 「线缩写-s序号」；真分岔的分支段场景以 `-b1/-b2/-b3` 后缀命名。分支段**不嵌套选项、不带 heart**，末行必有 `merge` 回主线 | 一组 label |
| `Scene.lines` / `choices` | 台词行列表；场景收尾的选项（每幕合计 2–3 个，全剧本无超过 3 选项的场景） | label + `menu` |
| `Act.id` / `index` / `title` / `scenes` | 幕 id（「线缩写-a序号」）、幕序（1 起）、幕名、场景列表 | label 命名空间 |
| `Act.quote` / `quoteBy` | 幕尾「蛙言蛙语」：本幕金句与出处蛙（或旁白）。每线 1–3 条、八线合计 16 条 | 结算卡数据 |

### 1.5 结局（Ending）

| 字段 | 含义 | 落点建议 |
|---|---|---|
| `id` / `title` / `text` | 结局 id（线缩写-e档序，如 `fc-e3`）/ 标题 / 结局正文（约两百字，收刀落在一个具体动作上，见 §5） | label |
| `minSilence` / `maxSilence` | 命中该结局的沉默值区间，闭区间；`maxSilence` 可缺省 = 无上限。每线三档必须连续覆盖 0 到最大值（核对项见 §6） | `if/elif` 分档 |
| `plus` | 二周目专属尾段（档案补记）：周目 ≥ 2 时追加在结局卡。写法要求「不管玩家上一学期开不开口都成立」 | `if 周目≥2` 追加 |
| `thirdNote` | 三周目免检批注：周目 ≥ 3 时在 `plus` 之下追加。档案腔、25-45 字、比补记更干燥——「连『记得』这道手续也按惯例免了」。全剧本 51 条 = 27 结局 + 未编目 1 + 深夜事件 11 + 白日小事件 12，写法纪律见 §3.6 | `if 周目≥3` 追加 |
| `endingCg` | 线级结局定格（线元信息层，非每档结局）：线完结时的收尾定格画 id。不进收集册、不计收集分母；当前配置九条（全部剧情线）：宿舍线「天亮之后」、图书馆线「十七扇窗」、食堂线「最后一盏灯」、社团线「没人回去开」、操场线「合唱」、自习楼线「不敢拆的答案」、行政楼线「最终解释权」、教学楼线「还是那张表」、湖边线「只剩湖」 | ED 卡 + `show` CG |

**判定规则**（引擎无关）：线完结时取当前**累计沉默值**（口径见 §3.1），与该线三档区间按序比对，取第一条命中的结局；全部未命中时兜底最后一档。24 个结局全部带 `plus`；隐藏「未编目」页（§4.2）不写区间、由「全收集」派生。

### 1.6 运行时插入段（数据不在剧本行里）

以下段落在**播放流合成**时插入，剧本数据里只有触发条件与文案。这是本模型里最容易漏搬的部分——它们不属于任何剧本行。

| 插入段 | 数据 | 触发条件 | 插入位置 |
|---|---|---|---|
| 蛙记得你（二周目记忆开场） | 每线 1–2 句、九线合计 18 句，注册表按线全键必填 | 周目 ≥ 2 | 该线第一个节点之前 |
| 天气旁白 | 通用池每天气 2 个变体 + 湖边（雨/雾）、操场（雨）、自习楼（雨）专属变体 | 每次进线 | 记忆开场之后、正片之前 |
| 真心话 | 每只 NPC 一组真心话包：摘面具旁白 1 句 + 真话 4 句 + 主角反应 2 句（6 只 NPC 全配） | 该蛙坦诚度**跨过** 40 / 80 档的瞬间；每蛙每档只触发一次 | 选项之后；40 档播前两句、80 档播后两句 |
| 二周目回响 | 选项上的 `echo` 字段 | 周目 ≥ 2 且该选项的首次选择学期**早于**当前学期（学期档案缺失视为「更早学期」——旧档升级后第一次重选即触发） | 选项之后、真心话之前 |
| 记忆锚点段 | 每处 3 句，挂在其后插入的行 id（`afterId`）上 | 周目 ≥ 2 | 锚点行之后；锚点必须在线性主推进路径上、不带 `merge`、非 heart |
| 湖边微调 | 最高坦诚度蛙的替换句（湖边第 3–6 行各 1 句）+ 尾部附加句 1 句 | 湖边线 | 对应行原位替换 + 尾部追加 |
| 湖边路线台词 | 本学期认定蛙的专属台词（六组，共 8 句） | 湖边线且本学期已完成路线认定 | 微调之后、锚点 `lk-l7` 之前 |
| 全员真话收束段 | 7 句固定段（两句旁白 + 四只原班蛙 + 主角内心） | **所有**能赚真话分的 NPC（六只）坦诚度全部 ≥ 85 | 湖边夜谈最后 |

**播放流合成顺序**（引擎无关约定）：前缀层 = 二周目记忆开场（若有）→ 天气旁白；正片层按剧本顺序推进；插入点顺序固定为 **选项 → 回响 → 真心话 → 分支段落 → 汇流**。回响只有在不排队真心话时才携带跳转，否则顺序落入插入段。本项目当前实现的原则是「插不进就跳过、不崩」，搬迁时建议保留这一条。

### 1.7 表情差分

8 档枚举：`laugh` / `smile` / `frozen` / `silent`（沉默值侧四档）+ `soft` / `blush` / `teary` / `sparkle`（关系侧四档，不进数值口径）。

选取优先级（引擎无关）：

1. 行内 `expression` 标注（全剧本 175 处，旁白行 0 处生效）；
2. 主角按沉默值自动选：0 → 笑 / 1–2 → 微笑 / 3–4 → 僵住 / 5+ → 沉默；
3. NPC 按坦诚度档位单调映射：85+ → 眉眼放松 / 55+ → 微笑 / 25+ → 保持预设默认 / 其余 → 僵住。

### 1.8 外围数据模型

- **角色与真心话包**：七只蛙（主角 + 六只 NPC）。每只 NPC 一组真心话包 `{ 摘面具旁白, 真话 4 句, 主角反应 2 句 }`；关系称呼四档阈值 0 / 25 / 55 / 85（§3.2）。
- **深夜事件**：11 个 = 平日夜池 7 个 + 期末特别夜池 4 个（完成常规线 ≥ 4 后整个池子替换为期末池；其中《约谈》还需被注意值 ≥ 8 才进池，见 §3.7）。每个事件可带 `bgId`（舞台背景 id，批次 S 全部配置）——弹层按它渲染真实舞台背景，配乐按同表取「同地点同曲」。每个事件 = 3 个节点 + 1 个选项（±1 / 0；《约谈》为三支选项）+ 二周目档案补记 2 条 + 三周目免检批注 1 条。每晚最多触发一次，按日历日记录已看。
- **白日小事件「校园角落」**：12 个（水杯阵 / 饭卡 / 换到一半的灯 / 排队的机器 / 退社申请表 / 转专业的窗口 / 手写的通知 / 湖边扣着的书 / 回收带上那只盘 / 单杠前的线 / 伞桶里那把伞 / 代收件）。每个 = 3 个节点 + 1 个选项（±1 / 0）+ 二周目补记 2 条 + 三周目批注 1 条。触发窗口第 2–7 天、每天最多一个、按局洗牌（深夜事件同一套种子）；回图自动弹出（共通日程优先）；已看记录跨周目保留，不进图鉴、不算收集分母。
- **共通日程**：6 个里程碑场景（第 1 / 2 / 4 / 5 / 7 / 8 天；第 3、6 天是普通日不出场景——批次 T 起第 1 天「宿舍钥匙」开场，灰灰在共通线首次登场）。每场可带 `plus`（批次 U：二周目回响 1–2 条，周目 ≥ 2 时追加为「上学期」节点）。每场 3–4 个节点 + 0–1 个选项；第 5 天是「路线认定」gate 场景，播完直接进认定表而不是普通选项（§3.5）。
- **定格画注册表**：每张 = id / 标题 / 一句话图注 / 出处线 / 绑定行（1–3 条台词行 id）。注册表与剧本行的 `cg` 字段**双向呼应**（§6 核对项）。全 45 张，合计 61 处行绑定；另有 9 幅线级结局定格（`cg-dawn-dorm` / `cg-17-windows` / `cg-lamp-off` / `cg-ten-minutes` / `cg-chorus` / `cg-locked-answer` / `cg-final-clause` / `cg-same-sheet` / `cg-only-the-lake`）单列、不进注册表绑定核对（见 4.5）。
- **二周目记忆开场**：按线组织的注册表，新增线必须同步补全键（§6）。
- **天气旁白**：通用池 + 「线 × 天气」专属变体；按天确定性轮换（同一存档同一天恒定同一种天气）。
- **真话罐**：不是注册表，是**派生清单**——由 `silenceDelta ≤ 0` 的选项文案自动收进（见 §3.4）。

## §3 数值口径

四个数值（沉默值 / 真话点数 / 表演分 / 被注意值）来自**同一次选择**，方向却可以互相矛盾——这是全剧的产品语义，搬迁时不要拆成四个独立面板。

### 3.1 沉默值

- **选项分布**（132 个实测）：+1 × 36、+2 × 29、+3 × 22、0 × 38、−1 × 4、−2 × 3。加值越大越「识时务」——越配合表演，内心越沉默；`0` 是真话出口；负值是直接说破（共 9 个）。
- **累计口径**：沉默值**按学期累计、跨线不清零**，下限钳制在 0（真话选项把累计值往下压，压到底就是 0）。这是本项目当前实现的口径；若目标引擎改成「每线独立计」，必须同步重排各线三档区间，否则区间语义会整体漂移。
- **结局判定**：见 1.5。各线三档区间：

| 线 | 低档 | 中档 | 高档 |
|---|---|---|---|
| 八条常规线（第一课 / 卷王 / 食堂 / 招新 / 草坪 / 自习楼 / 行政楼 / 宿舍楼） | 0–4 | 5–12 | 13+ |
| 蛙生的意义（隐藏线，全篇累计） | 0–10 | 11–24 | 25+ |

- **表情映射**（演出层，可搬可不搬）：0 → 笑 / 1–2 → 微笑 / 3–4 → 僵住 / 5+ → 沉默（与结局分档无关）。
- **确认反馈**（演出层）：增量 ≥ 3 的选项确认时舞台轻晃约 120ms。
- 深夜事件、白日小事件与共通日程的选项同样计入沉默值（±1 / 0），且 ≤ 0 的文案会进真话罐（§3.4）；同时按被注意值规则记账（§3.7）。

### 3.7 被注意值

- **规则**：真话出口与说破（`silenceDelta ≤ 0`）记 **+1**；表演（`silenceDelta ≥ 2`）记 **−1**（下限 0、无上限）；`+1` 不变。正片、深夜事件、白日小事件、共通日程同规则。
- **口径**：按学期累计，开新学期清零；旧档缺字段补 0。沉默值记录你被驯化了多少，被注意值记录你**被盯上了**多少——说真话的代价不只是沉默，是上名单。
- **不进结局分档**：沉默值仍是唯一分档依据；被注意值是平行记录。
- **展示三档**（0–2 / 3–7 / 8+）：结局卡「档案注意记录」一行；毕业证学籍备注（0–7「无异常记录」/ 8+「重点关注名单在列」）；地图页 8+ 常显一行名单提示。
- **门槛事件**：期末周且被注意值 ≥ 8 时，期末深夜池追加《约谈》（`night-talk`）——桌上按日期排好的摘录，就是你说过的真话；三支选项（0 / +1 / −1），两支 ≤ 0 进真话罐。

### 3.2 真话点数与坦诚度

- 存的是每只蛙的「真话点数」，界面换算成 0–100 的**坦诚度 = 点数 ÷ 该蛙满值 × 100**（四舍五入）。
- **满值 = 该蛙在全部正片剧本里能赚到的正分之和**（按剧本自动统计，改剧本不用改口径）。实测满值：

| 蛙 | 满值 | 构成 |
|---|---|---|
| 奶白（主角） | 72 | 38 个沉默 0 的真话出口，每个 +2 |
| 抹抹 | 19 | 图书馆线 13 + 湖边 6 |
| 莓莓 | 21 | 社团线 11 + 湖边 10 |
| 灰灰 | 30 | 操场线 11 + 湖边 6 + 宿舍楼线 13 |
| 干饭叔 | 26 | 教学线 7 + 食堂线 13 + 湖边 6 |
| 再再 | 12 | 自习楼线 |
| 格格 | 18 | 行政楼线 15 + 宿舍楼线 3 |

- **关键选项 38 个**（带 `affinityTarget`）：指向具体蛙或 `all`（3 个，全在湖边线，受益全体出场蛙）。正分分布：+2 × 4、+3 × 7、+4 × 11、+5 × 7（合计 29 个正分选项）。
- **代价选项 9 个**（`affinityDelta = −2`，每线恰 1 个）：四条线（卷王 / 自习楼 / 行政楼 / 宿舍楼）的是沉默 0 的真话出口，其余是表演型收场——两种都以关系代价换「把话送出去」。这是数值设计里最重要的一条不对称：**说真话不加分反而扣关系**。
- **关系称呼四档**：点头之交 0+ / 饭搭子 25+ / 树洞 55+ / 真心蛙友 85+。
- **真心话触发**：某蛙坦诚度**跨过** 40 或 80 档的瞬间排队播放（每蛙每档一次，不重复）。40 档播真心话包前两句、80 档播后两句；每次插入 4 个节点（摘面具旁白 + 两句真话 + 主角反应），由引擎合成、不占剧本行。
- **全员真话收束段**：所有能赚真话分的 NPC（六只，含再再与格格）坦诚度全部 ≥ 85 时，湖边夜谈最后追加 7 句固定段。判定只看百分比是否 ≥ 85，不看称呼档位的名字。

### 3.3 印象分（表演分）

- 沉默增量 ≥ 2 的选项记为「表演」，分值 = 该增量；**表演分满值 = 全剧本表演选项分值之和（实测 124）**。
- **印象分 = 表演分 ÷ 满值 × 100**（四舍五入，与坦诚度同口径）。
- **五档称号**：查无此蛙 0+ / 眼熟 25+ / 靠谱 50+ / 明星蛙 75+ / 模板 95+。
- 结局卡按印象分档追加**公示栏评语**（区间严格对照，评语为项目原文，可直接搬）：

| 印象分 | 公示栏评语 |
|---|---|
| 不足 25 | 该蛙存在感较低，建议多参加集体活动 |
| 25–49 | 表现平稳，未给集体添麻烦 |
| 50–74 | 积极性高，情绪稳定，值得信任 |
| 75–94 | 同学学习的榜样，多次活动照片入选 |
| 95 及以上 | 该生表现完美，作为模板供后续参考 |

### 3.4 真话罐

- 口径：`silenceDelta ≤ 0` 的选项文案自动收进罐子（按文案幂等去重、跨周目保留）。
- **全集 63 句**（实测，零文案重合）= 正片 45 句（第一课 3 / 卷王 7 / 食堂 4 / 招新 9 / 草坪 4 / 湖边 3 / 自习楼 6 / 行政楼 6 / 宿舍楼 3）+ 深夜事件 9 句 + 共通日程 3 句 + 白日小事件 6 句。
- **「集齐」判定只按正片 45 句**口径；集齐后解锁隐藏「未编目」页（§4.2）。深夜与日程的真话在图鉴里归入「散落的真话」组，不计入集齐判定。

### 3.5 校园日历与共通日程

- **天数 = 完成常规线数 + 1**（开学第一天 = 第 1 天）。天数不落盘，随时可由进度派生。
- **里程碑**：第 2 天「横幅换了」/ 第 4 天「期中 · 各就各位」/ 第 5 天「期末周 · 意向表」（gate）/ 第 7 天「倒数第二天 · 清书仪式」/ 第 8 天「湖边的请柬」。第 3、6 天是普通日。
- **期末周**：完成 ≥ 4 条常规线后进入——天色偏暗、深夜事件池整体替换为期末池、地图配乐换曲。
- **路线认定（第 5 天）**：六只 NPC 按坦诚度降序取前三只上表，追加固定一项「先不填，再看看」（提示文案：这一栏今天先空着。空着不算违纪。）；若全员坦诚度为 0，额外追加一项「就写排在第一位的」。选中后二次确认 → 播放该蛙的即时反应（六组共 17 句）→ **一次锁定、本学期不改**（存档层兜底，重复认定是空操作）。锁定蛙在湖边夜谈有专属台词（六组共 8 句），毕业证上有一行专属批注。
- **天气**：晴 / 阴 / 雨 / 雾 / 风 5 种，基准权重 24 / 20 / 28 / 14 / 14，按天确定性轮换（同一存档同一天永远是同一种天气，好让回响与补记引用稳定）。天气种子随存档携带，**开新档时随机重摇——每局一套天气序列 + 一种「天气性格」**（性格把某一种天气的权重 +12，这一局的雨可能特别多、也可能老是阴着）；旧档（无种子字段）沿用旧版固定序列，不闪变。
- **今日公告**：28 条（常规 20 + 期末 8），按「种子 × 天数」派生，同一局同一天恒定、不同局序列不同；期末周整池替换（与深夜事件、天色的换法一致）。

### 3.6 二周目与三周目

**二周目（周目 ≥ 2）**：

- **数值全部从零开始**（沉默值、好感、印象分）。蛙「记得你」只体现在台词层。
- **开场**：进线先播「蛙记得你」（九线合计 18 句，各线 1–2 句），再播天气旁白。
- **回响**：见 1.6。回响不改任何数值。
- **记忆锚点段**：16 处（每处 3 句），周目 ≥ 2 时插在锚点行之后。锚点纪律见 §5。
- **档案补记**：27 个结局全部带 `plus`；10 个深夜事件各带 2 条补记；「未编目」页也有 `plus`。补记写法要求「不管玩家开不开口都成立」。
- **收集品跨周目保留**：结局图鉴、真话罐、深夜事件、定格画、选项学期档案。共通日程与路线认定是「进行时」，随学期重开。
- **湖边例外**：湖边第 24 行（`lk-l24`）及其后的结构不许动——好感微调、路线台词、全员收束段都锚在这一带；要加分岔只能加在它之前。

## §5 引擎无关的写作纪律

以下纪律是这部剧本多年迭代沉淀下来的，与引擎无关；搬迁或续写时建议原样保留。每条给原则与反例。

1. **纪实优先，寓言减量。** 文本按纪实标准写：不解释、不总结、不卖萌；狠感来自具体的灯、纸、电话、勺子。反例：把「图书馆」写成「知识的海洋」，把「打饭窗口」写成「命运的分配台」——一旦出现比喻性升华，纪实感就漏气。
2. **每线 ≥ 5 处「具体到心里一紧」的现实细节。** 细节必须能被核对：准确到数量、时刻、物件上的字。反例：「他付出了很多」「她其实很努力」——不可核对的细节等于没有。
3. **梗当刀用。** 热梗不是贴纸，必须有一句台词把它解剖开；解剖句要幼稚与成熟混着用——让蛙先用梗说话，再用一句清醒的话把梗拆穿。反例：把网络流行语原样贴在台词里当笑点。
4. **人物去金句化。** 金句全留给最痛的时刻：一条线最多 2 句、出现即收刀；幕尾「蛙言蛙语」是存量金句的官方位置，其余正文不许再攒金句。反例：每个角色每场都留一句格言式总结。
5. **结局三档狠法。** 三档都不是安慰：低档没收出口（你的清醒不是免疫力，只是还没轮到你）；中档写循环接手（下一位坐进同一个位置）；高档写你成了系统本身、或回到开头那个物件上。**每一档结局必须引用本线正文里的具体道具**；最高沉默档不许用比喻糊过去，要落在一个具体动作上——多年后你也会做的那个动作。
6. **不新增分岔的扩写方法。** 给既有场景加戏时：只在场景尾部追加台词行、不动既有行 id、保留每幕 2–3 选项的结构。想要新剧情 → 新线或新深夜事件，不要在既有分岔上加支。
7. **真分岔纪律。** 分岔处每处固定 3 支；同场景全部选项都必须带 `branch`（包括直接汇流的那个）；分支段内不嵌套选项、不带 heart、末行 `merge` 回主线；每支都要有「只有走这条支才能知道的信息」——不能三支写成一个意思的三种说法。
8. **回响纪律。** 回响只写「同一件事第二学期再说一遍时的变化」：更熟练、更疲惫、更客气、或当场拆穿你；不改任何数值。反例：借回响说教、总结上一学期。
9. **锚点纪律。** 锚点在线性主推进路径上（分支段之外）、所在场景无选项、不带 `merge`、非 heart；每处 3 句，写蛙怎么记得你，不写「我们又是一年没见」这类空话。
10. **收束语纪律。** 一行 20–40 字，写「这条支路把事情变成了什么」，对三档结局都成立（它挂在支路上，不是挂在某档结局上）；每处分岔 3 支各 1 条，非分岔选项不配。
11. **id 纪律。** 台词行 / 选项 / 场景 / 幕 / 结局 id 用所在线缩写前缀、顺延编号、全局唯一；存档 key 用「线:幕:场:选项」四段。新内容不允许改写既有 id（它们被档案、定格画、锚点、图鉴多处引用）。
12. **真话写法。** 沉默 ≤ 0 的选项会自动进真话罐，文案要写得像「能被别人听见的一句话」，不要写成系统提示或玩家自白。
