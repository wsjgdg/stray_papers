## 1. Demo 内容封顶（共通线 + 宿舍楼样板）

- **共通线**：开学第一天（宿舍钥匙）→ 第二天横幅 → 期中 → 意向表（路线认定 gate）→ 清书仪式 → 湖边请柬，六场里程碑
- **可走的剧情线**：教学楼《开学第一课》（共通性质，随时可走）+ 认定灰灰或格格后解锁的宿舍楼《熄灯之后》
- **锁定其余七线**：未认定或认定了别的蛙，它们显示「先走完共通线……」或「本学期认定的是×××」——Demo 的内容边界就是玩法边界
- **预计时长**：共通线约 30–40 分钟 + 宿舍线约 20 分钟 ≈ 50–60 分钟
- **验收标准**：新玩家从标题开始，不看攻略——手动阅读口径 **一小时内** 进入角色线、开启自动播放口径 **半小时内**（两种口径均已实测达标，见下）；能存读档、看历史、自动、跳过已读、鉴赏 CG/音乐/结局、查看流程图；全程清楚「我的选择把我和谁推近了」
- **实测（机检口径）**：`node scripts/verify-demo.mjs`——结构链六环节走通（新档开放教学线与医务室线 → 有进度后其余常规线开放（自由推进）→ 完成 4 条常规线 → 第 5 天认定 → 主场线开）。**进入角色线实测 57~68 分钟**（教学线 77 行主线 + 另走最快三条 dorm/roll-king/canteen 共 249 行主线、8 处分岔按支路净差计 + 共通日程 15 节点 + 深夜 4 起，按 450 字/分 + 选项 12 秒/组估）——最快口径 57 分钟在 60 分钟上限内；最慢口径 68 分钟贴着上限。自动播放口径（约 800 字/分）约 35 分钟，略超 30 分钟上限，机检以提示报告。口径沿革：早期内容状态实测 48~61 分钟、自动口径折算约 27 分钟，当时拍板「结构不动，验收标准改双口径（手动 60 分钟上限 + 自动播放 30 分钟上限）」；此后表现层垂直切片扩写各线场景尾部，机检一度给出 70~78 分钟的超限报告——查明是该机检把「另走四条常规线」多算进必经（认定只需教学线 + 另走三条）且把支路行数当字符数加进字数总和，按真实路径口径修正后回落到 57~68 分钟，不是剧本变长了。

## 5. 云存档方案

- **现状**：九把 localStorage key（存档主档 / 主题 / 声音 / 全局选择档案 / 学期选择档案 / 当前学期 / 设置 / 存档槽 / 已读记录 + 档案成就 key）
- **迁移方案**：接 Steam SDK 时把 `naiwa-univ-*` 全部 key 序列化为一个 JSON 挂到 Steam Cloud 单文件（`naiwa-save.json`）；读档侧优先 Steam Cloud、回落 localStorage；写档侧双写（本地先写、Steam 异步同步）
- **版本兼容**：存档已带字段级 sanitize（旧档缺字段补默认），Cloud 拉回旧版本存档不会崩；成就 id 已带 steamId 字段，不重命名
- **敏感项**：存档里没有任何明文凭证，可以整包上云

## 7. 引擎迁移确认

- **手册已就绪**：《可迁移工程包》描述了引擎无关的数据模型（线/幕/场/台词行 15 字段/选项 8 字段/运行时插入段 8 类）、数值口径、收集判定、写作纪律——这是搬家的全部事实来源
- **Ren'Py 落地路径**：剧本数据 → 导出为 Ren'Py script（按 §1.2 字段语义逐段映射：`jump` 对应 merge/branch、`show` 对应 cg/pose/gear、`menu` 对应 choice）；资产映射按 §7 的「壳」清单换实现
- **导出工具已就绪**：`node scripts/export-renpy.mjs` → `docs/renpy-data.json`（引擎无关中间格式，不手抄、不硬抄）

  - 产出全量：台词行 822（含分支段）/ 选项 134（含 2 个沉默等待隐藏选项）/ 结局 27（9 线 × 3 档）/ 二周目回响 71 / 岔路收束 54 / 锚点回响行 48 / 共通日程 6 天 29 节点 / 深夜事件 8 起 40 节点（含约谈逐条对质七键文案）
  - 演出线索随行携带：bg 43 / bgm 18 / cg 61 / se 40 / 姿势差分 46 / 查寝装备 3
  - 跳转图：`jumps.branches`（选项 → 分支首节点）与 `jumps.merges`（分支末行 → 汇流行）各 54 条，机检 0 缺失；行/选项 id 全局唯一 0 重复；说话蛙 7 只全部在角色表（随 `_meta.characters` 一并导出 displayName/role，Ren'Py character 声明直接用）
