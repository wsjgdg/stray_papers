## 返工管线（P0/P1 不合格的句子）

1. 按标点切分为短段（逗号/破折号/句号）
2. 逐段生成（同渠道同音色）
3. ffmpeg concat 拼接，段间 200-300ms 静音垫
4. 过渡处听感检查（音量/语速一致性）
5. 重新打包：`python make-voice-data.py && python build.py`
