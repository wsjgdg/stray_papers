## 指挥音色随性格切换（ConductorPanel.tsx）
- 用户问「指挥的音色能不能和性格类型对应切换」。结论：可以——浏览器不能合成任意音色，但能在已安装中文 voice 中按人格挑不同 voice（Edge 有 17 个中文 voice，足够分）。
- 实现：
  - 新增 `PERSONA_VOICE: Record<Persona,{gender,names[]}>` 映射（mentor=男/Kangkang 系，buddy=女/Xiaoxiao 系，explorer=男/Yunxi 系，default=任意）。
  - 新增 `pickVoice(persona, voices)`：先按名称子串命中 → 再按性别 token 回退 → 最后退到首个中文 voice；`matchGender()` 用常见中/英 voice 名 token 判断性别。
  - `zhVoice` 由固定「首个 zh voice」改为：`zhVoices`(全中文 voice 列表 state) + `useMemo(() => pickVoice(persona, zhVoices), [persona, zhVoices])`，**人格一变即重算当前音色**。
  - voiceschanged 监听器由 `setZhVoice(find...)` 改为 `setZhVoices(filter...)`。
  - 「朗读」汉堡下拉新增一行「当前音色：<voice.name>（随人格切换）」，让用户看到切换生效。
- 边界：名称/性别都靠已知 voice 名 token 启发式匹配；若本机无对应音色，自动回退首个中文 voice，不报错。需用户本机实测各人格音色是否如预期（不同机器 voice 名不同，可能回退到同一/默认 voice）。
- `npm run build` 通过（EXIT 0）。

## 音色仍全部一样（用户实测：显示 huihui/kangkang/yaoyao/kangkang，但听感四者相同）
- 诊断：显示的名字不同说明 `pickVoice` 确实选了不同 voice 对象；但声音相同 → **Windows 旧 SAPI 中文语音（Huihui/Yaoyao/Kangkang）是同一引擎别名/回退**，尤其 Kangkang 男声在该机未真正渲染、全部回退默认 Huihui。名字不同 ≠ 音色不同。
- 修复：`pickVoice` 改为**优先用神经语音**（名称含 `Online`/`Natural`，如 Xiaoxiao Online / Yunxi Online，才是真分得出音色的），再同性别回退、再首个中文 voice。`isNeural()` + 名称命中按 neural 排序；`PERSONA_VOICE` 名称顺序调整为 Yunxi/Yunyang 优先（mentor→Yunxi，explorer→Yunyang，buddy→Xiaoxiao，三者尽量取不同神经 voice）。
- 边界：若本机只有旧 SAPI 语音而无神经语音，浏览器 TTS 无法区分音色——此时唯一真解是云 TTS（Zhipu/Edge 在线），非 Web Speech 能解决。需用户重启用 `start.cmd` 后复测；若仍相同，要用户 F12 Console 粘贴 `speechSynthesis.getVoices().filter(v=>v.lang.toLowerCase().startsWith('zh')).map(v=>v.name)` 的真实列表以精确绑定。
- `npm run build` 通过（EXIT 0）。
