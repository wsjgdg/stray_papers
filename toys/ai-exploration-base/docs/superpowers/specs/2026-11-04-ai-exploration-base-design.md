# Design: AI Exploration Base (给妈妈的 AI 探索基地)

> Date: 2026-11-04
> Status: Approved (with user modifications applied)
> Audience: 用户的妈妈（退休销售/财务背景，现做保险，手机+电脑都会用，有投资被骗经历，性格：贪财、易被哄骗）

## 1. Goals

让妈妈在一个**多页互动网站**中：

1. 理解 AI 能做什么（用真实 AI 生成的成果说话，精选精要）
2. 看清 AI 趋势与各行业现状
3. 直观感受 AI 的强大（含"儿子的 AI 实验室"——GitHub 实证）
4. 找到适合的副业方向（三层递进：零门槛 → 需学习 → Agent 开发等深度方向）
5. 被引导进行 AI 深度探索（提示词学院、Agent 入门，不止"豆包点按钮"）
6. 深度免疫投资诈骗（针对其性格定制，不是浅层提醒）

**成功标准**：她愿意自己研究怎么打开这个项目；看完后主动打开一个 AI App 做一次真实探索；在骗局模拟器里走完全程。

## 2. Product Shape

- **多页静态站**，零构建、零网络依赖（动效库本地化到 `assets/vendor/`）
- 打包为 zip 交付；从解压到打开网页本身是第一课（"让她自己研究怎么打开"）
- **任务进度系统**：localStorage 打卡，完成板块解锁庆祝动画，集齐解锁"结业证书"
- 手机优先响应式（正文 ≥18px，卡片式布局，触摸友好）；桌面亦可

```
ai-exploration-base/
├── 先读我.txt              # 给她的第一封信（怎么打开、这是什么、怎么探索）
├── index.html              # 启动页：任务地图 + 进度打卡
├── pages/
│   ├── what-ai-can-do.html # ① AI 能做什么（精选成果 + 3小时→3分钟对比）
│   ├── trends.html         # ② AI 趋势与行业现状
│   ├── side-jobs.html      # ③ 副业地图（三层递进）
│   ├── lab.html            # ④ 儿子的 AI 实验室（GitHub 展示）
│   ├── anti-scam.html      # ⑤ 骗局解剖室
│   ├── academy.html        # ⑥ 提示词学院 + Agent 入门
│   └── graduation.html     # ⑦ 结业：行动清单 + 证书
├── assets/
│   ├── css/  js/           # 全站样式与脚本（含任务系统）
│   ├── vendor/             # GSAP(ScrollTrigger,TextPlugin) / canvas-confetti / Chart.js —— 本地化
│   └── media/              # AI 生成的精选素材（图像、海报等）
└── docs/                   # 项目内部文档（spec、plan、进度日志）
```

## 3. Content Design

### ① AI 能做什么（精选精要）
- 开场立意："这个网页本身就是 AI 写的"——以成果自证
- **精选 5-6 个成果卡**（宁精勿多，每个都要有冲击力）：AI 图像生成（对比卡：以前要 3 小时 → 现在 3 分钟）、AI 写一篇小红书文案（打字机实录）、AI 修复老照片、AI 制作海报、AI 写财务报表解读。每卡可展开"它是怎么被做出来的"
- 交互：点击翻转对比卡 + GSAP 滚动渐入

### ② 趋势与行业现状
- 2024-2026 AI 大事记时间线
- 行业 AI 化现状：电商/自媒体/金融/保险/教育（数据用 Chart.js 呈现）
- 结论指向："普通人的机会在哪"——引用可信来源，不编造数据

### ③ 副业地图（三层递进）
| 层级 | 方向 | 特点 |
|---|---|---|
| 新手层（今天就能做） | AI 生成图文发朋友圈/小红书图文带货 | 无需学习，先赢一次 |
| 进阶层（学 1-3 个月） | 保险知识短视频获客（剪映+AI 脚本）、AI 绘图接单、财务知识付费 | 学习路线图+周期+收入预期+风险提示 |
| 深度层（学 3-12 个月） | AI 工作流搭建、**Agent 开发入门**（Python+大模型 API）、AI 数据标注管理 | 技能投资，复利最高；附学习资源清单 |

- 每条副业带风险提示与"因人而异"标注；不编造收入数字，引用可查案例
- 深度层与 ⑥ 学院打通，结尾钩子："等你学完，我们一起做一个 agent"

### ④ 儿子的 AI 实验室（GitHub: wsjgdg）
叙述角度："这些全是 AI 帮我写出来的——你现在看到的这个网站也是。"

选定展示（已核实仓库内容，不编造）：
- **stray_papers**：交互式科学可视化项目集。亮点子项目：
  - `algorithm-lab`（零依赖算法实验室：细胞自动机艺术画布、节拍制作器、算法工作室、霍夫曼编码——**standalone.html 可直接内嵌让她玩**）
  - `schrodinger-workshop`（量子物理交互工作坊）
  - `procedural-3d-fantasy-planet`（程序化 3D 奇幻星球）
  - `particle-life`（粒子生命模拟）
- **score-transcriber**：乐谱识别（Python，"拍张照片 AI 认出乐谱"）
- **matlit-miner**：AI 文献挖掘（"AI 能做科研级工作"）
- **spot-visual**：视觉分析网站

每个配一句话拆解"AI 在里面干了什么"。能内嵌的（algorithm-lab standalone）直接嵌入可玩。

### ⑤ 骗局解剖室（重头戏，针对性格定制）
基调：**不否定想赚钱的心，让"赚钱欲"与"刹车"并存。**

- **骗局模拟器（核心互动）**：对话式角色扮演，扮演投资者走完整杀猪盘剧本（偶遇→小赚→加大→收网），每步屏幕解剖："骗子此刻在做什么 / 你为什么觉得赚了 / 下一步钩子"。走到"充值 5 万"揭示全貌
- **心理机制图谱**：沉没成本、稀缺紧迫、权威包装、社会认同——每机制配真实话术
- **话术词典**："稳赚不赔""内部渠道""国家扶持项目"逐条拆解
- **核实工具包**：国家反诈中心 App、企业查查、证监会官网——"赚钱之前先花 5 分钟查这三样"
- **数据事实层**：引用公开可查的老年人投资诈骗数据，用数据不说教

### ⑥ 提示词学院 + Agent 入门
- 好提示词三要素（角色+背景+要求）；互动改写练习（选不同提示词，看 AI 回答质量变化——预置实录）
- Agent 概念入门："不止会说话、还会帮你干活的助理"
- 深度探索任务卡（贯穿全站）：L1 用豆包提一个好问题 → L2 用 AI 完成一个作品 → L3 与一个 agent 式工具互动 → L4 看懂儿子的一个项目 → L5（远期）一起做 agent

### ⑦ 结业
- 行动清单（今天/本周/本月三档）
- 结业证书动画（进度集齐解锁 + confetti）

## 4. Tech Choices

- 纯 HTML/CSS/JS，无框架无构建（她的电脑双击即开）
- 动效库本地化：**GSAP**（ScrollTrigger + TextPlugin，免费版）、**canvas-confetti**、**Chart.js**——全部下载进 `assets/vendor/`，断网可用
- 素材管线：文案/图表手写；图像素材用图像生成工具产出嵌入；对话展示用打字机动画模拟真实实录（不用大视频文件）
- 存储：localStorage 存任务进度（单机本地，无隐私外发）
- 浏览器目标：现代 Edge/Chrome（手机+桌面）

## 5. Non-Goals (YAGNI)

- 无后端、无注册、无实时 AI API 调用（预置实录代替）
- 暂不部署上线（本地 zip 交付；之后想在线再部署）
- 不做移动 App

## 6. Risks & Mitigations

- 内容真实性：所有数据/案例标注来源可查，收入案例注明"因人而异"；不编造
- 妈妈性格适配：全站语气"赚钱是对的，但要用对方法"；骗局板块给欲望装刹车而非泼冷水
- 交互复杂度：每轮做完整可验收的小块，失败不遗留到下一轮（用户明确要求）

## 7. Execution Plan (Multi-Round)

定时任务每 30 分钟推进一轮；每轮必须做实事；本轮决策/问题本轮解决，不留尾巴；可用子智能体；力求最好，不追速度；可上网找开源参考，不重复造轮子。

- Phase 1: 骨架（目录、共享 CSS/JS、任务系统、启动页）+ vendor 库本地化
- Phase 2: 板块①②④（成果精选、趋势、实验室）
- Phase 3: 骗局解剖室（最重，独立轮次打磨）
- Phase 4: 副业地图 + 学院
- Phase 5: 结业 + 素材精修 + 打包 zip + 交付说明

每轮结束：git commit（逻辑区域）、更新进度日志（docs/progress.md）。
