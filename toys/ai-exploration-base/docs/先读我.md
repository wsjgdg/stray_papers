# AI 探索基地 · 先读我

> 纯文本版 `先读我.txt` 由构建脚本从本文件生成；要改内容，改这份 Markdown 就够了。

## 一、这是什么

一个给 55—65 岁的人用的 AI 入门站，一共六关。

每一关不是一篇文章，而是一个能动手的台子：
卡片能翻面、情报能分拣、细胞能跑、路线能选、骗局能拆、提问能改。

六张页面互相独立，点开哪一关都能直接玩，不用按顺序，
也不用注册、不用登录、不填任何个人信息。

## 二、怎么打开

**最快**：双击 `prototype/index.html`。

**更稳**：在 `ai-exploration-base/` 目录里起一个本地服务器，然后访问
`http://localhost:8000/prototype/index.html`

命令：`python3 -m http.server 8000`

> 有些浏览器对"双击打开的文件"限制脚本，用本地服务器能保证
> 每张卡的动画和交互都正常。两种都能看，只是后者更完整。

**放到网上**：整个 `ai-exploration-base/` 文件夹就是一个静态站点，
直接上传到任意静态托管即可，不需要后端、不需要数据库。

| 关 | 标题 | 在做什么 |
|---|---|---|
| ① | AI 能做什么 | 五张能翻面的实物卡：海报、朋友圈、账单、老照片、微信问答，背面是能照抄的提示词。 |

| ④ | 副业地图 | 别先算收入，先看路怎么走。三条路线按你的条件重新排序，再把这周排出来。 |

| ⑥ | 提示词学院 | 不是让 AI 猜，是把问题说准。角色、背景、要求补齐，再试投一次看哪里分岔。 |

## 四、哪些是真的，哪些是编的

这条请一定看，也是这套东西最要紧的规矩：

- **每个数字都能点开来核对。** 每关末尾都挂着来源清单，写着标题、
  链接、状态码和访问日期。
- **卡片背面的对话、海报、朋友圈文案，都是预先写好的教学样例**，
  标着"演示样例""示意"。它们不是真实的 AI 即时输出，也不是实拍照片。
- **⑤ 关的八幕话术是综合教学模拟**，不对应某个具体案件；
  但每一幕底下都挂着一条真实案件报道。
- **④ 关只做定性判断**，不预测收入，不承诺赚钱。

这些标注是故意留着的：把编的内容标出来，读者才知道哪句能信、
哪句只是举例。

## 五、它不做什么

- 不调用任何 AI 接口（页面里的"AI 回应"都是预写的）
- 不保存、不上传你输入的任何内容（全部在浏览器里跑）
- 不需要注册，不收集个人信息
- 不预测收入，不推荐任何具体产品去投资

## 六、想改内容怎么办

正文的文字真源在 `ai-exploration-base/docs/content/`，是 Markdown。
改完之后在 `ai-exploration-base/` 下运行：

```
python3 scripts/build-source-pages.py
```

七张页面会重新生成；再跑一次带 `--check` 的可以自检：

```
python3 scripts/build-source-pages.py --check
```

**不要直接改 `prototype/` 里的 `.html`** —— 它们是生成物，下次构建会被覆盖。

## 七、目录里都有什么

```
ai-exploration-base/      站点本身（可直接打开）
  prototype/              七张页面 + 样式 + 脚本
  assets/                 字体、第三方库
  docs/content/           内容真源（Markdown）
  scripts/                构建脚本
docs/                     过程文档（设计评审、方案、交付说明）
README.md                 给维护者看的技术说明
先读我.txt                 就是这一份（由 docs/先读我.md 生成）
```
