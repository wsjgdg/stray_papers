# 《撕开账面》旧版改造：第一张可拖动切片

> 2026-11-05；入口 `ai-exploration-base/prototype/motion-lab-v2.html`。批准方向后的**单幕切片**，保留 `prototype/motion-lab.html` 原页和 `prototype/index.html` 拨盘。没有替换七幕原型、正式六关或旧离线包；方案见 `docs/OLD_TEAR_REDESIGN_PROPOSAL.md`。

## 做到了什么

- 保留旧版青色“账面盈利 +6,000”对撞红色“提现先交 20% 保证金”、右侧抓手向左撕、松手回弹/继续揭开与一键揭示/复位；按用户反馈移除了“揭开程度”滑杆。标题“到账没有？”现在是可聚焦按钮，点击揭开/合上；揭开时短暂裂解式抖动与红色风险文字受控撞击，仅作用在文字，不让整个视口常驻震动。页面从旧版介绍→演示框→口号结尾改成同一个近满屏镜头。
- 可变形的 80×48 WebGL 网格替换旧版纯二维分屏。纸面纹样由本地 Canvas 2D 生成；抓取位置改变局部斜折线，速度影响卷半径和轻微颤动；背面、表面受光与随形影子均随网格变化；完整揭开后票面滑出画幅，不覆盖标题。红色风险层按遮挡关系露出，而不是单独播放淡入。
- 账面下面另有三面立体“客服说法”滚筒；向上拖、点箭头或按方向键，保证金 → 解冻费 → 最后一笔 → 保证金循环，每一面改变对应风险解释。它与已知诈骗话术的识别相关，不是进度列表或无后果的装饰。
- 独立存放精简 Noto Sans SC 中文字体（SIL OFL，原型目录含许可证）。WebGL 不可用时仍有 HTML 账面/底层警示；无 JS 时有静态风险结论；减少动效使状态立即就位，键盘/触屏均可操作；离开可视区停止持续渲染。

## 目视与功能检查

- Chromium 在 320/375/768/1280/1440px 看过版式：起始、撕开中途、完全揭开无横向溢出；中途卷起的背面与底层 20% 能同时看见；100% 票面退出，不再压住桌面标题或手机风险文字。桌面/触屏拖动、松手回弹/完成、标题按钮、滚筒循环/方向键、减少动效、禁 JS、WebGL 失效与 context lost 需在每次改动后重新核对。
- `scripts/smoke.js` 和正式站 `scripts/test.js` 通过。**没有真实手机 GPU/帧时间数据，也没有得到用户对美术的验收**；这是单幕比较样张，不是“已经达到获奖网站效果”的宣称。
