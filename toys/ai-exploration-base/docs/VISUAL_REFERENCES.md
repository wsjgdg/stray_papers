# 视觉参考与素材说明（2026-11-05）

## 参考的是方法，不是直接复制画面

- 互动教育案例：[1](https://blog.tubikstudio.com/case-study-educational-interactive-website/) —— 参考其把复杂教育信息拆成可理解的视觉段落、让字体和交互服务主题的方式；没有复制该站布局、素材或动效。
- 内容本身成为视觉：[2](https://blog.tubikstudio.com/annual-awwwards-website-design/) —— 参考「用作品的题材组织视觉语言，而不是给通用模板换皮」这一思路；本项目六关分别用创作桌面、纸质数据雕塑、算法玩具、三条路线、识别骗局、提示词纸卡作视觉隐喻。
- 数据叙事：[3](https://dappasol.com/guides/scrollytelling-website-examples/) —— 参考阅读流程与数据可视化同步的做法；当前趋势页仍优先保证数据可读，不做滚动锁定。
- 另查看了博物馆/编辑式网站的图片搜索参考，只用于确定图片与标题的占比、留白和排版节奏；**没有下载或使用搜索结果中的受版权保护图片作为交付素材**。

## 本站素材

- `assets/media/chapter-01.jpg`～`chapter-06.jpg`：为本站制作的六张原创概念图，并非真实软件截图、AI 模型的实际回答或项目作品证据；页面已标注「概念视觉 · 非产品截图」。其中第一张经过人工检查并重新编辑，移除了生成图上不正确的伪文字。
- 实际项目证据仍是第三关可交互的本地 `algorithm-lab-standalone.html`、页面里的真实仓库链接以及可查的统计来源。概念图只提供章节氛围，不能替代事实来源。
- 图片与 CSS 一同放在本地 ZIP 中，断网可用；`smoke.js` 现在同时检查 CSS 中的本地图片引用。
