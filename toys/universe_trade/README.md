# 真实事件三部曲 · 免服务器单页版

这是 `universe_trade` 项目的一个**最小实现**：把整部应用打包成两个文件，
**不需要 Node、不需要构建、不需要起服务器**——直接双击 `index.html` 即可在浏览器里看。

## 包含的内容

- `index.html` —— 页面外壳（已内联 Tailwind 样式、favicon）
- `app.js` —— 整部应用的打包代码（React + 三个故事页面及其全部内容）

应用是纯前端、自包含的：所有文案、3 张海报图（已转 base64 内联）、Web Audio 合成的
预告片音效都在这一个文件里。没有后端、没有在线请求，所以**离线也能跑全套**。

五个页面（用地址栏 hash 切换）：

| 路由            | 内容                          |
| --------------- | ----------------------------- |
| `#/`            | 选片首页                      |
| `#/voyager`     | 旅行者一号 · 深空之旅         |
| `#/behind`      | 幕后 · 这部片子是怎么做出来的  |
| `#/moon`        | 人类登月                      |
| `#/deep`        | 下潜万米海底                  |

## 怎么用

**最简单**：双击 `index.html`。

如果你的系统不允许双击本地 HTML 直接打开，也可以：

- 用浏览器打开 `index.html`（文件 → 打开文件）
- 或起一个任意静态服务器，例如 `python -m http.server`，然后访问 `index.html`

> 注意：因为是用 `file://` 打开，路由用的是 hash（`#/voyager`），不是普通路径。

## 这个版本和完整项目的区别

| 项目                | 完整版（Vite）         | 本单页版（standalone）       |
| ------------------- | ---------------------- | ---------------------------- |
| 启动方式            | `pnpm dev` 起服务器    | 双击 `index.html`            |
| 构建                | 需要 Node + Vite       | 已预构建，无需构建           |
| 开发 / 热更新       | 支持                   | 不支持（这是发布产物）       |
| 标签页图标          | `public/favicon.svg`   | 已内联进 `index.html`         |
| `.rh/` 设计资产     | 项目设计稿，不参与运行  | 未包含（应用不引用）         |

## 重新生成这个单页（开发者）

完整项目里用：

```bash
run.cmd standalone        # 重新打包生成 index.html + app.js
```

`build-standalone.mjs` 会在进程内用 TypeScript 转译 + rollup + tailwind 完成打包，
不需要 Node 启动任何子进程。
