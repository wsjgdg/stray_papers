知识卡片。

理解被求解的流体，和被看见的颜色。

观察卡片 / 0101 — 05

速度遍布空间，
压力约束体积。

速度场按不可压缩 Navier–Stokes 方程演化：速度输运自身，黏性使速度差扩散，压力投影降低散度；推流时加入局部外力。

∂u/∂t + (u·∇)u = −∇p + ν∇²u + fext
∇·u ≈ 0
当前散度均方根—

交错网格、半拉格朗日速度输运和有限次压力迭代；散度 RMS 衡量离散场距无散状态的程度，不衡量画面清晰度，也不保证整体精度。开启剖面后，颜色来自当前网格速度的离散旋度 |∇×u|；这不同于被动染料，也不自动识别涡核。

观察卡片 / 0202 — 05

看得见的颜色，
不是涡量本身。

金色和青色是两种被流场搬运的被动标量。它们不会推动流体，也不等同于涡量、真实烟雾的化学过程或流体界面。

示踪物积分 A / B—

示踪物由保守有限体积通量输运，仍有数值扩散。体积视图沿视线累积浓度；清晰轮廓叠加的是当前两种染料总浓度的等值面，阈值按当帧峰值归一。它不是物理界面，光照也只是可视化近似。

观察卡片 / 0303 — 05

初态是环，
后来交给流场。

初始速度由两条带平滑核的涡环诱导场生成，并叠加可调的三维无散扰动；随后各网格速度独立演化，不再假设两个环始终同轴或圆形。

染料轴向质心 B − A—

正负表示两种染料质心的前后顺序；染料不是涡核，顺序交换不单独证明涡核穿越。相向预设不触发旧涡丝近核暂停；有限网格中的混合不能直接定量预测真实重联。
