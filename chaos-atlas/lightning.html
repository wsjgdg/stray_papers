FIELD NOTES

知识卡片。

从电势到概率，从一个节点到一条路径。

观察卡片 / 0101 — 08

路径不是画出来，
是逐步选出来。

电极和已有通道固定电势；其余空间求解三维拉普拉斯方程。通道周围每条候选连接，按局部场强的 η 次方抽样。

∇²φ ≈ 0　　E = −∇φ
P(连接) ∝ (Δφ / d)η
当前 η / 候选节点—

每个候选节点可通过面邻或斜邻连接已有通道，距离分别为 h、√2h；节点总概率是各连接概率之和。η 越大通常越偏爱强场，但单次结果不代表统计规律。

伸出的尖端附近场强通常较大；已形成的通道会改变电势，使内侧分支的候选位置可能受到电场屏蔽。用探针比较外侧尖端和分叉内侧：概率也受连接数与 η 影响，并非每个点都符合这一趋势。

候选点有多亮，
取决于真实概率。

选「候选探针」后点击或触摸点位；也可直接选择当下概率最大的节点。探测会暂停；已提交的生长步完成后再读取，不改变电势或已有路径。

观察卡片 / 0404 — 08

电场是计算的，
光晕是表现。

上极板和通道 φ=0，下极板和正极 φ=1；四个侧壁绝缘。每生长一步后，迭代至电势残差达标，才继续抽样。

网格 / 电势残差—

18 邻接离散场中，面邻权重 1、斜邻权重 1/2；残差是自由节点与加权邻点均值之差的最大值，不是整体误差上界。电极目标尺寸跨网格保持不变，但体素吸附会改变实际边界，不是严格的单变量收敛实验。

DBM 生长是准静态随机介质击穿模型，不含电离、电流、发热、声音或电磁波；接通后的直流电热与回击 RLC 是独立的降阶扩展。合成云背景、辉光、线宽和网格间的细小弯折仅作视觉表现；「原始网格」显示求解连接。接触正极后停止，显示接触前最后一个电势场。

观察卡片 / 05POST-CONTACT

接通后才有电流，
热来自电路计算。

把已接通的击穿树暂时视为电阻网络，并串联固定镇流电阻；恒压源驱动唯一的源—目标路径。未接通的悬空支路在这个直流模型中没有电流。

I = V / (R源 + ΣR通路)
Pᵢ = Iᵢ²Rᵢ　 Cᵢ dTᵢ/dt = Pᵢ − 散热
电流 / 峰值温度—

通道电阻随示例温度增长，热容量与段长成比例；电极体素视为等势、不模拟其内部电流分布。颜色可由实际计算的温度、电流或单位长度功率映射；不计算空气光谱、等离子体、先导或回击，也不修改 DBM 电势。

观察卡片 / 06ONE EVENT

一段通道出现，
周围的场随之改变。

在一个随机选择后，将新节点加入等势通道，再重新求解电势。前后剖面的差值来自这两次真实求解：暖色为增加，冷色为减少。

Δφ = φ后 − φ前
Δ|E| = |∇φ后| − |∇φ前|

场强由三维中心差分计算；只比较前后均为空间的内部格点。候选概率仅在该节点确为候选时显示，不能把非候选当作已测概率。

这是离散模型的局部场重排，不是已证明的真实雷电测量。继续生长或更改模型参数会清除旧对照。

观察卡片 / 07ENSEMBLE

一次分叉是故事，
多次重复才有统计。

不同种子产生不同随机击穿树；两组使用相同种子和电极边界，但按照各自的 η 独立求场和抽样。比较分叉节点数、实际生长键的总长度与预算内接通比例。

接通比例 = 预算内接通数 / 已完成样本数
均值 ± 样本标准差　·　接通率 Wilson 近似区间

事件预算内未接通的运行是截尾样本；长度和分叉只统计到截尾时。样本数小时区间可能很宽，不应仅凭一组数字认定 η 的趋势或真实闪电规律。

观察卡片 / 08RETURN STROKE

接地的影响，
不是同时到达全树。

以一棵已接通的 DBM 树为假设通道，给它预置负电压；在地面闭合后，电压与电流扰动沿每条等效 RLC 线传播，并在分叉和开路端反射。

∂V/∂s = −L′∂I/∂t − R′I
∂I/∂s = −C′∂V/∂t
v = 1 / √(L′C′)
波速 / 当前探针电流—
悬空支路：回击 / 直流—

地面流入方向约定为正；电流波的传播不等于电子运动轨迹。与上方直流电阻模型不同，悬空支路可因等效电容充放电而产生瞬态电流；两模型单位不同，只比较是否有支路电流，不比较数值大小。

线长、电压和 R′L′C′ 均为假设；通道电离、三维电磁辐射、气体动力学和真实光谱未计算。底部色阶不是实测亮度，也不能用于雷击预测。
