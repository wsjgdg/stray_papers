THE EXPERIMENTS01 — 09

NINE WAYS TO EXPLORE

选择一个问题，
进入实验。

从可拖动的摆到高速世界里的光，每个实验都有独立的三维场景、控制台和知识卡。图片为实验静帧。

LAB / 01 进入空间摆实验↗
01 / 轨迹 / 经典力学SPATIAL PENDULUM

空间摆

在三维关节链中，研究初始条件与能量如何塑造运动轨迹。

动手观察

拖动摆球、增减级数，对照两条初态仅有微小差异的摆链。

  • 约束运动
  • 初值敏感
  • 理想能量守恒

模型范围理想无摩擦；数值积分不严格守恒。

进入实验 ↗：空间摆
LAB / 02 进入相空间图谱实验↗
02 / 轨迹 / 非线性系统PHASE SPACE ATLAS

相空间图谱

Lorenz、Rössler 与 Thomas 系统的轨迹，在状态空间中如何组织？

动手观察

切换方程与参数，比较两条轨迹的分离和相空间形状。

  • 相空间
  • 吸引子
  • 初值敏感

模型范围吸引子及其稳定性依赖方程与参数；短时分离不单独证明混沌。

进入实验 ↗：相空间图谱
LAB / 03 进入自由刚体实验↗
03 / 运动 / 旋转与稳定性RIGID BODY

自由刚体

自由刚体绕不同惯量主轴转动时，为什么可能突然翻转？

动手观察

改变初始姿态和主轴，施加可调大小、方向与位置的恒力。

  • 中间轴不稳定
  • 角动量
  • 力矩

模型范围不稳定不等于混沌；偏心外力会产生力矩。

进入实验 ↗：自由刚体
LAB / 04 进入势能地形实验↗
04 / 轨迹 / 哈密顿系统HÉNON–HEILES

势能地形

把二维粒子的势能画成高度，观察轨道、鞍点与逃逸边界。

动手观察

移动状态点和地形探针，改变能量并比较庞加莱截面。

  • 哈密顿系统
  • 势能梯度
  • 庞加莱截面

模型范围地形高度表示势能，不是运动的第三空间维。

进入实验 ↗：势能地形
LAB / 05 进入涡环追逐实验↗
05 / 场 / 流体动力学VORTEX RINGS

涡环追逐

不可压缩三维流体中，相互靠近的涡环如何影响彼此？

动手观察

切换流场预设、查看速度切片；从控制台进入涡丝对照。

  • 涡量
  • 平流与扩散
  • 不可压缩流

模型范围染料用于可视化流动，并不直接等同于涡核。

进入实验 ↗：涡环追逐
LAB / 06 进入球面图灵斑纹实验↗
06 / 场 / 自组织REACTION / DIFFUSION

球面图灵斑纹

反应与扩散相互竞争，如何在球面形成斑点和条纹？

动手观察

调整扩散比、反应参数与球半径，对照不同方程。

  • 反应扩散
  • 图灵失稳
  • 空间模态

模型范围Gray–Scott 的有限种子斑纹不一定是线性图灵失稳。

进入实验 ↗：球面图灵斑纹
LAB / 07 进入闪电生长实验↗
07 / 场 / 随机生长DIELECTRIC BREAKDOWN

闪电生长

电势场与随机生长怎样共同塑造介质击穿的分叉？

动手观察

移动电极、比较场与生长概率；从控制台进入局部流注对照。

  • 电势场
  • 分枝生长
  • 局部场反馈

模型范围介质击穿模型不是完整雷电；局部流注仅覆盖小范围。

进入实验 ↗：闪电生长
LAB / 08 进入三维自旋晶格实验↗
08 / 统计 / 集体行为ISING LATTICE

三维自旋晶格

近邻相互作用与热涨落，如何产生磁畴与相变？

动手观察

调整温度、外场和晶体结构，查看磁化、关联与相变曲线。

  • Ising 自旋
  • 序参量
  • 临界涨落

模型范围蒙特卡洛扫描是采样步数，不等同于真实时间。

进入实验 ↗：三维自旋晶格
LAB / 09 进入近光速世界实验↗
09 / 观察 / 狭义相对论THE SPEED OF LIGHT

近光速世界

接近光速时，物体观察到的形状、颜色与阴影如何改变？

动手观察

改变速度与观察者，比较光锥照片和同一时刻的几何投影。

  • 光行时
  • 洛伦兹变换
  • 相对论多普勒

模型范围匀速和理想化光学；不模拟加速、碰撞或广义相对论。

进入实验 ↗：近光速世界
FOLLOW THE CONNECTIONSTHREE PATHS / 三条路线

A PLACE TO START

从一个实验，
走向下一个。

这些路线不是前置课程。它们把可比较的概念放在一起，也提醒你留意不同模型之间的边界。

PATH / 01↗

从轨迹到规律

先比较空间摆的初值，再看相空间与势能地形。理想摆和 Hénon–Heiles 是保守模型；Lorenz 的典型吸引子则来自耗散。刚体翻转展示不稳定性，但不因此就是混沌。

01 空间摆→02 相空间→04 地形→03 刚体
PATH / 02↗

场怎样长出结构

对照流体中的平流、扩散与压力约束，球面上的反应扩散，以及电势场驱动的分叉。它们都研究空间分布如何改变，却由不同方程和机制支配。

05 涡环→06 斑纹→07 击穿
PATH / 03↗

概率、统计与观察

击穿和自旋采样都包含随机选择，但目标和规则不同；蒙特卡洛扫描数不是实际时间。再到相对论实验，区分物体的同时几何与光抵达观察者的结果。

07 击穿→08 自旋→09 光行时
