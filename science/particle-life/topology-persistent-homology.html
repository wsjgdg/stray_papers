拓扑学：从「谁吸引谁」里抽身，只看结构本身

拓扑学（Topology）研究在同胚（连续且可逆地连续变形）下保持不变的性质——可以拉伸、压缩、弯曲，唯独不能撕裂、不能粘连。它只关心三件事：连不连通、有几个洞、把手（亏格）多少。这些量与坐标系、距离大小、动力学机制完全无关。本页是一个零依赖、纯 HTML/CSS 的静态教材，把拓扑度量讲到底。

00全景图谱：从点云到拓扑签名的全链路

先给一张总览图：拓扑数据分析的标准流水线——离散点云经 Rips 过滤长成单纯复形，持续同调记录每个特征的生灭，条形码/持久图可视化这些履历，最终压缩成可进入机器学习的拓扑签名。后文逐站详解。

01橡皮膜几何学：允许与禁止的操作

把几何体想象成用理想的橡皮膜做成：可以任意拉伸、压缩、弯曲、扭曲，但不许撕开裂缝，也不许把两点粘在一起。凡是经过这类操作仍保持不变的性质，就是拓扑性质。著名的例子是：咖啡杯 ≅ 甜甜圈——杯柄的孔洞恰好对应甜甜圈的中空圆环。

允许：橡皮膜操作

拉伸 · 压缩 · 弯曲 · 扭曲 · 倾斜投影。这些操作改变度量（距离、角度、面积），但不改变"结构"。

禁止：破坏连通关系

撕裂（把一处断开）、粘连（把两处焊上）、穿刺。一旦允许这些操作，任何空间都能变成任何空间，"结构"一词就失去意义。

为什么叫"橡皮膜几何"？欧几里得几何关心长度与角度；微分几何关心曲率；而拓扑学把度量信息全部丢掉，只保留"连通方式"。这也是为什么拓扑量对坐标系、尺度、噪声都极其稳健。

02拓扑不变量：同胚下不动的量

如果一个量在同胚映射下保持不变，就称为拓扑不变量。它是我们区分"不同胚"空间的武器：只要某项不变量不同，两个空间就一定不同胚。下面是最常用的几个。

欧拉示性数与亏格

对可定向闭曲面，三者被一条公式锁死：

χ = β₀ − β₁ + β₂ = 2 − 2g

球面 2 = 2−0；环面 0 = 2−2；双孔面包 −2 = 2−4。看到 χ 就知道亏格，看到亏格就知道洞的数量。

不变量的"分辨力"

不变量是单向的：不同 ⇒ 必不同胚；但相同 ⇏ 一定同胚。例如 θ 形图（两点间三条边）与三叶结的补空间可能共享部分不变量，却不同胚。要完全分类，往往需要一整套不变量协同工作。

04单纯复形与 Rips 过滤：把点云变成拓扑

真实数据是离散点云，没有"洞"的定义。拓扑数据分析的做法是：引入尺度参数 ε，把点云逐步"长成"一个单纯复形（simplicial complex）——点（0-单形）、三角形（2-单形）等拼装出的组合结构。ε 从小到大的过程称为过滤（filtration）。

Rips 复形的构造规则

规则一：任意两点距离 ≤ ε，则连一条边（1-单形）。
规则二：若 k+1 个点两两相连，则填入 k-单形（三点围三角、四点填四面体）。
规则三：ε 增大时，复形只增不减——这就形成嵌套序列，即过滤。

K(ε₁) ⊆ K(ε₂) ⊆ K(ε₃) ⊆ … （ε₁ < ε₂ < ε₃）

为什么要"过滤"而不是取单个 ε？

单一阈值的结论对 ε 极度敏感：取小了洞还没长出来，取大了洞已被填平。过滤把所有尺度的信息一次性打包——每个洞从出生到死亡的完整履历都被记录下来，从中再区分"真结构"与"噪声"。

Rips vs Čech：一对兄弟复形

Čech 复形：半径 ε 的球族若存在公共交点，则这些球心张成一个单形——它是"球并"空间的形变收缩（Nerve 定理）。
Rips 复形：只要两两距离 ≤ ε 就连边填单形——不检查公共交点，算得快得多。

Ripsε ⊆ Čechε ⊆ Rips2ε

左包含：两两 ≤ ε 的点集，任取一点就是所有球的公共交点；右包含：公共交点存在 ⇒ 两两距离 ≤ 2ε。两者只差一个常数因子的"时间轴"，捕捉的拓扑本质相同——这就是用 Rips 不丢真的数学底气。

05持续同调：给每个洞记下生与死

在过滤过程中，每个拓扑特征都有出生尺度 ε_birth（首次出现）与死亡尺度 ε_death（被填平或合并）。二者的差

persistence = ε_death − ε_birth

称为持久性。真实结构会在很大一段尺度区间里存活（持久性大）；噪声造成的假洞往往旋生旋灭（持久性小）。持续同调（Persistent Homology）就是把每个尺度的同调群串成一个"缩略图序列"，再抽取这些生灭配对[1]。

β₀ 的生灭：合并

每个点在 ε = 0 时各自成一块（β₀ = n）。随着 ε 增大，点与点连通，块与块合并——被吸收的块"死亡"。最后只剩 1 块。所以 H₀ 的条形码永远是一组从 0 出发、先后终止的条，外加一根贯穿始终的最长条（整体连通块永生）。

β₁ 的生灭：闭合与填平

一维洞的出生是回路首次闭合的尺度，死亡是三角形首次把洞盖住的尺度。长寿命的 H₁ 条对应数据里真实的环状结构（如甜甜圈的两个洞、点云中央的空洞），短寿命的则是局部噪声。

核心思想一句话：与其争论"ε 该取多少"，不如让 ε 跑遍全程，把每个特征的一生都记下来——活得久的才是真的。这是拓扑数据分析抗噪性强的根本原因。

06算法内幕：矩阵约简与生灭配对

持续同调不是黑盒。它的计算内核只有一件事：把一张边界矩阵从左到右约简，从最下非零行里读出每个特征的生与死。理解了这一步，条形码和持久图就不再是"软件输出的图"，而是可以手推的代数。

代数地基：单形的"边界"是线性算子 ∂，满足 ∂ ∘ ∂ = 0（边界的边界是零）。第 k 个同调群定义为 Hₖ = ker ∂ₖ / im ∂ₖ₊₁——闭链（无边界的东西，如回路）模掉恰当链（某个高维单形的边界，如被填平的环），留下的就是"真正的洞"。持续同调只是把这套代数放到过滤序列上，并记录每个类的生死。

四步流程：从过滤到配对

① 排序：按过滤顺序给所有单形编号 σ₁, σ₂, …, σₙ（点、边、三角形混排，维度无关紧要，出场顺序才重要）。
② 建矩阵：第 j 列记 ∂σⱼ 的系数（如 ∂e₁₂ = v₁ + v₂），ℤ₂ 系数最常用（符号无所谓）。
③ 约简：从左到右逐列处理——取该列最下方非零行 i；若 i 已是左侧某列的 pivot，就把那列加过来消掉它，反复直到最下方非零行落在"无人占用"的行，或整列归零。
④ 读配对：约简后列 j 的最下非零行若为 i，则配对 (i, j)；从未被配对引用的索引，对应永生的拓扑特征。

谁是"负单形"，谁是"正单形"

每个配对 (i, j) 读作：特征在 σᵢ 处出生，在 σⱼ 处死亡。σᵢ 称负单形（创造者），σⱼ 称正单形（消灭者）。

同一个几何操作可以生也可以死：加入一条边可能让回路闭合（创造 H₁），也可能把两块连通域合并（杀死一个 H₀）；加入一个三角形通常填平一个 H₁。生与死不由单形维度决定，由它在过滤序列中的位置与上下文决定。

手推一个例子：填满的三角形

过滤顺序：v₁ → v₂ → v₃ → e₁₂ → e₂₃ → e₁₃ → t₁₂₃（三点 → 三边 → 填面）。列约简后得到三个配对加一个永生类：

配对 (i, j)同调特征出生死亡
(v₂, e₁₂)H₀v₂ 的连通块v₂ 出现e₁₂ 与 v₁ 合并
(v₃, e₂₃)H₀v₃ 的连通块v₃ 出现e₂₃ 并入大块
(e₁₃, t₁₂₃)H₁三角环e₁₃ 使回路闭合t₁₂₃ 把洞填平
v₁ 无配对H₀整体连通块v₁ 出现∞ 永生

对应到条形码：三根有限长的条 + 一根贯穿全程的 H₀ 长条；对应到持久图：三个有限点 + 一个"死亡 = ∞"的点。约简算法读出的就是这份生灭履历。

low(j) = i ⟹ persistence pair (i, j) ⟹ interval [εᵢ, εⱼ)
复杂度与工程实践：朴素矩阵约简是 O(n³)，大点云会很慢。成熟实现（GUDHI、Ripser、Dionysus、giotto-tda）用 clearing、apparent pairs、稀疏表示等技巧把常数和阶数大幅压低，百万级单形也能出图。理解本节的手推流程，调参和读结果时就不会被黑盒牵着走。

07条形码与持久图：持续同调的两种读法

同一份生灭数据有两种等价的可视化。条形码（Barcode）用横条长度直观展示持久性；持久图（Persistence Diagram）把每个特征画成 (ε_birth, ε_death) 平面上的点，离对角线越远越重要。

H₀ 特征（连通分支） H₁ 特征（一维洞） 高持久性信号 低持久性噪声

从条形码到向量

条形码/持久图本身还不是机器学习可用的"向量"。常用转化：

持续图景观（Landscape）：把每个三角形峰折成函数再采样；持续熵（Persistence Entropy）：对条长分布取熵；Betti 曲线：逐 ε 记录 β_k(ε) 形成的曲线。转化后即可进入回归、分类、聚类流程。

稳定性定理：为什么抗噪

持续同调满足稳定性定理[3]：数据点轻微扰动时，持久图的变化被扰动幅度所控制（瓶颈距离不超过 Hausdorff 距离的 2 倍）。这保证了拓扑特征不会因为几个离群点而翻盘——这是它在真实噪声数据上可靠工作的数学底气。

六步流程（对任何数据集都适用）

  1. 列距离矩阵：n 个点两两求距，圈出所有不同的距离值 d₁ < d₂ < … < dₘ——它们就是全部事件时刻。
  2. 排过滤序：ε 每越过一个 dₖ 就加入一批单形（新边、新三角形）。
  3. 逐时刻数 β：画出该 ε 的复形，数连通块 β₀ 与独立回路 β₁。
  4. 记生灭表：每个特征在哪个 dₖ 出生、哪个 dₖ 消失，写下区间 [birth, death)。
  5. 画条形码：一根横条一个特征，标好事件刻度。
  6. 校验：最后 ε 足够大时复形应可收缩（只剩永生 H₀）；用 χ = V − E + F 抽查中间步骤。

识别多边形：曲面的"身份证"

每个闭曲面都能由一个多边形把边按方向两两粘合得到。环面是正方形按 aba⁻¹b⁻¹ 粘合：左右边同向粘（a），上下边同向粘（b）。粘合方式一旦改变，得到的曲面就不同——识别字（如 aabb、abab）正是曲面的组合密码。

亏格与 β₁ 的关系：可定向闭曲面上，每个把手贡献两条独立回路（绕把手一圈 + 穿过把手一圈），因此 β₁ = 2g。看到 β₁ = 4，立刻反推 g = 2。
非可定向曲面的 β₂：射影平面、克莱因瓶无法在 ℝ³ 中无自交地实现，且不存在一致的"内外"，因此没有可定向的整体腔体，β₂ = 0（ℚ 系数）。它们的拓扑由交叉帽数 k 区分：ℝP² 是 k=1，克莱因瓶是 k=2。
实用判据：拿一张曲面网格，用欧拉公式 V − E + F = χ 数顶点、边、面即可算出 χ——不需要任何几何测量，纯计数就得到拓扑指纹。

Q1环面 T² 的 β₁ 是多少？

✓ 正确。绕中空管的纬线 + 绕管截面的经线 = 两条互不等价的闭合回路，β₁ = 2。视觉上"一个孔"与同调意义的"两个洞"不同——这正是 Betti 数的微妙之处。
✗ 再想想。提示：数的是"独立闭合回路"，不是视觉上的孔。想想甜甜圈上你能画出几种"套不进彼此"的圈。

Q2持久图上紧贴对角线的点，通常意味着什么？

✓ 正确。越贴近对角线，death − birth 越接近 0，特征旋生旋灭——多为采样噪声。稳定性定理保证真结构不会被小扰动推到对角线附近。
✗ 再想想。提示：横轴是出生 ε_birth，纵轴是死亡 ε_death。两点坐标很接近，说明这个特征活了多久？

Q3某特征 ε_birth = 0.2、ε_death = 0.5，其持久性是多少？

✓ 正确。persistence = death − birth = 0.5 − 0.2 = 0.3，即条形码中该横条的长度。
✗ 再想想。提示：持久性是两个尺度的差，不是和。

Q4同一点云、同一 ε 下，Rips_ε 与 Čech_ε 的包含关系是？

✓ 正确。两两距离 ≤ ε 的点集，任取一点就是所有半径 ε 球的公共交点，所以 Rips_ε ⊆ Čech_ε；反向不成立，但 Čech_ε ⊆ Rips_{2ε}，二者只差尺度因子。
✗ 再想想。提示：Rips 只查"两两距离"，Čech 要求"公共交点"。哪个判据更容易满足？

Q5一张可定向闭曲面网格数出 V − E + F = 0，它的亏格是？

✓ 正确。χ = V − E + F = 0 = 2 − 2g ⟹ g = 1，即环面。纯计数就能读出拓扑——欧拉示性数的威力。
✗ 再想想。提示：代入 χ = 2 − 2g 解方程即可。

思考题 · 点开看参考答案

Q1 · 无柄马克杯和甜甜圈同胚吗？
不同胚。无柄杯可连续收缩为一点（其边界是球面 S²，β₁ = 0）；甜甜圈含两条独立回路（β₁ = 2）。不变量不同 ⇒ 必不同胚。

Q2 · 为什么 H₀ 条形码里永远有一根贯穿全程的长条？
因为整体连通块永不消失：它在 ε = 0 诞生，直到过滤结束仍然存活（死亡尺度为 ∞）。其余 H₀ 条都对应被合并掉的分块。

Q3 · 持久图上贴着对角线的点为什么可以丢弃？
它们的持久性 ≈ 0，几乎肯定来自采样噪声。稳定性定理保证真实结构只会被小扰动轻微推动，不会整体滑到对角线附近。

Q4 · 一张可定向曲面网格数出 V − E + F = −2，它是什么？
χ = −2 ⇒ 2 − 2g = −2 ⇒ g = 2，即双环面（双孔面包），β₁ = 2g = 4。
