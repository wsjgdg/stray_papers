观察卡片 / 0101 — 05

旋转到一半，
为什么翻过来了？

无外力矩且三个惯量互不相同时，绕中间惯量轴旋转的微小偏离会增长；绕最大或最小惯量轴则是稳定的。

中间轴与 L 的方向余弦1.000
轴方向 · −1 到 +1BODY ↔ L
开始┊ 最近受力改变现在 →

精确绕中间轴旋转可以持续；预设加入微小偏转，才会看到不稳定性。它不等同于混沌：理想自由刚体是可积模型。L 为零时方向未定义，显示为「—」。

偏心恒力可产生外力矩；此时翻转也可能由外力驱动，不能直接套用自由刚体的稳定性结论。

观察卡片 / 0202 — 05

翻转了，
仍有东西不变。

没有外力矩时，绕质心的角动量 L 在空间中的大小和方向都守恒；旋转动能也守恒。刚体的朝向和角速度仍可变化。

恒力改变质心运动；偏心施力还可改变绕质心的 L 和旋转动能。受力不变的每一段，平动、转动与恒力势能之和守恒。

观察卡片 / 0303 — 05

形状决定
三个主惯量。

刚体的三条主轴与它一起转动。沿各轴转动的惯量取决于质量如何分布；中间轴由数值大小决定，不固定是某个颜色。

当前惯量从小到大X < Y < Z
Ix = m(b² + c²)/12
Iy = m(a² + c²)/12
Iz = m(a² + b²)/12

模型为质量 1 kg 的均匀长方体；几何尺寸按惯量比例计算，装饰线和箭头不计入质量。主惯量必须满足严格三角不等式。

观察卡片 / 0404 — 05

刚体坐标系里的
运动方程。

角速度的三个分量是在随刚体旋转的主轴系中测量的；即使空间中的 L 不变，这些分量也可以互相交换。

Ix dωx/dt = (Iy − Iz)ωyωz + τx
Iy dωy/dt = (Iz − Ix)ωzωx + τy
Iz dωz/dt = (Ix − Iy)ωxωy + τz
m r̈ = F；τ空间 = (R a) × F
τ刚体 = Rᵀ τ空间

a 是刚体坐标中的作用点相对质心的位置。默认 F = 0；每次调力后，力在空间中保持不变，刚体系的力矩可随姿态变化。无摩擦；用固定步长 1/240 s 的四阶 Runge–Kutta 并归一化姿态四元数。
