# 动力学与时空实验室 / The Chaos Atlas

九个可以动手操作的**动力学、场与时空实验台**：拖动球体、连续添加或移除球体的空间多重摆；研究中间轴不稳定性和恒力作用的刚体；Lorenz、Rössler 和 Thomas 系统的相空间图谱；Hénon–Heiles 势能地形与庞加莱截面；相互作用的三维流体涡环；球面反应扩散与图灵不稳定性；三维电势场驱动的随机介质击穿，三维伊辛自旋晶格的相变与涨落，以及狭义相对论下的光行时与高速视野。另有保留的理想涡丝与局部流注物理对照工作台，以及第八页控制台中的晶体结构图谱与基于其几何的自旋采样。每个实验都有可交互的三维场景、控制台和与模拟联动的知识卡片。

本仓库由彼此独立的科学和学习项目组成。这里包含经典非线性运动、场模型与狭义相对论，不同于 `schrodinger-workshop` 中的量子混沌能级统计、`particle-life` 中的多粒子规则，以及持久同调项目。

## 开始使用

建议先打开[九个实验总览](overview.html)：通过可点选的知识图谱查看实验之间的联系，再从九张卡片进入实验。图谱支持键盘方向键，页面无需 JavaScript，也不在后台运行实验；缩略图是本地实验静帧。各实验顶部「实验导航」左侧都有「回到总览」，两个对照页也可以返回。原来的 `index.html` 仍是空间摆，不改变现有直链。

也可用现代浏览器直接打开[空间摆](index.html)、[相空间图谱](attractors.html)、[刚体翻转与恒力](rigid-body.html)、[势能地形](henon-heiles.html)、[涡环追逐](vortex-rings.html)、[球面图灵斑纹](turing-patterns.html)、[三维闪电生长](lightning.html)、[三维自旋晶格](ising.html)和[近光速世界](relativity.html)；也可以在此目录启动静态服务器：

```sh
cd chaos-atlas
python3 serve.py
# 打开 http://localhost:4173/
# 如需局域网或预览访问：python3 serve.py --bind 0.0.0.0 --port 4173
# 让根地址打开九实验总览：python3 serve.py --bind 0.0.0.0 --port 4173 --entry overview.html
# 让根地址直接打开第九页：python3 serve.py --bind 0.0.0.0 --port 4173 --entry relativity.html
```

默认服务器根地址与 `index.html` 仍直接进入占满浏览器视口的空间摆实验台；总览位于 `overview.html`。各实验台：左侧控制台和右侧知识卡可独立收起、展开并在面板内滚动。顶部「实验导航」仅列九个主章节：在主章节中显示其余八项，在对照页中显示九项。理想涡丝与局部流注（B 页）不出现在章节导航，只从各自主页面的控制台进入；对照页控制台也可返回主模型。当前主章节不重复列入跳转。导航保持紧凑，初始显示四个入口，可拖动右侧滑块、在列表上滚轮或触摸滑动查看其余入口；滑块及列表也支持键盘滚动。按 `Esc` 收起导航不会重置模拟。较窄或纵向的视口默认收起侧栏，同一时间展开一侧，以免挡住模型；空间摆点击聚焦后会自动让出画面，并可用画面上的「退出聚焦」返回。底部始终保留播放与实时数据。若需要浏览器的真正全屏模式，可使用浏览器自身的全屏快捷键。

实验台优先使用本地 WebGL 绘制三维场景；空间摆、刚体、势能地形、涡环、球面斑纹、闪电、局部流注和自旋晶格使用随附的 Three.js。前四个实验、球面斑纹、闪电、局部流注、自旋晶格、晶体结构图谱及涡丝对照在 WebGL 不可用或渲染失败时，可切换为可交互的 Canvas 2D 投影；模型不因降级改变。第九页使用独立的光线求交，不依赖 Three.js；默认使用低分辨率 Canvas，支持时在 Worker 中绘制，不会为检测设备而主动创建 WebGL 上下文。用户可手动启用 WebGL 高画质；Worker 不可用或图形上下文丢失时有 Canvas 退路，物理几何相同、材质细节简化。第五个实验默认是**三维流体网格**，其体积渲染需要 WebGL2、三维纹理和 Worker；不支持时明确提示并提供原来的涡丝对照入口，不会把简化模型伪装成三维流体。球面反应扩散、闪电生长、局部流注和自旋晶格同样需要 Worker，无法启动时会明确提示而不会播放假数据。空间摆和刚体的物理运动是三维的；势能地形的物理运动是二维的，第三个画面坐标只是势能；图灵模型只计算二维球面上的浓度。资源均在此目录内，不需要构建、账号或联网；若浏览器限制本地文件的 Worker，可使用上述静态服务器。内置服务器禁用缓存；维护时同步更新各实验入口及对照页面 HTML 中应用 CSS、模型和脚本的版本参数，避免静态托管环境混用旧资源。项目仓库及外部参考文献链接需要联网。

### 动手实验

1. 在**实验预设**中选择「蝴蝶效应」「微小摆动」或「高能摆动」。默认两颗球，其中「蝴蝶效应」初始姿态本身就是非共面的。金色为主链 A；可在控制台开启蓝色微扰链 B，它的末节初始方向与 A 仅有微小偏差，用于观察两条轨迹的演化。对照链默认隐藏，但两条轨迹和距离读数仍会计算。
2. **直接拖动任意摆球**，可在相邻关节限定的球面上设置它的三维初始位置；下游球体会随上游关节一起移动。拖动时会暂停并将当前姿态作为新初态，初始速度设为零。也可在控制台选择球号，分别调节相对竖直向下的夹角 `θ`（0–180°）和水平面内的方位角 `φ`（−180–180°）。拖动空白处旋转视角，滚轮缩放，双击或点击恢复视角复位。
3. 用**添加球体**在末端接一节，用减号移除当前选中球体（至少保留一颗）；球号下拉框可选择任何一级。「聚焦」会跟随选中球并隐藏支架，再点击「取消聚焦」或按 `Esc` 返回聚焦前的视角；工具栏「恢复视角」则回到默认视角。添加或移除时同样暂停并将当前姿态保存为新初态。选择预设或卡片中的实验按钮会恢复相应的两球预设。
4. 控制台还可调节重力、后续球相对于第一球的质量比，以及两条链末节初始方向的微小偏差；可切换微扰链和末端轨迹。修改参数会按新条件重置，但不改变当前播放/暂停状态。
5. **播放、暂停、单步、重置和倍速**控制实验。单步推进 1/60 秒；重置使用当前初始条件并保留播放状态。球体数量**没有人为设定的上限**，但计算时间、显存、内存和数值稳定性受设备限制；球越多播放可能越慢，遇到数值失稳会暂停并提示调整。下载按钮保存模型画布 PNG，不含周围 HTML 控件或标签。
6. 点击知识卡片，观察两条链的真实末端距离、主链动能和势能交换，或末节方向与其变化速率；实时数据和曲线都来自当前模拟。

模型获得键盘焦点后，方向键旋转，`+` / `−` 缩放，空格播放或暂停。遵循系统减少动态效果设置时，实验初始为暂停；标签页隐藏时，运行中的实验会暂停，需手动继续。

### 三维多重摆模型与数值说明

这是具有**三维球铰**的理想串联摆：每根质量可忽略的刚性杆长度为 1 m，所有摆球可在三维运动，并非把平面轨迹旋转成三维图像。第一球质量为 `m₁ = 1 kg`，后续球质量均为 `m₁ × 质量比`；重力可调。理想模型不包含空气阻力、摩擦、杆/球碰撞，也不将装饰支架视为障碍物。

令 `qᵢ` 是从上一关节指向第 `i` 个球的三维单位向量，`l = 1 m`，则：

```text
qᵢ = (sin θᵢ cos φᵢ, −cos θᵢ, sin θᵢ sin φᵢ)
rᵢ = Σⱼ₌₁ⁱ l qⱼ                 vᵢ = Σⱼ₌₁ⁱ l q̇ⱼ
T = Σᵢ ½mᵢ |vᵢ|²                V = Σᵢ mᵢg(rᵢ,y + il)
```

势能以整条链垂直下垂为零。对于每根杆，刚性约束满足 `|qᵢ| = 1`，且 `qᵢ · (r̈ᵢ − r̈ᵢ₋₁) = −l|q̇ᵢ|²`。`spatial-model.js` 通过求解杆约束力的对称三对角系统来计算加速度，每次导数计算为 O(N)；每次积分后将方向与方向速度投影回约束面。两条链独立积分，B 的末节方向相对 A 旋转指定微小角度。

公开模拟时钟步长为 `1/240 s`，内部采用四阶 Runge–Kutta（RK4）；长链、较强重力或高速运动时会自动细分内部步长。为避免数值失稳使页面卡死，如果所需细分超过安全阈值（每个公开步最多 128 个子步），模拟会停止并提示调整。RK4 不是辛积分器，也不严格守恒能量；误差和浮点舍入会累积。界面显示主链 `T + V` 与初值之差：初始能量不小于 `10⁻⁶ J` 时以百分比显示，否则显示焦耳单位的绝对误差。

为使不同长度的链都能显示在画面中，**画面按球数缩放模型**，每根杆在计算中仍为 1 m。主链和蓝色对照链及其轨迹采用相同的空间缩放和坐标变换，**没有人为平移错位**；在初态偏差很小时，两条链可能几乎完全重合。「敏感依赖」卡片和实时读数使用两条实际数值轨迹的三维末端欧氏距离，对数图中小于 `10⁻⁶ m` 的值仅在绘图时按下限显示。历史曲线会逐步降低旧数据采样密度，空间轨迹只保留最近一段。距离可能增长也可能缩小，短时间分离不是混沌的证明；无摩擦摆是保守系统，不应直接称作耗散系统的奇异吸引子。

## 自由刚体与恒力实验

[`rigid-body.html`](rigid-body.html) 是第三个全视口实验台。控制台、知识卡和顶部导航沿用相同的可收起布局；窄屏默认收起侧栏，同一时间只展开一侧。

1. 默认无外力。选择「小惯量轴」「中间轴」或「大惯量轴」作对照；每个预设在主要旋转方向以外加入小扰动。默认惯量为 `[1, 2, 2.6] kg·m²`，初始角速度为 `[0.10, 3.20, 0.15] rad/s`。播放中间轴预设，观察刚体翻转，再与最大、最小惯量轴对照。精确绕中间轴旋转是解，但对微小扰动不稳定。**不稳定性不等于混沌**：无力矩自由刚体是可积系统。
2. 在控制台打开「施加恒力 F」，设置 `0–3 N` 的大小、水平角 `φ` 和仰角 `α`，也可用六个方向按钮快速指向空间中的 `±X`、`±Y`、`±Z`。恒力的方向固定在**空间坐标系**中：水平 `0°` 指向 `+X`，`90°` 指向 `+Z`；仰角 `+90°` 指向 `+Y`，`−90°` 指向 `−Y`。场景右上角的小坐标架表示空间方向，刚体上的彩色轴则随刚体转动。控制台还显示力的空间分量、质心位移、质心速度和当前力矩。
3. 作用位置可选「质心」或「刚体 +X 面」。作用于质心时只有平动加速，不改变绕质心的自转；作用于 +X 面时，施力点固定在刚体上并随之转动，通常产生随姿态变化的力矩。在两次调节之间，力在空间中的大小和方向保持不变，并非随刚体一起转向。相机和装饰性参考环跟随质心，底网是空间参考，不是障碍物。
4. 力的开关、大小、方向和作用点都即时生效：位置、速度、姿态、角速度、轨迹和仿真时钟保持连续，播放状态不变。关闭力后已获得的速度保留，质心按惯性继续运动，控制台仍显示位移和速度；底部「重置」才按当前设置回到初态。左侧主惯量和**刚体坐标系**中的初始角速度则属于初始条件，调整它们或选择旋转预设会重新开始，质心初始位置和速度为零。旋转预设不会关闭恒力；知识卡的「复现中间轴」按钮会先关闭恒力，避免把外力驱动误认成无力矩不稳定性。中间轴按惯量大小排序；存在相等主惯量时没有唯一的中间轴，相关预设与读数会停用。
5. 拖动刚体设置三维初始姿态，操作会暂停并以当前姿态和控制台中的初始角速度重置轨迹；「恢复默认姿态」也会暂停并重置。拖动空白处仅旋转视角，滚轮缩放，双击或点击「恢复视角」复位相机。高分辨率屏幕拖动期间临时降低绘制分辨率，结束后恢复，不改变动力学计算。模型获得键盘焦点后，方向键旋转视角，`Alt` + 方向键调整初始姿态，`+` / `−` 缩放，空格播放或暂停；触摸屏可直接拖动。
6. 可显示或隐藏刚体主轴、绕质心角动量 `L`、角速度 `ω`、质心速度 `v`、中间轴轨迹和质心轨迹。浅色 `v` 箭头从质心出发，表示**空间坐标系**中的速度；关闭外力后，只要速度非零仍会显示。橙色质心轨迹记录真实计算位置，并叠加在实体上以显示短轨迹（不是表面划痕，也没有人为平移）；当观察方向与路径接近重合时，可旋转视角查看。`L`、`ω` 箭头长度固定，只表示方向；`F` 与 `v` 使用各自的显示比例，并为较小的可见非零值保留最短长度，`v` 箭头在高速时达到长度上限，不可直接比较不同物理量的箭头长度。同向的 `F` 与 `v` 可能重叠。右侧卡片以中间轴与 `L` 的方向余弦及其历史曲线观察翻转，虚线标出最近一次受力改变；当 `L = 0` 时方向未定义，显示「—」。偏心外力下，翻转也可能由力矩驱动，不能直接用无力矩稳定性定理解释；即使后来关闭或改为质心施力，卡片仍会提醒轨迹包含此前的偏心受力，直到重置实验。每条空间轨迹只保存最近 420 个显示采样点；右侧方向余弦历史曲线在长时间运行后会逐步降低采样密度。
7. 在「力与速度」知识卡查看实时速度、加速度、力矩和 `F` 与 `v` 的空间夹角。点击「演示先加速，再转向」会**重置并暂停**：保留控制台中的惯量、初始角速度与初始姿态，从静止开始以 `1.5 N` 沿空间 `+X` 方向在质心施力 1 模拟秒，然后不改变运动状态、将力转向 `+Y`，并自动显示速度箭头和质心轨迹。此时 `r = [0.75, 0, 0] m`、`v = [1.5, 0, 0] m/s`、`F = [0, 1.5, 0] N`，夹角为 `90°`。点击播放可观察速度逐渐转向与路径弯曲；窄屏会自动收起卡片以露出模型。底部普通「重置」使用当前的 `+Y` 受力设置，不会自动重演第一段；再次点击卡片按钮才重演完整对照。
8. 底部可播放、暂停、推进 `1/60 s`、按当前初态重置、调整倍速或下载模型 PNG。导出包含场景及背景，不包含 HTML 控制台、卡片、页眉文字或空间坐标小图；画布内的矢量标签保留。启用或关闭力时取景会平滑调整；遵循系统减少动态效果设置时初始暂停并立即调整取景。标签页隐藏时自动暂停。受设备和浏览器负载影响，播放速度不保证始终与真实时间一致。

### 刚体模型与数值说明

模型是质量 `m = 1 kg` 的均匀长方体，无支点、摩擦、空气阻力或碰撞。默认 `F = 0`，质心初速度为零，因而保持原位；启用恒力后，质心按牛顿方程自由平动。三个正的主惯量须满足严格三角不等式；滑块自动限制在可实现的范围。长方体的物理尺寸由主惯量反算，渲染时尺寸与位移整体使用相同缩放以适应画面，装饰线和箭头不参与质量计算。

设 `q` 与 `R(q)` 将刚体坐标变换到空间坐标，`a` 是刚体坐标中从质心指向作用点的向量。对于主轴系中的分量，模型同时求解牛顿–欧拉方程与姿态四元数：

```text
m r̈ = F                         τ_body = a × (Rᵀ F)
I_x dω_x/dt = (I_y − I_z) ω_y ω_z + τ_x
I_y dω_y/dt = (I_z − I_x) ω_z ω_x + τ_y
I_z dω_z/dt = (I_x − I_y) ω_x ω_y + τ_z
q̇ = ½ q ⊗ (ω_x, ω_y, ω_z, 0)    L_cm = R · (I_x ω_x, I_y ω_y, I_z ω_z)
```

力的空间分量为 `F = |F|(cos α cos φ, sin α, cos α sin φ)`。作用于质心时 `a = 0`、力矩为零；作用于 +X 面时 `a = (a_box/2, 0, 0)`。实时夹角使用空间向量 `acos(F·v / (|F||v|))` 并限制余弦到 `[-1, 1]`；任一向量为零时方向未定义，为避免浮点噪声，大小不超过 `10⁻¹⁰`（分别以 N 和 m/s 为单位）也显示「—」。场景中 `v` 的长度采用 `min(2.2, max(0.8, 0.5 |v|))` 显示单位，`F` 采用 `max(0.32, 0.65 |F|)`；这只是各自的绘图尺度，不改变动力学或读数。

无外力矩时旋转动能和空间中的 `L_cm` 守恒；偏心施力下它们一般不守恒，因此卡片会改为检查总机械能与线动量定理：

```text
E_total = ½ Σᵢ Iᵢωᵢ² + ½m|v|² − F · (r + R a)
m(v − vₛ) = F (t − tₛ)
```

`tₛ` 和 `vₛ` 是当前受力段开始时的时刻和速度。实际的力向量或作用点发生变化时，系统保留运动状态和全程时钟，并以新受力条件重新建立一段诊断基准；之后直至下次调整，`F` 和 `a` 固定。由于 `−F · (r + R a)` 的定义随受力设置变化，段与段之间的机械能数值可能跳变，不能直接用全程初值声称守恒。关闭力后的无力矩段也从关闭时的旋转能量和角动量重新检查守恒。

显示的动量定理误差为上述向量差的绝对大小，单位 `N·s`；能量误差相对本段初值显示，初值接近零时显示绝对误差。积分使用固定步长 `1/240 s` 的 RK4，并在每一步归一化四元数。RK4 并非严格守恒方法，长期积分仍有舍入与数值误差；恒力持续作用时位移和速度会不断增长，渲染与数值精度受到设备限制。中间轴对齐值为 `Iᵢωᵢ / |L_cm|`，不是绕该轴的转数。

## Hénon–Heiles 势能地形与庞加莱截面

[`henon-heiles.html`](henon-heiles.html) 是第四个全视口实验台。它把**二维构型空间** `(x, y)` 中的运动映射到三维势能图：图上高度是 `V(x, y)`，不是物理高度，质点也不是沿曲面受重力滚动。左侧可收起控制台设置总能量、初始位置和速度方向；右侧可收起知识卡联动显示截面、势能与动能、鞍点通道及方程。

1. 默认「环状截面」与「复杂轨道」使用同一总能量 `E = 0.125`，分别从 `(x₀, y₀, φ) = (0.15, 0, 90°)` 和 `(0.2, 0, 101°)` 出发；选择预设会重置实时轨迹并重新快速采样。比较它们的截面可以看到不同的有限时间形态，单凭这些点不能严格证明混沌或长期稳定性。
2. 修改滑块会以新初态重置轨迹，但保留播放/暂停状态。初始位置限制在 `r ≤ 0.95` 且 `V(x₀,y₀) ≤ E`；不满足时拒绝该次调整并提示。速度方向 `φ` 从 `+x` 朝 `+y` 测量，速度大小为 `√[2(E − V)]`，所以改位置或能量会改变初速度大小。拖动金色状态点会暂停，并从所指的当前位置重设初始位置；拖动时沿用控制台选定的初速度方向。若当前点已离开初态允许区，请先重置或使用滑块。空白处拖动、滚轮、方向键和 `+` / `−` 控制视角；双击或按钮恢复视角，空格播放/暂停。
3. 青色菱形 **Q 是独立的地形探针**，默认位于 `(0.4, −0.25)`；鼠标悬停显示当前位置的 `x、y、V、|F|`，点击或触摸地形放置探针，也可拖动菱形，控制台的探针滑块支持键盘微调。面板与浮窗显示探针处势能和受力，探针竖线连接它在构型平面上的投影。探测、拖动、跟随质点、切换矢量均不暂停、重置或改变真实轨道，也不取消截面采样。探针限于显示范围 `r ≤ 1.5、V ≤ 0.36`，可以测量 `V > E` 的位置；只有在 `r ≤ 0.95、V ≤ E` 时才能主动点击「设为初态」。应用会保留能量和速度方向、暂停并重置轨道、重新采样，保留同能量对照。预设或轨道重置不会自动移动探针；「移到质点」可以将它移至当前状态。
   悬停或点选使用原始三次势能求交，若画面上前后地形重叠则选择最靠近镜头的可见分支；拖动已有探针沿局部分支移动。显示网格是有限密度的近似，因此在边缘或轮廓处可能与精确求交略有差异。隐藏探针时，若力的来源原为探针则切回质点；重新选择「探针处」或点击地形会重新显示探针。
4. 青色线是真实二维轨迹按 `(x, y, V)` 映射到势能面上的记录；可选的淡色线是同一轨迹在构型平面上的投影。紫色速度箭头始终跟随质点；珊瑚色受力 `F = −∇V` 和蓝色梯度 `∇V` 可单独开关，并可选择在质点或探针处观察。三者都表示**二维构型平面内的物理矢量**，不是势能图的高度方向；力与梯度严格相反，零矢量不绘制。箭头长度按大小缩放并有显示上限，数字读数仍是真实大小。金色等势线表示 `V = E`，包括显示范围内可能存在的外侧部分；`V ≤ E` 只是位置可达的必要条件，不代表轨道一定会到达。地形采样并裁切为 `r ≤ 1.5`、`V ≤ 0.36`，纵向相对于水平坐标放大 4 倍；裁切、放大、有限的网格密度和显示轨迹长度不改变积分。屏幕轨迹最多保留最近 2400 个显示采样点。
5. 默认知识卡绘制 `y = 0, pᵧ > 0` 的**定向庞加莱截面**：每次向上穿越时，以数值插值记录 `(x, pₓ)`。金点是实时轨迹的穿越，最多保留最近 400 点；青点由**相同初态的独立积分副本**快速采样，不会推进、改变或重置实时模拟。自动采样以 100 次穿越为目标，最多积分 920 个无量纲时间单位（220,800 步），遇到观察边界或数值问题也会提前停止；点击「重新采样」可重新开始，再次点击可取消并保留已采到的点。点击「保留对照」可固定当前采样，在相同能量下改变初态或选择另一预设后比较；改变能量会清除对照。
   在截面圆内点击或触摸拖动，可以直接设置 `(x₀, pₓ₀)`；方向键以 0.01 微调，按住 Shift 以 0.05 调整。程序取 `y₀ = 0`、`pᵧ₀ = √(2E − x₀² − pₓ₀²) > 0`，暂停并重置真实模拟，停止拖动或短暂停止键盘调整后重新独立采样；原有同能量对照保留，旧采样任务会取消。圆边 `x² + pₓ² = 2E` 上 `pᵧ = 0`，不属于向上穿越，圆边及圆外选择会被拒绝而不改变模拟；紧贴边界的一层数值容差也不接受，以免把切向运动误判为上穿。金色准星只在当前初态确实位于上穿截面时显示；其他初态下可用方向键从当前 `x₀` 附近开始新选择。
6. 三个鞍点分别为 `(0,1)`、`(±√3/2,−1/2)`，势能均为 `1/6`。低于该值时，**中央**允许区域与外侧区域分离，而外侧仍可能存在其他允许区域；高于该值时几何通道开放，但并不保证每条轨道离开。「开放通道」使用 `E = 0.200`、原点、`φ = 90°`。为了限制显示范围并避免势能向远处无界带来的数值发散，状态向外越出 `r = 1.5` 时暂停并提示；这只是有限观察边界，**不是永久逃逸的严格证明**。重置后可再次播放。
7. 底部支持播放、暂停、推进 `1/60` 模拟时间、按当前初态重置、倍速和下载 PNG；截图包含画布场景及背景，不包含控制台、知识卡或 HTML 标题。减少动态效果设置下初始暂停，标签页隐藏时自动暂停；显示速度受设备负载影响。

### 模型与数值说明

使用无量纲坐标及单位质量，`pₓ = ẋ`、`pᵧ = ẏ`：

```text
H = ½(pₓ² + pᵧ²) + V(x, y)
V = ½(x² + y²) + x²y − y³/3
ẋ = pₓ             ẏ = pᵧ
ṗₓ = −x − 2xy      ṗᵧ = −y − x² + y²
```

这是两个自由度的自治保守哈密顿系统，不含阻尼、碰撞或耗散吸引子。模型以固定步长 `1/240` 使用四阶 Runge–Kutta；该方法并非辛积分器，也不严格保能，长期误差会积累。实时读数 `|ΔE|/|E₀|` 从当前模拟状态计算；截面在相邻积分步之间线性插值，而不是把插值点当作新动力学状态。截面形态、通道开放和有限时间边界穿越都不等于严格的长期分类或证明。

## 三维流体涡环

[`vortex-rings.html`](vortex-rings.html) 是第五个全视口实验台的**三维流体模式**。它不再强制涡环始终保持圆形或同轴：控制台的环半径、轴向间距、环流及三维扰动只用于建立**初始速度场**，之后速度场在整个三维网格上演化。十二种预设覆盖同向追逐、相向、不等环流、不同环径与间距，以及扰动和黏度对照；选中后会重新建立初态并应用该预设的黏度，保留网格、视角、画质和播放状态。默认同向初态的半径均为 `0.86`、间距 `0.80`、环流均为 `3.0`，三维扰动为 `0.025`。在三档网格的有限时间试验中，两种染料质心会交换先后，但这不等于已证明涡核穿越或长期周期性；是否形成或持续追逐取决于初态和数值条件。控制台可切换到原来的理想涡丝对照，该对照有自己的方程和保护阈值，不与三维流体共享状态。

1. 金色和青色分别是两种**被动示踪标量浓度**，初始浓度有空间起伏，之后由计算出的速度场搬运；染料不施力，不是涡量、真实烟雾成分、流体界面或物质粒子轨迹。默认「清晰轮廓」由 WebGL2 沿视线采样当前 `A+B` 浓度，在首次越过阈值处用四次二分近似等值面，叠加淡体积和近似光照；阈值是该帧显示纹理峰值的百分比，会随峰值变化，轮廓**不是固体表面或涡核**。也可切换回沿视线累计浓度的「柔和体积」。两种方式使用同一数值场；轮廓视图每条射线采样 64 次，柔和体积采样 48 次。两种染料分别以 16 位量化打包到四个 8 位纹理通道并截到 `0–1`，再线性重建，读数仍使用未量化的计算值。这些显示方式不能创造网格中不存在的细节，也不是精确的真实光学成像。
2. 选择初态或调整半径、环流、间距、黏度、三维扰动、网格、时间步和压力迭代上限后，后台重新建立并投影初始流场，清空时间，保留播放/暂停状态；滑块停止输入约 180 ms 后应用。预设还保留时间步和迭代上限。初始扰动是速度势旋度生成的无散三维速度扰动，不是动画噪声。相向两环靠近后可继续计算，不再套用涡丝模式的近核暂停；但这不等于对真实涡线重联的可靠预测。
3. 计算盒体为 `7.2 × 4.8 × 4.8`，六面不透流并采用近似自由滑移壁面；染料也不穿墙。墙壁会改变后续轨迹，长时间演化会受到黏性及数值扩散影响，不是无界流体。网格可选 `36×24×24`、`48×32×32` 或 `72×48×48`；窄屏默认较快的第一档，其余默认第二档。网格越密计算越慢，改变网格也会改变离散误差。
4. 单步按所选 `Δt = 0.04、0.02、0.01` 推进，倍速是目标模拟速率；更小时间步需要更多计算。网格求解在 Worker 中运行，机器较慢时模拟时间会慢于真实时间。底部散度 RMS 为当前单元中心离散散度的均方根，只反映离散速度场距无散状态的程度，不能衡量画面清晰度或整体物理精度；染料质心 `B − A` 是两种浓度的轴向质心之差，不是涡核位置，也不单独证明涡核穿越。知识卡中的速度比是最大单元中心速度乘 `Δt/h` 的估计，不是染料子步的严格 CFL 上界。两种染料积分由浮点浓度计算；有限体积内部面的通量成对抵消，在封闭盒中除舍入误差外保持守恒。
5. 拖动空白处或用方向键旋转视角，滚轮及 `+` / `−` 缩放，双击或按钮恢复视角；触屏也可用控制台的「观察缩放」滑块。默认跟随两种染料的**轴向质量中心**，可以关闭；这不是涡核中心追踪。截图包含体积和背景，不含 HTML 控制台。「画面分辨率」与物理网格分开：自动模式根据负载降低绘制分辨率，暂停后恢复较清晰的静态画面；「清晰」最多每个 CSS 像素绘制 2 个画布像素（通常不超过设备像素，最长边限制为 2048 像素），「流畅」使用较少像素，拖动期间都可能临时降低绘制分辨率。控制台显示实际画布像素及其相对于屏幕像素的百分比。切换画面模式、阈值或画质不会重置流场；切换**网格分辨率**则会重新计算初态。
6. 开启「真实流场剖面」，可在 `XY、XZ、YZ` 方向选择并移动剖面；位置对齐最近的单元中心，显示的是实际坐标。Worker 从当前交错速度网格重建中心速度，以中心差分（边缘单侧差分）计算离散 `|∇×u|`，剖面颜色按**该帧该剖面的最大涡量**归一化，具体最大值在控制台显示；颜色本身不能在不同时间直接作绝对量比较。箭头表示速度投影到剖面内的分量，长度按本帧最大面内速度缩放；为减少杂乱，小于该最大值 6% 的箭头不显示，也可以隐藏全部箭头。切换或移动剖面不重置模拟。剖面叠加显示在体积前方，颜色不是染料浓度，也不是经过验证的涡核识别。
7. 选择「推动流体」会打开剖面；在剖面上鼠标或单指拖动，沿拖动方向向邻域的真实网格速度施加有限局部外加速度，随后压力投影并推进染料。可调强度、影响半径，也可用「中心试推」按钮。暂停时施力会推进一步；播放时随正常步进应用，后台繁忙时合并尚未处理的拖动输入，所以指针速度不应被视作精确的物理力–时间曲线。切回「旋转视角」保留剖面；关闭剖面会自动回到旋转工具。
8. 在「实验对照」卡播放一段并点击「保留当前实验」，保存当时截图、参数和此前的有限时间曲线；再切换预设或数值设置并运行。新实验**恰好到达**参考截图时刻会自动截取当前画面；若所选步长不能恰好到达，则提示步长未对齐。曲线记录染料质心差和最大单元中心速度，使用模拟时间对齐并在参考采样点间线性插值；超过参考时段不外推。截图受当时视角、剖面和渲染设置影响。历史最多保留 1200 个点，达到上限会逐步抽样；参考仅存在当前页面内。含交互外力的实验标记为不适合单独解释成网格收敛。
9. 要比较数值设置，可先保存一组参考，保持初态和黏度不变，只修改网格或时间步并运行至相同时间；也可比较压力迭代上限。卡片会标明初态/黏度差异或交互外力，避免把物理参数变化当成数值收敛。两档有限时间结果接近并不单独证明收敛。为减少播放卡顿，显示缓冲区在 Worker 与渲染器之间回收复用，峰值和可见区域在后台计算；等浓度视图跳过零贡献的采样工作。这些优化不改变流体网格，实际速度仍受设备限制。

### 三维流体模型与数值说明

速度 `u`、压力 `p`、运动黏度 `ν`、示踪物浓度 `c`、空间和时间都使用无量纲单位。流体假定密度恒定且不可压缩；没有温度、浮力、相变、固体碰撞或亚网格湍流模型：

```text
∂u/∂t + (u·∇)u = −∇p + ν∇²u + f_ext      ∇·u ≈ 0
∂c/∂t + ∇·(u c) = κ∇²c             κ = 0.0005
```

速度分量存放在交错 MAC 网格的面上，压力和标量存放在单元中心。速度以中点回溯的半拉格朗日方法输运，黏性以显式中心差分计算；交互外力以局部高斯核加到网格面速度，再由压力投影减少散度。施力核在每个方向截到 3 个半径，并保留墙面零法向速度。压力泊松方程采用对角预条件共轭梯度，去除 Neumann 方程右端与压力的平均值；以上一步压力热启动，若热启动残差较差则改用零初值，有限次迭代后若残差比不投影更差则放弃该次修正。每步迭代上限可选 `16、32、64、96`，默认 32；初态最多使用 150 次。目标散度 RMS 是 `max(10⁻⁹, 投影前 RMS × 0.005)`；达到目标或迭代上限后停止，浮点速度重算后的散度仍可能未达标，卡片会如实显示。因此散度只近似为零。

`Δt` 默认 `0.04`，也可选 `0.02、0.01`；三档 `h` 分别为 `0.20、0.15、0.10`，黏度范围 `0–0.030`，所有界面选项均满足显式扩散约束 `νΔt/h² ≤ 1/6`。示踪物采用保守有限体积通量、minmod 限幅与 SSP-RK2；按速度和扩散估计的 CFL 自动细分标量子步。有限迭代、半拉格朗日速度输运和有限网格会产生误差与数值耗散，即使 `ν = 0` 也不意味着数值上完全无耗散。

初始场由两条圆环的平滑 Biot–Savart 积分生成（平滑核 `ε = 0.25`、28 个角向采样点），再加可调三维无散扰动并做压力投影；这只是初态构造，后续没有圆环约束。该求解器是交互教学实验，不是经过网格收敛验证的工程 CFD，不能定量预测高雷诺数湍流、黏性重联或真实实验结果。降低网格、时间步和迭代误差并做系统收敛验证后，才能进一步讨论精度。

## 球面图灵不稳定性与反应扩散

[`turing-patterns.html`](turing-patterns.html) 是第六个全视口实验台：**二维浓度场在封闭球面上数值演化，三维球体只是显示方式**。实验包含 Brusselator 与 Gray–Scott 两套真实方程，不是贴图或球体内部的三维化学流体。这是无量纲教学模型，不包含组织生长或遗传机制，不能定量预测真实动物皮肤。

1. **Brusselator** 默认从确定的小扰动实际积分到 `t=16`；「从微扰开始」、重置与双球对照均从 `t=0` 开始。改变反应参数 B 或扩散比会保留当前场与时间；改变初态、网格、固定半径、预设或对照方式会重建初态。减少动态效果设置下开始时暂停；标签页隐藏时暂停。
2. **球面探针**与会改写浓度的「触碰激发」是两个不同工具。探针点击、拖动或按 `Enter` 选择最近的实际网格顶点，卡片实时显示该点 U、V、局部反应项、余切拉普拉斯扩散项及总变化率；双球读取相同角度位置。U 和 V 箭头的方向是 `J=−D∇ₛ浓度`：切向梯度由邻点的局部最小二乘估计，长度为 `min(0.55, 8|J|)` 显示单位，两种通量使用相同比例、过长截断；零通量不显示。箭头与求解器中的余切拉普拉斯使用不同的离散估计，背面被球体遮挡。Canvas 降级也读取和绘制相同真实数据。
3. **固定物理半径** `R=0.60–1.35` 改变真实扩散算子、扩散步长约束和理论谱，不只是缩放画面。半径对照从同一角度分布初态出发，A 为 `R=1`、B 为所选半径；反应、扩散系数和自适应子步相同。扩散比对照则令 A 的 `Dᵥ/Dᵤ=1`。两球面积加权 U 标准差、实际 `l=1–18` 主导模态和固定阈值顶点连通区域数分别显示；区域数不是客观生物斑点计数，连起来的斑点或条纹是一个区域，且依赖阈值与网格。两球物理大小按半径比例显示。这是对不同**固定球面**的比较，不是随时间生长、带稀释项的球面。
4. **稳定性相图**用指针、触摸或键盘改变 Brusselator 的 B 和扩散比，数值场不重置。实线为整数球谐阶数的理想球面临界曲线下包络，虚线允许连续波数；图中同时给出实际 U 起伏。线性边界只对均匀态附近的理想球面有效，不是有限网格精确边界，也不能保证已有图案立即消失或预测最终形状。Gray–Scott 时该 B—扩散比图明确禁用，不套用不相干的公式。
5. **球谐分解与历史**使用真实 U 场减去面积均值后、对全部实 `Yₗₘ` 的面积加权投影。可在球面显示指定 `l=1–18` 的各 m 分量重建结果：这是**有符号滤波场，不是实际浓度**，固定色阶为 `−0.20–+0.20`，零等值线与范围外截色均有标注。历史曲线保存真实计算时的投影幅度和 U 标准差，可选对数/线性纵轴；参数改变和局部激发有时间标记，重置清空，不提供虚构回放。Brusselator 预演约每 1 个时间单位、Gray–Scott 预演约每 10 个时间单位保存一次真实中间样本；播放中按模型约每 0.6 或 3 个模拟时间单位请求采样。最多保留 480 个点并对旧点抽稀。有限网格尤其是快速网格会影响高阶投影。
6. **Gray–Scott** 默认从有限幅 V 局部高斯种子实际预演到 `t=200`，另可从种子或精确均匀静息态 `(U,V)=(1,0)` 开始，调整补给率 F、移除率 k 和扩散比；局部激发添加 V 并扣除 U。静息态对无限小扰动线性稳定，图案来自这里施加的有限幅种子及后续非线性演化，不能直接称为 `(1,0)` 的线性图灵失稳。模型对照让 A 与 B 使用不同方程、默认参数和初态，半径与时间步同步，但**不是同初态单变量实验**；此时触碰只作用于 B。两模型使用各自固定色阶，不能按颜色直接跨模型比较浓度。
7. 实际浓度使用固定绝对色阶并在范围外截色，不按每一帧自动拉伸：Brusselator U 为 `0.40–4.50`（平方根映射）、V 为 `0.30–2.30`，等值线 U=`1.25`、V=`1.45`；Gray–Scott U 为 `0.20–1.00`、V 为 `0.00–0.45`，等值线 U=`0.50`、V=`0.18`。光照、插值、Canvas 投影和颜色截断不改变实际读数。底部提供暂停、单步、倍速、重置与 PNG 导出；单步通常为 `0.2`，Gray–Scott 或双模型对照为 `1` 模拟时间单位。名义 1× 速率分别为每秒 4 或 20 模拟时间单位，负载高时更慢，不跳过求解。快速、标准和精细球面分别为 642、2562、10242 顶点，精细网格更耗时和内存。

### 方程、稳定性与数值方法

固定物理半径 `R` 的球面拉普拉斯算子记为 `Δ_R`。Brusselator 在此范围使用：

```text
∂U/∂t = A − (B+1)U + U²V + Dᵤ Δ_R U
∂V/∂t = BU − U²V + Dᵥ Δ_R V
A = 1, Dᵤ = 0.002, Dᵥ/Dᵤ = 1–40, B = 1.40–1.95
(U*, V*) = (1, B)
```

`U²V` 消耗 V 并促进 U，V 并非直接抑制 U。此范围内均匀反应的线性化矩阵 `J=[[B−1,1],[−B,−1]]` 的特征值实部为负。球谐满足 `Δ_R Yₗₘ=−l(l+1)Yₗₘ/R²`，故理论增长率为 `J−[l(l+1)/R²]diag(Dᵤ,Dᵥ)` 的最大特征值实部。默认 `B=1.8、R=1、Dᵥ/Dᵤ=20` 时，均匀模态为 `−0.1`，理想球面 `l=6–17` 可增长，最快 `l=10` 约 `+0.262`。令 `q=Dᵤl(l+1)/R²`，当 `0<q<B−1` 时，该阶数过零的扩散比为 `(1+q)/[q(B−1−q)]`；整数 l 的最小值即相图实线。允许波数连续变化时阈值为 `((1+√B)/(B−1))²`，默认约 `8.568`；`R=1` 离散球谐阈值约 `8.595`。有限网格的特征值又与理想球面不同。

Gray–Scott 使用独立的方程与参数：

```text
∂U/∂t = −UV² + F(1−U) + Dᵤ Δ_R U
∂V/∂t = UV² − (F+k)V + Dᵥ Δ_R V
Dᵤ = 0.0016, Dᵥ/Dᵤ = 0.10–1.50, F = 0.015–0.080, k = 0.045–0.075
默认 F = 0.050, k = 0.065, Dᵥ/Dᵤ = 0.50
```

这对应 `U+2V→3V`、U 补给和 V 移除。均匀静息态 `(1,0)` 的反应特征值是 `−F` 与 `−(F+k)`；加入非负球谐扩散后仍为负。图中 Gray–Scott 理论曲线只描述该静息态，不分析可能存在的其他非零均匀平衡态，也不将所有斑纹归为经典图灵失稳。

两模型使用细分正二十面体上的质量集中的余切有限元拉普拉斯算子，面积加权扩散总和为零；固定 R 将单位球面的拉普拉斯除以 `R²`、切向梯度除以 `R`。反应和扩散采用自适应子步的二阶 Heun / SSP-RK2；步长受扩散与各自非线性反应约束，两阶段检查有限、非负和安全上限，必要时重试更小子步，双球共用子步。无法安全推进时报告数值错误，不将其解释为物理爆炸。频谱是有限网格的面积加权投影，线性预测、滤波场、离散样本与实际浓度各不相同；这些测试不构成化学实验或生物模型精度认证。

## 三维闪电生长与介质击穿

[`lightning.html`](lightning.html) 是第七个全视口实验台。它在**真实三维离散网格上反复求解电势，再按局部场强随机选择生长连接**。实际连接和分叉来自计算，并非预录闪电或电子轨迹；「放电观感」中节点间的小弯折只是显示插值。上极板、负极与已有通道固定为 `φ=0`，下极板和正极固定为 `φ=1`，四侧以省略越界连接的方式近似绝缘。DBM 的电势、距离和场强以及独立直流电热模型均为无量纲量；新增回击模型另外假设 SI 长度、电压及等效线参数，不由 DBM 自动标定。它们都不是完整真实雷电。

1. 默认「分枝闪电」使用 `η=4.0、种子 19`，从初态实际预演 120 个生长事件。其他预设为「尖端偏选」`η=4.6、种子 27、42 步`，「密集分叉」`η=1.0、种子 2026、110 步`，以及两极错位的 `η=2.8、种子 42、70 步`；名称描述观察方向，不保证每次单样本呈现特定统计结果。按当前条件「重置」从第 0 步开始。电热区的「快速网格：预演至接通」会将模型重置为快速网格、尖针、`η=4.6`、种子 27，并真实计算到接触（该设置约 69 步）；它不会伪造一个已经接通的图形。
2. **电极形状与尺寸**同时改变两侧电极的实际固定电势体素：可选锥形尖针或圆端钝头，调伸入长度及基部半径（均相对极板间距）。场景绘制这些体素的外表面，而不是把一根细针换个外观。连续目标尺寸在每个网格上吸附到格点；界面显示实际体素数量与伸入长度，粗网格可能无法区分小幅尺寸变化。电极中心限制在能容纳所选半径的范围内。选择「移动负极／正极」，在尖端高度的水平面点击或拖动；松手后旧路径被丢弃，按新位置从初态重算。X、Z 滑块及聚焦画布后的方向键也可调整位置。拖动时隐藏旧通道；模型参数变化立即取消后台对照并清除旧的事件／电热／回击结果，停止输入约 180 ms 后启动新求解。
3. `η=0` 时每条候选**连接**等概率，增大 `η` 则偏重电势落差除以连接距离更大的连接。实时改变实验侧 `η` 保留已有路径和当前电势；已提交的生长步可能先完成，概率更新前不允许按旧概率探测。更换随机种子、网格、残差阈值或电极会重置。每一步只是一次随机生长事件，不代表真实物理时间。
4. 显示候选节点，选择「候选探针」后点击／触摸节点；也可点击按钮或按 `Enter` 选择当前概率最大的候选。探测会暂停；若后台已有提交的生长步，等待完成后读取最新候选。读数显示节点电势、面邻和斜邻连接的场强、节点总概率与两种连接数；节点有多条连接时总概率是各连接概率之和。候选点亮度使用 `√(节点概率 / 本帧最大节点概率)`，不等于绝对概率色阶。
5. 开启**同种子双模型对照**后，从第 0 步独立求解两侧，A 和 B 的网格、电极及种子相同，`η` 可以不同；双方尚未结束时逐个事件同步。中途改变 B 的 `η` 会提示这不再是全程恒定的单变量对照；先接触的一侧停止，另一侧继续。同一随机数可能因概率不同而选择不同连接。电热模型仅对关闭双模型对照后的单棵已接通树启用；回击模型同样只对单棵已接通树启用。
6. 「电势剖面」使用真实网格电势与固定 `0–1` 色阶，Z 位置吸附到网格；箭头是 `E=−∇φ` 的平面内中心差分投影，长度按该剖面的最大面内场强缩放，并非绝对三维场强。探针连接两端的差分与箭头的中心差分不是同一种估计。选择「单次事件的前后场」中的捕获按钮会暂停，等待任何已提交生长批次后**只捕获下一事件的前场与重算后的后场**。可切换前／后电势、`Δφ` 或 `Δ|E|` 剖面，并用 X、Y、Z 控件移动探针，查看前后电势、场强和候选概率。差值色阶按当前剖面的最大绝对差归一化，并以 `|Δ/最大差|^0.3` 非线性增强微弱变化：暖色增加，冷色减少；仅比较事件前后均为空间的内部节点，非候选节点显示「非候选」而不是虚构概率。差值模式不叠加当前场箭头。若该事件恰好接触正极，DBM 不求后场，界面明确拒绝显示伪差值。继续生长、失败或更改模型条件会清除旧对照。
7. 「真实网格对照」在独立 Worker 中以相同目标电极尺寸、`η` 和种子，从初态分别求解两套所选网格；显示实际事件数、分叉数、已生长通道长度、初态中心电势与最大候选连接场、末态中心电势和残差。每组使用相同事件预算，接触则提前停止。相同事件数不等于相同物理时间或通道长度；格点吸附和随机路径也不同，这不是严格收敛证明。计算可取消，预演按完整生长事件分批让出 Worker，并显示进度。
8. **接通后的电热**是与 DBM 生长分离的简化直流电阻—热模型。实际接触正极后可调无量纲电源电压与散热、播放或单步；显示电流、峰值温度及通道焦耳功率。唯一源—目标树路径导电，未接通的悬空支路在此直流模型中电流为零；电极本身视为等势，内部电流分布不求解。电流、温度或单位长度功率可分别作为通道颜色／亮度的**固定非线性显示色阶**，超出色阶饱和，颜色不是求出的光谱或真实发光强度。此模型不反向改变 DBM 电势或树，也不是先导、回击或真实空气参数。
9. 「多随机种子统计」在独立、可取消的 Worker 中，以当前电极和起始种子、所选统计网格、固定事件预算，分别求解当前 `η` 与对照 `η` 的同一组连续种子（超过 4294967295 后从 1 循环）。显示每组样本数、预算内接通数与比例、未接通截尾数、假设样本近似独立的 95% Wilson 比例近似区间、分叉数和实际生长键长度的均值及样本标准差。未在预算内接通不代表永不接通；分叉与长度均统计至接通或预算上限，**包含截尾样本**；单个样本时样本标准差未定义，显示「—」。比例区间不是两组差异的显著性检验。有限样本、网格取整和经验 `η` 不能证明显著性或预测真实雷电；运行中更改相关模型条件会取消并清除结果。
10. 「原始网格」只显示实际生长的直线连接；「放电观感」将每条连接细分四段，保留物理端点与分叉，并用固定、垂直于连接的有界偏移制造视觉折线。合成云、辉光、细节弯折和默认线宽仅作视觉表现。拖动空白处旋转视角；滚轮或 `+`/`−` 缩放；底部提供播放、暂停、单步、倍速及 PNG 截图。截图包含背景与模型范围说明，不含控制台或知识卡。`1×` 是每秒约 16 个事件的目标速率，设备繁忙时更慢；减少动态效果设置下初始暂停，隐藏标签页会暂停。每棵树的生长容量为 3000 事件，达到上限暂停，容量不是物理击穿判据。

11. **回击传播**位于控制台靠上方。接触目标后点击「后台计算回击」，或者点击「快速接通并演示回击」——后者会重置为快速网格、`η=4.6`、种子 27，真实生长至接通后自动求解并播放。它不修改 DBM 路径：只把已接通树作为**假设先导通道**，丢弃 DBM 的无量纲电势，给每个等效节点预置负电压，将目标端接地，在独立 Worker 中计算有限速度的瞬态 RLC 响应。可设置假设极板间距、初始电压幅值、单位长度 R′/L′/C′、接地电阻和求解时长；改变求解参数立即取消并丢弃旧结果，显示设置不触发重算。
12. 结果提供接地点和主路径探针的电流曲线、探针电压与焦耳功率、当前帧悬空支路最大电流、累计电荷和能量收支。探针位置按**接地点起的主路径弧长**吸附到线段中点，不是垂直高度；其余支路仍参与求解。时间滑杆、播放、单步和重置回放 241 帧**已计算**的解；默认观看速度为每现实秒 5 μs，底部倍速只影响回放。显示回击色阶时，底部播放／单步／重置控制回击；隐藏色阶后恢复生长控制。通道可按 `|I|`、`I²R′` 或累计焦耳热／长度着色，使用固定非线性归一色阶并在上限饱和，不是计算的光谱或真实亮度。PNG 会标注回击模式和模型时间。回击与无量纲直流电热可切换查看，知识卡并列显示回击的支路最大电流和已启动直流模型的支路电流；单位与边界条件不同，只比较是否有支路电流，不能直接比较数值大小。
13. 回击结果由后台预计算并可取消；后台失败不会伪造结果或破坏主 DBM。切换网格、电极、种子或拖动电极立即清除旧回击；另一个网格／统计 Worker 可独立运行。标签隐藏时停止回放，不在回来后自动继续。回击 RLC 是**人为预充电的简化传输线模型**，不是三维麦克斯韦—等离子体、气动或光谱模拟；未用实测闪电校准，不能预测或用于防雷设计。

### 生长规则、数值与电热限制

快速、标准、精细和高密网格分别为 `17×25×17`、`25×37×25`、`33×49×33` 和 `41×61×41`，高度为 1，`h=1/(ny−1)`。目标长度 `L` 和半径 `R` 在跨网格时不变，实际轴长吸附为 `round(L/h)h`。尖针在该长度上按锥形缩小半径；钝头是带圆端的柱体；格点中心落入形状的单元作为实际固定电势边界。负极体素内部的树形连接只用于保持数据拓扑，不显示成闪电，不计入生长长度或初始分叉；负极表面可作为生长起点，固定电势的其余上极板不同时产生种子。有限网格体素使实际表面和场仍随分辨率变化。

自由节点采用 18 邻接加权图拉普拉斯近似，6 个面邻的权重为 `1`，12 个棱向斜邻权重为 `1/2`；边界仅计入域内连接。令通道节点为 `j`，候选节点为 `i`：

```text
φᵢ ≈ Σⱼ wᵢⱼφⱼ / Σⱼ wᵢⱼ               w面 = 1, w斜 = 1/2
P(连接 i←j) ∝ (Δφᵢⱼ / dᵢⱼ)^η         d面 = h, d斜 = √2 h
P(节点 i) = Σⱼ P(连接 i←j)              通道 φⱼ = 0
```

连接和节点按上述权重采样；每一步以上一场为初猜，固定次序 SOR 反复求解。前三档默认 `ω=1.86`，高密档采用 `ω=1.75`；每 8 次扫描检查自由节点与其**加权邻点均值**之差的最大绝对值，默认阈值 `10⁻⁵`、最多 1600 次扫描。未达标时停止并提示，不使用未验证的场继续生长。残差是离散方程局部指标，**不是整体误差上界**；离散方向、电极取整、随机选择和有限阈值均会影响路径，也不保证严格网格收敛。

接触正极或下极板时 DBM 立即停止，不对同一节点再施加互相冲突的电势，所保留的电势仍是**接触前最后一场**。之后的独立教学电路给每条非电极通道键 `i` 赋予 `Rᵢ=ℓᵢ[1+0.15(Tᵢ−1)]` 和 `Cᵢ=ℓᵢ`，以固定镇流电阻 `Rₛ=0.5` 串联：

```text
I = V / (Rₛ + Σ导通路径 Rᵢ)      Pᵢ = Iᵢ²Rᵢ
Cᵢ dTᵢ/dt = Pᵢ − λ Cᵢ(Tᵢ−1)     T初始 = 1
```

无量纲电压 `V` 可调 0–5、散热系数 `λ` 可调 0–3；每个电热单步使用显式 `Δt=0.04`。不建模电极内部、支路间热传导、空气流动、电离或光谱。若下一步超过 `T=20`，为数值安全而停止并保留上一步；这不是物理击穿判据。累计焦耳热、散热和热储能使用同一离散步计算，测试检查其收支一致。DBM 生长本身不包含真实电流、发热、声或电磁波；这一独立电阻—热扩展也不是等离子体求解或云地闪电预测。

### 回击传播：假设、方程和数值边界

`lightning-return.js` / `lightning-return-worker.js` 是完全独立的**预充电分叉 RLC 传输线**。它仅借用 DBM 的树拓扑：将负极内部体素骨架折叠为一个理想等势源节点；每个真实生长键分成 4 条等长线段，给定极板间距 `H` 后，每段长度按网格位移和 `H/(ny−1)` 换算为米。目标端被解释为接地端；切换模型时没有用 DBM 的 `φ=0/1` 作为真实先导电压，而是显式假设通道节点的初始电压均为 `−V₀`、初始电流为 0。每个自由节点的对地电容为相邻线段 `C′ℓ/2` 之和；接地端不赋自由电容，末段另串接接地电阻 `R_g`。源端没有持续云端供电，末端支路开路，但开路支路的等效电容仍可在瞬态过程中充放电；线端反射导致的电流反向并不等于模拟了后续闪击。源电极体素、其内部电流和电容未单独求解。

每条线段和节点满足分布参数电路离散式：

```text
Lₑ dIₑ/dt = Vₐ − Vᵦ − (Rₑ + δ接地 R_g) Iₑ
Cᵢ dVᵢ/dt = −Σ离开节点 Iₑ + Σ进入节点 Iₑ
Lₑ = L′ℓₑ       Rₑ = R′ℓₑ       v = 1/√(L′C′)       Z₀ = √(L′/C′)
```

内部电流方向规定为 DBM 树的源→目标；界面曲线把**接地点流入通道**取正，因此显示内部电流的负值。默认 `H=2000 m、V₀=10 MV、R′=0.10 Ω/m、L′=2 μH/m、C′=50 pF/m、R_g=10 Ω`，得到假设线参数下 `v=1×10⁸ m/s、Z₀=200 Ω`。界面范围分别为 `H 500–5000 m、V₀ 1–30 MV、R′ 0.02–0.8 Ω/m、L′ 1–8 μH/m、C′ 20–120 pF/m、R_g 0–100 Ω`；代码拒绝超过光速的等效参数。这些是独立可调的**模型假设**，不等于从雷云和空气测得的特性。

采用电压整步、电流半步的交错显式更新，电阻项用梯形平均。时间步由电容—电感矩阵的 Gershgorin 上界和电阻时间尺度取安全余量，再将所选 `20/50/100 μs` 均分为 240 个输出间隔、每个间隔细分为整数内部步；显示的电流相对整步时间偏移不超过半个内部步。计算用 Float64，传给画面的每段电流、电压和累计热以 Float32 存储；曲线和色彩来自同一批计算快照。峰值过大或非有限的数值会在提交前停止并保留上一步，这只是数值保护，不是物理击穿判据。

能量与电荷收支检查的是**离散方程**：

```text
Hⁿ = ½Σ Cᵢ(Vᵢⁿ)² + ½Σ Lₑ(Iₑⁿ⁻½)² + (Δt/2)Σ Iₑⁿ⁻½(Vₐⁿ−Vᵦⁿ)
Jₑ += Δt Rₑ [(Iₑⁿ⁻½ + Iₑⁿ⁺½)/2]²
J_g += Δt R_g [(I_gⁿ⁻½ + I_gⁿ⁺½)/2]²
能量残差 = H⁰ − Hⁿ − ΣJₑ − J_g
电荷残差 = ΣCᵢVᵢ − Q₀ − 累计接地注入电荷
```

`H` 的最后一项是交错时间网格的修正项，不是热量。色阶按参考 `I_ref=V₀/Z₀` 定标：电流上限为 `I_ref`，功率上限为 `R′I_ref²`，累计热／长度上限为 `R′I_ref²×10 μs`；颜色按归一值的 `0.42` 次幂显示并饱和。探针瞬时功率使用半步电流的 `R′I²`，累计热使用上面的梯形电阻耗散；两者的时间离散略有区别。背景云、线宽和光晕只是表现。

单元测试对无损直线检验有限传播时间及接地点电流 `V₀/Z₀`，检查有限网格细化时前沿到达误差下降、分支瞬态电流、带损电路的离散能量和电荷收支，以及参数极值和失败回滚。这些只是对数学和实现的检验：均匀预充电、理想接地、固定局部 R′L′C′、独立对地电容与无互感都很粗糙。模型没有求解真实的先导电荷分布、空气导电率与热反馈、冠层、三维全波电磁辐射、流体冲击、雷声或光谱；也没有把电流波速等同于光学波速。**没有采用实测波形校准或验证，不能称为真实雷电复现或工程预测。**

## 三维自旋晶格与伊辛相变

[`ising.html`](ising.html) 是第八个全屏实验台；闪电仍保留为第七页。默认简单立方的每个位置、或所选晶体结构中手动启用的每个点位都有实际计算的 `+1` 或 `−1` 自旋，金色/青色和上下箭头默认对应方向；背景、地面平台、剖面边框与光晕是视觉表现，不表示材料的真实照片、磁场或光谱。控制台与知识卡均可收起，移动端一次展开一侧。

1. **临界涨落**默认使用 `L=20`、`T=4.51`、`h=0` 和随机初态，从种子 `20261031` 真正执行 120 次扫描后展示；这些预演不计入下方短窗口，也不保证已经达到平衡。另有「低温有序」（`T=2.5`、全向上、0 步）、「高温无序」（`T=7`、随机、预演 30）、「降温成畴」（`T=2.8`、随机、0 步）和「外场偏置」（`T=5.5,h=0.6`、随机、预演 60）。选择预设会重建；底部重置使用当前温度、外场、种子与选中的初态，从第 0 扫描重新开始，不自动重复预演。L、初始排列或种子改变同样从初态重建，保留播放/暂停状态；预设会覆盖初始排列。切到晶体图后，「中温」等示例按平均绝对耦合场选择演示温度，**不是**估计该结构的临界点。
2. 以 `J₀=k_B=1` 为基准，温度 `k_BT/J₀` 可调 0.25–20，外场 `h/J₀` 可调 −1.5–1.5；修改时**保留所有自旋、随机数状态与扫描数**，按新外场立即更新能量，并清空统计窗口与历史。播放、暂停、单扫描和 0.5×/1×/2× 控制后台采样，1× 名义目标为每秒约 12 次扫描，实际受设备性能与浏览器调度限制。标签隐藏时暂停，返回后需手动继续。扫描不是物理时间。
3. 可独立选择随机、全部向上、全部向下或 X 向对半磁畴的初始排列（周期边界使对半磁畴有两个界面），原简单立方可在 12³、16³、20³、24³ 间选择；其他结构可选受计算预算限制的晶胞重复数，或修改并应用 32 位随机种子。**同一运行环境**中，相同初态、种子、参数和操作序列可复现；不同 JavaScript 引擎在浮点指数的最后一位可能不同，不能承诺跨引擎逐位一致。
4. 「自旋箭头」「光点晶格」和「磁畴体素」使用相同的采样自旋，可从画面右上角或控制台切换（极窄屏和横屏通过控制台）；光点大小和辉光只为可视化，不代表自旋强度。Z/晶胞 c 方向层滑块只改变显示，周期胞与晶胞块以细线标示剖面，曲面样品则仅隐藏层；隐藏的自旋和所选边界下的连接仍参与计算，所有统计始终覆盖完整样品。底部磁化条以中央为零，长度与颜色对应当前有符号磁化 m。旋转/缩放不会改变采样；探针模式点击晶格，或通过 X、Y、Z 输入坐标定位，可读取该自旋、实际邻接、加权局部场和对应翻转能量及接受概率（原简单立方为六邻居）；晶体结构通过 X/Y/Z 晶胞坐标与胞内点位定位；画面标记可见邻居；默认颜色表示实际自旋方向，组元着色时按箭头区分方向。跨周期边界的邻居只标记、不用一条穿过晶格的直线连接；隐藏层中的邻居不显示标记，但仍参与计算。选中隐藏层时会展开到该层。手动翻转是额外干预，不消耗随机数、不增加扫描数，清空统计窗口与历史。模型支持鼠标、触摸及键盘视角；移动端选择探针模式后自动收起控制台。触摸未命中细箭头时，会在可见晶格中选取附近投影点并显示其真实坐标；探针模式下 `Enter` 选择可见区域中央附近的位置；若开启界面筛选，则选择最近的可见界面格点。
5. 可开关「净变化闪光」：它比较**相邻后台快照**中的实际自旋，仅在部分发生净变化且可见的位置短暂添加显示光点，视口较小会进一步限制数量；一次批处理中偶数次翻转不会出现在净差异里。这不是每次更新的完整记录，也不是物理发光或强度。系统要求减少动态时默认关闭，之后也可手动开关。
6. 知识卡显示磁化历史、平均绝对磁化、最近邻关联与窗口内的磁化率/热容估计；磁畴卡可按当前温度和外场重建对半磁畴并切换完整体素显示。历史图每个显示帧记录一个真实状态，最多保留 150 个点；统计窗口在每个真实扫描后记录，最多 256 个点，少于 16 个样本不显示涨落估计。温度、外场改变或手动翻转后窗口重新开始，不跨不同条件混合。WebGL 不可用或上下文丢失时，交互和数值状态保留并切换 Canvas 2D 投影；截图包含数值模式标记与背景，不含 HTML 控制台。
7. **界面格点筛选**从完整相互作用图的真实自旋计算：原立方六个最近邻、或新结构的非零耦合邻接中至少一个方向相反的活跃点位才算相反邻接点；有向邻接可视为每条周期键两次，反向键只计一次。知识卡报告完整晶格的界面格点占比和反向键比例 `f=(1−最近邻关联)/2`。筛选与切层、箭头/光点/体素、探针及 Canvas 降级兼容，只改变显示与点击候选，不修改模型；直接输入坐标仍可探查被筛掉的格点。全同方向或当前显示层无界面时明确提示。原周期立方对半磁畴有两个界面；这是一种离散图诊断，并非实际材料畴壁的连续形貌或尺寸测量。无耦合键时关联和反向键比例显示「—」而不是 0；负耦合时反向邻接可能是低能有序状态。

16. **有限尺寸 / 多种子研究**：在分析台第 04 项输入 2–4 个重复数、温度范围、2/3/5 个种子及采样预算，独立 Worker 为每个尺寸和种子运行从随机态开始的升温链，每个温点预热后采样，合计有 6000 万次自旋尝试的安全预算。曲线可切换种子链内方差平均的 `χ/N` 或 `C/N`、以及由全部种子的 `m²,m⁴` 合并得到的 Binder `U=1−⟨m⁴⟩/(3⟨m²⟩²)`；误差线是**各种子单独估计值的样本标准差**，不是置信区间；若任一种子 U 无定义则不显示 U 的种子标准差。误差线超过图框会截断并在选点读数中显示完整值。仅连通全正 J 使用总磁化；连通全负 J 且二分时使用交错磁化；混合符号、受挫或断连时不画序参量涨落与 Binder，仍可看能量涨落。CSV 含每个种子的样本矩、逐种子指标、汇总量、边界、耦合规则与晶胞。短链可能低估慢涨落，温度间沿同一链升温，有限尺寸、表面、非零场、滞留态与自相关均会影响峰和曲线；不得将峰或交点直接当作真实临界温度。

### 伊辛模型与统计边界

令立方晶格有 `N=L³` 个自旋 `sᵢ ∈ {−1,+1}`，各轴周期边界。只考虑铁磁最近邻耦合并取 `J=k_B=1`：

```text
H = − Σ_<ij> sᵢsⱼ − h Σᵢsᵢ        m = Σᵢsᵢ/N        e = H/N
ΔH(翻转 i) = 2sᵢ(Σ_六个邻居 sⱼ + h)
P(接受) = min(1, exp(−ΔH/T))
```

对于所选晶体，实际计算改为 `H = −Σ_<ij> Jᵢⱼsᵢsⱼ − hΣᵢsᵢ`、`ΔHᵢ = 2sᵢ(h + ΣⱼJᵢⱼsⱼ)`；求和只涉及样品内用户启用的活跃点位及实际非零耦合；周期和开放边界不可同时使用。周期平移导致的重边按各自的周期键计数，若周期像折叠为自身则其能量为常数、不加入翻转局部场。不同组元的磁矩一律假设等大小；对单连通全负 J 二分图可用上述交错磁化，其他反铁磁或受挫体系未必有这种简单序参量，总磁化不能识别所有有序态。

每次尝试**有放回地随机选取一个活跃位置**，共 `N` 次尝试为一次 Monte Carlo 扫描，某个位置在一轮可多次或零次被选中。使用独立 Worker、随机点 Metropolis 更新与可复现的 32 位伪随机序列；能量通过接受的增量更新，外场变化时补记 `−Δh·Σsᵢ`。最近邻关联是完整晶格所有键的 `⟨sᵢsⱼ⟩`，不是磁畴大小的估计。

```text
窗口估计： χ/N = N(⟨m²⟩ − ⟨m⟩²)/T
           C/N = N(⟨e²⟩ − ⟨e⟩²)/T²
```

方括号代表当前最多 256 个连续扫描状态的简单窗口平均，并非独立样本或自动平衡证明。局部更新在临界附近可能出现临界慢化；非平衡初态、有限样本、自相关和有限尺寸均会影响这些估计，不能据此报告材料参数或精确临界指数。零场、无限简单立方晶格的文献参考值 `T_c≈4.5115` 仅作标记；有非零外场时它不是当前系统的相变边界。模型不模拟连续自旋方向、真实磁动力学、声子或材料微观细节。

### 几何与结构因子

令 `A,B,C` 为由边长及夹角构造的晶胞向量，`b₁,b₂,b₃` 为不含 `2π` 的对偶基矢，满足 `Aᵢ·bⱼ=δᵢⱼ`。把基元和中心化平移展开到所用晶胞后，周期原子位置、距离截止及点散射量为：

```text
rⱼ(n) = A(xⱼ+n₁) + B(yⱼ+n₂) + C(zⱼ+n₃),  n∈ℤ³
r_cut = (全结构最短非零周期距离) × 所选倍率
F(hkl) = Σⱼ fⱼ exp[2πi(hxⱼ+kyⱼ+lzⱼ)]
d_hkl = 1 / |h b₁ + k b₂ + l b₃|
```

图谱不求化学势、键阶或磁耦合。以理想结构和默认倍率为例，简单立方/体心立方/面心立方的第一壳分别有 6/8/12 个几何邻居，HCP 为 12，金刚石为 4。NaCl 的 Na 和 Cl 在此阈值下各有 6 个异种邻居，CsCl 各有 8 个；由于角和体心为不同元素，CsCl 是**简单立方点阵加二元基元**，不能称为单元素 BCC 点阵。金红石与锐钛矿虽然都为 TiO₂，但所用晶胞及点位不同。自定义点位或距离阈值改变后，这些计数不必保留。

## 光抵达的世界：狭义相对论光线实验

[`relativity.html`](relativity.html) 是第九个全视口实验。底部「场景」可在**车站站台、城市街道、工业长廊、山间公路和港口货场**之间切换；站台有圆柱梁柱、静止列车、木座椅与垃圾桶；四节车厢均有三角形斜顶，最近两节的车门、门框和独立车窗是具有厚度的实体，会参与相机与阴影求交；车窗为不透明示意表面，不模拟透明玻璃或车厢内部；街道有多种立面、行道树、停放车辆和路口信号设施；长廊有设备柜、接线盒与圆柱管线；山路有护栏、三角形山坡和针叶树；港口有成排集装箱、龙门吊、叉车、圆柱轮胎、货盘和油桶。这些设施都与射线实际求交，而不只是换背景。五种环境分别使用旅行箱帆布、快递纸箱、工业设备面板、山地木箱与金属货箱的前景外观，并有不同的天空或室内背景；港口集装箱的锈蚀、褶纹是示意贴图而非额外凹凸几何。默认「场景物件」不仅材质不同，主体尺寸也分别为 `[.88, 1.00, .42]`、`[1.02, .89, .82]`、`[.72, 1.13, .54]`、`[1.10, .89, .97]` 和 `[1.02, .92, .76]`（静止系半尺寸），主体是具有 12 条切角面的凸几何（五种倒角宽度分别为 0.12、0.045、0.075、0.055、0.035），并带有限三维提手、护边、圆柱滚轮、环绕封条、通风片、开关、木框条、横梁或货箱锁杆；这些部件固定在物体静止系，参与相机与阴影射线、多普勒和探针。标准方块主体半边为 1.22，也带场景部件；球体半径 1.22，不附方块部件。这些是简化的组合几何，并非真实行李或设备的精确重建；金属高光、粗糙度和纹理也不是实测 PBR 材料。切换环境会保留实验类型、速度、事件时间、形状、镜头和对照状态，并清除旧光线采样、把固定材料点重置到新物体表面；播放中的时间继续。默认 β=0.60、γ=1.25、收缩比 0.80，0.86 和 0.98 预设及清晰对照示例仍可使用。默认初态为暂停，两侧面板默认收起，以保留视野；打开左侧可调实验，点击场景采样光线会展开右侧知识卡。拖动旋转镜头，滚轮或 `+` / `−` 调视场，方向键旋转，`Enter` 采样中心，`Shift` + 方向键移动采样点，空格播放/暂停。竖屏为保留横向画面自动扩大实际竖直视场；控制台显示的是基准值。

1. **运动物体**：实验室相机静止，带静止系表面标记的物件、标准方块或球以恒定速度飞掠。水平运动轴可从 −180° 到 180°、仰角可从 −90° 到 90° 调整：正 β 时水平 0° 向右、−90° 迎面、90° 远离，正仰角向上；负 β 将三维方向整体反转。速度箭头是实验室系方向示意，单照片及左右对比时锚定中心的过去光锥事件，纯几何视图锚定同时中心（左右对比只画一支示意箭头）；可透过遮挡，既不是额外光线也不是光追物体。速度正对视线、二维箭头长度接近零时，用圆点/叉分别表示向屏幕外/内。「光锥照片」追踪同时抵达相机的光，物体上不同像素一般有不同发射时间；「同时几何」是**同一实验室观察时刻**的空间切片，包含运动方向的洛伦兹收缩，但本身不是照片。左右对照左为照片、右为同时几何；分界滑块只改变显示区域，不改变时刻或镜头方向。物体在同一事件的两种表示可能出现在很不相同的位置、甚至部分离开视野，这是光行时与有限视场的结果，并非把物体复制到两个不同时刻。控制台的「载入一个清晰的对照示例」明确将参数设为 `β=0.86, t=−2`，便于同时看到两种位置。
2. **高速观察者**：所选环境及物体在实验室静止，观察者沿可调的水平轴和仰角匀速运动；正 β 时 0° 沿场景 `+z`、90° 沿 `+x`，负 β 反向。左边为在**同一个事件**与其相遇的实验室静止观察者，右边为高速观察者；每个像素的观测方向先变换到实验室，再与所选环境的几何求交。图像中的变化是方向变换造成的，不是对一张静态照片套滤镜。速度滑块范围为 `−0.98c … +0.98c`，正负表示方向；改变速度、方向或实验会暂停、清除探针并重置事件时间。`β=0` 时两种视图重合。
3. 直接点击画面或在知识卡中「采样画面中心」可定格并查看所选射线。物体照片显示光程、发射时刻及 x–z 俯视投影；若选择的是运动物体实验中的「同时几何」视图，发射时刻显示 `—`，因为那不是照片，且静态物体的遮挡也可能不同。高速观察者卡显示观察者与实验室方向相对所选运动轴的夹角，以及**实验室静止光源**的频率比；角度图只画模型公式；光谱开关会根据假设的辐射光谱另行计算颜色。天空是无有限距离的贴图，不报告其光行时。改变环境、视角、时刻、速度、形状或对照分界会清除过期采样。
4. 在知识卡的「两束光对照」中，将有效采样固定为 **A**，再点击画面另一处，或将焦点返回场景并按 `Shift` + 方向键选 **B**。画面标记 A/B，卡片显示各自光源、实验室系发射时刻及 `B−A`；同一观察事件下 `Δt_发射 = −(ℓ_B−ℓ_A)/c`。数值为无量纲时间，不是实际秒数。天空与运动物体实验中的「同时几何」视图均不提供发射时刻，因此不能固定或用作有效 B；高速观察者的静止和高速视野则均为该事件的光线视野。开始播放或在主控制台改变事件、视角及其他会改变射线的参数时，A/B 一起清除；下述时空图滑块另提供按固定屏幕方向重采样。
5. 打开「三维光路与时空图」，可拖动、触摸或用方向键、按钮旋转第三视角，`+` / `−` 缩放。实线与箭头直接连接实际探针或固定材料点的发射事件和同一观察事件；固定 A、选择 B 后显示两条路径、三维坐标和发射时差。彩色线框是**主体**在发射时的实验室同时截面，灰色线框是观察时的截面，不是另一张照片，也不画小部件；网格仅为坐标参考。天空只画任意长度的虚线方向，不声称有限距离；飞掠「同时几何」只画虚线视线、不赋予发射时间。也可切到「时空图与时间轴」；播放中打开会暂停在当前实际显示的事件，下方滑块选择实验室观察时刻，等待匹配物理帧后重算图；A/B 保留的是屏幕采样方向，因此可能命中不同表面；画布尺寸变化会清除这些方向并提示重新采样。M 则始终是物体静止系的同一点。图示按需以 Canvas 绘制，不新建 WebGL。
6. 底部「多普勒光谱」「投射阴影」可分别开关，两者默认开启；左控制台可调光谱曝光（`−8…+4 EV`）和探针参考谱线（`380…780 nm`，只改变读数，不改变材质）。**关闭多普勒光谱时，画面暂停全部假设光源谱、材料谱和光谱曝光，保留普通贴图、光照与阴影的颜色；重新开启恢复先前设置。**天然蓝天、暖色物体等不会被强制变成灰度。发射时刻伪彩是独立开关，若仍开启会覆盖有限表面，底栏会明确提醒。探针仍计算理论频率比 `D` 和参考波长，但关态注明它们未用于画面。探针也显示主光是否被遮挡、遮挡物及实验室系遮挡时刻；开启软阴影后显示所选 4 / 8 / 16 条采样光线中受阻的条数及第一个遮挡物/时刻。曝光、谱线和光学开关不改变观察事件或清除 A/B；调整速度、时刻、视角等仍会清除它们。速度较大时辐射可能变暗或高亮，固定色调映射与可调曝光用于显示，不是自动伪造颜色。

右侧频谱图在默认 RGB 模式也会显示两条曲线：未采样时为**单位线性白的示例谱基**；采样后从实际渲染器读取最近像素的局部 RGB 输入，绘制所用的 RGB 假设基谱、黑体或人为展宽的谱线，并应用该表面的双程频移。选定材料时另画其反射响应；布料、木材、金属示例是假设，USGS 三个选项是特定样本的实测曲线。纹理 RGB 不能唯一反演光谱，也不是这些样本的实拍光谱。青色虚线为源谱、橙色实线为观察谱，绿色点线使用反射率的独立 0–1 隐含尺度；图显示相对形状，不额外包含雾、整体阴影增益、曝光与最终色调映射（局部高光输入本身受遮挡影响）。关态或同时几何只显示明确标注的 `D=1` 参考，不用于画面；尚未读回时显示参考而不冒称已采样。可点探针卡中的「查看采样频谱」跳到图表；图只覆盖 200–1200 nm。

### 本次新增：同事件分屏、采样谱、光路与双物体

- 底部「光谱开 / 关对照」固定同一照片观察事件、镜头和几何，左侧旁路所有假设光谱与光谱曝光、右侧按所选光谱计算；分界线可拖动或以方向键调整。它与照片/同时几何及延迟/冻结阴影分屏互斥；发射时刻伪彩若再次开启会覆盖两侧颜色并提示。
- 「主光路径动态」在三维光路窗口独立改变观察时刻，对固定屏幕方向重新求交，并绘制有限主灯→表面→观察者及相应时刻；面积光仅取中心样本。遇到遮挡，红色虚线只从表面反向追到遮挡处，不伪造从光源抵达的路径；无限远平行光不制造有限发光时刻。它独立于主画面时间，始终使用延迟遮挡诊断，即使主画面关闭阴影或选择冻结参考。
- 运动物体模式可开启第二个同尺寸、同形状的简化物体 B；两者速度大小、水平轴与仰角独立，分别按自身世界线、过去光锥、发射时刻和双程频移求交，也会互相遮挡。允许穿透，**没有碰撞、受力或加速**。知识卡的两条采样光 A/B、参数对照的两组 A/B 与场景物体 A/B 是不同概念；固定材料点 M、主体钟面读数及 2+1 主世界管仍属于物体 A。
- 粗糙度倍率 `0.5–1.5` 调整场景材质的假设微表面参数；直接高光采用 GGX/Schlick 近似，普通金属使用简化金属性及有界 SDR 天空反射，并不自动反射场景；下述独立镜板是一跳反射的例外。没有透射、全局光照或真实 HDR 标定。有限点灯的相对衰减为 `min(2, 26/(d²+1))`，在 `d=5` 归一；室外平行光不随距离衰减。它们仍与经验环境光、贴图及有界显示近似混合，不是实测材质和灯具。
- 左侧「播放 / 拖动的画质下限」提供约 1 万、1.6 万、3.2 万像素三级（受画布大小及取整限制）；数值越高越清晰也可能更慢。物理帧率只统计真正追踪完成并呈现的动态帧，不把重投影或动画刷新计作光追帧。静止相机的运动物体播放可缓存静态主射线、固定表面到固定光源的静态遮挡及相同着色条件下的静止背景线性辐射；两个移动主体及其可能改变的遮挡、频移仍逐事件重算，表面亮度和可见光比例变化也会更新缓存。相机、环境、光源或分辨率改变会使射线缓存失效，材质、光谱和照明变化不会沿用旧着色；高速观察者及拖动不复用这些静态射线。软阴影、快门和双物体均增加负担。
- 底部可选 **0.25×、0.5×、1×、2× 时间播放速率**；1× 表示每现实秒推进 0.65 个无量纲实验室时间单位，倍率不改变物体或观察者的速度 β。播放时用可见页面的实际经过时间计算观察事件，不再将每帧推进上限截为 0.08 秒；设备忙时会跳过未渲染的中间事件，画面可能跳动，而不是声称计算了全部帧。页面隐藏时冻结时间，返回后继续；到时间滑块末端暂停，重新播放从该实验的起点开始。调整倍率在变更时刻连续衔接。倍率随实验快照保存，旧快照缺失此项时默认为 1×。
- Canvas 纹理采样从最近邻改为对周围四个纹素做双线性插值，坐标方向、纹素中心及边界钳制与非 mipmapped WebGL 线性采样一致；插值发生在已有 SDR 贴图通道中，不增加射线或画面分辨率，也不是物体边缘的空间抗锯齿。Canvas 路面与石材仍预过滤至 64×64，WebGL 则使用随像素足迹变化的 mipmap，因此两者并不保证逐像素相同。

**新增对照与实验记录：**左侧「同时轮廓」将同一观察时刻经速度向量收缩的主体和真实组件投影到照片上；青色虚线是可穿透场景遮挡的几何参考，不是第二张照片，球与圆柱的投影采用有限多边形近似。发射时刻伪彩色对有限照片命中使用固定范围 `t发射−t观察 = −距离/c`：0 为暖色，−20 及更早截断到蓝色；飞掠同时几何与无限远天空不赋予发射时刻，也不能把伪彩色当作实际光谱。分屏仅在照片侧叠加轮廓。

控制台将常用实验、速度和镜头与可展开的「进阶物理设置」分层。五个引导实验分别检查照片与同时形状、迎面/远离的光行差、延迟阴影、谱线频移和有限快门；每个都有「操作—观察—验证」三个具体步骤。载入实验会重置参数与采样，但不强制切换渲染模式。移动端可收起并重新展开底部控制区，左右侧栏仍可独立收起。「保存到本机」只写浏览器的 localStorage，只有一份并会覆盖；「下载 JSON」另保存全部物理参数、固定材料点坐标，以及当前与 A/B 的方向、距离、发射时刻、频率比和阴影结果；旧版 schema 1 文件没有材料点时使用默认表面点。暂停且当前完整画面已到达后才能保存。导入会严格验证参数并按保存位置重新求交；画布宽高比改变时不伪造旧采样，只恢复参数，原始结果仍保留在 JSON。图形模式仅作记录，不自动从流畅模式切到 WebGL。文件和本机数据均不上传服务器。

### 静止场景镜面与实测材料光谱

在左侧「进阶物理设置」打开**场景理想镜面**（默认关闭），可调镜板的水平位置与竖直轴旋转；镜板有有限尺寸、实体深色边框和支架，并对直射和阴影射线遮挡。照片中射线先与镜板求交，再按反射定律追踪真实有限场景及运动主体 A/B，分别回溯观察者→镜板、镜板→来源两段光程，运动观察者使用镜板→观察者方向计算频移。点击镜中物体，探针列出镜面事件、来源事件与两段光程，并在俯视图画实际折线路径；导出的 JSON 同时记录镜面坐标、来源坐标、两段距离、事件时刻与对应频移，天空是无限远贴图，无有限来源时刻。现有直射 A/B 和三维光路图不画折线，因此镜面探针时禁用这些直射专用功能。照片/同时几何分屏只有照片侧反射；发射时刻伪彩显示镜板事件，不声称是反射来源时间。

这是**静止、双面、无吸收和无色的理想平面镜**；只跟踪一次反射，镜子不动，不模拟真实玻璃透射、镜面镀层谱、粗糙镜或二次反射。场景中其他金属及不透明车窗仍只近似反射天空。五场景和双主体均可用，镜子的可见范围会随位置、朝向和遮挡变化；快照保存开关与位置，旧快照缺失时默认关闭。开启镜面会增加射线与首次可选 shader 编译开销，具体取决于场景和设备。

「进阶物理设置」中的布料、木材、金属是**假设反射率**；新增三条可追溯的 USGS 光谱库 v7 样本：GDS333 浅灰涂漆铝板、GDS365 新鲜松木胶合板、GDS431 红色防撕裂尼龙。原始文件、2151 通道、元数据、SHA-256、引用与 **CC0 1.0** 说明见 [`data/usgs-splib07a/README.md`](data/usgs-splib07a/README.md)；数据来自固定提交的公开镜像，尚未逐字节与官方完整归档核对。这些是指定样本的反射率测量，不是场景贴图的实测光谱或完整角度依赖 BRDF；仅作用于主体的反射模式，RGB 贴图提供空间明暗。光源仍是 6504 K 假设照明、可调黑体或人为展宽的谱线，环境光、纹理、阴影和角度响应并非标定测量。

USGS 样本在约 **350–2500 nm** 实测，原始采样点之间线性插值，带外以端点常值外推；示例曲线则在 380–780 nm 外沿用端点。探针报告观察可见区换算到材料静止系后按波长长度计算的实测覆盖百分比，而非光强加权百分比。对观察波长 λ，反射率取材料静止系波长 `D出 λ`，入射谱按 `D入 D出` 变换并以 CIE 1931 2° 数据积分；黑体采用 65 × 65 双频移查表。窄高斯线在源波长 `±5σ` 范围内用 32 个中点与材料响应一起积分，不再只取线中心；可见带边缘、采样、色域裁剪仍会引入误差。颜色计算中的两个 D 均限制在 0.1–10，探针读数保留真实频率比；输出不是绝对辐射计量。离线生成脚本支持 `--check` 检查产物而不改写文件。

「高亮色调映射」可在默认 Reinhard 和保持线性通道比例的柔和高光肩部之间切换；它作用于线性样本累积后的显示变换，光谱开启时曝光可单独调节。这个处理不能恢复 JPEG 原有高光裁切，也不能把普通纹理变为实测 HDR。雾/空气光来自有限的线性 SDR 天空颜色，而不将近白 JPEG 通道反解成巨大的 HDR 强度；这只是经验雾效，不是实测大气散射或光源标定。快照和两组参数对照会保存选择；Canvas、WebGL、Worker 与离线回退共享这些选项。

### 高速理想镜面

左侧「高速镜面」是独立的有限孔径、匀速理想镜片实验，不是给原场景叠加镜面滤镜。可调镜片静止系法线、速度方向与入射方向（均在示意实验的 x–z 平面内）及有符号速度；先求入射光与镜面世界管的相遇，若仅穿过无限延拓平面但落在有限镜片外则不发生反射。命中时将光子的四动量变换到镜面静止系，按镜面法线反射，再变回实验室，显示相遇事件、两侧方向、频率比和若存在的 x=0 接收面到达事件。接收面是无限平面，不是预先放置的点探测器。

正面解析验证：光沿 +x 追向速度 `β` 的镜片，反射频率比为 `(1−β)/(1+β)`；例如 `β=0.6` 时为 0.25。默认镜片、波形颜色和接收面均是教学示意，反射为理想、双面、无损且瞬时，不模拟反冲、材料色散、加速或衍射。

### 双端光钟与同时性

独立的双端光钟由两片间距 `L` 的理想镜和往返光脉冲组成；两端时钟在钟静止系中按 Einstein 约定同步。可调整有符号速度与静止系镜间方向角 `θ`，同时显示两端在同一实验室时刻的读数、脉冲事件列表及发向静止接收器的闪光到达时刻。一个往返的静止系固有周期是 `2L`，实验室间隔是 `2γL`（`c=1`）；两端在同一实验室时刻的读数差为 `−β L cos θ`，两单程实验室间隔分别为 `γL(1±β cos θ)`。表中「到达」是每次反射时额外发出一个次级闪光、传播到静止点接收器的结果，并非把收到的信号间隔直接当成光钟固有周期。镜与接收器理想化，未建模机械受力、真空以外的介质或真实探测器。

### 2+1 维时空切片

三维光路窗口的「2+1 时空切片」选取**穿过同一观察事件的一张二维空间平面**加时间，显示该平面与过去光锥、运动主体世界管的截线及其交线；可选实验室 xy/xz/yz 平面，或包含 A、B、当前采样及 M 的平面。不同于 1+1 投影，它不把切片外的事件压进平面：界面报告法向偏距。图中浅色等时截线和边界连线是数值采样辅助，而不是固定材料点的世界线；橙色光锥交线是主体几何候选交点，可能被其他场景物体遮挡，不能自动视作已收到的光。图形是这张 2+1 切片的三维投影，不是完整四维图；主体近似排除附加小部件，有限角度和网格采样可能漏掉极细截面。

### 两组运动参数的独立对照

左侧速度区的「比较两组运动参数」会锁定当前实验室观察位置与时间、镜头方向/视场和同一时刻的主体中心。A/B 各自设置有符号速度、水平轴和仰角，分别从该共同事件延伸各自的匀速世界线；有限快门的其他时刻也沿各自世界线计算。两张图是独立 Canvas 光锥照片，不是主场景的相机重投影；采用单次空间采样并保留所选快门。主画面若为延迟/冻结阴影分屏，对照照片使用传播延迟。它与知识卡的**两束光 A/B**（同一参数组里的两条射线）不同。切换物体或观察者模式、环境、时刻、镜头后，可用「重新锁定」更新共同条件。

L/R 为所选主体前表面上方左右角附近的固定静止系材料点（倒角向内留少量余量；球取对应表面点）。每个点独立解过去光锥，表格给出候选发射时刻与 `tR−tL`；遮挡、画面外和相机后方均明确标识，只有可见点在照片上标 L/R。曲线分别固定两组方向，从 `β=−0.98` 到 `+0.98` 取 81 个真实计算点；曲线包含不可见点的**候选光锥交点**，不声称遮挡的光已经抵达。高速观察者实验中的主体静止，若固定同一实验室观察位置与时刻，角点发射时差不随观察者速度变化，但像素方向和频移仍可改变。

对照计算可取消，普通 HTTP 使用独立 Worker，`file://` / 无 Worker 使用主线程短分片；两条路径均等待渲染器列出的全部九张场景纹理解码完成才开始对照，任一解码失败时报告错误，不把占位色当成完整材质。更改组参数会使旧图/结果标为过期并禁用导出；完成后可下载标注两图和曲线的 PNG 与包含实现版本、共同状态、锁定事件、两组参数、点的可见性和 81 点曲线的 JSON。导入该 JSON 会验证条件并重新追踪，便于离线复现；图片为计算结果加 L/R 示意标记，不是实测照片。用户可在主实验台调节曝光，以处理强频移产生的亮部裁剪。

### 物体时钟、材料点与时空投影

物体的表盘是印在主体表面的理想钟面，不是独立悬浮贴纸：CPU 和 WebGL 的每条命中射线都用实际静止系表面坐标及该像素的事件计算指针，和主体一起收缩、运动、遮挡及频移；表盘整圈为 12 个固有时间单位，不模拟机械结构或透明表玻璃。知识卡比较**同一只钟的中心材料点**在实验室 `tₒ` 的同时读数与过去光锥交点的读数；表盘中心被遮挡、位于画外或不在照片侧时不冒称相机看到了读数。伪彩色会覆盖表盘；低分辨率、局部遮挡、强频移或曝光也可能使指针难以辨认。有限快门下读数取中心事件，实际画面是四个曝光样本的平均。

默认金色 **M** 是表面上一处不同于表盘的材料点。先用探针点击实际物体表面，再在知识卡中「将采样的物体表面设为 M」，可跟踪任意被命中的真实部件表面。标记的静止系坐标在时间、速度及视角变化中保持不变；更换场景或形状会重置为新物体的默认表面点。卡片分别列出观察时刻的实验室同时位置及过去光锥交点的坐标和 `t`；照片中的金色点和同时几何中的青色点分别接受遮挡、视场及分屏侧检测，不把自遮挡、场景遮挡、画外或对照另一侧伪装成可见。启用「同时轮廓」时照片侧可额外出现虚线青点，它是允许透视遮挡物的几何示意。三维光路中只有无阻挡的 M 才连成到达观察者的光线；被遮挡时仅画光锥交点，并明确不是已接收到的光。

以物体中心在实验室 `t=0` 的事件为静止系同步零点，记固定材料坐标为 `r′`，其在实验室同时切片内的收缩偏移为 `q=r′+(1/γ−1)(r′·b̂)b̂`。同一材料点的世界线和理想钟面读数为

```text
X(t) = C(tₒ) + q + β (t−tₒ)
τ(t, r′) = t/γ − β·r′
|X(t发射) − O| = tₒ − t发射      （c = 1）
```

零速时取 `q=r′`；高速观察者实验中物件在实验室静止，所以物体 `β=0`，运动的是相机。静止系同步项 `−β·r′` 不可省略。**照片中收到的走时不能直接等同于 `1/γ`**：不同时刻的光程变化也影响接收间隔。对于无遮挡的点源，接收钟的固有时间为自变量时，收到的钟面速率与相应源/观察者的多普勒因子一致；这里并未模拟真实相机识字或信号延迟的其他机制。

时空图用实验室系的一维空间轴（可选 `x、y、z` 或当前采样方向）加时间 `ct`，投影真实观察事件、A/B 发射事件、M 的世界线与候选交点，并在底部按实际时间排序；同时几何命中为空心切片点，无限远天空不制造有限发射事件。横纵采用同一单位尺度，淡色 45° 边界是过去光锥在该投影中的界限；丢弃另外两个空间维度后，普通光子投影**不一定是 45°**。它不是完整四维时空，也不含引力或加速。若 M 被遮挡，交点标 `×`，不把它连接成已抵达的光线。

取 `c=1`，实验室观察事件为 `(tₒ, O)`，像素源方向是从相机指向来源的单位向量 `n`。在照片中，距离参数 `ℓ` 对应的事件为 `(tₒ−ℓ, O+ℓn)`。物体速度为向量 `β`、当前中心为 `C(tₒ)`、`γ=1/√(1−|β|²)`。设 `r=O−C(tₒ)`，`b̂=β/|β|`，则与静止系理想盒或球求交的射线为：

```text
静止系原点 r′ = r + (γ−1)(r·b̂)b̂
光锥照片方向 d′ = n + (γ−1)(n·b̂)b̂ + γβ
同时几何方向 d′ = n + (γ−1)(n·b̂)b̂
物体静止系表面上的点 = r′ + ℓd′
```

零速单独处理。物体为匀速理想刚体；标准方块半边及球半径为 `1.22`，场景物件使用上述不同静止系半尺寸。显示的 `1/γ` 是与速度平行方向、同一参考系同时测得的长度比，不是照片宽度。照片可呈现表观旋转，但不应把所有参数下的可见形状简单称为一次刚体旋转。设当前形状的接地中心高度为 `h`，速度向量为 `β`：飞掠实验取 `O=(0,1.65,0)`、`C(tₒ)=(0,h,7.5)+β(7.05+tₒ)`；高速观察者实验取 `O=(0,1.65,0)+βtₒ`、静止物体中心 `(2.35,h+0.48,8.8)`。这个锚点使方向切换时初始光行时像仍大致在视场附近，并未改变匀速世界线。时间以一个长度单位的光行时间为单位，不代表秒或实验室尺度。

高速观察者的像素方向 `n′` 映射到实验室的源方向：

```text
n = [n′ + ((γ−1)(n′·β)/|β|² − γ)β] / [γ(1−β·n′)]
cos θ′ = (cos θ + β)/(1+β cos θ)   （速度沿 +z，θ 和 θ′ 均相对 +z）
ν′/ν = γ(1+β·n)                    （仅实验室静止光源）
```

### 光谱、亮度与遮挡的假设

设实验室系中 `n` 指向来源（与光子动量相反），表面和观察者的速度分别为 `βₛ`、`βₒ`。频率比及单色参考波长为

```text
D = γₒ(1 + βₒ·n) / [γₛ(1 + βₛ·n)]
ν观察 = D ν源，λ观察 = λ源 / D
Iλ,观察(λ) = D⁵ Iλ,源(D λ)
```

频谱变换来自 `Iν/ν³` 不变量，而不是把整幅画面套红蓝滤镜。默认「灰反射」模式把主光视为实验室静止，先变到运动表面静止系，再在该系假设弹性、无波长依赖的灰反射，最后变到观察者；`n入` 从表面指向主光源，`n出` 从相机指向表面：

```text
D入 = γ物体 (1 + β物体·n入)
D出 = γ观察(1 + β观察·n出) / [γ物体(1 + β物体·n出)]
D合 = D入 D出； λ观察 = λ实验室主光 / D合
```

飞掠场景探针显示两项及乘积；「自发光频率参考」模式只用出射项，但表面亮度仍含经验照明与阴影，不是纯自发光辐射模型。高速观察者场景中物体与主光均在实验室静止，入射项为 1；运动物体的「同时几何」不是照片，故不对它赋予频移读数。灰反射只用主光中心方向代表整个光谱，软影的各采样方向不分别积分光谱；经验环境光也用该近似。默认灰反射不含波长依赖反射率；可选的假设材料光谱见下文。模型不含完整 BRDF、相对论照度/方向分布的积分或多次反射，不能当作真实材质的精确双程反射。频率读数保留实际乘积，但颜色 LUT 仅覆盖 `D=0.1…10`，超出时颜色按端点截断。天空纹理在高速观察者实验中也按静止实验室来源的方向处理，但仍是无限远示意背景。角度、速度与源的位置共同影响 `D`，颜色不能只由速度正负判断。

**RGB 图像不能唯一还原真实光谱**。`relativity-spectrum-data.js` 存储 380–780 nm、5 nm 间隔的 CIE 1931 2° 标准观察者数据与七组经非负拟合、能近似还原线性 sRGB 的示例谱基（白、青、品红、黄、红、绿、蓝）。每个纹理颜色分解成非负权重，形成假设的源系辐射谱；谱基在可见范围外按各端点连接到 6504 K 黑体形状，是明确的人为外推，尤其不能代表材料真实紫外/红外反射。对 `Iλ` 按上式逐波长变换、CIE 积分并变换为线性 sRGB，再裁掉显示色域以外的负值，使用固定 Reinhard 曲线作中间参考并应用所选 EV；输入按同一参考曲线反算，再经所选最终色调映射及 sRGB 编码；为避免白点发散，线性输入上限取 0.995。曝光只是相对显示设置，结果不是经实测标定的照片。GPU 将 257 个对数 `D` 样本和七组积分响应打包到已有纹理中并插值；有限步长、纹理量化及显示色域引入误差。`relativity-spectrum.js` 中的直接积分与 CPU 查表可以单独检查；重建数据脚本 `tools/build-relativity-spectrum.py` 需要另装 Python 依赖，运行页面不需要。

左侧可把参考光谱切换为 2500–12000 K Planck 黑体或单条高斯谱线：灰反射模式将它作为假设主光，自发光模式将其作为物体表面的参考发射谱。谱线默认 σ=8 nm（FWHM 约 18.8 nm），宽度和归一化只是教学设定；Hα 656.3 nm、Hβ 486.1 nm、Na D 589.3 nm 为近似空气波长参考，Na D 双线在此未分开；其谱线数据可查 [NIST Atomic Spectra Database](https://physics.nist.gov/PhysRefData/ASD/lines_form.html)。模型在 `D=1` 时按可见 CIE `Y=1` 归一，而非绝对辐射计量；纹理明暗作为额外权重，其他环境表面仍用 RGB 假设基谱。黑体使用 CIE 5 nm 数据及 257 个 D 样本的有符号 15 位对数分量查表；高斯线使用上述 32 点积分，并在 WebGL 中按需编译专用程序。知识卡显示采样方向的源谱与观察谱，未采样或关闭频移时以 D=1 作演示；横轴只画 200–1200 nm，超出图范围的谱并未消失。它不是真实材料的热辐射或反射光谱。

主光源在车站、长廊和港口分别是**单个实验室静止光源**，可沿 x/z 移动；显眼的暖色发光面板随主光一起移动、参与相机和阴影求交；旧位置不会留下重叠副本，其他可见面板只作装饰、不是独立光源。CPU 重用未改变的灯具几何，避免逐光线反复分配。城市与山路使用可调整水平角和仰角的实验室系方向光。对于每个命中表面，沿朝光方向实际求交场景及物体：室内灯只检测到样本位置的有限距离，室外按无限远方向检测。照片表面在 `tₛ=tₒ−ℓ/c`；光向表面传播之前，遮挡物的交点又早了相应光行时间，匀速物体因此按其**过去世界管**求交。几何切片则以 `tₒ` 为表面时间，仍不是照片。接收表面背光时只有经验环境光，遮挡仅削弱主光，并在频谱变换和色调映射前作用于假设辐射强度。

默认软阴影关闭，室内是中心点光、室外是单一方向。左侧打开软阴影后可选 **4 / 8 / 16 条**独立遮挡光线：室内在矩形灯面上按 `2×2 / 4×2 / 4×4` 分层取样，宽度与纵深分别可调 `0.25–2.5` 倍，同时改变可见灯具几何；室外按均匀立体角采样圆盘，可调角半径 `0.1–8°`。真实太阳的视角**半径约 0.27°**，有单独预设；默认 `4.58°` 是刻意夸大、便于观察的教学光源，并非真实太阳。太阳圆盘假设均匀，没有边缘昏暗。每条样本独立检测有限光程、静态几何及运动物体的过去世界管，再按入射余弦及有限点光的近似距离衰减加权可见主光；样本有限可能出现阶梯，更多样本通常改善统计近似但不保证每一点单调收敛，且显著更慢。更改光源尺寸、采样数会使静态阴影缓存失效，旧快照按默认值补齐这些新参数。

可选「冻结参考」把遮挡体固定在接收表面事件的时刻，而不是沿光线回溯；左右阴影对照在同一个照片事件分别采用真实延迟模型和这个非物理参考。「冻结参考时刻」不能误当作真实遮挡事件。这里的光源、固定环境光和材质着色是教学近似，不含多次反射或完整的相对论反射模型。点光使用软化且截顶的反平方距离衰减，而非标定真实灯具；凹凸纹理不产生几何阴影。

`relativity-model.js`、`relativity-worlds.js` 和 `relativity-optics.js` 共享 CPU 探针与 GPU 的有限盒体、三角面、圆柱、光锥及遮挡规则；车辆使用盒体车身、三角形车窗和圆柱车轮；车灯是发亮的表面，并未额外照亮场景。木纹、车身、路面、标线和窗面细节是贴图或程序材质，不是微观凹凸几何。树干为圆柱，树冠是两张固定相交的纹理裁切平面：`relativity-foliage-mask.js` 的二值镂空轮廓同时参与 CPU/GPU 主光线与阴影求交，空洞可以透光，但它不是由真实树叶组成的体积树冠，也未模拟叶片透光和风。`relativity-spectrum.js` 负责假设光谱。各环境不是实景重建，背景贴图不参与有限距离阴影；除了上述三个可选主体样本，其余材料没有实测光谱；也没有经实测标定的光源空间分布、完整角度与波长依赖反射、全局光照、精确相机曝光、碰撞、加速参考系或广义相对论。物体可穿过场景。

**有限快门：**默认 `Δt=0` 为瞬时照片；非零时在以观察时间为中心的矩形快门区间内，取四个中点 `tₒ+Δt·[-3/8,-1/8,1/8,3/8]`，每个事件重新计算观察者/物体的位置、相机光锥、表面和阴影，再平均四张完整画面。它不是对一张截图做模糊：每个样本先由 RGB 参考颜色和假设光谱近似重建线性辐射强度，在线性空间混合雾和暗角，再对四个样本等权平均，最后进行所选固定色调映射及 sRGB 编码。纹理本来不是 HDR，重建前的色域裁剪、输入上限和频谱近似丢失的信息无法恢复，因此这不是标定的真实传感器曝光。Canvas 使用浮点累加；WebGL 1 不依赖浮点帧缓冲，把三通道分别以 10 位对数强度打包在 RGBA8 中逐样本累加，再解码显示，量化和四个时间样本仍有误差。轮廓、A/B、频谱和探针、时钟和材料点读数始终只对应快门中心事件，发射时刻伪彩色则是各样本各自的相对光程伪彩平均。播放及预览降低像素预算；最终 WebGL 若同时打开 4 次空间抗锯齿，共需 16 次射线计算，可能非常慢，仍只呈现完整帧。

**渲染负载与画质：**默认选择左侧控制台的「流畅优先」，不主动创建 WebGL 上下文，也不预编译其他场景。支持 Worker/OffscreenCanvas 时在后台按短分片计算光线（每片目标约 4 ms，并非硬实时保证）；过期工作可取消，快速操作合并到最新状态。静止时先呈现完整预览，再在后台复用预览中已经计算的真实射线、补算其余像素；只在整张细化图完成后原子替换，不显示半幅图。普通阴影下 Worker 的静止目标最多约 20 万像素、主线程回退约 12 万；例如 1200 × 750 视口约为 566 × 354、预览约 283 × 177，具体受视口尺寸和取整影响。软阴影的静止目标分别约 14 万和 8.4 万像素；开启多时刻快门会增加计算时间，并将静止目标进一步降至原来的 35%。首次载入、切换场景或细化仍可能需要数秒，细化结束后静止场景不持续重绘。

支持 Worker 的 HTTP 页面在设备报告至少 2 个逻辑核心、4 GB 内存且未启用省流量时，可在首帧、静止细化及宽视场缓存完成后的空闲时间启动至多一个辅助 Worker。拖动和松手后的第一帧按同一观察事件与同一完整像素网格分成两段真实射线，**两段均完成并验证后才作为一个整体发布**；过期帧一起取消，辅助 Worker 失败则回退到单 Worker。播放、静态精细化、WebGL、`file://` 和主线程回退不启用这条并行路径。设备报告是启发式而非实际资源保证；辅助线程增加内存和功耗，低内存、单核、启用省流量或不报告足够设备信息时不会启用辅助线程。

CPU 采样中，射线 `trace`、主体求交和片元着色是主要热点，垃圾回收亦占可观采样；因此这里对 BVH 热路径减少临时数组/命中对象、复用相机帧不变量，并以保守包围球跳过明显不可能命中的运动主体，最后仍走精确求交。相同站台帧的 V8 16 KiB 分配采样，两轮各 25 帧估计每帧分配量约 60.3 → 46.3 MB；这是含已回收对象的采样估计，不是峰值或常驻内存，也并不意味着其他设备有同等幅度。单 Worker、同机交错、`β=.6` 且阴影开启的 120 × 75 固定像素实测，旧四场景的单帧中位数为站台 117.3 → 69.0 ms、街道 82.0 → 60.3 ms、长廊 104.7 → 67.4 ms、山路 69.7 → 45.2 ms；两版的该帧 RGBA 哈希一致。港口是新场景，没有旧版同场景基线。另三次完整页面、同台机器、默认单 Worker 的中位数：新页面启动的首个真实帧约 3.58 → 2.60 秒、最终细化约 11.26 → 7.74 秒，站台切街道的首帧约 2.12 → 1.55 秒、最终细化约 7.36 → 5.36 秒；这包括加载和调度，受缓存、浏览器与设备影响很大，不是性能保证。

此前同机对照中，限定两核的测试环境为测量强制启用辅助 Worker（当时的默认门槛不会启用；现在放宽到至少 2 核、4 GB 且非省流量）：一次约 6 秒拖动中，单 Worker 约 4.91 个真实物理帧/秒、平均 10535 像素/帧，双 Worker 约 6.49 帧/秒、10571 像素/帧；两次自适应预算略有不同，帧率本身不是严格相同逐帧画质的比较。独立 120 × 75 固定像素的分段拼接与整帧逐通道一致。松手后匹配视角约 1.70 → 1.64 秒，最终细化约 6.24 → 6.56 秒，存在噪声且静帧并未并行。

此前一次同画质测试使用 160 × 100 像素、五个环境和同机交错测量：固定视角播放的单帧计算中位数由约 56.8–75.6 ms 降至 26.5–33.3 ms；五场景、13 种参数变化和三个时刻共 1,996,800 个 RGBA 字节与当时的修改前一致。之后的双线性纹理插值会有意改变颜色，该旧的逐字节结论不包含此次改色。浏览器报告两核、4 GB、1200 × 750 视口、软件合成及 1.6 万动态像素时，页面播放约 6 → 9 个真实物理帧/秒；两次各约 10 秒的同像素拖动交叉测试约 3.7–3.9 → 4.6–5.3 帧/秒，自动化鼠标移动调用的 90% 分位耗时约 274–299 → 112–143 ms。脚本驱动的调用耗时不是直接测得的真实手感，机器和浏览器差异也很大；拖动仍低于理想流畅度。这些数字不把 `requestAnimationFrame` 或重投影算成物理帧，也不保证其他设备有同等收益。

双线性采样的单机实验使用 160 × 100、五场景、阴影开启、光谱关闭、固定视角播放，交错测量预热后的 Canvas 单帧中位数：最近邻分别为 26.2、21.9、28.2、23.1、24.6 ms，双线性为 26.5、22.2、27.3、22.9、24.6 ms。相对于同分辨率软件 WebGL 帧，RGB 通道平均绝对差分别从 2.40、2.94、4.23、1.70、1.56 降至 1.71、1.53、3.71、0.98、0.89（0–255 范围）。这是有限状态下的 CPU/GPU 一致性测试，不是相对实景的误差或其他设备的性能保证；两条渲染路径仍有采样、贴图预过滤和量化差异。

**完整清晰帧缓存：**除下面的临时重投影外，页面还在内存中保存已经完整细化、纹理已载入、暂停且未拖动的静帧。场景、时间、速度、材质、镜面、光谱、光照、阴影、快门、抗锯齿、视角、视场、画布尺寸/DPR及实际渲染方式相同，再次回到该状态时会直接恢复原画布和相应读数，不再启动相同的光追/细化；探针仍按当前参数单独计算。播放中的帧、未完成预览和近似重投影不作为清晰帧入缓存；如果该静帧的低分辨率宽视场射线已经算完，也会把它作为拖动的近似底图一并保存并计入预算，回访后仍保持原有的拖动预览。拖动松手时，如果与同一物理状态的缓存视角相差不超过约 0.02 rad（约 1.15°，即拖动约 4 个 CSS 像素），会把**实际相机**吸附到原视角并标明；不是拿相近图像假装新角度。控制台提供带缩略图的已完成场景和视角列表（可键盘选择）、「返回上一缓存视角」、关闭和清空。选择缩略图会恢复保存的实验参数与真实相机；视窗尺寸、DPR 或渲染模式不匹配的项目标为不可直接恢复。缩略图直接使用同一缓存画布，不另存一份像素。只影响动态帧预算或界面叠层/探针的项目（动态画质、播放倍率、轮廓、速度箭头与参考波长）不改变清晰图像，因此不阻止复用；场景、时间、光学或视口等条件不同则不会误命中。

缓存仅在当前页面内存、刷新后清空；按最近使用淘汰，设备报告不超过 2 GB 时上限为 8 张 / 8 MiB，超过 4 GB 为 20 张 / 48 MiB，其他或未报告为 12 张 / 24 MiB。大小按每像素 4 字节估算，浏览器/显卡实际占用可能更高，单帧超过预算则不保存。切换渲染器后只有后端与设备能力匹配的缓存可复用；异步恢复会再次检查状态和缓存是否仍有效，快速切换或清空不会把旧帧盖到新场景上。缓存命中不是针对任意新状态的即时计算：第一次打开新多普勒状态，需要更新整幅图各个像素的频率与颜色；改变阴影时还可能改变许多光线的遮挡，单点探针只能说明该点，不能替代整图。流畅模式还在单独预算内复用适用的逐像素中间结果（见下）；这不意味着所有光学变化免计算，也不影响 WebGL 的画面采样。

此前一轮同一台自动化环境交错运行旧版、新版、新版、旧版：浏览器报告 2 核 / 4 GB，1200 × 750、流畅模式、硬阴影，从已细化的街道切回已细化的站台，旧版完整静帧约 3.67 / 3.43 秒，新版缓存命中约 18 / 18 毫秒（含自动化动作和状态等待）；初次保存的同步画布复制计时约 0.9 / 0.8 毫秒，不包括浏览器内部的全部成本。播放实际帧率旧版 18.62 / 18.46、新版 19.13 / 17.90 帧/秒；约 6 秒连续拖动旧版 7.28 / 8.98、新版 7.63 / 7.65 帧/秒，样本很少且有噪声。缓存只改善命中的回访，不代表新视角的连续拖动已流畅，也不是其他设备的性能保证。

**逐像素中间缓存与新视角：**流畅模式的 CPU 场景 BVH 在不改动原图元、求交公式和动态画质下限的情况下按包围盒表面积启发式重建，重合表面的原先优先顺序不变；WebGL 仍使用原有打包结构。暂停、瞬时快门、无场景镜面的单事件 Canvas 渲染可保留一个有界 Float64 几何缓冲、材质的光学变换前颜色及独立键控的硬影/软影遮挡结果。多普勒开关、光谱模型等变化仍逐像素重新着色；改变光源、几何、观察事件或相机会使相应结果失效，改变软影采样或遮挡时序会重算遮挡。镜面反弹、非零快门、播放、拖动、探针、参数对照和 WebGL 不使用这项逐像素缓存。它和完整静帧缓存是两个独立预算：设备报告不超过 2 GB 或未报告时，前者的类型化数组上限为 8 MiB，4 GB 为 24 MiB，超过 4 GB 为 32 MiB；不够保存所有像素时只保存规则子集的**真实射线**，未缓存像素仍完整求解，输出分辨率不变。少量元数据和浏览器对象不计在数组预算中，浏览器实际占用可能更高；关闭或清空缓存会释放这部分。

**本轮光学切换优化：**低内存预算下，暂停帧可以重新计算完全相同的相机方向、将严格轴对齐的法线编码为整数，并把其他法线与主体数据保存在有界的 Float64 分块中；硬阴影只需存储遮挡标记，材质按预算保存部分像素。预算不足时未保存的真实射线照常求解，软阴影还可能需要额外重算；没有使用 Float32、插值伪造射线或降低静帧尺寸。已有匹配几何时，双核及以上且未启用省流模式的 Worker 在约 4 ms 计算片之间使用较短的 4 ms 定时让步；初次建景、宽视场底图、单核/未知核数和省流模式保留原有的 12 ms 让步。无 Worker 的主线程回退更保守，符合条件时使用 8 ms；分片仍可取消，完成后不为此继续预先渲染其他光学状态。每片按小批次检查时钟，4 ms 不是硬实时上限。

**照明边界：**朝天与朝地表面采用不同的半球环境填光，站台和长廊的距离雾比室外弱，以避免把室内过度显示成有雾环境。该填光和距离雾是经验显示近似，并非实测大气或全局光照；直接照明、真实可遮挡实体、软影、理想单次镜面与频移路径保持原有的模型边界。CPU、WebGL、镜面和探针使用对应计算。

鼠标、触摸、滚轮或方向键只改变相机时，先以同一观察事件的已算射线做**临时重投影视角预览**，不必等待每一次拖动都重新光追。拖动期间只刷新变化的相机状态，合并过密的预览合成请求；设备能力或真实帧率较低时降低近似预览的更新频率，松手及参数变化会取消排队的旧预览。新的真实射线帧仍完整呈现、仍按实际次数计入物理帧率，动态像素下限不因此降低。静帧细化后还会分片计算一次较宽视场的低分辨率缓存；分屏的两侧各自求射线，不会把照片、同时几何、静止/高速视野或延迟/冻结阴影混用。只有事件、参数和时间匹配的缓存可合成；播放时若真实帧时间变化，不保留其他时间的细节层。缓存构建可取消，也会消耗一次额外计算；完成后不持续空闲重绘。大幅转动、缓存未完成或视场外可能出现模糊、接缝或空缺，重投影不能创造新射线、遮挡后方或新物理事件，也不代表光追帧率。松手后先求一个匹配视角的极粗真实帧，但不会立刻用它替换较清晰的同事件近似预览；等下一档真实预览到达再退出近似，并继续细化。Worker 按耗时调整普通阴影拖动与播放像素预算；主线程、软阴影和快门条件预算更低。预览期间材料点隐藏、探针请求排队，快照必须等待匹配真实帧；物理参数变化立即丢弃旧的临时预览及宽视场缓存；已完成静帧则保留在上述有界缓存中，只能在完整条件再次吻合时恢复。具体流畅程度与设备及合成器有关，不能保证每台设备都不卡。

首次先等本地材质准备完毕；CPU 求交复用不变的相机和观察事件，包围盒只计算遍历所需距离，光谱插值直接累加，避免为每个节点或像素分配临时命中对象与矩阵。运动部件共用保守整体包围盒，CPU 与 GPU 仅在可能命中时才逐件求交（GPU 对量化再扩边）；场景主体的切角面也参与主射线和阴影射线；射线在盒内时不会被错误跳过。后台将完成的帧作为 ImageBitmap 交回，主线程在显示前检查版本和物理事件，避免取消请求与最后一块同时发生时混入过期图像。隐藏页面停止绘制和动画更新；后台首次打开的页面要等显示后才创建渲染器。Worker 不可用或直接 `file://` 打开时，主线程同样分片、可取消。

左侧也可**手动开启「WebGL 高画质」**。暂停时先显示与当前参数一致的低分辨率预览，然后在独立后台画布中分块生成清晰帧；完整帧才替换预览，避免把旧场景或半张图显示出来。目标最高为画面 CSS 尺寸的 1.25 倍、总计约 200 万像素，并受实际 WebGL 绘制缓冲尺寸限制；例如 DPR=1、1200 × 750 视口最终是 1200 × 750，而不再把 400 × 250 的预览当作高画质。画面上方会显示生成进度，控制台显示实际像素尺寸与是否识别为软件 WebGL；播放或拖动期间仍暂时降低分辨率（已识别硬件预览约 20 万像素、动态初始约 8 万；软件或无法识别设备约 10 万和 2.4 万，动态预算会随实测耗时在有界范围内调整）。停止后再次生成清晰帧；开启软阴影时预览与动态像素预算进一步下降，但高清目标不降低。首次生成或切换场景可能需要较长时间，尤其在软件 WebGL 上；再次操作会取消过期工作。五个环境的 BVH 和图元由 `relativity-geometry-pack.js` 打包到已有标牌图集的空白区域，通过一个共享着色器遍历，场景切换不再逐个编译巨型程序；坐标采用 1/400 场景单位的定点量化，并对包围盒保守扩边。为容纳站台细节，GPU 的树叶最多放 3 个图元，CPU 则以表面积启发式和至多两个图元的树叶遍历相同实体，以减少转动视角时的求交负担。

如预计高清等待较长且目标分辨率足够大，会先呈现另一张完整中清帧；阶段进度按像素与采样工作量加权，只呈现当前参数的完整画面。可选「静止抗锯齿」默认关闭，只对最终 WebGL 静帧做 4 次子像素采样，预览和动态不做额外空间抗锯齿（若开启快门仍计算四个时间样本）；空间样本与快门样本同样在重建的线性强度中平均，WebGL 使用对数打包与量化；与软阴影同时开启会进一步放大计算量。

预览和高清画面都以小块提交，并在块之间等待；每块做一次单像素同步读回以限制 GPU 工作排队，避免画面看似完成后仍在后台长期占用 GPU。不同浏览器或驱动的实际耗时仍可能不同：若设备支持 `KHR_parallel_shader_compile`，后台轮询编译完成后再查询状态；不支持时退回同步路径，驱动的链接或首次绘制仍可能阻塞。首次着色器编译可能让 GPU 驱动或整个浏览器卡顿，分块、Worker 和像素上限都不能保证任何机器完全不卡。浏览器隐藏图形设备身份时使用较保守的分块策略，并标为「图形设备未识别」，不把它误报为软件或硬件；设备不支持该路径、编译失败或上下文丢失时切回流畅模式，控制台明确显示当前渲染方式和分辨率。CPU/GPU 量化、像素和 LUT 误差会使几何或阴影边界略有差异，不能用于工程测量。

近处纹理、建筑立面、植被、远山与天空均为本地资源；港口天空与金属材质是合成示意素材，不是实景采集。HTTP 页面分别异步加载 `assets/relativity/` 下的 JPEG，避免每次入口解析和跨线程复制大段 base64；`file://` 则使用内嵌数据 URL 保持 Canvas 来源干净，可不联网运行。两个版本必须一致：修改内嵌纹理后可运行 `node tools/extract-relativity-textures.cjs` 更新各 JPEG，测试会检查字节一致性。

## 局部流注：电子、离子与自洽电场

`streamer.html` 是第七页控制台中的独立物理对照；[原随机闪电 DBM](lightning.html) 保留。新页面不是把 DBM 路径当作真实电流，而是在较小的三维计算域中求解无量纲电子密度、正离子密度和静电势。它是非附着气体的**最小流体教学模型**，不是完整雷电、真实空气放电或工程预测模型。

1. 默认「自洽流注」使用 `E₀=0.65、Dₑ=0.16、μᵢ=0.015、初始种子峰值 0.012`，从中性高斯种子实际计算至约 `t=6` 再显示；「重置」以当前参数回到 `t=0`。其余预设为较弱外场、较大种子密度（用于观察反馈）、错位电极；名称是观察建议，不保证分叉或任何特定形态。
2. 左侧可调整极板平均场、电子扩散、种子密度、离子迁移率、网格和泊松残差阈值，也可关闭空间电荷反馈：后者仍演化粒子与电离，但求场时令 `ρ=0`，作为固定外场对照；改变这些参数会从初态重算。两种模式的时间步可能不同，应在**相近模拟时间**比较，而不是简单比较步数。
3. 用滑块、鼠标／触摸拖动或键盘移动两针；位置吸附网格，初始种子跟随负极。拖动期间隐藏旧密度和电场，松手后重新求解。图中圆柱是体素针极的示意；不是精确的连续金属边界。拖动空白旋转、滚轮或 `+` / `−` 缩放，方向键旋转，空格播放／暂停。单步推进一个**自适应**时间步，PNG 保存模型画布、背景以及「非轨迹、非完整雷电」说明。
4. 青色与暖色点分别显示实际网格的电子和离子密度，亮度以可调参考值作对数映射，辉光、颜色和点大小不是发光强度或粒子轨迹；两组点没有人为错位。半透明壳由当前电子密度求出 `nₑ = 0.25 max(nₑ)` 的**相对等值面**：每个网格立方体拆成四面体并线性插值生成三角面，法线由密度梯度插值得到、仅用于显示；壳的光亮不是计算的发光强度。峰值随时间变化，不应把该面的位置当成固定密度前沿，也不是闪电通道。Canvas 降级显示该面上进一步稀疏采样的线段。
5. 可打开空间电荷／电势剖面及面内电场箭头。电荷固定色阶在 `|ρ|=0.04` 饱和，电势使用 `φ/V` 的 0–1 色阶（`V=0` 时取 0）；箭头由中心差分的电场投影得到，长度按该剖面最大面内场强归一。探针可点击剖面或选择电子峰值，显示该点电子、离子、净电荷、电势、三维场强和电离率。探测会暂停并等待在途批次完成，再读取最新有效状态；继续播放时固定探针数值随时间更新。
6. 右侧卡片实时显示累计电离对、积分电离率、最大场强、电荷收支、吸收和泊松残差。`1×` 目标约为每实际秒 1.5 个无量纲时间单位，但求解成本、网格和自适应步长可能使其更慢；每批最多 8 步。后台标签页暂停，减少动态效果设置下初始暂停。达到 `t≥60`、`6000` 步或任一粒子峰值 `≥30` 时会保护暂停（最后一步可能略微越过阈值）；这些只是计算预算，不是物理击穿判据。

### 方程与数值边界

在无量纲单位中，电子、正离子的漂移–扩散通量和局域 Townsend 碰撞电离为：

```text
∂ₜ nₑ + ∇·Γₑ = S         Γₑ = −nₑ E − Dₑ∇nₑ
∂ₜ nᵢ + ∇·Γᵢ = S         Γᵢ = μᵢ nᵢ E − Dᵢ∇nᵢ    Dᵢ = μᵢDₑ
S = nₑ |E| exp(−1/|E|)  （|E|=0 时 S=0）
ρ = nᵢ − nₑ              ∇²φ = −ρ                  E = −∇φ
```

快速／标准／精细分别为 `17×25×17`、`25×37×25`、`33×49×33`；域宽 `24`、高度 `36`，`h=1.5 / 1 / 0.75`。上、下极板与针极固定电势 `0 / V`，`V=36E₀`；四侧电场采用离散绝缘边界，粒子侧壁零通量。电极吸收向外的粒子而不注入粒子。针长取 `round(4.5/h)` 格，横截面按半径 `1.3` 的节点近似；分辨率改变时离散针长、形状和种子位置也有取整变化，所以这不是严格单变量网格收敛试验。

节点之间共享面通量采用一级迎风漂移和中心扩散，先输运再以冻结的局部电离系数作指数反应，新增电子和离子数相等；这是一阶分裂而非高阶守恒方法。显式步长同时受面通量、扩散、介电弛豫与电离率约束，每步最多 `0.16`。粒子和场用 Float64 运算，每步用红黑 SOR（`ω=1.84`）求泊松场，默认自由节点局部残差阈值 `2×10⁻⁵`、最多 1600 次扫描；残差不是全局误差上界。负密度或场不收敛会停止并回滚到上一个有效状态；仅允许极小浮点舍入归零。渲染快照使用 Float32，Worker 中计算不依赖画布。

收支显示 `Q−Q₀−Aₑ+Aᵢ`，其中 `Q=∑(nᵢ−nₑ)h³`，`Aₑ、Aᵢ` 分别是吸收的电子与离子量；它检查离散粒子收支而非证明模型的物理精度。一个固定快速网格、固定几何、`t=6` 的有限时间步检查中，最大步长 `0.08 / 0.04 / 0.02` 对应的电子总量约为 `8.371 / 8.385 / 8.391`；这只是该案例的时间步敏感性，不是空间收敛或真实放电验证。

该模型不包含真实空气参数标定、电子附着、复合、光电离、光子输运、气体热化、声、流注群、先导、回击或云地大尺度条件。一级迎风的数值扩散、粗网格、有限域、针极近似和局域反应都会改变前沿及屏蔽；不能据此预测真实闪电的强度、速度、距离或分叉，也不保证出现分叉。

## 理想涡丝对照

`vortex-filament.html` 保留原来的同轴涡丝模型。它以金色 A 和青色 B 显示两条可以改变半径、轴向位置与环流的同轴圆形涡丝；控制台和四张知识卡与实时模拟联动。默认「同向追逐」在这组参数下会反复交换轴向先后；「反向相迎」和「不等环流」用于对照。后者使用 `R_A = 1、R_B = 0.85、Δz = 1.00、Γ_A = 2.5、Γ_B = 1.5`，在 100 个模拟时间单位的数值检查中保持在保护范围内。涡环是否持续追逐取决于初态，有限时间穿越不是周期性或稳定性的证明。

1. 控制台分别设置两环的初始半径 `0.40–2.30` 和环流大小 `0.50–3.50`，A 的环流取正，B 可选同向或反向。**有向间距** `Δz = Z_B − Z_A` 可在 `−3.20–3.20` 内调整，因此键盘也能设置前后顺序；底部「轴向间距」则显示绝对值。两环中心线最短距离必须大于 `2.5ε = 0.30`，否则拒绝初态修改并提示。滑块和方向修改会以新初态重置模拟，但保留播放/暂停状态；重新点击已选的环流方向不会重置。
2. 鼠标或单指可拖动环的轮廓，沿公共轴调整所选环的位置：按下环先暂停，实际拖动时以当前的两环几何及环流为新初态，并清空计数和历史；松手时有向间距对齐滑块的 `0.02` 步长，且不会越过近核限制。若当前几何超出初态滑块允许范围，请先重置或使用滑块。拖动空白处、滚轮、方向键和 `+` / `−` 控制视角；双击或按钮恢复视角，空格播放/暂停。画面跟随两环的**平均轴向位置**，并随半径和间距适度调整取景，因此背景和轨迹是随动视图，不能把环在屏幕上的位置直接当作实验室坐标。高分辨率拖动期间暂时降低绘制分辨率，松开后恢复，不改变方程。
3. 环上一处代表点的粗箭头表示实际 `(Ż, Ṙ)`：长度为 `min(1.15, 1.25√(Ż²+Ṙ²))` 显示单位，零速不绘制；环周的小箭头表示**环流方向**，不是代表点速度。代表点轨迹记录实际数值状态，每 4 个积分步采样，最多保留 210 点；知识卡的半径曲线最多保留 360 点。轴向穿越计数只记录两个环的轴向位置交换、且交会时中心线分开超过 `2ε` 的事件；相邻步之间线性插值，精确落在步边界的交会也只计一次。
4. 可选的淡色曲线是在一个轴向剖面中，根据**当前两环产生的速度场**追踪的瞬时流线，播放中约每 360 ms 更新；线上的细箭头指出局部流动方向。它们不是被持续追踪的流体粒子轨迹，也不是烟雾粒子。柔光、颗粒和参考网格仅为视觉装饰，网格不是容器壁；显示的雾状外圈并不是计算出来的黏性涡核。
5. 四张卡分别解释半径交换、自诱导速度与总轴向速度、环流方向对照，以及方程与加权面积误差。近核时（两条圆形中心线的最短距离 `√[(R_A − R_B)² + (Z_A − Z_B)²]` 不超过 `2.5ε = 0.30`）自动暂停：这是一道人为保护阈值，不是对真实重联的预测，也不等同于底部显示的轴向间距。「反向相迎」预设约在模拟时间 `2.98` 触发该保护。若半径离开 `0.35–2.40` 或轴向间距超过 `3.20`，也会暂停；这些是实验选择的观察与数值验证范围，不是实际流体的物理边界。提示会说明具体触发项；**重置会重新演化同一初态，因而可能再次在同一处暂停**，要改变结果需调整初态或选择「同向追逐」。播放、暂停、`1/60` 单步、倍速和 PNG 导出与其他工作台一致，受设备负载影响，播放速度不保证与真实时间一致；减少动态效果设置下初始暂停，隐藏标签页时暂停。

### 涡丝模型与数值说明

模型假设两条涡丝始终**保持同轴圆形**，不模拟完整 Navier–Stokes 方程、黏性扩散、烟雾输运、涡环三维失稳、边界或重联。`R_i、Z_i、Γ_i` 和时间均为无量纲量。两环产生的速度采用同一正则化 Biot–Savart 核，包含各环自诱导；在柱坐标半径 `r ≥ 0`、轴坐标 `z` 处，由第 `j` 环产生的速度为：

```text
d² = r² + Rⱼ² − 2rRⱼ cos θ + (z − Zⱼ)² + ε²       ε = 0.12
uᵣ = Γⱼ Rⱼ (z − Zⱼ)/(4π) ∫₀²π cos θ / d³ dθ
u_z = Γⱼ/(4π) ∫₀²π (Rⱼ² − Rⱼ r cos θ) / d³ dθ
Ṙᵢ = Σⱼ uᵣ(Rᵢ, Zᵢ)                  Żᵢ = Σⱼ u_z(Rᵢ, Zᵢ)
```

角向积分采用 256 个中点，环状态以固定 `Δt = 1/120` 的 RK4 更新；流线则以归一化场方向作中点追踪，在靠近涡丝或离开绘图范围时截断。连续方程中 `S = Γ_A R_A² + Γ_B R_B²` 守恒；卡片显示 `|S − S₀| / (|Γ_A|R_A0² + |Γ_B|R_B0²)`，避免反向环流时初始 `S₀ = 0` 导致除零。角向求积与 RK4 不是严格保结构方法；长时间误差和对参数的数值敏感性都应谨慎解释。

## 延伸：相空间图谱

[`attractors.html`](attractors.html) 是独立的英文交互图谱，现与空间摆使用一致的全视口实验台布局：左侧选择系统、参数与引导实验，右侧切换知识卡片，两侧均可收起并在面板内滚动；顶部导航可返回空间摆。较窄或纵向视口默认收起侧栏，同一时间展开一侧。底部保留实时读数和播放控制。

图谱优先使用 WebGL 投影预计算的参考轨迹和实时路径，静态背景与实时元素分层绘制，避免旋转视角时在主线程反复描画上万个线段；WebGL 不可用、绘制失败或上下文丢失时会自动切换为 Canvas 2D。为保持交互流畅，高分辨率屏幕在视角变化期间暂用较低绘制分辨率并在停止操作后恢复；WebGL 的实时路径在操作期间临时减少显示采样。Canvas 2D 降级时，参考轨迹和实时路径使用有界显示采样，操作停止后参考轨迹恢复较密的采样。这些只是绘制优化，不改变积分、完整的预计算数据或实时读数。下载的 PNG 会合成背景和所有轨迹层。

选择不同系统、调整参数和初始间距，观察两条实时轨迹；拖动、键盘和滚轮控制视角。它也支持单步、重置、倍速、截图和减少动态效果设置。敏感依赖、相空间体积、增长估计及方程/数值方法分别位于右侧的交互卡片中，距离图与系统数据会随模拟更新。

这些坐标与时间使用无量纲单位，点号表示对模拟时间求导：

| 系统 | 方程 | 固定参数与默认滑块 |
| --- | --- | --- |
| Lorenz | ẋ = σ(y − x); ẏ = x(ρ − z) − y; ż = xy − βz | σ = 10, β = 8/3; ρ = 28（0–50） |
| Rössler | ẋ = −y − z; ẏ = x + ay; ż = b + z(x − c) | a = b = 0.2; c = 5.7（2–8） |
| Thomas | ẋ = sin(y) − bx; ẏ = sin(z) − by; ż = sin(x) − bz | b = 0.208（0.1–0.35） |

系统参数变化后不一定混沌，也可能趋于平衡或周期运动；界面中的「attractor」指系统家族而非每个参数值的严格分类。浅色轨迹是有限时长的预计算参考，金色与青色轨迹则是从参考起点开始的实时解。它们使用各自的固定步长 RK4；参考轨迹先经过预热，实时时钟从预热后开始。背景星点与颜色渐变仅作装饰。

实时路径 B 的初始 x 坐标比 A 多所选的 `10⁻³`、`10⁻⁵` 或 `10⁻⁷`，**从不重缩放**；距离和对数图记录两条路径的真实欧氏距离，对数图仅在绘图时将值截到 `10⁻¹⁵`。另有一个不可见的独立探针，从 A 的 x 方向偏移 `10⁻⁶`，约每 0.5 模拟时间单位重缩放。若重缩放前距离为 `dᵢ`，显示的运行估计是 `Σ ln(dᵢ / 10⁻⁶) / Σ Δtᵢ`。它是有限时间、单方向的估计而非精确的最大奇异值指数；短期正值不能单独证明混沌。该估计不由可见的、未经重缩放的双轨距离计算。

| 系统 | RK4 步长 | 预热时间 | 参考轨迹时长 | 名义 1× 速率（模拟单位/秒） |
| --- | ---: | ---: | ---: | ---: |
| Lorenz | 0.008 | 16 | 80 | 1.6 |
| Rössler | 0.03 | 90 | 480 | 5 |
| Thomas | 0.05 | 80 | 1000 | 6 |

Lorenz 在 `ρ > 1` 时有两个非零平衡点 `(±√(β(ρ−1)), ±√(β(ρ−1)), ρ−1)`，在 `1 < ρ < ρ_H` 局部稳定，其中 `ρ_H = σ(σ + β + 3)/(σ − β − 1) ≈ 24.74`。这是局部 Hopf 稳定性边界而非通用混沌阈值；在其下方的一部分参数区间，稳定平衡点和混沌吸引子可能共存。图谱的散度分别为 `−σ−1−β`、`a+x−c` 和 `−3b`；Rössler 的散度随位置变化，并非处处为负。

所有结果都是有限时间的数值实验，而非长期预测或严格证明。敏感系统会放大步长和浮点差异；图形轨迹、增长估计及长期行为均应结合数值精度理解。
