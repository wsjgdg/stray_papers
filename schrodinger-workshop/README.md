# 薛定谔工场 · Schrödinger Workshop

WebGL2 **含时薛定谔方程（TDSE）实时求解器**，含可插拔物理内核（薛定谔 / 非线性薛定谔 /
Gross-Pitaevskii / Pauli 自旋 / Dirac 相对论）。无依赖、无构建，浏览器打开即跑——在画布上拖拽发射物质波波包，亲眼看见量子力学：
隧穿、干涉、色散、散射、叠加自干涉、孤子与自聚焦塌缩、BEC 集体呼吸与量子化涡旋、自旋进动与 Stern-Gerlach 分离、相对论群速与 Zitterbewegung 颤振、Klein 佯谬。

```
iħ ∂ψ/∂t = −ħ²/2m ∇²ψ + V(x)ψ              （薛定谔内核）
iħ ∂ψ/∂t = −ħ²/2m ∇²ψ + V(x)ψ − g|ψ|²ψ     （NLS 内核，g>0 = 聚焦；
                                             同一方程族即 Gross-Pitaevskii，g<0 = 排斥 BEC）
iħ ∂ψ/∂t = [−ħ²/2m ∇² + V − (qℏ/2m)·σ·B]ψ  （Pauli 内核，旋量 pairs=2，CN 积分器）
iħ ∂ψ/∂t = (α_x p_x + α_y p_y + βm + V)ψ    （Dirac 内核，一阶系统、CN 积分器）
```

工程分形态：**ES 模块源码**（`index.html` + `src/`，组件化进课程站用）与
**单文件分发版**（`dist/quantum-field.html`，file:// 双击直开）——后者由
`scripts/build-standalone.mjs` 从前者一键生成，行为经 CDP 实测等价。

## 运行

```bash
# 方式一：单文件分发版（零前提，双击即开）
open dist/quantum-field.html

# 方式二：ES 模块版（需 HTTP，file:// 受模块 CORS 限制）
python3 -m http.server 8765          # 或 npm start
# 访问 http://localhost:8765
```

**环境要求**：支持 WebGL2 + `EXT_color_buffer_float` 的浏览器
（Chrome/Edge 90+、Firefox 90+、Safari 16.4+）。无 WebGL2 时页面会明确报错而非白屏。

**URL 参数**：`?kernel=schrodinger|nls|gp|pauli|dirac|schrodinger3d` 物理内核 ·
`?preset=free|barrier|slits|harmonic|scatter|box`（薛定谔）、
`free|soliton|focus|barrier`（NLS）、`tf|vortex|tof|breather`（GP）、
`larmor|stern-gerlach|tilted|free`（Pauli）、
`relativistic|zitter|klein-barrier|klein-resonance`（Dirac）或
`free3d|sphere|oscillator|ground|orbital2p|slits3d|slit1_3d|slit_sphere3d`（薛定谔 3D）初始预设 ·
`?grid=128|192|256|320` 网格精度（`schrodinger3d` 为 32|48|64|96|128 的**体积**网格） ·
`?speed=N` 积分子步 · `?kx=0.1&ky=0.05` 覆盖初始波包动量（2D 内核）

### Gross-Pitaevskii 内核：4 个预设场景（BEC）

与 NLS 同一方程族（localH/density/kinetic/potential 片段逐字相同，引擎零改动），
物理诠释换成玻色-爱因斯坦凝聚：谐波阱 + 排斥相互作用（g<0）。共享的 **σ 滑块**
在本内核语义为「云半径」（世界 px，势场面布 256²）。

| 预设 | 物理内容 |
|---|---|
| 托马斯-费米云 | 抛物密度穹顶 \|ψ\|²=(μ−V)/\|g\|；初态与基态轮廓差激发不衰减的 2ω 集体呼吸模（实测周期 ~107 sim-time、峰值摆动 ×2.7），无耗散下持续可见 |
| 量子化涡旋 | 穹顶中植入单量子化涡旋：密度空心（愈合层 ~4px ≈ ξ）+ 相位绕核一周（色相 wheel）；心部受拓扑保护不消失（CDP 实测 argmax 持续偏中心 4–9px） |
| 时飞行膨胀 | 瞬间撤去势阱：平均场排斥能→动能，云自由膨胀（实测 T ×1.52、峰值 ×0.38 @60 sim-time）——实验 TOF 成像的反推依据 |
| 集体呼吸模 | 强过压缩初态（σ=10，峰值 3.4× 于默认）大幅膨胀-回缩（实测摆动 ×9.4–10、最低 ×0.15），2D L² 临界系统的大振幅集体激发 |
| **基态（虚时间弛豫）**（R51 ⟹ R52 渐进） | 虚时间流 ∂ψ/∂τ=−(H−μ)ψ 收敛到**离散 H 的精确基态**（Hψ=μψ）：呼吸模被弛豫掉 ⟹ 云半径/密度峰在实时间演化中平稳（CDP 实测 200 帧窗 Rrms 摆动 **1.22%**、P 漂移 1.21%，对照托马斯-费米云 58.24%——**48×**）。基态由 g 唯一确定，σ 只作弛豫起点（σ=8/11/18 起点收敛态离散度 1.9e-5% ⟹ 拖动 σ 不改稳态）。**半径对账（R52 重构口径）**：对账基准 = **精确基态半径**（GS_REF 参考表，Node 离线驱动生产弛豫测得：g=−20/−12/−4 ⟹ √3·Rrms = 14.27/13.06/11.33；cdp42 浏览器实测偏差 ≤0.5%）；TF 公式 R_TF 是渐线近似，与基态差 +30.0…+5.2%（g=−4…−40）为**真实 TF 有限耦合修正**，随 \|g\| 收敛——不再是判据基准（详见验证表 R52 行）。g≥0（吸引侧）无稳定基态（2D L² 临界塌缩）⟹ 退回穹顶初态。**R52 渐进化**：弛豫由帧循环分帧推进（每帧 8 步、共 212 步 ⟹ ~27 帧 ~0.45s），预设切换不再阻塞主线程（makeWave 18ms vs R51 同步 870ms）；弛豫期间 KDK 冻结、场快照逐帧上传（收敛过程可见），暂停态切预设亦照常完成；弛豫帧不占扫描器测量窗（序列仍 20/帧仍 200） |

GP 附加控件：**相互作用 g 滑块**（−150…300，负=排斥稳定 BEC / 正=吸引。
吸引侧超过临界后自聚焦塌缩，与 NLS「自聚焦」同机制——网格截断奇性，
HUD 如实显示，见「物理诚实声明」）。默认 g=−10、子步 16。

### Pauli 自旋内核：4 个预设场景（spin-1/2）

第一个多复分量内核（`pairs=2`，RGBA32F：xy=↑ 分量、zw=↓ 分量），
验证 PhysicsKernel 契约对自旋族的支持。方程
*i*ℏ ∂ψ/∂t = [−ℏ²/2m ∇² + V − (*q*ℏ/2m)·σ·B]·ψ，
σ·B 以厄米 4×4 实线性作用写入 localH。**R33 起切 CN 积分器**
（`integrator='cn'`）：KDK 速度 Verlet 对 σ_y 耦合（(u|v) 分裂下的**奇**
算符）结构性失效——谱半径 ρ=√(1+φ²)（φ=dt_sub·uK·|B_y|），B_y=0.05 滑块
上限 900 帧漂移 +9.85%（R32 量化）；CN 的 Cayley 矩阵严格正交，该漂移
根治（CDP 复测 +9.941% → −0.0099%，详见「积分器模式」节与 worklog R33）。

**诚实声明**：只含自旋（塞曼）耦合，**不含轨道耦合 (p−qA)²/2m**——对应
「中性粒子（如中子）磁矩」图像：无电荷即无轨道耦合，塞曼项是全部电磁
作用。均匀 B 的 Landau 量子化需要拉普拉斯项的 link 相位扩展（引擎级
改动），不在本内核范围，如实标注为已知限制。

| 预设 | 物理内容 |
|---|---|
| 拉莫尔进动 | 自旋沿 +x 的波包置于均匀 B_z：布洛赫向量绕磁场轴进动，ω=B_z/m（B_z=0.02、m=1 时周期 ≈314 sim-time ≈4.4s）。波包 k=0 静止，空间与自旋解耦，进动不受波包扩散干扰 |
| 斯特恩-盖拉赫 | B_z 沿 x 线性梯度（g=∂B_z/∂x）：↑ 分量受恒力 +uK·g、↓ 受 −uK·g，波包分裂为相反偏转的两束（蓝=↑ / 橙=↓）——不均匀磁场把自旋叠加态分解为空间可分两束，即自旋-空间纠缠的产生过程。Bx=By=0 ⟹ 无横向场、自旋不混合，两束保持纯 ↑/↓；总 ⟨σ⟩ 随两束空间重叠衰减 |
| 斜场进动 | B∥(1,1,1)（\|B\|=0.02），自旋沿 +z：绕斜轴锥形进动（半锥角 54.7°）。可检验签名 ⟨σ_z⟩=⅓+⅔·cos(ωt)，ω=\|B\|/m。波包 k=0.05 漂移，「边飞边转」 |
| 自由自旋波包 | B=0：自旋态冻结（\|⟨σ⟩\|=1 恒定），波包自由飞行并扩散。自旋动力学对照组；此时透射率扫描面板可用——V 自旋无关，势垒透射率与薛定谔内核逐字一致 |

附加控件：**B_x / B_y / B_z 滑块**（磁场三分量；B_z 支持热切换——uniform
逐帧刷新，频率即时跟随）、**梯度 g 滑块**（0…0.05，SG 偏转强度）、
**自旋 θ/φ 滑块**（布洛赫球初态 |ψ⟩=cos(θ/2)|↑⟩+e^{iφ}sin(θ/2)|↓⟩，
变更即时重发波包）。HUD 自旋区实时显示 ⟨σ_x⟩/⟨σ_y⟩/⟨σ_z⟩/|⟨σ⟩|。

**SG 时标与量纲（诚实公式）**：引擎拉普拉斯为 texel 间距 5 点 stencil
（h=1/grid），归一化坐标下有效质量 m_eff=m·grid²，故每束半位移（格点）

```
ΔX = uK²·g·t²/(m·grid)     （m=1、grid=256 ⟹ ΔX = g·t²/1024）
```

g=0.016 时 60fps 下 ~15s 分离约 2σ，调大 g 滑块可加速。CDP 实测（R30）：
ΔX 与理论偏差 <1%（t² 律比值 5.86 vs 5.85）；进动签名 ⟨σ_x⟩=cos(ωt)、
⟨σ_y⟩=−sin(ωt) 逐点吻合，实测 ω 与 B_z/m 偏差 <0.1%（B_z 热切换
0.02→0.04 频率精确翻倍）。

### Dirac 相对论内核：4 个预设场景（2+1 维）

第一个**一阶方程**内核（`integrator='cn'`，引擎 CN 积分器路径），旋量
ψ=(ψ₁,ψ₂)（pairs=2，RGBA32F：xy=ψ₁、zw=ψ₂）。Weyl 表象
*i*ℏ ∂ψ/∂t = (α_x p_x + α_y p_y + βm + V)ψ（α_x=σ_x、α_y=σ_y、β=diag(1,−1)）；
格点口径 ∂→i·sin k（中心差分），色散 E±(k)=±√(sin²k_x+sin²k_y+m²)，
谱半径 √2+m+1（eMaxExtra 补足引擎基线）。正能旋量初态
u(k)=(1, (sin k_x+i·sin k_y)/(E+m))，k=0 时 u=(1,0) 纯上分量。

**积分器（引擎级扩展）**：KDK 速度 Verlet 对 Dirac **结构性失效**——M=α·p+βm+V
混合通道（α·p 把 ψ₂ 的导数耦合进 ψ₁ 方程），无法按 kick/drift 两通道投影分解，
映射谱半径实测 1.0216@dt_sub=0.2（1D m=1；平面波 400 步放大 1.97e4），范数指数爆炸。改用
**Crank-Nicolson**：(I−hG)w_{n+1}=(I+hG)w_n，h=dt_sub/2，G=−J·M 斜对称
（J=复结构 (a,b)↦(−b,a)）⟹ Cayley 矩阵严格正交：**无条件稳定、总概率机器精度
守恒**（CDP 实测 t=210 时 |P−1|=6.4e-6；12 次 block-Jacobi 扫掠截断 ~1e-9/子步，
收缩 ~0.18/迭代）。因子 2（h=dt_sub/2）是 CN 的正确离散——时间域单模相位率实测确认。

| 预设 | 物理内容 |
|---|---|
| 相对论群速 | m=1、k=0.5 波包自由飞行：格点群速 v_g=dE/dk=sin(k)·cos(k)/E=0.379，比薛定谔 k/m=0.5 低 24%——质量拖累下相对论色散的直接可测量。CDP 实测质心漂移 1.4488e-3 vs 理论 1.4820e-3 world/sim-time（偏差 2.2%）。注意 v_g≠⟨α_x⟩=sin(k)/E=0.432：格点速度算符是 ∂H/∂k=α_x·cos k，窄包 ⟨v⟩=cos k·sin k/E 才等于群速（klein_td4.py 时间域同口径 0.25% 吻合） |
| Zitterbewegung 颤振 | 静止的纯上分量高斯波包（k=0，u=(1,0)）——它不是 Dirac 方程的本征态：波包内每个 k 的正能旋量 (1,(sin k)/(E+m)) 取向不同，叠加后残留负能成分，正负能干涉使两分量概率以 ~2m 的频率高速振荡。这是 Dirac 方程最著名的「病态」：点粒子的位置期待值也存在这种 ~2m 频率的抖动。CDP 实测（paused+manualPass 确定性步进，固定频率最小二乘拟合）：m=1 幅度 0.0242、残差/幅度 0.147、直流电平 0.974；m=2 热切换频率精确翻倍（幅度 0.0103）。与 numpy 参考实现（同算法复刻）逐位互证；幅度 ∝σ_k²/m²（σ=6 格 ⟹ 负能含量 ~0.014），**ZB 是物理内容不是数值误差** |
| Klein 佯谬·势垒 | m=0.3 粒子（E≈0.42）撞上 V0≈0.95 势垒——垒高超过 E+m=0.72，进入 Klein 区：势垒内不出现消失波，而是负能（空穴）态群速反向「载着」概率继续前进，透射率不随势垒宽度指数衰减。格点精确解（transmissionModel/latticeT：界面匹配 8 方程最小二乘、T+R=1、全场残差 1e-15）给出 T≈0.17；同参数薛定谔方程 ≈10⁻¹⁰（指数抑制）——两个理论的判决性分歧。CDP 时间域实测（透射率扫描工具）T=0.2759 vs 格点精确解（Δk 卷积口径）0.2593，比值 1.064 |
| Klein 共振全透射 | 同一势垒（V0≈0.95）宽度调到 14 格：格点色散下 q_latt·a≈2π 近共振——实测透射率 ≈0.99，势垒几乎完全透明，像不存在一样（经典粒子 100% 反弹、薛定谔 ≈100% 反射的势垒！）。物理来源：Dirac 方程一阶结构下，势垒两个界面产生的反射相干相消。latticeT T=0.995 反而比连续公式的 0.86 更接近全透射——离散色散把共振条件修对了（q_latt·a=6.31 vs 2π=6.28）。共振周期 2π/q_latt≈13.9 格：轻扫质量/势场笔刷破坏共振条件，透射率随即坍塌 |

附加控件：**m 质量滑块**（0.15…4，热切换——uMass 对 rhs/sweep 双 program
每帧刷新，CDP 实测 m 0.3→1 切换后 P=1.000045 守恒、无重发）。

**诚实声明**：
- **格点 vs 连续**：连续解析解（一阶方程界面 ψ 连续即可、无需导数匹配）在 q·a=nπ 处精确共振全透射，但那是 k,q→0 极限；格点（\|sin k\|≤1、每区 4 模态含 Nyquist 别名对）的精确解由 latticeT 给出——实测与格点解一致、与连续公式的系统偏离是**色散离散的物理而非数值缺陷**（a=16：T_latt=0.166 vs T_cont=0.337；klein_td4.py 时间域裁决 T_sim=T_latt 谱平均 ±3%，分区/link 流双测量互证）
- **势场 8 位编码上限 ±1**（引擎约束）⟹ Klein 区（E−V0<0）要求 m<0.5，预设取小质量
- ZB 颤振是 Dirac 方程的物理内容（连续极限的标准结果），不是数值误差；格点上频率为 2√(sin²k+m²)

### 薛定谔 3D 内核：8 个预设场景（3D 纹理 + 体积 ray-march）

第一个**三维**内核（`?kernel=schrodinger3d`，`dim3=true`），也是引擎首次启用 3D 纹理管线：
波函数存于 **RG32F n³ 3D 纹理**（默认 **64³**），演化按 **逐层 draw** 推进全卷
（WebGL2 无法把 3D 纹理整体挂为附件，每 pass = n 次 `framebufferTextureLayer` + draw），
显示走 **volume ray-march**（发射-吸收模型 + 轨道相机）。

**与 2D 路径的差异（关键，勿混用）**

### 等份叠加（Democratic Superposition）

发射前场上有 n 个波包，新包加入后 **n+1 个各占 1/(n+1)** 概率：

```
旧场 × √(n/(n+1))   +   新包 × √(1/(n+1))    →    Σ|ψ|² ≡ 1
```

任意连发次数下所有波包份额一致、旧包永不淡出。实测 6 连发 7 包列积分全相等
`[0.0111, 0.0103, 0.0115×5]`，P=1.0000 恒定。
（早期「新包取 1/2」规则会把旧包逐次几何减半，约 6 次连发后最旧包淡出可见性；
更早的版本把未归一化的原始高斯 Σ≈154 直接叠进归一化旧场，统一缩放 0.080 把旧场
碾掉 √154≈12.4 倍——一次发射即「丢包」。）

### 3D 实验现场序列化（R37）

3D 内核「体积渲染」区的 **导出现场 / 导入现场** 把当前完整实验现场存为单个 JSON（64³ 实测 2.7MiB）：

```json
{
  "format": "schrodinger-workshop.snapshot3d",
  "version": 1,
  "kernel": "schrodinger3d",
  "grid": 64,
  "state": { "m": 1, "sigma": 6, "potKind": 0, "potV0": 0.02, "…": "白名单标量参数" },

  "wave": { "encoding": "rg32f-f32", "floats": 524288, "data": "<base64 全卷场>" }

```

- **结构段（数组，白名单只收标量故显式存档）**：`blobs` 势丘列表 [[x,y,z,r,v0,rx,ry,rz,soft],...]（**R60 九字段**：三轴半轴 rx/ry/rz + 高斯软化宽度 soft；**R49 旧档五元组** [x,y,z,r,v0] 导入时迁为球+硬边，三轴=r、soft=0）+ **`abSols` 磁通管列表 [[x,y,φ],...]（R57，3D 磁通管沿 z 轴，x/y 为管轴 xy 的 uv 投影）**；两者导入时均做「≤上限 + 全有限元组」校验（9 元组另校验三轴 >0、soft ≥0），旧存档无段 ⟹ 空列表（3D 此前不支持 AB，无需迁移）
- **存档单元是「实验现场」而非「势场画布」**：3D 的势是解析式（参数级存档），另存**波函数体积数据**（psiA3 全卷 RG32F 交错 float32，base64 无损）、积分器选择（KDK/CN 对照从同一现场出发）、轨道相机（视角也是复现的一部分）

- **网格不符拒绝导入**：存档 32³ 遇到现场 64³ 直接抛错——重采样会改变物理，属欺骗性兼容
- **P 守恒基准重捕**：导入后 `_baseCaptured` 回落，HUD 的 err% 按导入场重新取基准（实测 err=0.000%）
- **无 wave 段的部分导入**：只恢复参数并按预设重发初态（toast 明示）

### 耗散 / 开放系统

「开放系统」区的 **耗散 γ** 滑块把幺正演化扩展为开放系统：每帧演化结束后对 (u, v) 整场乘 e^{-γ·dt}（帧级 scale pass，`TPL_SCALE`）。

- **物理**：iψ_t = Hψ + 损失项 ⟹ 振幅 e^{-γt}、**密度 e^{-2γt}**；γ>0 = 粒子损失（BEC 三体损耗/成像损失一类），γ<0 = 增益
- **数值**：帧级标量衰减数学上精确——CDP 实测 P(t) 与 e^{-2γt} 三点偏差 0.0%（γ=0.05）、γ=0.1 与增益 γ=−0.05 同样精确；与子步数/网格/内核全部解耦
- **设计取舍**：早期方案把 −iγ 塞进 KDK 的 H（localH 加 −iγ·c 项），衰减率带 O((γ·dt_sub)²) 误差且与谱/子步耦合（默认 6 子步 dt_sub=0.2 时实测 γ_eff 偏离 15–30%），已弃用，教训
- **3D（R58）**：同一帧级标量衰减经新增 `TPL_SCALE3D`（sampler3D + 逐层 draw，与 `evolve3d` 同机制）作用于全卷——与子步/网格/内核/积分器（KDK 与 CN 通用）解耦的性质在 3D 同样成立；`γ=0` 时整个 pass 跳过 ⟹ 厄米路径零改动。CDP 实测（64³，γ=0.05，24 帧）P 比 0.0561348 vs 理论 e^{-2γt}=0.0561348，**相对误差 1.4e-7**记入 `kernel.js` 契约注释；帧级方案 γ=0 时跳过该 pass，幺正路径零改动、历史回归零风险

|---|---|---|
| 驱动幅值 A | 0–0.5，默认 0（关闭） | V_d 幅值（势单位） |
| 驱动频率 ω | 0.01–0.5，默认 0.1 | 角频率；相位 φ = ω·(t+dt/2) 按帧中点推算（simTime 派生，无累加态） |
| 驱动模式 | 均匀 AC Stark / x 行波 | mode 0：V_d=A·cos(φ) 空间均匀；mode 1：V_d=A·cos(2πx−φ) 空间非匀 |
| 适用内核 | 2D + **3D（R58）** | 3D 侧同一引擎级注入（KDK/CN-rhs/CN-sweep 三模板），x 取 uv 空间的 `p.x`（与 2D 的 `vUv.x` 同口径）；稳定界 eMax 计入 \|A\|（3D 为 `k·12+1+附加项+\|A\|`）；⟨V⟩ 归约（reduce3d）**不含**时变驱动项——与 2D TPL_REDUCE 同口径 |

- **物理**：V_d 为实势 → H 仍厄米 → **总概率严格守恒**（实测 P∈[0.999989, 1.000000]）；能量 E 不守恒（外场做功）属预期。均匀模式即 AC Stark 位移：与 H 全部对易，密度演化逐点不变、ψ 仅获整体相位 −(A/ω)·sin(ω(t+dt/2))（CDP 实测相关系数 0.9995、幅值 0.9996 vs 理论 1.0——能级周期性调制的严格签名）；行波模式产生空间力 F=−∂V_d/∂x=A·2π·sin(2πx−φ)，镜像点 (x, ½)/(1−x, ½) 的密度与相位差周期性破缺对称（实测镜像密度不对称 4.8e-4 vs 均匀模式 4.2e-10）
- **数值**：A=0 时 `V += 0·cos(φ)` 为 IEEE 精确恒等，幺正路径零改动；E_max 稳定界计入 |A|（2D `k·8+1+附加项+|A|`；**R58 起 3D 为 `k·12+1+附加项+|A|`**），防极端小质量下 dt_sub·E 越过 KDK 稳定极限
- **3D 实测（R58，cdp58 12/12）**：零回归——A=0 时 3D 全卷 524288 个 float 与无驱动**逐位相同**（max-abs=0）；**均匀 AC Stark 密度不变**——mode 0 下密度场相对峰值残差 **8.75e-4**（与 2D 侧「相关系数 0.9995」同量级；连续解为逐点严格不变，残差来自 KDK 对时变 H 的帧中点冻结离散化，非逐位结论）；行波 mode 1 密度场改变 1.89e-4（空间力 F=A·2π·sin(2πx−φ) 生效）；**P 守恒的诚实边界**——驱动引入的 P 漂移为**时变 H 的独立离散项**，与静态基线不同源且不随子步收敛到基线（比值恒 ~44×），但满足 **∝1/sub²**：sub 6→12→24 ⟹ dP 1.086e-2 → 2.720e-3 → 6.844e-4（每档降 ~3.98×），收敛档 sub=24 的相对漂移 6.8e-6 已**优于 2D 侧记录**（2D P∈[0.999989,1.000000] ⟹ 1.1e-5）。属 KDK 子步离散截断（与 AB 的 O((ω·dt_sub)²) 同族），非实现缺陷；默认 6 子步的 0.011% 量级在教学演示中无可见影响，精密对账应抬高子步
- **诚实说明**：谐振阱频率 ω_trap≈0.0066（V=2.2e-5·d²，d 为网格单元），演示默认 ω=0.05 处于高频抑制区——质心受迫振幅 ≈ F/(mω²) 仅 ~1e-3 uv（驱动/控制范围比仍达 1.7×10⁷，响应真实）；行波相位差的朴素局部相位理论幅值 1.96 为上限估计，∇V_d 空间耦合使实测约为其 55%（均匀模式无梯度，故 AC Stark 相位结果精确）
- **序列化**：driveAmp/driveOmega/driveMode 为白名单标量参数，随势场存档/恢复（round-trip 已验证）

### Aharonov-Bohm 效应（R26 ⟹ R54 多管 ⟹ R55 视觉编码）

「磁通(AB)」工具 + 「AB 磁通（多管）」区：在双缝之间放置**若干根**无限细螺线管（上限 **8** 根，超出 FIFO 淘汰最旧）。磁场 B 被完全约束在各管内，管外 B=0 而矢势 A≠0——从两缝出发、分别绕过螺线管两侧的两条路径包围不同磁通，获得附加相位差 Δφ=Φ，屏幕上的干涉条纹整体平移，而粒子从未进入有磁场的区域。Φ=π 时明暗条纹互换；把 Φ 滑回 0 即回归标准双缝。多管时各管磁通按**矢势可加性线性叠加**：共位两管 Φ₁,Φ₂ ≡ 单管 Φ₁+Φ₂（Wilson 环 = e^{i(Φ₁+Φ₂)}）；不共位时每根管只对绕过它的路径贡献相位——这就是「分别调参」的物理基础。

| 控件 | 范围 / 默认 | 物理 |
|---|---|---|
| 磁通(AB) 工具 | 点击画布 | 点空白处以**草稿 Φ** 放新管（放置即选中）；点已有环切换选中（后放置者优先，命中半径 0.05 世界单位）；Φ=0 也落点（位置标记，演化路径 link 相位恒 0） |
| 磁通 Φ | 0–2π，默认 0（AB 预设注入 π） | 无选中时 = **草稿 Φ**（下一根新管取用）；有选中时编辑**该管** Φ——滑块写入目标随选中态切换 |
| 选中读数 | — | 「#k/N · Φ=x.xx @ (x, y)」或「无 · 放置即新建」；`Delete`/`Backspace` 删除选中管，删后顺移选中（保持可继续调参） |
| 置中按钮 | — | 选中管回 (0.5, 0.5) |

- **实现**：AB 矢势作用在动能项（拉普拉斯）而非势项——backlog 原表述「矢势注入 localH」已按此修正。5 点拉普拉斯的每条邻格跳变乘 link 相位 U=e^{iθ}，θ=∫A·dl 取**精确线积分**：对称规范 A=(Φ/2π)·dθ 是角度 1-形式，沿直线 link 的积分即端点视角差 θ=(Φ/2π)·wrapPi(β(p+Δ)−β(p))（比中点采样 A(mid)·Δ 的 O(texel²) 近似高一阶；atan2 处处有限，无奇点、无需 r² 钳制）。**R54 多管化**：U(1) 链变量相乘 ⟹ 各管相位**线性相加**——shader 循环体内每管 k 以本管位置为心独立计算 β_k(q)=atan2(q.y−y_k, q.x−x_k) 与视角差 θ_k=(Φ_k/2π)·wrapPi(β_k(p+Δ)−β_k(p))，四方向累加器 abPhXp/Xm/Yp/Ym 跨管求和；`-4c` 中心项只减一次（与管数无关）。循环上界 AB_MAX=8 为编译期常量 + uABCount 动态 break（R49 blobSum 同款 GLSL ES 3.00 写法），尾部未用管位不读；四个 shader 模板（TPL_EVOLVE/CN_RHS/CN_SWEEP/composite）的 uniform 区逐字同款。
- **物理**：∮A·dl=Φ 绕螺线管一周的相位即磁通本身；条纹平移量 D≈s·Φ 近线性（CDP 实测拟合 s=−0.797 vs 几何预测 0.73，rms≈0.99°）；D(−Φ)=−D(Φ) 奇函数（镜像格心对称，实测 D(−π/2)+D(π/2)=−1.63°）；算符层面 Φ→Φ+2π 严格规范等价（H(Φ+2π)=G†H(Φ)G，G=diag(e^{iβ_v})），但**规范等价的密度比较需初态同步变换**（ψ₀→Gψ₀）——初态固定时 Φ 与 Φ+2π 是两个不同物理初态，CDP 实测 I(2π) vs I(0) 相对差 17%（对 substeps 不敏感，证实非积分误差）；若需比较同物理设置，应在 Φ 改变时同步旋转初态相位分布。多管可加性的数值边界：float32 下各管 c_k=Φ_k/2π 独立舍入，Σc_k 与 (ΣΦ)/2π 一般相差 ~1ulp——共位双 π 管 2·fround(π/2π)=1.0 与 fround(2π/2π)=1.0 恰相等，但一般 Φ 值不保证逐位一致，属系数舍入级差异（物理等价不变）。
- **数值**：Φ=0 时 uABOn=0 走原 5 点 stencil，逐字等价旧路径；|U|=1 ⟹ link 拉普拉斯每行元素模不变，Gershgorin 谱半径仍 ≤8，E_max 不变（无需像含时外场那样抬稳定界）；正反 link 共享同一对端点 ⟹ θ 精确反号 ⟹ link 拉普拉斯严格厄米（算符层面总概率守恒）；**但显式 KDK 对 link 相位的高频空间模式有 O((ω·dtSub)²) 振幅误差**：CDP 实测 P 漂移随 Φ 单调增大（Φ=0: 1.1e-5 → π: 1.1e-3 → 2π: 4.3e-3，≈Φ² 标度），substeps 6→24 可降约 4×（2π 时 4.31e-3→1.19e-3，Φ=0 时 1.06e-5→6e-6）——厄米算符 + 辛积分的守恒极限被子步离散截断，属已知数值精度限制而非实现缺陷；Wilson 环=e^{iΦ} 精确成立（无钳制残差）；wrapPi 分支切割在螺线管负 x 射线构成规范弦（纯规范，密度等规范不变量不受影响）。**R54 多管零回归**（cdp54 34/34）：count=0 ⟹ uABOn=0 逐位等价旧路径；count=1 ⟹ 循环体即旧单管体（相位和 0+θ、加法结合序一致）max-abs 口径零回归——唯一差异是 IEEE ±0 符号位（0.0+x=x 精确除非 x=∓0：邻值精确 0 的边界 texel 或相位精确 0 时可能出现），无任何数值/物理意义。**多管 P 漂移对照**（kx=0 原地波包 60 帧口径，排除开放边界流出，纯净测 link 保范）：无管 **1.21e-6** / 单管 π **3.26e-6** / 共位双 π（≡ 单 2π）**1.70e-5** / 不共位双管 π+2π **6.45e-5**——漂移随 |Φ|（相位全幅 ⟹ GPU sin/cos/atan2 舍入全幅作用）与管数（各管独立舍入叠加）增长，均为 float32 + GPU transcendentals 固有数值极限，非 R54 回归。
- **实现迭代（诚实记录）**：初版 θ 按 link 中点采样 A(mid)·Δ + r²≥4 格² 钳制，实测两个缺陷——(1) 格心采样（非中点）时正反 link 的 θ 非精确反号，非厄米，P 漂移 3e-4@Φ=π/2；(2) 中点采样虽厄米，但钳制使管心邻近小环路的 Wilson 环偏离 e^{iΦ}（螺线管格间位置时核心 4-cycle 全部落钳制区，残差 −0.18 rad），Φ→Φ+2π 规范等价被破坏（CDP 实测屏密度差 8.5e-5，为自漂移噪声底的 2.4 倍）。精确线积分方案同时解决两者。R54 多管化沿该方案扩展：循环累加器 + 动态 break，单管路径逐位兼容（见上）。
- **R55 视觉编码**（多管「分别调参」的直观反馈，composite 段 shader 渲染）：① **色相轮** hue=0.55+0.28·fract(Φ/2π)——Φ=0 青（G/B≈0.86）→ π 蓝紫（G/B≈0.35）→ 2π⁻ 品红（G/B≈0.35，与蓝紫同 G/B，区分回绕须靠 G 通道比值判据）；周期 2π 与 AB 规范等价周期一致（Φ 与 Φ+2π 同色——float32 下 URL 6.283185307179586 与字面量 6.28318530718 舍入到同一表示，fract 恒 0，回绕**精确**成立）。② **辉光** aglow=0.30+0.50·|sin(Φ/2)|（Φ=π 峰值 0.80、Φ=0/2π 谷值 0.30，周期同为 2π）——CDP 环-对照相消实测管心辉光比 core(π)/core(0)=2.10 vs 理论 2.09。③ **选中金色外环**（区分「正在调参的对象」）+ **规范弦低 α 射线**（提示 wrapPi 分支切割的存在与走向，纯规范对象）。④ **放置预览虚影环**：flux 工具悬停处半透明环，色相/辉光取草稿 Φ（放置即得该外观），(-1,-1) 关闭。⑤ **屏幕正圆**：世界坐标圆环经 uAspect 修正；环为加法混合，绝对色相被场背景污染，CDP 验证一律用同张截图内「同半径、固定偏移对照环」相消后比对（G5 回归：preset=ab 宽束场 420px 尺度平滑，对照带干净）。
- **序列化**：**abSols 顶层段** [[x,y,φ],...]（与 state.abSols 同构，≤8 个全有限元组）；abSel 是 UI 选中态（运行时概念，入 SKIP 不存档）；**旧存档迁移**：无 abSols 段时按 abX/abY/abPhi 标量段迁移为单管列表（abPhi≠0 ⟹ 单管并选中；abPhi=0/缺失 ⟹ 空列表，与旧版关闭态一致）；abPhi 仍是草稿键，照常恢复。随势场存档/恢复（round-trip 已验证）。
- **URL 参数**：`?abSols=x,y,φ;x,y,φ;…` 多管语法（分号分隔元组，整体替换列表并选中首管）+ 旧单管简写兼容（`?preset=ab&abPhi=π`：编辑当前选中/首管，列表为空且 Φ≠0 时落一根新管，默认位置 0.5,0.5；Φ=0 保持关闭态与旧版语义一致）；时序 loadPreset（预设 params 可注入 abSols/abSel）→ initWave → 此处覆盖，均在 frame() 主循环启动之前，首帧即以目标配置演化（旧口径不变）。
- **3D 磁通管（R57）**：同一份 `abSols` 状态与同一套面板控件现为 **2D + 3D 通用**——3D 的「磁通管」是沿 **z 轴的无限细直线螺线管**（磁场约束在管内、管外 B=0 而矢势 A≠0），管轴在 xy 平面的投影点即 `uABPos[k]`。关键物理差异只有一条：**方位角 θ(q)=atan2(q.y−y_k, q.x−x_k) 与 z 无关** ⟹ ±z 两个 link 的相位恒为 0（沿管轴平移不改变方位角，与 A_z=0 的对称规范自洽），仅 ±x/±y 四个 link 携带相位；7 点 stencil 的 −6c 中心项仍只减一次。数学与 2D **逐字同构**：θ 取精确线积分 `wrapPi(θ(p+Δ)−θ(p))`、正反 link 精确反号（严格厄米）、Wilson 环 = e^{iΦ} 精确成立、多管 U(1) 链变量相乘 ⟹ 相位线性相加。实现上抽 `TPL_LAP3D_BLOCK`（R33「单源真值」原则：此前 3D 三个模板各自内联复制 7 点 stencil），KDK 与 CN（rhs/sweep）三 program 共用；uniform 为引擎级（与 2D 同名同义，经 `setABUniforms` 一次上传）。交互：3D 体积面板切「磁通(AB)」模式后点击体积放置，位置取 R44 同口径的「视线 slab 穿透段中点」xy 投影；因管沿 z 贯穿，命中判据只看 xy 距离（< 0.05）。**实测（cdp57 12/12）**：零回归——无管 vs Φ=0 单管 64³ 全卷 524288 个 float **max-abs = 0**（逐位相同）；矢势可加性——共位双管 π/2+π/2 ≡ 单管 π 亦 **max-abs = 0**；Φ=π 管使场改变 3.56e-3、加第二根不共位管再改 7.16e-4；3D 现场存档（R37）新增 abSols 顶层段，round-trip 逐位恢复；CN 路径同源（dP=1.2e-6，严格正交低于 KDK 的 4.3e-3）。
- **3D 磁通管可视化（R59）**：R57 只解决了「物理生效」，管在画面上不可见。R59 在 `TPL_DISPLAY3D` 两条渲染路径落地同款视觉编码——**ray-march 模式**：循环内判据只有「到管轴的 xy 距离」（与 z 无关，管沿 z 贯穿 ⟹ 射线在圆柱内行程与倾角有关，斜视更亮），贡献乘当前 `trans` ⟹ 深度遮挡天然正确（无需单独深度排序）；**z 切片模式**：每个切片上都截出一个圆点（管沿 z 贯穿 ⟹ 任意 z 层都有截面）。编码与 2D R55 逐字同款：色相 `hue=0.55+0.28·fract(Φ/2π)`、辉光 `0.30+0.50·|sin(Φ/2)|`（Φ=0 亦有 0.30 底座 ⟹ 管恒可见）、选中管 ×1.6 提亮。**实测（cdp59 7/7，src + dist 双通道）**：中心画布区差分法（排除 HUD 帧率计数器的字形噪声）——Φ=π 管 maxPix=532、Φ=0 管 maxPix=322 且 G/B=0.977 vs Φ=π 的 0.501（青 vs 蓝紫，色相编码成立）、切片截面 maxPix=574、glError=0、零异常；另有隔离页测试（iso59：直接编译 display3d + 同套 uniform）4/4 先行证实 shader 本身正确。**教训**：首轮 cdp59 曾 4/7——多语句 `ev()` 被包装成 `JSON.stringify(a; b)` 语法错误致放置调用从未执行，「PASS」实为 HUD 帧率 8→7 字形翻转的假阳性（判据已改为中心画布区 + 显式噪声地板 W1）

### 透射率扫描（矩势垒）

「透射率扫描」区：矩势垒透射率 T(V₀) 的**实测扫描 + 解析对照**。对一排递增的势垒高度 V₀，逐一发射相同波包穿过势垒，测右侧稳定概率得实测 T；同时按同一入射条件计算理论曲线（Δk 卷积）画在同一图上逐点比对。

| 控件 | 范围 / 默认 | 物理 |
|---|---|---|
| V0/E 下限 | 0.05–2，默认 0.25 | 扫描起点（按入射中心能量 E_c 归一） |
| V0/E 上限 | 0.1–4，默认 2.2 | 扫描终点 |
| 扫描点数 | 3–25，默认 13 | V₀ 采样数（在区间内按 E_c 均匀布点） |
| 开始 / 中止 | — | 逐点演化（借用主循环，结束时自动恢复运行态） |

- **扫描几何**（固定，保证与 1D 解析模型可比）：grid 强制 256²；势垒为全高矩垒（x=120 texel、宽 16 texel）；波包 x₀=0.25、k_x=0.3、σ=18；透/反射分界线取势垒右缘 +6 px。13 点全程约数分钟（SwiftShader 软渲染 ~23s/点）
- **停止判据**（原子快照：一次 readPixels 同测总概率 P / 右侧概率 / 垒区概率 / 质心）：门（帧≥30 且垒区概率曾达 1%·P）→ 清（垒区<0.2%·P，两束已离开相互作用区）→ 稳（右侧概率连续两次变化<0.1%·P，平台化）→ 兜底 framesMax=900。避免固定帧数在深隧穿（波包滞留垒区）与高透（早早通过）两端空转

- **实测精度**（CDP 18/18）：控制点 V₀=0 时 T=0.9986；越障点 T=0.8941 vs 卷积理论 0.8964（0.25%）；隧穿点 T=0.2425 vs 0.2454（1.2%）。系统偏差来源：势场 8 位量化（V∈[−1,1] 步进 1/127，记录时与理论同口径 v0q）、包络宽度（宽包络内 T 剧烈变化使卷积近似本身有误差）、分界线有限宽度（右缘+6 px 处两束空间有微小重叠）

### 3D 双缝干涉（R39）

「双缝干涉 / 单缝衍射」预设：高斯波包（k_x=1.2、σ=6、中心 x=−26）沿 +x 撞上**带双缝的不透明墙**（potKind=4：wallX=0、wallT=4、slitW=6、slitD=20、V₀=3，墙在 **z 向无限**）。每条缝成为柱面波源，两束相干叠加在墙后「屏幕」方向长出干涉图样；D=0 时退化为单缝衍射，两预设互为干涉/衍射分工的对照。缝参数（V₀/wallX/wallT/slitW/slitD）为面板滑块，**即时生效**（下一批演化帧即用新势，无需重发波包；要墙切片反映新缝几何则重发波包，如 σ 变更同）。

- **可分离性（对账的数学基础）**：3D 初态为 x·y·z 高斯积、势与 z 无关、7 点 stencil 可分离 ⟹ 精确解 ψ(x,y,z,t)=φ(x,y,t)·G(z,t)，φ 满足同一 2D 双缝方程；又 Σ_z|ψ_3D|²=|φ_2D|²（三维归一化与二维归一化互相抵消）⟹ GPU 屏剖面的 z 求和应与 2D CPU 镜像**绝对相等**（无拟合常数）。z 不变性判据：各 z 层 y 剖面同构（实测 ≤0.0136，float32 噪声级）
- **GPU↔CPU 镜像对账（R39 核心验证）**：Node 侧 Float64 2D 镜像（同初态 + `Math.fround` float32 舍入、生产 `pot3JS` 势、同离散化 KDK sub=8）与 GPU 3D 场逐帧对账——24 条屏剖面 **maxDiff ≤1.62e-3、rms ≤7.4e-4、峰位逐帧一致**。float32 GPU（3D/GLSL/KDK）与 float64 CPU（2D）互相独立实现同吻合同一数值，双缝内核（GLSL `pot3` kind 4 + 7 点 stencil + KDK + sub=8 + 初态）确认正确
- **守恒**：全程 P 守恒 ≤1e-3；E=T+V 守恒 max\|dE/E₀\|=7.9e-4 且**集中在撞墙期**（f≈14，KDK 在势界面处的时间离散振荡），穿墙后回落至 1e-5 量级、无系统漂移
- **墙几何**：墙平面切片（x=0）密度仅存于缝区 y∈±[7,13]（D=20、缝宽 6），实墙区 y∈(−7,7) 为 evanescent 尾
- **诚实记录——屏上图样不是等间距条纹**：该几何下 Fresnel 近轴近似定量失效（D²/λ=76 ≫ L=24，深 Fresnel 区；且 λ/W=0.87 强非近轴），脉冲源不同延迟时刻的贡献按自相关 exp(−v_g²δ²/4σ²) 抹掉可见度——实测干净时窗为**双瓣（|y|≈9.5–15.5）+ 弱中心**（峰数 3–5）而非等间距明暗条纹。这是该几何的真实物理而非 bug（CPU 参考同步复现）；要标准 Fraunhofer 条纹需拉远屏幕或加长缝距
- **单缝对照**：D=0 同参数重跑，干净时窗（波已过墙、y 边界反射未回）峰数恒为 1（宽中央主极大）；同窗双缝峰数 ≥3 ⟹ 干涉/衍射分工可直接对照
- **时间线**（slits3d，64³）：波包中心 −26 → 撞墙 t≈28 → 抵屏（x=24）t≈54 → y 边界反射波 t≈55 起混入、+x 边界反射回屏 t≈73–80——测量/演示取 t≈40–65 干净时窗
- **CDP 验证**（cdp39，34/34 PASS，零控制台异常）：预设挂载 + 面板 + PRE 实测（挂载 rAF 预演化帧数经 `simTime/dt` 实测，不用硬编码——实测 4↔5 帧抖动，硬编码会令 GPU 与 CPU 参考差整帧）/ P·E 守恒 / z 不变性 / 屏峰数 / **GPU↔CPU 对账 maxDiff 1.62e-3 + 峰位 0/24 mismatch** / 单缝对照（峰数 1 vs 双缝 ≥3 + D=0 对账 1.10e-3）/ 热切换缝距（滑块 input → 缝心 ±4/±10 响应）/ snapshot3d round-trip / 2D 矩垒扫描回归冒烟 / 人眼截图复核

### 3D 双槽势组合（R41）

3D 势由单势枚举升级为**双槽解析叠加**：V(**w**) = pot3Slot(主槽 potKind) + pot3Slot(第二槽 potKind2)。第二槽下拉选「无（单势）/ 球势垒 / 谐振子 / 库仑 / 双缝墙」，对应参数行**动态显隐**（仅当前第二势类型所需的行显示，避免面板臃肿）。**`potKind2=0`（默认）时第二槽恒 0 ⟹ 与 R34–R40 逐位一致（零回归）**。

- **镜像契约的扩展**：单槽势抽为 `pot3Slot`——GLSL 侧经 `helpers` 注入位定义为 `float pot3Slot(...)`（evolve3d / cnRhs3d / cnSweep3d / **reduce3d** 四 program 同源），CPU 侧为同名导出 `pot3Slot(...)`,`pot3JS` 返回两槽之和。「GPU↔CPU ⟨V⟩ 同帧对账」rel **8.8e-10 / 7.6e-8 / 6.5e-9**（单势基线 / 球垒叠加 / 组合预设三配置，R35 口径阈值 2e-7）——两条独立实现路径（GLSL float32 vs CPU float64）在叠加势下仍同源
- **reduce3d 的 HELPERS 注入位（R41 补）**：TPL_REDUCE3D 原有 `{{POT3}}` 但**无 `{{HELPERS}}`**——若势函数放 helpers，reduce3d 会编译失败（函数未定义）。已补注入位 + fill 传参（默认空串，零回归）；否则 GPU ⟨V⟩ 归约与 evolve3d 的势不同源，R35 双测量对账即失效
- **稳定界**：`eMaxExtra` = 两槽上界之和（保守：只在两槽极值同点位时取等）⟹ 子步自动提升。组合势（V₀=3 + V₀₂=2）120 帧长跑实测 P 守恒 **1.36e-4**、无 NaN/Inf、E 稳定 0.6393
- **组合预设「球垒调制双缝」**（主槽双缝墙 D=20 + 第二槽球垒 R₂=6/V₀₂=2）：球半径 6 小于缝内缘 |y|=7 故**不遮缝**，只占据墙中央实墙区——波包先经球垒散射（动量重分布）再入射双缝，屏图样为被调制的干涉；可用 SlitScanner（R40）与 slits3d 纯墙做峰数/峰位定量对照
- **CPU 侧恒等式（Node 纯计算，4096 采样点）**：`pot3JS == 主槽 + 第二槽` 逐点精确（worst=0）；`potKind2=0 ⟹ pot3JS 退化为单槽主势`（worst=0，零回归不变式）
- **序列化**：第二势字段（potKind2/potV02/potR2/…）为数字 state ⟹ 自动进 snapshot3d 存档 + 导入恢复（含下拉同步）
- **CDP 验证**（cdp41，30/30 PASS，零控制台异常）：组合预设挂载 + 下拉/读数同步 + 球垒分支显隐 + `glError=0` / CPU 恒等式（三配置 worst=0 + 零回归不变式）/ **GPU↔CPU ⟨V⟩ 同帧对账三配置 rel ≤7.6e-8** / 叠加生效（同场 ⟨V⟩ 5.8e-4→6.4e-3）+ CPU 逐点重算确定判据 / 稳定界长跑 / 显隐反转（0→2→3→4 四态 + 滑块写 state）/ 序列化 round-trip / R40 扫描回归（D=16 峰数 3）/ 人眼截图复核

### 非线性内核参数扫描（R42）

「非线性参数扫描」区：为 **GP / NLS** 两个非线性内核提供参数扫描（其余内核无此工具——薛定谔系已有矩垒透射扫描）。底层是**通用扫描框架** `GenericScanner`（R42 随本功能引入；**R46 起既有三扫描器 2D 矩垒/3D 球垒/3D 双缝亦迁入该基座**，五扫描器共享生命周期：paused + 自驱 rAF + boost + 原子快照 + 中止/状态恢复 + 按钮翻转 + 状态行，差异全经 SPEC 钩子注入）＋内核适配器（`GP_SPEC` / `NLS_SPEC`，注入 measure / summarize / plot / initExtra）。面板按内核选实例（GP 扫 g<0 排斥侧、NLS 扫 g>0 focusing 侧，滑块量程随内核切换）。

- **停止判据的关键设计分歧——固定测量窗 + 全程序列**：既有三扫描器的判据都建立在「散射有终态」上（R29 垒区清空+双稳、R38 band 门+fwd 峰值回落、R40 固定窗因时间线确定）。**NLS/GP 没有终态**：无耗散哈密顿系统的呼吸模永久振荡（实测 Rrms 全程 8.6↔9.3 不衰减）、TOF 单调膨胀、孤子稳定传播。故本框架一律用**固定测量窗 200 帧 + 每 10 帧一次的全程序列**，结论由曲线自身（时间平均 + 摆动幅度）给出，而不是伪造一个停止判据
- **GP 适配器（扫相互作用强度 g，排斥侧 g<0）**：测云半径 Rrms（二阶矩 ⟹ R_TF=√3·Rrms）、峰值 n₀、涡旋愈合层 ξ。解析对照（`gp.js` 文件头自洽公式，本轮独立验算）：`R_TF=(2·R_trap²·|g|/π)^¼`、`n₀=μ/|g|`、`ξ=1/√(|g|·n₀)`；验算 g=−10 ⟹ R_TF≈11.0 px、n₀≈5.26e-3（内核注释 5.3e-3 ✓）。**初态 σ 取 R_TF(g)**（否则云半径由初态主导，与 R_TF(g) 偏差达 47%，因无耗散不弛豫）
- **GP 实测（3 点 g=−20,−12,−4，cdp42）**：**峰值 n₀ 对账中位偏差 3.5%**（对账主量）；R_TF 半径对账偏差 **29.9%**。**归因修正（R47 对照实验取证）**：该偏差主因**不是** `makeWave` 的平滑窗——无论窗宽，演化层都把振荡中心推宽到初态的 1.4–2.2 倍（弱耦合 TF 穹顶宽于精确基态 + 无耗散呼吸模不衰减，g=−4 最弱耦合推宽 +118%）；原 6px 窗压窄初态（−17~−28%）恰是对演化推宽的**部分补偿（误差相消）**，R42 原注「平滑窗变形初态是根因」不准确。R47 已将平滑窗比例化（w=max(2, R/4)，见「GP 初态平滑窗」节），初态形状层偏差 17–28%→6.8%，但演化层推宽如实暴露（复测中位偏差 46.0%）——峰值受窗影响小而可靠（6.4%）
- **NLS 适配器（扫 focusing 强度 g>0）**：测 σx/σy 与**峰值最大/初值比**作自聚焦发散判据。诚实限制：2D 立方 NLS 是 L² 临界，超临界 g 触发塌缩、网格精度最终截断奇性（README「物理诚实声明」已记录）⟹ **不套用平面孤子解析式**（严格平面孤子只在 1D 稳定），只标定「宽度收缩/峰值发散」的**分辨率依赖数值阈值**
- **NLS 实测（3 点 g=1,3.5,6）**：g=1 → 线性主导（σx 16.2、P=1.0005）；g=3.5 → 近阈值（峰值比 1.00）；**g=6 → 峰值比 10.80（检出塌缩）**，随后网格截断使数值崩坏（P→0.68、Rrms→82），如实记录为「数值后果非物理」
- **判据修正（R42 实测抓出）**：塌缩判定原用「末值峰值/初值」——塌缩后期崩坏使末值骤降（g=6：峰值升到 2× 后末值只剩 0.0002）⟹ 会把塌缩点**误判为不塌缩**。改为**序列峰值最大值/初值**（实测检出比 10.80）
- **P 的诚实记录（更正「后续方向」原注）**：原注称「非线性系统的停止判据无守恒量可依赖（P 不守恒）」——**P 在非线性内核下确有漂移，但机制是 KDK 对非线性项的离散耗散**（而非「无守恒量」）：实测 200 帧漂移 **0.5–3.1%，随 |g| 增长**（g=−20 → 3.1%、g=−4 → 0.5%）；塌缩/网格截断时 P 崩坏（NLS g=6 → 0.68）。**对照：同一引擎的线性内核**（2D 矩垒扫描）P 守恒 **2.06e-6**。故 P 在本框架中只作记录（防呆 ≤6%）与崩坏指示，不作守恒判据
- **门控**：仅 GP / NLS 内核显示该区（其余隐藏；薛定谔系显示矩垒扫描区，互斥）；start() 内 kernelId 不符时拒绝并 toast
- **CDP 验证**（cdp42，32/32 PASS，零控制台异常）：门控反转 + 面板 DOM/画布/量程（GP −20…−4、NLS 1…8）/ GP 3 点（序列长 20、帧 200、峰值对账 3.5%、P 漂移 3.10%、半径偏差如实记录、xi=0 如实）/ NLS 3 点（g=6 塌缩检出 10.80 + 崩坏记录 P=0.68、g=1 线性扩散 P 守恒）/ 中止+重启 / **回归冒烟（2D 矩垒 P 守恒 2.06e-6 + 3D 双缝峰数 3：既有三扫描器零改动）** / 人眼截图复核

### 3D 势刷：交互式球形势丘（R44 ⟹ R49 连续涂抹）

3D 体积视图新增「势刷」工具：切到「势刷放置」（面板按钮或 **P 键**）后在体积上拖拽，**沿视线中点放置球形硬边势丘**，松开即生效（下一帧 uniform 生效，演化继续、不重发波包）。与主槽（potKind）、第二槽（potKind2，R41）**三方独立叠加**：`V = pot3Slot(主) + pot3Slot(第二) + Σ pot3Blobs`。

- **交互语义**：`tool3='cam'`（默认）拖拽旋转相机；`tool3='pot'` 拖拽**连续涂抹**。势丘强度可负（**势阱**）或正（势垒）；半径 R（3–24 texel）与强度 V₀（−2…2）由面板滑块控制（stamp 时快照进每个丘——改滑块只影响后续丘，不追溯已落丘）
- **R49 丘列表（连续涂抹）**：R44 为单丘（potBX/BY/BZ/BR/BV0 五字段）；R49 升级为**丘列表** `state.potBlobs`（≤16 个 `{x,y,z,r,v0}`）。pointerdown 必落首丘（无视阈值）；pointermove 拖拽时仅在与最后一个丘中心距 ≥ **0.6·R** 时续落——球链重叠 ⟹ 视觉连续，同时天然节流（慢拖不密、快拖不断）；超出 16 丘 FIFO 淘汰最旧（toast 明示）；「清空势丘」一键清空
- **融合语义 = 求和**：硬边球重叠处强度相加（`pot3Blobs` 逐丘循环求和；GLSL `blobSum` 逐字镜像）——正负丘重叠可相消
- **放置深度的确定口径**：射线与单位立方体 [−0.5,0.5]³ slab 求交，取**穿透段中点**（非最近表面）——确定、可复现（CDP 可逐位断言），用户用拖拽微调位置。位置世界 texel 坐标，留 2 texel 边缘余量
- **相机模型的 CPU 镜像**（`screenRay3`）：与 TPL_DISPLAY3D 的 ray-march 相机段**逐字同源**（ro/fwd/right/up/rd 同公式，φ 钳制 ±1.45 同口径）。改 shader 相机段必须同步此处，否则拾取点与画面不符——镜像契约已在双方注释互指
- **零回归**：`potBlobs=[]`（默认）时 blobSum 恒 0 ⟹ pot3 与 R34–R44 逐位一致（Node 单测 6 组配置 × 2400 点 worst=0）；GPU/CPU 双路 ⟨V⟩ 同帧对账 rel **≤ 5.6e-7**（多丘含负强度近相消场景；单丘场景 R44 实测 ≤4.4e-8）
- **守恒**：硬边球势为实函数（厄米）⟹ 幺正性不破。CDP 实测丘链存在时 30 帧 P 漂移 **0.0012%**
- **组合实验叙事**：blob 列表是独立 state 字段，预设切换（`Object.assign` 合并不触及）与扫描器生命周期（SlitScanner 的 `_restore` 走 loadPreset）都**不重置丘列表** ⟹ 「双缝墙 + 用户自选势丘链」「主槽球垒 + blob 势阱」等组合可持续演化/扫描对照
- **稳定界**：`eMaxExtra` 增加 `Σ|v0|`（硬边球 |V|max 与位置无关，逐丘求和保守）；`eMax = uK·12 + 1 + 主槽 + 第二槽 + Σ|blob v0|`
- **序列化（R49 扩容）**：丘列表为顶层 `blobs` 段 `[[x,y,z,r,v0],...]`（数组非数字 ⟹ 白名单循环不收，须显式存档）；导入校验 ≤16 项且元组全有限（5 类非法原子拒绝、现场零变动）。**R44 旧存档迁移**：无 blobs 段时若 `potBV0≠0` 迁为列表首项（五字段同构），`potBR→potBlobR` 滑块规格一并迁移；`potBV0=0` ⟹ 空列表（关闭态一致）
- **CDP 验证**（cdp44 R44 30/30 ⟹ **cdp49 R49 51/51 PASS**，零控制台异常）：真实 pointer 连续涂抹（down 首丘 ⟹ 小位移不落 ⟹ 大位移成链，链上相邻心距全部 ≥0.6·R ⟹ 再 down 新首丘）+ 滑块快照语义 + FIFO 淘汰（17+ 次稳定 16、最旧淘汰）+ 清空 + 多丘（含负强度）⟨V⟩ GPU↔CPU 对账 5.6e-7 + P 守恒 0.0012% + 序列化 round-trip 逐位恢复 + R44 旧存档迁移（五字段逐位 + 滑块同步）+ 5 类错误路径原子拒绝 + 跨预设保留 + cam 模式回归；Node 单测 pot49 48/48（丘分支语义·三方叠加·eMaxExtra·setUniforms mock 上传·零回归 2400 点·GLSL 源码契约·defaults 契约）

### 3D 势刷：椭球三轴 + 高斯软化边（R60）

R49 丘列表只支持**球形硬边**（三轴同值、边界阶跃）。R60 把丘形状自由度扩展为**任意轴比椭球 + 可选高斯软化边**——仍是同一 `pot3Blobs`/`blobSum` 列表框架内的字段扩展（零新机制、零新状态段、零新预设）。

- **形状模型（九字段丘）**：每个丘 `{x, y, z, r, v0, rx, ry, rz, soft}`——`rx/ry/rz` 为三轴半轴（texel），`soft` 为高斯软化宽度（texel，0=硬边）。面板新增**三轴比滑块**（RX/RY/RZ 各 0.2–2，stamp 时快照：实际半轴 = R×轴比）与**软化宽度滑块**（0–8，步长 0.5）。轴比 1/1/1 + 软化 0 ⟹ 逐位回归 R49 球形硬边（见「零回归」）
- **势函数（CPU `pot3Blobs` 与 GLSL `blobSum` 逐字同构的显式三分支）**：
  - `soft > 0`（高斯软化）：归一化距离 `dn = √((dx/rx)²+(dy/ry)²+(dz/rz)²)`，权重 `exp(−½·max(0,dn−1)²/soft²)`——丘内（dn≤1）恒 1、丘外缘按宽度 soft 指数过渡；soft=0 时该式在 dn=1 处不连续，故不入此支
  - `soft = 0` 且三轴相等（rx=ry=rz=r）：R49 逐字 `dot(d,d) < r²` 硬边球——**零回归走此支**
  - 其余（硬边椭球）：`dot(d/rx, d/ry, d/rz) < 1`
  - 为什么必须显式三分支（而非「soft=0 时统一公式自动退化」）：texel 恰在球面（dn=1，如 (8,0,0) vs r=8）时硬边判 `64<64` 为假（外）而 dn≤1 分支为真（内）；且 dn−1∈(0,1e-5) 边界带权重 ∈(0,1)——统一公式在 soft→0⁺ 的极限与硬边阶跃在**球面点集上**不可调和。GLSL 侧 `v0·1.0=v0`、`v0·0.0` 加法中性 ⟹ 三分支选择对零回归点集逐位成立
- **链间距阈值改最短轴口径**：连续涂抹距离阈值由 `0.6·R` 改为 `0.6·min(rx,ry,rz)`——球时 ≡ R49 同值；扁丘（rz=0.2R）时按最短轴收紧 ⟹ 任意轴比下链连续（视觉无断裂）。阈值取**滑块 spec（新丘形状）**而非末丘形状（与 stamp 快照语义一致）
- **归一化契约**：`normBlob` 在四个写边界调用（构造 options.state / stampBlob3 / importSnapshot3Data / loadPreset）——轴 ≤0/NaN 回落 r、soft 缺/负/NaN ⟹ 0。物理读取路径（pot3Blobs/setUniforms）直接读全字段（与 GLSL uniform 数组同构）；未归一丘（NaN 轴）GPU/CPU 一致给出权重 0（不崩溃、NaN 不扩散）
- **融合与守恒语义不变**：多丘仍求和叠加（正负相消）；软化为实函数 ⟹ 厄米性不破；`eMaxExtra` 仍取 Σ|v0|（软化丘 |V|max=v0 与位置无关，椭球/软化下稳定界不变）
- **读数**：面板读数追加最后丘形状段「· R=8 轴1.5/1.0/0.5 · 软化2.0」（三轴相等显「球」；空列表仍显「无」——R49 契约兼容）
- **零回归（soft=0 且三轴=r ⟹ R49 逐位等价）**：Node 单测 6 配置（球心/球内/球外/硬边界取外/偏心/负强度）× 4800 点 `===` 逐位 worst=0 + 边界恰界点集（|d|=R）bad=0；CDP 同配置 GPU↔CPU ⟨V⟩ 对账 rel 2.73e-08（R49 多丘口径 5.6e-7 内）
- **物理效应实测（cdp60，同波比形法）**：`state.paused=true` 冻结波后，清空 ⟹ 落丘 ⟹ `probSum3d()` 读 ⟨V⟩（stamp 不改波，可在同一波态下比较丘形）——同初态下球丘 ⟨V⟩=0.0574 vs 扁椭球（rx=ry=8, rz=1.6）0.1380；软化单调 soft=0/2/4/8 ⟹ ⟨V⟩ 0.049986→0.491108 单调不降（v0>0）；混合丘（球+扁+软化+负强度阱）GPU↔CPU 同帧对账 rel 1.26e-08；CN 路径同源 1.10e-07；丘链 30 帧 P 漂移 0.0017%

### 概率流 J / 连续性方程 / Bohm 轨迹（R61）

概率流 **J = Im(ψ\*∇ψ)**（ℏ=m=1，texel 单位；dxp=2∂ψ）把「密度在动」变成可视的矢量场，并用连续性方程 ∇·J = −∂ρ/∂t 做数值自校验；Bohm 导航波轨迹按 v = J/ρ 制导积分，给出「粒子沿概率流运动」的直观图景。

- **J 场 pass（2D `TPL_JFIELD` / 3D `TPL_JFIELD3`）**：4 阶中心差分 stencil 与能量项同算子；2D 输出 RG32F 的 24×24 格点场（箭头 overlay 采样源），3D 同构（体积路径不挂箭头层，见下）。**平面波闭式对账**：J_x = (1/3m)·sin k·(4−cos k)（4 阶 stencil 精确；小 k → k/m ✓）——**分轴闭式**（斜向波按 kx=k·cosθ 逐轴对账，4 阶截距 O(k⁵) 破坏各向同性，|J| 无标量闭式）

### 光学晶格与 Bloch 能带（R62）

预设「光学晶格」给出周期势 V=V₀sin²(πx/a)（默认 V₀=0.1、a=32 世界 px ⟹ 网格内 8 个周期），是原子在光场驻波中的标准模型。

- **Bloch 定理**：周期势中本征态满足 ψ(x+a)=e^{ika}ψ(x)。准动量 k 只在简约布里渊区 [0,π/a] 内独立，能量分裂成**能带**，带间是**能隙（gap）**。面板「Bloch 相位 θ=k·a」滑块 0→π 覆盖整个简约 BZ；GPU 侧由 twisted 边界携带（跨整个网格的总相位是 h·θ，h=网格内周期数；θ=0 时逐位退化为原 Dirichlet 路径）。
- **Bloch 弛漾**（CPU 虚时间流）：PR-ADI（Peaceman-Rachford）分裂，两步都是精确三对角/循环三对角求解，**无位置相关指数乘子**。收敛到当前 (k, 带) 的精确本征态：
  - 带 2 以带 1 收敛态作 **Gram-Schmidt 投影**；
  - **每步把态投影回目标晶体动量块**（P₀=(1/h)Σ_m e^{iθ_BC·m/h}T_{a_t}^m）与**横向 Dirichlet 基模**。这两个投影是正确性必需而非加速技巧：初态的动量泄漏、以及「y 激发（3.5e-3）比 x 带间跃迁（0.26）便宜两个量级」这两条逃逸通道，都会让带 2 塌到相邻 k 的带 1（详见 worklog 五轮记录）。
- **Bloch 能带扫描**：逐 k 点先跑带 1（作参考）再跑带 2，读收敛 ⟨E⟩，叠图 1D Mathieu 解析谱（傅里叶三对角 Sturm 二分，与 scipy.special.mathieu_a/b 对账）。
- **解析对照的口径（重要）**：
  - 2D 系统可分离 ⟹ E = E_x(带,k) + ey₀（横向基模能量），y 基模投影使该式严格成立，故叠图画的是「解析带 + ey₀」；
  - 离散系统的世界单位有效质量为 **m·(grid/256)²**（与谐振子能级口径同一约定）⟹ **只有 grid=256² 时离散谱与 Mathieu 解析才是同一物理系统**（其余网格是不同系统，偏差 80%~500%），扫描强制 256²；
  - 残余偏差来自势纹理的 8 位量化（round(v·127)/127，步长 1/127≈0.0079）与有限差分：实测 BZ 边界 gap **0.037832 vs 解析 0.037743（0.24%）**，带 1 绝对偏差 ~8.9e-4。
- 面板：晶格深度 V₀ / 周期 a / Bloch 相位 θ / 目标能带下拉 + 「Bloch 弛漾」按钮与状态行；URL `?latV0=&latA=&twistX=&latBand=`。
### 均匀磁场：Landau 能级与晶格回旋（R63）

面板「均匀磁场 B（Landau 能级）」的 `B_z` 滑块给系统加**均匀轨道耦合**（最小耦合 p→p−qA，Landau 规范 A=(−B·y,0,0)，q=1，`state.bOrb` ∈ [−0.06, 0.06]，URL `?bOrb=`）。

**离散化**：A_x 只依赖 y ⟹ 沿 x 向 link 的线积分**精确**，x 向 ±link 相位 e^{±iB·y}，y 向无相位（A_y=0）。正反 link 相位精确反号 ⟹ 离散 H **严格厄米**；|U|=1 ⟹ 谱半径不变。谱间距/B 由 CPU 对角化验证 **0.9861**（r_B≈3.16 格点下的格点修正 −1.4%），即 Landau 能级 E_n=(n+½)ℏω_c、ω_c=B/m。

**积分器：规范帧 ADI（为什么不能直接用 Peierls-stencil KDK）**

GPU 的 KDK 是 `v_half = v − ½dt·Re(Hψ)`、`u_new = u + dt·Im(Hψ)` 的 Re/Im 拆分——对**实** H（B=0）精确酉，对**复** H（B≠0）**不酉**：放大矩阵谱半径 ρ>1 且 ρ−1 随网格线性增长（n=16/B=0.02 时 3.4e-3/子步，n=128 外推 ~2.4e-2，数十步即爆）。因此 B≠0 改走**规范帧分裂**：

- **x 扫描**：逐 texel 规范旋转 φ=e^{+iBxy}ψ，把 x 向 link 变成**实** stencil ⟹ 与 B=0 **逐字同构**的精确酉 KDK；
- **y 扫描**：Landau 规范下 y 向本无相位，原帧内裸实 1D stencil；
- 两个方向**交替**（偶子步 x→y、奇子步 y→x）⟹ `[A,B]` 项相消的二阶格式（等价 Strang）；V 对半 splitting（每扫描含 V/2，两次合计为全 V，含驱动势——驱动是 V 的一部分，规范不变）；
- 每子步 6 pass（两方向 × kick/drift/kick）；B 模式强制 uTwistX=0 且 AB 关闭。

**稳定性（实测口径，勿按单方向界推）**：交替 splitting 的稳定域由**完整 2D H 的谱**支配，不是单方向 1D 界——CPU 镜像扫 dts：0.1/0.2/0.3 保范 2e-6/5e-5/2e-4（有界），**0.4 在 t≈90 崩、0.6 立即漂移**。故 eMax 取与 plain KDK 逐字相同的全 2D 界（uK·8+1）⟹ dt=1.2 时 4 子步、dts=0.3。

**物理：晶格回旋的非谐修正（本轮核心结论）**

紧束缚带 E(k)=−(1/m)(cosθ+cosφ)（θ=k_x+B·y、φ=k_y）的半经典方程 θ̇=(B/m)sinφ、φ̇=−(B/m)sinθ。(0,0) 是稳定平衡 ⟹ **小振幅下 T₀=2πm/B 精确成立**；振幅变大后轨道类单摆拉长：

```
T(θ₀) = (4m/B)∫₀^{π/2} dα / √((1−s²sin²α)(1−s²cos²α)),  s = sin(θ₀/2)
```

θ₀ 是轨道在 θ 空间的振幅（= B·轨道半径）。θ₀ ≥ π 时闭式前提失效（θ₀→π⁻ 时 T 对数发散），`landauModel` 返回 `valid=false`、T 置 NaN，HUD 显示「θ₀>π 半经典近似失效」而**不给假数**。

所以「连续统公式 T=2πm/B」只是小轨道极限——扫 B 时实测周期贴的是 T(θ₀) 曲线而不是 1/B 直线，这正是紧束缚带非抛物性的直接可视化（能级间距=ω_c 不受影响）。

**回旋读数**（`landauStat`）：ω_c=B/m、T₀=2πm/B（并换算帧数）、T_晶格（闭式）、θ₀ 与轨道 y 向包络、贴墙预警（轨道出界后半经典对应失效，实测周期不再遵循任何一条曲线）。

**回旋周期扫描**（`LandauScanner`）：固定轨道半径 r=30 texel、逐点扫 B ∈ {0.02…0.06}，每点发高斯包（σ=5 ≪ 磁长度 1/B）测**质心轨迹**（Ehrenfest：线性演化下质心严格走经典轨道），用复信号 z=(cx−x̄)+i(cy−ȳ) 的**相位展开 + 最小二乘斜率**得周期。叠图两条参考曲线（灰虚线 T₀=2πm/B、青虚线 T 晶格）+ 实测点。实测 5 点 vs 半经典闭式 **中位偏差 0.6%**、vs T₀ **21.8%**（后者说明非谐修正确实被看见，不是拟合到齐）。

**门控与互斥**：仅薛定谔内核（NLS/GP 非线性项进双扫描会双重计数、Dirac/Pauli 走 CN、3D 无 B 分支）；**与 AB 磁通/扭曲边界互斥**（规范帧不兼容，滑块/URL/扫描 gate 三层拒绝并提示，不静默改写用户状态）；与 Pauli 自旋塞曼滑块正交（那是纯自旋项，无轨道耦合）。B=0 走原 KDK，逐位等价 R62 及以前。

**已修的四个相关缺陷（本轮回归实测发现）**：`rot4` 的 sin/cos 在 float32 下非正交 ⟹ 每帧 ~3e-3 的范数损失（用 `inversesqrt` 正交归一化；float64 CPU 镜像掩盖了它，同源解释 R54 记录的长时程残差）；ADI 稳定域被低估（见上）；`landauModel` 把分数坐标 fy 当 texel 用；`dirac.js` 的 AB helper 仍用 R26 单管标量 ⟹ **Dirac 内核此前整个无法启动**（R54 升级漏改，已改数组循环）。


### 量子弹球：能级统计与 scar（R64）

两个新预设 `billiard`（stadium 跑道腔 + 偏心小凸起）与 `billiardC`（圆形腔）。腔外画 V=1.0 的高势当硬壁（E~1e-3 时 κ≈1.41 texel⁻¹、墙厚 ≥8 texel ⟹ 外泄 e^{−11}），腔内 V=0。

**为什么形状决定谱**：弹球 = Dirichlet 边界内的自由粒子，经典动力学决定量子谱。

| 腔 | 经典 | 最近邻间距比 ⟨r⟩（CPU 120 态） | 含义 |
|---|---|---|---|
| 圆形 | 可积（能量+角动量） | 0.044–0.070 | 大量精确简并（Bessel 零点二重），远低于 Poisson |
| stadium（无凸起） | 混沌，但保留 x/y 反射对称 | 0.388 | **恰等于 Poisson 0.386**——对称性把谱劈成多条独立序列，低能区"伪可积" |
| stadium（带偏心凸起） | 混沌、无残余对称 | **0.493–0.505** | 贴 GOE 0.5307：能级排斥 |

⟨r⟩ = ⟨min(sᵢ,sᵢ₋₁)/max(sᵢ,sᵢ₋₁)⟩（Oganesyan-Huse）不需要展开能级密度，是有限样本下最稳的可积/混沌判据。Poisson 0.386 / GOE 0.5307 / GUE 0.5996。

凸起的作用就是把第二行变成第三行——这不是数值修正，而是"对称性 = 守恒量 = 多条独立谱"的物理后果，面板 hint 里明确说明。

**谱求解（腔压缩 + shift-invert Lanczos）**：H 与 GPU **同一离散口径**（5 点 Laplacian + Dirichlet），但**只在腔内格点上定义**（把腔外自由度压缩掉）——这一步是必需的：用 V=1 全网格的 H 直接做 Lanczos，墙能级会把谱宽拉到 0..9，而 E₁≈9e-4，条件数 1e4，实测 m=128 时第 16 个 Ritz 值仍差 20 倍。

压缩后仍不够（E₁₆/E₁ 跨度 20），所以再套 **shift-invert**：解 B=(H+ε)⁻¹ 的最大本征值（ε=1e-4，每步一次 CG，tol 1e-11）。λ→1/(λ+ε) 把低端拉开，m=40 即收敛到 1e-10。**256² 约 5 s、128² 约 0.7 s**，面板显示耗时与残差。

- 与 numpy 全网格 eigsh 对照：前 8 个本征值系统高 **1.5–2.2%**（压缩丢弃墙内穿透 ⟹ 壁更硬 ⟹ 能量略高），⟨r⟩ 不受影响（尺度不变量）；
- **显示选中态**：把该本征向量上传到场上（实部），画面上直接看驻波图样；本征态在演化下只累积全局相位，密度静止 ⟹ 可以长时间观察；
- 门控：仅薛定谔内核 + 两个弹球预设；求谱按预设腔体几何，忽略手绘势场改动。

**诚实限制**：只求前 10 态（8 个间距），⟨r⟩ 的统计误差 ~0.1，结论只能定性看分离方向；**scar** 要在第 20–40 态才明显，本工程的前 10 态处于低激发区、主要显示腔形状的驻波；圆形腔的简并子空间里本征向量是任意正交组合（能量准、图样不保证是实的角动量本征态）。

### 双势阱：Josephson 振荡（R65）

GP 内核新增预设 `dw`：两个抛物阱（阱心距 14px、阱宽 48px、中央垒高 ≈0.021）中的 BEC，初态是双高斯叠加——左/右幅度 √((1±z₀)/2)、右阱带相对相位 φ₀，直接给定初始粒子数差 z₀ 与相位差。

**两模模型**（z=(N_L−N_R)/N）：

```
ż  = −2K·√(1−z²)·sinφ
φ̇  = ΔE + Λ·z + 2K·z/√(1−z²)·cosφ,   Λ = N·U/(2K)
```

线性极限下 z(t)=z₀cos(ΔE·t)，ΔE 是双阱对称/反对称本征态的能量分裂。面板「求 ΔE」用 **R64 的谱求解器**独立算出（求解器已下沉到引擎层 `kernel.js` 的 `linearSpectrum`，弹球与 GP 共用同一离散口径）。

**实测**（Chromium + Xvfb + SwiftShader）：

| 项 | 结果 |
|---|---|
| ΔE（256²，sep=14） | **9.279e-3**（evals 0.024029/0.033307/0.053520/0.055271），1.4–1.8 s |
| g=0 的 z(t)（600 帧） | +0.412 → −0.396 ⟹ 完整过零、一次振荡 |
| 初态实测 z₀ | 设定 0.6 时只有 **0.41**（双包重叠 2.3σ，尾部漏到对侧） |

**自囚禁：本几何下没有达到（如实记录）**。192² 上扫 g：

| g | z_min | 过零 |
|---|---|---|
| −40 | −0.354 | 3 |
| −100 | −0.315 | 3 |
| −150 | −0.260 | 4 |

\|z_min\| 随 \|g\| 单调下降 27%（振荡被压制、趋势正确），但始终跨过零点 ⟹ **没有相变**。原因：sep=14、σ=6 时两包重叠 40%，左/右模式不正交，U 的有效值被重叠积分压低；且强排斥（g=−150 时 g|ψ|²≈1.3 vs E≈0.02）把化学势推得远高于两模近似成立的范围。同时网格分辨率把可实现 z₀ 锁在 ~0.45（sep 要更大就要更深的垒，周期又长到测不动）。

面板与文档都写「未跨过自囚禁相变」，不把「振幅被压制」包装成相变。要真正演示自囚禁，需要更深的垒 + 更长的测量窗，或直接把双模模型画出来（而非 2D GP）。

## 物理与数值方法

### 演化核：速度 Verlet（KDK）

薛定谔方程化为一阶系统 u'=Hv, v'=−Hu 后做 KDK 三重奏，每子步三遍：

```
v_half = v − dt/2·H·u ;  u_new = u + dt·H·v_half ;  v_new = v_half − dt/2·H·u_new
```

辛积分对线性系统**严格保范**：数值上 P=1.0000、守恒误差 0.000%（边界长测 162s /
4 次墙反弹，每次采样零漂移；NLS 的 g=0 线性极限同样 P=1.0000 精确）。
对非线性系统为辛但非严格酉，P 有 O(dt²) 漂移（g=2.5 孤子实测 0.08%）。

### 积分器模式：Crank-Nicolson（一阶内核）

`kernel.integrator='cn'` 时引擎分流到 CN 路径（`app.js` evolveCN/_cnSteps，
`kernel.js` TPL_CN_RHS/TPL_CN_SWEEP 双 pass 模板）：
(I−hG)w_{n+1}=(I+hG)w_n，h=dt_sub/2（每子步推进 2h=dt_sub），每子步 cnRhs 一遍
（w_n→rhs 固定纹理）+ 12 次 block-Jacobi 扫掠。局部块 (I−h·Gloc)⁻¹ 的闭式解
由内核经 `cnLocalSolve` snippet 注入（Dirac：βm+V 对角 2×2 块；Pauli：σ·B
Cayley 全 4×4 块，R33），Gkin 只剩导数项（Dirac 的 α·p 一阶差分收缩 ~0.18/
迭代、截断 ~1e-9/步；Pauli 的拉普拉斯理论上界 h·uK·8=0.4，但平滑波包高频
内容指数衰减，numpy float64 复刻实测截断 6.4e-13/16200 子步——Jacobi 不动点
即精确 CN 系统，收敛后严格正交）。

**动机**：KDK 要求 M 通道对齐（本征基可按 kick/drift 两通道投影分解为逐模态
2×2 旋转）；Dirac 的 M=α·p+βm+V **混合通道**（α·p 把 ψ₂ 的导数耦合进 ψ₁ 方程）
结构性失效——映射谱半径实测 1.0216@dt_sub=0.2，范数指数爆炸，非符号/边界细节。
Pauli 的常数 σ·B 是同族但更轻的缺陷（R32 量化）：σ_x/σ_z 在 (u|v) 分裂下为
**偶**算符 ⟹ ρ=1 精确稳定；σ_y 为**奇**算符（u|v 互换）⟹ kick 自耦合 ⟹
ρ=√(1+φ²)（φ=dt_sub·uK·|B_y|）——B_y=0.05 滑块上限 900 帧漂移 +9.85%（numpy
全算符复刻 +9.850% 与 CDP 实测 +9.941% 互证），属慢指数漂移而非爆炸。
**R33 已修复**：Pauli 内核切 CN（局部 σ·B 走 Cayley 全 4×4 块），CDP 复测
（9×manualPass(1800)=1620 sim-time）：

| 案例 | KDK（R32，1080 sim-time） | CN（R33，1620 sim-time） |
|---|---|---|
| larmor Bz=0.02 | −0.000% | +0.1492% |
| tilted B=(0.0115)³ | +0.127% | +0.1228% |
| tilted+B_y=0.05（关键） | +9.941% | **−0.0099%** |
| SG bGrad=0.016 | −0.0000%（B_y=0 偶算符，解析 ρ=1 实测印证） | +0.0272% |

σ_y 系统泄漏消除（同跨度下 KDK 线性外推 ~+15% ⟹ >1500× 改善）；残差
0.01–0.15% 为 RGBA32F 纹理 float32 舍入积累（算法层机器精度，numpy 双轨
复刻：12 扫掠 +6.4e-13 / 精确 CN +6.8e-13），无系统偏向、60fps 交互时标下
<0.01% 不可见；Dirac CN 回归 +0.0099%（同 R31 基线量级）。物理签名复测
9/9（larmor ⟨σ_x⟩=cos(ωt) 四分频 4 位吻合、tilted 锥形 ⟨σ_z⟩=−0.3333 精确、
|⟨σ⟩|=1）。
CN 的 Cayley 矩阵严格正交（G=−J·M，J=复结构，M 厄米 ⟹ G 斜对称）⟹ 无条件稳定、
总概率守恒（算法层机器精度；GPU float32 管线另有 ~0.1%/1620 sim-time 舍入底噪，
已如实量化）。dissipation 帧级衰减在分支之后通用（标量乘法与积分器无关）；
KDK 路径对既有内核逐字不变（evolve 分流重构经回归矩阵验证行为等价）。

#### 3D CN（R36）：运行时切换而非内核级开关

2D 的 CN 是**内核级开关**（`kernel.integrator='cn'`）——Dirac/Pauli 因 KDK 结构性失效
被迫切 CN。3D 标量薛定谔无此缺陷（标量 M 通道天然对齐），故改为**运行时切换**：
`state.integrator3='kdk'|'cn'`（面板「积分器」select + URL `?int3=cn`），默认 kdk，
**不选即零回归**（3D 预设参数不含该项，选择跨预设保留）。CN3D 通路为
`app.js` evolveCN3d（每子步 cnRhs3d 一遍 + 12 次 Jacobi 扫掠，
`kernel.js` TPL_CN_RHS3D/TPL_CN_SWEEP3D），7 点 stencil 谱半径 12（Gkin 收缩界
h·uK·12，光滑势下截断机器精度级；不连续势（球垒边缘）激发高频，12 扫掠残留 ~1e-9，
扫掠数实测依赖 12→24→60 扫：2.80e-9→2.65e-12→3.71e-14）。局部块标量闭式解
`(1+i·hV)⁻¹` 复平面 Cayley 旋转经 `cnLocalSolve3` snippet 注入；边界 clamp 到自身的
邻居计入对角项（界外方向贡献 +c ⟹ 对角 6uK+V 各减一个 uK）。
**代价**：每子步绘制数 3→13（~4.3×），实测 32³ 825→3866ms、64³ 2820→12801ms
（理论 13/3=4.33×）——CN 定位为精密对账档；守恒对照见验证表。

### 稳定性：dt·E ≤ 2

每模式旋转角 θ = arccos(1−(dt_sub·E)²/2)，稳定充要条件 dt_sub·E ≤ 2。
H 特征值上界 E_max = k·8 + 1 + 内核附加项 + |驱动幅值 A|
（5 点拉普拉斯 2D 最大特征值 8，势幅 ±1；非线性内核另计 |g|·峰值密度——NLS 按初始峰值，GP 按呼吸收缩的
实测动力学极值 2/σ² 取；含时外场把势幅上界抬到 1+|A|）。每帧 dt=1.2，子步数取
`max(substeps, ceil(dt·E_max/1.5))` 自适应兜底（对稳定极限留 1.33× 裕度）
——m=0.15 时 E_max≈27.7，自动加密至 23 子步。
直接把 dt 提过头的教训已固化为代码注释：E_max=5 的模式半对角 1−0.36·25/2 = −3.5，
特征值溢出单位圆，棋盘格噪声指数发散，数帧内炸穿浮点缓冲（P=NaN）。

### 边界：Dirichlet 零墙（2D）／Neumann 零梯度（3D）

**2D**：`S(uv)` 在域外返回 0 = 无限高势墙，酉反射、P 严格守恒（「无限深方阱」预设即此边界）。

**3D**（`kernel.dim3`）：纹理 `CLAMP_TO_EDGE` ⟹ 越界取边界值 = 零梯度（Neumann），
波包触壁为软反射而非硬墙。有界势（谐振子/氢原子）场景下更物理——这也是 3D 预设全部
采用解析势的原因。**两者不可混用口径**，文档与代码注释均已分别标注。

### NLS 符号约定

代码方程写作 `iψ_t = −k∇²ψ + Vψ − g|ψ|²ψ`，**g>0 = 聚焦**（自聚焦/亮孤子），
与教科书 `iψ_t + ∇²ψ/2 + g_std|ψ|²ψ = 0` 的 g_std = g 一致。
（历史教训：本式若写成 `+g|ψ|²ψ`，+g 实为散焦——符号曾靠 g 扫描实验纠正：
g=+8 峰值 ×25 压缩确认聚焦方向。）

### Gross-Pitaevskii 数值约定（默认参数的依据）

引擎把总概率归一化到 Σ|ψ|²=1。TF 自洽条件 `|g| = πμR²/2`（μ 化学势、R 云半径）
给出平衡半径与耦合强度的一一对应：`R_TF⁴ = 2·TRAP_R²·|g|/π`，`μ_eq/ħω = √(|g|/π)`。
g=−10 → TF 平衡半径 ≈ 11px、平衡峰值 ≈ 5.3e-3（μ/ħω ≈ 1.8，弱 TF 区）。

- **为什么默认 \|g\|=10 而不是自洽的 ≈45**：R=16 取自洽值时耦合强度约为 NLS 孤子的
  8×，辛积分 O(dt³) 相误差使 100 sim-time 窗 P 漂移达 7%（子步 6）/2.6%（子步 16），
  超出教学可接受度。默认弱耦合 + 子步 16，240 sim-time 窗漂移 ~1%，HUD 如实显示。
- **呼吸幅度 vs 云半径**（CDP 实测，g=−10、子步 16、180–240 sim-time 窗峰值摆动）：
  σ=8 ×24.8 · σ=10 ×9.9 · σ=12 ×4.9 · σ=14 ×2.9 · **σ=16 ×2.7（默认，最小点）** · σ=18 ×3.7。
  机制：抛物穹顶初态与真实基态的轮廓差激发 2ω 集体呼吸模；周期 ≈ 105–115 sim-time
  （半周 ~70/~40 交替的非简谐波形），与线性 2ω 模（阱周期 213 的一半）定性一致。
- **初态几何经 Node 单测逐点验证**（不依赖浏览器）：穹顶解析形状、涡旋核密度=0、
  孔洞剖面 (1−exp(−r²/2ξ²))² 零误差、相位绕数 arg=φ、kx 相位梯度（20/20 PASS）。
- **TF 硬边平滑窗比例化（R47）**：`makeWave` 的边缘平滑窗由固定 6px 改为
  **w=max(2, R/4)**（R=σ=R_TF(g)）。诊断（256² 全网格逐点复刻）：固定 6px 在扫描
  量程 g=−20…−4（R_TF=13.1…8.75px，窗占半径 46–69%）把 √3·Rrms 拉偏 16.9–27.6%，
  R/4 压到 ~6.8% 且全 g 一致、质量保持 0.54–0.75→~0.91、峰值比 1.000；CDP 演化层
  复测 P 漂移 3.10%→2.88%（未恶化）、峰值对账 3.5%→6.4%；R42 记录的 R_TF 半径偏差
  29.9% 归因已修正（主因是演化推宽而非平滑窗，见「非线性内核参数扫描」节），
  比例窗后初态诚实、偏差如实暴露为 46.0%

### 物理诚实声明：2D L² 临界塌缩的网格截断

2D 立方 NLS 是 L² 临界系统：强聚焦下波包无休止压缩，理论上形成奇性。
256² 网格的离散拉普拉斯在 σ_eff ≲ 2 cell 时失效，**奇性被网格截断**——
实测特征：能量瞬间倾泻到格子尺度（E 跳升 5–7×），P 从 ~0.98 崩至 0.68–0.82，
峰值崩解为宽底噪声。归因实验（同预设 substeps=6→16）证实：
**子步加密只推迟截断时刻、不改变机制**——这是分辨率极限，不是积分器缺陷。
因此：HUD 守恒误差列如实显示（>1% 变琥珀色告警），「自聚焦」预设文案已声明
「网格精度最终会截断奇性」，守恒回归断言只覆盖截断前的前塌缩相（t<80 sim-time，
P>0.98）。不对该过程做任何「守恒美化」。

### 渲染管线（每帧 4 pass）

```
Evolve (RG32F ping-pong ×sub×3) → Display (+trail max 混合 → dispA/dispB)
  → Composite (扫描线/颗粒/亮度曝光 → 屏幕) → Reduce (32² MRT 三附件 → HUD)
```

- **Reduce MRT 三附件**（各 RGBA32F，120ms 节流）：o0=(Σp, uK·ΣT, Σp², ΣVp)、o1=(Σx·p, Σy·p, Σx²·p, Σy²·p) 世界坐标概率矩、o2=(uK·ΣT_x, uK·ΣT_y, Σ⟨p_x⟩, Σ⟨p_y⟩) 分轴动能 + 梯度版均值动量——后两者供不确定原理 HUD 的逐轴紧致界
- **tone map** `lum = 1−exp(−p·1000)`：小 p 段近线性保结构，大 p 段平滑封顶不刺眼
- **亮度曝光点在 composite 末端**：若在 display pass，亮度会经 trail 缓冲反馈双重缩放
- **resize 不丢拖尾**：旧 dispA 经纯拷贝 shader blit 进新 dispA，LINEAR 滤波兼做分辨率缩放

**3D 体积路径**（`kernel.dim3`，与 2D 完全分离——`frame()` 早返回走 `frame3d()`，
两者不共享显示 program 与归约管线）：

```
Evolve3D (n³ RG32F ping-pong ×sub×3 × n 层逐层 draw；积分器分流见「积分器模式」节)
  → Volume ray-march (轨道相机 → dispA/dispB)
  → Composite (同 2D) → reduce3d (GPU 全卷归约 → HUD)
```

- **逐层 draw**：WebGL2 无完整 3D FBO，每 pass = n 次 `framebufferTextureLayer` + draw（R34 spike 实测 64³ 8.8ms/pass、128³ 105.6ms/pass，SwiftShader）
- **HUD 测量**走 GPU 3D 归约（R35，线性索引分块，120ms 节流）；`probSum3d` 全卷 CPU 回读保留为独立对账路径（两条路径唯一共享的是内核 `moments3d` 公式定义，实测 rel ≤ 2e-7，属实现互证）
- **曝光逐预设标定**：体积密度峰值跨 36×（归一化到 n³ 个体素），且发射-吸收存在「外壳遮挡核心」的权衡（过高曝光下弥散态的外晕先变不透明、把亮核挡成暗壳）⟹ 曝光不是一个常数：free3d 3600 / sphere 4800 / oscillator 2400 / 1s 1200 / 2p_z 8000（CDP 实测标定，目标峰值亮度 0.7–0.9），滑块量程 100–10000
- **相位着色与 2D 同源**：两处共用同一 `hsv2rgb(vec3(arg(ψ)/2π+0.5, 0.80, 1.0))` 映射（引擎级共享注入位 `{{HSV}}`）——相位差 π 的两瓣呈互补色（2p_z 实测青/红 + 中间节面）

### PhysicsKernel 契约

引擎（`core/app.js`）负责一切与物理无关的事务：DOM、GL 资源、KDK 积分循环、
渲染管线、交互、HUD、URL 参数、调试句柄。内核只提供：

| 成员 | 类型 | 职责 |
|---|---|---|
| `id` / `name` / `equation` | string | 注册表键（URL `?kernel=` 用）/ 顶栏标题 / 方程 HTML |
| `pairs` | 1 \| 2 | 复分量对数：1 → RG32F，2 → RGBA32F（自旋/Dirac 用） |
| `shaders()` | {uniforms, localH, density, kinetic, potential, pixelColor?} | GLSL 注入点，填入模板的 `{{TOKEN}}` |
| `makeWave(grid, p)` | → {data, sum} | CPU 端初始场形状（引擎负责归一化与等份叠加） |
| `presets()` | {key: {name, text, build(paint), wave, params?}} | 场景势场与初始条件 |
| `defaults()` | {...} | 内核默认 state 覆盖（如 NLS 的 g、GP 的 g/substeps） |
| `extraControls()` | {html, rows:[{id,out,key,fmt}]} | 附加控件 HTML 及滑块绑定行（如 NLS/GP 的 g 滑块） |
| `setUniforms(gl, prog, state)` | fn | 逐帧赋内核私有 uniform（三个 program 均调用） |
| `applyParams(qp, state)` | fn | URL 查询参数扩展 |
| `eMaxExtra(state)` | number | E_max 上界的附加项（非线性内核按 |g|·动力学峰值密度计） |

**vec4 泛型管线**：所有 shader 按 vec4 书写；RG32F 采样得 (r,g,0,1)，
多余 zw 通道在写回 RG32F 附件时自然丢弃，数值与逐字等价。
内核私有 uniform（如 NLS 的 `uniform float uG;`）经 `{{UNIFORMS}}` token
注入三个 shader 模板的 uniform 区。

### 新增一个内核（5 步）

```js
// 1. src/physics/mykernel.js —— 继承契约
import { PhysicsKernel, registerKernel } from './kernel.js';
class MyKernel extends PhysicsKernel {
  constructor(){
    super();
    this.id = 'mykernel';  this.name = '我的内核';  this.pairs = 1;
    this.equation = '<b>MY EQUATION</b> · ...';
  }
  shaders(){ return {
    localH: 'V*c',                                    // 域内 H·c 片段
    density: 'dot(psi.xy,psi.xy)',                    // |ψ|²
    kinetic: '0.25*(dot(dxp,dxp)+dot(dyp,dyp))',      // 动能密度
    potential: 'V*p',                                 // 势能密度
  }; }
  makeWave(grid, p){ /* → {data, sum} */ }
  presets(){ /* → {key: {name, text, build(paint), wave:[fx,fy,kx,ky], params?}} */ }
  defaults(){ return { /* state 覆盖 */ }; }
  eMaxExtra(){ return 0; }
}
// 2. 注册
registerKernel(new MyKernel());
```

```js
// 3. src/main.js 引入（side-effect import 即注册）
import './physics/mykernel.js';
// 4. 访问 ?kernel=mykernel
// 5. 重新生成单文件版
//    npm run build:standalone
```
